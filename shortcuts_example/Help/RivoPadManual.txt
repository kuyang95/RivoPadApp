@chapter 시작하기
@section 지원 기기와 로컬 처리
@text 이 앱은 Apple silicon iPad에서 VisionCraft의 주요 기능을 로컬 우선으로 제공합니다.
@text AI 채팅과 이미지 설명은 M4의 MLX 모델을 사용하며, OCR과 문서 처리는 가능한 범위에서 iPad 안에서 실행합니다.
@text 모델을 처음 준비하거나 VisionLink 서버에 연결할 때에는 네트워크가 필요할 수 있습니다.
@section 권한
@text 카메라·문서 스캔·실시간 글자 읽기에는 카메라 권한이 필요합니다.
@text 음성 질문에는 마이크와 음성 인식 권한이 필요합니다.
@text Rivo 연결에는 Bluetooth 권한이 필요합니다.
@text 거부한 권한은 홈의 설정에서 VisionCraft 권한 설정 열기를 눌러 바꿀 수 있습니다.

@chapter AI와 음성
@section AI 채팅
@text 홈에서 AI 채팅을 누르면 이전 대화를 열거나 새 로컬 대화를 시작할 수 있습니다.
@text 이미지, PDF와 텍스트 문서를 Files 또는 공유 메뉴로 가져와 질문할 수 있습니다.
@text 생성 중인 답변은 화면에 이어서 표시되며 대화 기록은 앱 내부에 저장됩니다.
@text 대화 목록에서 제목이나 메시지 내용을 검색하고, 항목을 밀거나 길게 눌러 제목을 수정하거나 개별 삭제할 수 있습니다.
@text 전체 삭제는 확인 뒤 실행하며 삭제한 대화는 복구할 수 없습니다.
@text 긴 대화를 다시 열면 M4 메모리 등급에 맞춰 최근 기록만 AI 문맥으로 복원하지만, 화면과 저장소의 이전 메시지는 모두 유지합니다.
@text 답변 아래의 음성 제어로 전체 답변을 문장별로 이어 읽거나 이전 문장, 현재 문장 다시 읽기, 다음 문장과 정지를 사용할 수 있습니다.
@text 로컬 AI 화면에서 Rivo 4, 5, 6은 이전 문장, 현재 문장 다시 읽기, 다음 문장이고 R3는 답변 전체 읽기와 정지입니다.
@text 새 답변 생성을 시작하거나 음성 입력·다른 화면으로 이동하면 이전 답변 읽기를 자동으로 멈춥니다.
@text 대화 입력 위의 첨부에서 PDF·TXT·XLSX·XLS·HWP 문서, 클립보드 텍스트 또는 사진을 현재 대화에 추가할 수 있습니다.
@text TXT와 클립보드 문맥은 누적되고, 사진·PDF·XLSX·XLS·HWP 원본은 새 원본 파일을 첨부하면 교체됩니다. 첨부 상태와 원본 참조는 대화 기록과 함께 복원됩니다.
@text PDF는 14MB·100페이지까지 PDFKit 또는 Vision OCR로 텍스트를 로컬 추출하고, 사진은 32MB까지 최대 2,048픽셀로 줄여 M4 비전 모델에서 처리합니다.
@text XLSX는 20MB까지 여러 시트의 문자열·숫자·불리언과 저장된 수식 결과를 로컬 추출합니다. 암호화·손상·과도하게 큰 압축 문서는 열지 않습니다.
@text Excel 97-2003 XLS는 20MB까지 OLE/BIFF8 공유 문자열·숫자·불리언·저장된 수식 결과를 로컬 추출합니다. 암호화된 파일과 더 오래된 BIFF 형식은 열지 않습니다.
@text HWP는 20MB까지 HWP 5.x 본문 구역을 로컬에서 압축 해제해 문단 텍스트를 추출합니다. 암호·배포용·DRM·공인인증서 암호화 문서는 열지 않으며 스크립트와 첨부 개체를 실행하지 않습니다.
@text TXT·PDF·XLSX·XLS·HWP의 추출 문맥은 최대 1MB까지 보존합니다. 더 긴 내용은 생략을 표시하지만 앱 내부에 복사한 원본 파일은 유지합니다.
@text 긴 첨부는 약 820자 구간으로 나누고 매 질문과 관련된 부분을 M4 문맥 한도 안에서 다시 선택합니다. 요약 질문은 문서 처음·중간·끝을 고르게 사용합니다.
@text 첨부가 바뀌면 텍스트·비전 모델을 안전하게 전환하며 저장 원본은 유지합니다.
@text 요약, 정보 목록과 다음 행동 빠른 질문을 누르면 현재 대화와 첨부를 기준으로 바로 질문합니다.
@text 본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
@section 로컬 번역
@text AI 대화 화면의 번역에서 한국어, 영어 또는 일본어를 선택하고 M4 로컬 AI로 번역할 수 있습니다.
@text 원문은 직접 입력하거나 붙여넣고 결과는 복사하거나 iPad 음성으로 읽을 수 있습니다.
@section 웹페이지 질문
@text AI 대화 화면의 웹페이지에서 주소를 입력하거나 붙여넣으면 제목과 본문을 추출해 질문할 수 있습니다.
@text 웹페이지 다운로드에만 네트워크를 사용하며 추출한 본문의 AI 처리는 M4 로컬 모델에서 실행합니다.
@text 긴 본문은 24,000자까지 사용하고 동적 사이트는 짧은 정적 본문일 때만 비공개 WebKit으로 한 번 더 읽습니다.
@text 답변 화면에서 출처 제목과 최종 URL을 확인하고 Safari 원문을 열 수 있습니다.
@section 선택적 웹 검색
@text 최신 뉴스·가격·일정처럼 현재 정보가 필요한 질문은 AI 대화 화면의 웹 검색에서 출처를 찾을 수 있습니다.
@text 설정에서 개인 Brave Search API 키를 Keychain에 저장하고 개인정보 고지에 동의한 뒤 온라인 웹 검색을 켭니다.
@text 검색어와 API 키만 Brave LLM Context로 보내 출처별 관련 발췌를 받고, 최종 답변은 M4 로컬 모델이 만듭니다.
@text Brave는 과금·장애 대응·남용 방지를 위해 검색어 로그를 최대 90일 보관할 수 있으며 요금과 조건은 바뀔 수 있습니다.
@text 검색 출처와 답변은 대화 기록에 저장하거나 캐시하지 않으며, 답변의 출처 번호를 위 출처 목록과 대조해 원문을 열 수 있습니다.
@section 음성 명령
@text Rivo 빠른 메뉴 또는 지원되는 진입점에서 음성 명령을 시작할 수 있습니다.
@text 스캐너 열어, 카메라 열어, 독서 열어, 파일 열어 같은 앱 내부 명령은 로컬 규칙으로 처리합니다.
@text 일반 질문은 로컬 AI로 전달하고 번역 요청은 전용 로컬 번역 화면으로 전달합니다.
@text 웹 검색 요청은 기능이 켜져 있을 때 출처 검색, M4 로컬 답변과 TTS까지 자동으로 이어집니다.
@section 소리와 음성
@text 설정에서 효과음, 자동 음성 안내와 기본 말하기 속도를 바꿀 수 있습니다.
@text 자동 음성 안내를 꺼도 사용자가 직접 시작한 문서·OCR·독서 읽기는 유지됩니다.

@chapter 카메라와 문서 스캔
@section 돋보기
@text 홈의 카메라에서 돋보기를 열 수 있습니다.
@text 전·후면 카메라, 핀치 줌, 탭 초점, 토치, 흑백·반전·고대비 색상 필터를 지원합니다.
@text Rivo L2 화면 조작 모드의 16색 조합, 반전과 임계값은 기기에 저장되며 다음에 화면 조작 모드에 들어갈 때 복원됩니다. 미리보기 밝기는 시스템 밝기를 바꾸지 않으며 저장하지 않습니다.
@text 카메라 화면에서 촬영한 이미지를 OCR 결과로 이어갈 수 있습니다.
@text 사진 저장에서는 현재 필터와 확대가 적용된 화면을 사진 보관함 또는 Files로 저장하며, 사진 보관함에는 추가 전용 권한만 요청합니다.
@section 실시간 글자 읽기
@text 카메라 앞의 글자를 주기적으로 인식하고 새로운 문장을 자동으로 읽습니다.
@text 짧은 첫 인식은 두 번 확인하고, 너무 작은 글자는 가까이 비출 때까지 기다립니다.
@text 최근에 읽은 비슷한 문장과 같은 문서의 부분 인식은 최대 30초 동안 반복하지 않으며, 글자 없는 장면이 세 번 이어지면 새 장면으로 판단합니다.
@text 장시간 사용할 때에는 발열과 배터리 사용량을 확인해 주세요.
@section 이미지 설명
@text 홈의 카메라에서 이미지 설명을 열고 사진을 촬영하면 M4 로컬 비전 모델이 장면, 사물, 글자와 사람의 행동을 한국어로 설명합니다.
@text 촬영 이미지는 임시 파일이나 사진 보관함에 자동 저장하지 않고 메모리에서 분석 화면으로 직접 전달합니다.
@text 설명이 끝나면 답변을 자동으로 읽으며, 입력창에서 같은 사진에 후속 질문을 할 수 있습니다.
@section 자체 문서 스캐너
@text Apple 시스템 스캐너가 아니라 VisionCraft 자체 AVFoundation 카메라를 사용합니다.
@text 문서 모서리, 방향, 흔들림과 선명도를 확인하고 조건이 맞으면 자동 촬영합니다.
@text 촬영 뒤 원근 보정, 휘어진 페이지 보정, 크기 정규화와 선택적 색상 강화를 적용합니다.
@text 설정에서 문서 자동 촬영을 끄면 모서리와 안정 안내는 유지하고 화면 촬영 버튼이나 Rivo 7로만 촬영합니다.
@text 휘어진 페이지 자동 보정을 끄면 UVDoc 모델 준비와 추론을 생략하며 LCNet 모서리와 원근 보정은 그대로 적용합니다.
@text 설정의 문서 색상 자동 보정을 꺼도 모서리·원근·곡면 보정은 유지됩니다.
@text 설정의 OCR 오타 자동 교정을 켜면 한 장 사진과 텍스트 레이어가 없는 PDF 페이지의 Vision OCR 원문을 실제 이미지와 대조해 M4 Qwen3-VL이 로컬로 교정합니다.
@text 숫자·URL·줄바꿈이 바뀌거나 결과가 과도하게 늘거나 줄면 원문을 유지합니다. AI가 다른 작업 중이거나 모델 교정에 실패해도 Vision OCR 원문을 바로 사용할 수 있습니다.
@text 실시간 카메라 OCR은 지연과 발열을 피하기 위해 프레임마다 Qwen3-VL 교정을 실행하지 않습니다.
@text 최대 20장을 연속 촬영하고 재촬영·회전·삭제·순서 변경 뒤 여러 페이지 PDF로 저장할 수 있습니다.
@text 완료하지 못한 촬영 세션은 다음 실행에서 복원할 수 있습니다.

@chapter 문서와 독서
@section PDF와 텍스트
@text 홈의 파일에서 사진·EPUB·PDF·TXT·XLSX·XLS·HWP 하나를 고르거나 검색할 폴더를 승인할 수 있습니다.
@text 승인한 폴더 권한은 보안 범위 북마크로 저장되며 PDF·TXT·XLSX·XLS·HWP를 이름과 상대 폴더 경로로 검색하고 최근 수정 순으로 표시합니다.
@text iPadOS 정책상 승인하지 않은 기기 전체 저장소는 검색할 수 없으며 폴더 권한을 지워도 원본 파일은 삭제되지 않습니다.
@text PDF와 텍스트는 큰 글자 문서 화면에서 읽기, 편집, 복사와 AI 질문을 사용할 수 있습니다.
@text XLSX·Excel 97-2003 XLS·HWP 5.x는 안전한 로컬 추출문을 문서 보기·TTS·복사·편집·AI 질문에 사용합니다.
@text 문서 보기 설정의 가로 화면 한 줄 읽기를 켜면 세로 화면은 일반 줄바꿈을 유지하고 가로 화면은 현재 논리 줄 하나를 줄바꿈 없이 좌우로 이동해 읽습니다.
@text 문장 음성 도구는 현재 보이는 줄부터 문장별로 연속 재생하고 발화 중인 문장을 강조합니다. 이전 문장, 현재 문장 다시 읽기, 정지와 다음 문장을 사용할 수 있습니다.
@text 줄·페이지·처음·끝으로 이동하고 TXT 또는 여러 페이지 PDF로 내보낼 수 있습니다.
@text 설정에서 글자 크기, 줄 간격, 16가지 색상 조합과 줄 구분선 기본값을 바꿀 수 있습니다.
@text AI 대화에서는 XLSX·Excel 97-2003 XLS·HWP 5.x를 첨부해 여러 시트의 셀 또는 HWP 문단 내용을 질문할 수 있습니다.
@section EPUB와 DAISY
@text EPUB, DAISY 2.02와 DAISY 3 책을 가져와 읽을 수 있습니다.
@text 가져온 모든 책을 최근 읽은 순으로 서재에 보관하고 책별 장·문단 위치를 저장하며 계층 목차, EPUB·DAISY의 인쇄 페이지 목록과 본문 검색을 제공합니다.
@text 같은 내용의 책은 파일 이름이 달라도 기존 보관본을 열며, 서재에서 삭제해도 Files의 원본은 지우지 않습니다.
@text 독서 화면 아래의 재생 위치 슬라이더는 오디오와 로컬 음성을 합친 전체 시간을 표시하며, 원하는 위치로 옮길 수 있습니다.
@text SMIL 오디오가 있으면 해당 구간을 재생하고 오디오가 없거나 실패하면 iPad 로컬 TTS로 이어 읽습니다.
@text 설정에서 테마, 글자 배율, 줄 간격과 재생 속도 기본값을 바꿀 수 있습니다.

@chapter Rivo 리모컨
@section 연결
@text 홈 위쪽의 Rivo 연결 상태를 누르면 검색, 저장된 기기 자동 연결과 진단 화면을 볼 수 있습니다.
@text Rivo Three와 Mini 계열은 서비스 UUID를 우선 사용하고 알려진 기기 이름을 보조로 사용해 식별합니다.
@text iPadOS가 앱을 백그라운드에서 정리한 경우에도 허용된 CoreBluetooth 범위에서 진행 중인 검색·연결을 복원하며, 사용자가 앱 전환 화면에서 강제 종료하면 복원되지 않습니다.
@text 연결이 끊기면 지수 백오프로 다시 시도하며 저장된 선호 기기를 유지합니다.
@section VisionCraft 내부 조작
@text Rivo 버튼으로 앱 내부 빠른 메뉴, AI 음성 입력, 돋보기, 실시간 읽기, 스캐너, 문서와 EPUB·DAISY 화면을 조작할 수 있습니다.
@text 기능 화면 밖에서 R1을 누르면 명령 모드가 됩니다. 2는 클립보드를 M4 로컬 AI로 즉시 번역하고 결과를 읽으며, 3은 실시간 카메라 글자 읽기, 4는 카메라 돋보기, 9는 촬영 이미지 설명을 엽니다.
@text R1을 두 번 누르면 명령 키 전체 안내를 읽습니다. 카메라를 연 뒤 R1과 5·6·7·별표·0·샵을 사용하면 카메라 전환, 토치, 촬영과 확대를 조작합니다.
@text 화면마다 사용할 수 있는 버튼이 다르며 지원되지 않는 모드에서는 iPad 제한 안내가 표시됩니다.
@text 연결 직후와 활성 세션 중에는 Android 호환 형식으로 리모컨 시간을 동기화합니다.

@chapter VisionLink
@section 연결과 수신
@text VisionLink 화면에서 페어링 코드를 사용해 다른 기기와 연결하고 자격 증명은 Keychain에 저장합니다.
@text WebRTC 영상과 데이터 채널로 이미지, 일반 파일, 클립보드 텍스트와 카메라 상태를 받을 수 있습니다.
@text 큰 파일은 디스크로 스트리밍하고 크기와 SHA-256을 확인하며 전송을 취소할 수 있습니다.
@section 원격 기능
@text 원격 이미지 OCR, 이미지 설명, 번역과 텍스트 번역을 M4의 로컬 처리기로 실행할 수 있습니다.
@text 원격 AI 채팅은 대화 ID와 이미지·TXT·PDF·XLSX·Excel 97-2003 XLS·HWP 5.x 첨부 문맥을 지원합니다.
@text 원격 HWP·XLS·XLSX는 로컬 파서의 20MB·암호화·손상·압축 해제 제한을 적용하고 추출한 텍스트만 대화에 누적합니다.
@text 원격 영상 실시간 읽기는 최근 결과와 비슷한 OCR 문장을 반복하지 않습니다.

@chapter 다른 앱과 iPadOS 통합
@section 공유와 선택 텍스트
@text 다른 앱의 공유 메뉴에서 사진, PDF, 텍스트 또는 URL을 VisionCraft로 보낼 수 있습니다.
@text 공유한 URL은 웹페이지 질문 화면에서 자동으로 읽고, 일반 공유 텍스트는 설정한 로컬 AI 화면의 문맥으로 엽니다.
@text 설정의 공유 텍스트 열기에서 음성 질문을 고르면 공유 내용을 문맥으로 준비한 뒤 바로 듣기를 시작하고, AI 채팅을 고르면 문맥을 첨부한 새 대화에서 질문을 기다립니다.
@text 선택한 텍스트의 동작 메뉴에서는 VisionCraft에 질문하거나 나중에 열 수 있습니다.
@text 공유 항목은 App Group의 로컬 수신함에 저장된 뒤 앱이 한 번만 소비합니다.
@section 위젯, Siri와 단축어
@text 소형 위젯은 최근 Rivo 연결 스냅샷을 표시하고 중형 위젯은 AI·스캔·카메라·독서 바로가기를 제공합니다.
@text VisionCraft 빠른 실행 소형 위젯은 편집할 때 새 AI 대화, AI 대화 기록, 문서 스캔, 실시간 글자 읽기, 카메라 돋보기, 음성 명령, 문서 열기, 독서 또는 카메라 도구 중 하나를 선택할 수 있습니다.
@text 같은 빠른 실행 위젯을 여러 개 추가하면 자주 쓰는 기능마다 홈 화면 버튼을 따로 둘 수 있습니다.
@text 오늘 M4 로컬 AI 활동 소형 위젯과 홈 카드는 현지 날짜별 완료·실패·취소 횟수, 생성 글자 수와 처리 시간을 이 iPad에만 기록합니다. 로컬 모델이라 일일 제한은 없으며 위젯을 누르면 새 AI 대화를 엽니다.
@text Siri와 단축어에는 설정, AI, 독서, 카메라, 스캔, 돋보기, 실시간 읽기, 파일, Rivo와 VisionLink 바로가기가 표시됩니다.
@text iPad와 Siri 언어가 영어 또는 일본어이면 App Intent 이름·매개변수와 Siri 호출 문구도 해당 언어로 표시됩니다.
@text 카메라, Files와 권한처럼 사용자 확인이 필요한 단계는 자동으로 건너뛰지 않습니다.

@chapter 설정과 접근성
@section 통합 설정
@text 홈의 설정에서 효과음, 자동 음성 안내, TTS 속도, 스캔 자동 촬영·UVDoc 곡면·색상 보정, OCR 오타 자동 교정, 앱 언어·글꼴과 문서·독서 기본값을 관리합니다.
@text 선택적 웹 검색의 개인 API 키, 네트워크 동의와 사용 여부도 설정에서 관리합니다.
@text 설정 초기화는 보기와 음성 기본값만 되돌리며 대화·문서·책은 삭제하지 않습니다.
@text 앱 언어는 시스템 설정, 한국어, 영어와 일본어 중에서 고를 수 있고 즉시 화면과 로컬 번역·웹 검색 기본 언어에 적용됩니다. 시스템 권한 문구와 확장 기능 언어는 iPad 설정의 VisionCraft 앱 언어를 따릅니다.
@text 앱 글꼴에서는 시스템 글꼴, 기본 나눔스퀘어라운드와 현재 앱 언어용 추가 글꼴을 고를 수 있습니다. 추가 글꼴은 선택할 때만 VisionCraft 서버에서 내려받습니다.
@text 내려받은 글꼴은 파일 크기와 SHA-256을 확인한 뒤 앱 안에 보관하므로 다음 실행부터 오프라인에서도 사용할 수 있습니다. 각 항목의 라이선스 보기를 눌러 사용 조건을 확인할 수 있습니다.
@section 진단과 개인정보
@text 설정의 진단 및 개인정보에서 앱·iPadOS 버전, M4 메모리·저장 공간·온도 상태와 iPadOS가 제공한 MetricKit 자료 개수를 확인할 수 있습니다.
@text VisionCraft는 Crashlytics, Analytics와 성능 자료를 서버로 자동 전송하지 않습니다. 지원에 필요한 경우에만 진단 보고서 내보내기를 눌러 JSON 파일을 직접 저장합니다.
@text 보고서에는 대화·사진·OCR·문서 내용, API 키와 사용자가 정한 기기 이름을 앱이 직접 추가하지 않습니다. 공유 전에는 파일 내용을 확인하세요.
@section VoiceOver와 큰 글자
@text 모든 주요 버튼에는 기능 이름과 힌트를 제공하며 iPad의 VoiceOver와 큰 글자를 함께 사용할 수 있습니다.
@text 시스템 VoiceOver, 확대, 색상 필터와 접근성 단축키는 iPad 설정에서 직접 구성합니다.

@chapter Android와 다른 점
@section 일반 iPad 앱에서 할 수 없는 동작
@text 다른 앱의 버튼을 임의로 누르거나 스와이프하고 접근성 포커스를 이동할 수 없습니다.
@text 다른 앱 위에 Remote Ribbon을 계속 표시하거나 홈·뒤로·최근 앱·알림창을 대신 조작할 수 없습니다.
@text 시스템 VoiceOver, 밝기, 회전 잠금과 화면 색상 필터를 VisionCraft가 직접 바꿀 수 없습니다.
@text Android의 TalkBack 설정·회전 잠금·전역 확대·메뉴·다른 앱 음소거 위젯은 iPadOS에서 같은 시스템 동작으로 제공할 수 없습니다.
@text iPad의 AI는 M4 로컬 모델을 사용하므로 Android Gemini 일일 사용량 위젯과 같은 서버 쿼터는 없습니다. 대신 홈과 위젯에서 오늘의 로컬 처리 활동과 일일 제한 없음을 확인합니다.
@text 앱을 완전히 종료한 뒤 영구 수신하거나 부팅과 동시에 상주할 수 없습니다.
@section iPad 대체 경로
@text 다른 앱의 내용은 공유 확장, 선택 텍스트 동작, Files 선택기와 사용자가 제공한 스크린샷으로 가져옵니다.
@text Android R1 명령의 무음 화면 캡처는 사용할 수 없으므로 3은 실시간 카메라 OCR, 9는 카메라 촬영 뒤 M4 로컬 이미지 설명으로 동작합니다.
@text 빠른 실행은 위젯, Siri, 단축어와 앱 내부 Rivo 빠른 메뉴를 사용합니다.
@text 시스템 접근성 조작이 필요하면 iPad의 접근성 단축키 또는 Rivo의 HID·Switch Control 펌웨어 대안을 사용합니다.
@text 앱 업데이트는 Android APK 설치가 아니라 App Store, TestFlight 또는 MDM으로 받습니다.

@chapter 문제 해결
@section 기능이 열리지 않을 때
@text 홈의 설정에서 VisionCraft 권한 설정 열기를 눌러 카메라·사진 추가·마이크·음성 인식·Bluetooth 권한을 확인합니다.
@text Siri 또는 딥링크를 처음 실행하면 iPadOS가 VisionCraft에서 열지 확인할 수 있습니다.
@text 모델 준비 중에는 앱을 앞에 두고 충분한 저장 공간과 네트워크 상태를 확인합니다.
@section 연결이 되지 않을 때
@text Rivo는 전원과 페어링 상태를 확인한 뒤 Rivo 화면의 즉시 재시도를 누르고 연결 진단을 확인합니다.
@text VisionLink는 페어링 코드, 같은 서버 환경, Wi-Fi 전환과 상대 기기의 송신 상태를 확인합니다.
@text 문제가 반복되면 재현 시각과 화면에 표시된 진단 내용을 함께 기록해 주세요.
