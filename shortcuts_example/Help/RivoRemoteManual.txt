@chapter 리보탭

@section 외형
@text 탭을 가로로 놓았을 때, 위쪽 측면에는 왼쪽부터 순서대로 전원, 볼륨 업, 볼륨 다운 버튼이 있습니다.
@text 탭의 좌우 측면에는 상단과 하단에 각각 스피커가 하나씩 있어, 총 4개의 스피커가 있습니다.
@text 오른쪽 측면 가운데에는 USB-C 충전 포트가 있습니다.

@section 전원 및 확대/톡백 설정
@text 전원 버튼을 길게 누르면 탭의 전원이 켜집니다.
@text 전원 버튼과 볼륨 다운 버튼을 동시에 길게 누르면, 탭 화면에 전원을 끄거나 다시 시작할 수 있는 옵션이 표시됩니다.
@text 탭이 켜지거나 꺼질 때, 화면에 로고가 표시되며 음성 안내가 재생됩니다.
@text 전원 버튼과 볼륨 업 버튼을 동시에 누르면, 화면 확대 기능이 켜지거나 꺼집니다.
@text 볼륨 업 버튼과 볼륨 다운 버튼을 길게 누르면, 확대 기능과는 별개로 톡백 기능이 켜지거나 꺼집니다.


@chapter 비전크래프트 앱

@section 앱 실행과 메뉴 열기
@text 화면 오른쪽 하단의 접근성 버튼을 누르면 앱을 실행하거나 종료할 수 있습니다.
@text 앱이 실행되면 화면 왼쪽 하단에 노란색 엣지 패널이 표시됩니다.
@text 엣지 패널이 위치한 화면 가장자리에서 오른쪽으로 한 손가락 쓸기를 하면 비전크래프트 메뉴가 열립니다.
@text 비전크래프트 앱 내 설정을 통해, 앱 아이콘을 눌러 메뉴를 열 수 있도록 설정할 수 있습니다.
@text 메뉴는 오른쪽의 ‘닫기’ 버튼으로 닫을 수 있으며, 음성 재생은 ‘그만 듣기’ 버튼으로 중지할 수 있습니다.

@section 메뉴
@text 메뉴는 '홈', '도구', '화면 확대', '카메라', '화면' 메뉴로 구성되어 있습니다.
@text '홈' 메뉴를 누르면 비전크래프트 앱의 메인 화면이 열립니다.
@text '도구' 메뉴에는 음성 명령, 캡처, 이미지 설명, OCR, 번역, 텍스트 등의 기능이 포함되어 있습니다.
@text '뒤로' 메뉴를 누르면 바로 전 단계의 메뉴로 이동합니다.
@text '화면 확대' 메뉴를 누르면  화면 확대 기능을 켜거나 끌 수 있습니다. 기능이 켜지면 화면은 기본 2배로 확대되며, 이후 두 손가락 제스처로 추가 확대, 축소, 이동이 가능합니다.
@text '카메라' 메뉴에는 도구, 배율, 화면 확대, 색상, 화면, 전면/후면 전환, 라이트 켜기/끄기 기능이 포함되어 있습니다.
@text '화면' 메뉴에는 반전, 화면 밝기, 반시계 방향 회전, 시계 방향 회전, 회전 잠금 등의 기능이 포함되어 있습니다.

@section 터치 제스처
@text 화면 확대 상태에서 한 손가락 제스처로 탭 화면을 조작할 수 있습니다.
@text 화면 확대 상태에서 두 손가락 제스처로 화면을 확대하거나 축소하고, 이동할 수 있습니다.
@text 카메라가 켜져 있을 때, 한 손가락 좌우 제스처로 색상 조합을 변경할 수 있으며, 더블 터치를 하면 기본 색상으로 복원됩니다.
@text 카메라가 켜져 있을 때, 한 손가락 상하 제스처로 전면 카메라와 후면 카메라를 전환할 수 있습니다.
@text 카메라가 켜져 있을 때, 두 손가락 제스처로 화면의 확대 비율을 조절할 수 있습니다.


@chapter 리보탭 리모컨

@section 외형
@text 리모컨의 크기는 가로 98mm, 세로 52mm, 두께 9.5mm이고 무게는 52g입니다.
@text 위 측면에 있는 4개의 버튼은 왼쪽부터 오른쪽으로 전원, 시계, 키보드, 단축 버튼입니다.
@text 앞면 왼쪽에는 세로로 작은 3개의 버튼이 있고 가운데에는 가로 4 줄, 세로 5줄로 배열된 20개의 버튼이 있습니다.
@text 앞면 맨 왼쪽에 있는 3개의 작은 버튼은 위에서부터 아래로 S1, S2, S3이고 그 오른쪽에 있는 버튼은 L1, L2, L3, L4입니다.
@text 앞면 맨 오른쪽에 있는 버튼은 위에서부터 아래로 R1, R2, R3, R4입니다.
@text 가운데 있는 12개의 버튼은 1부터 9, *, 0, #입니다.
@text 아래쪽 측면 가운데에는 USB-C 충전 포트가 있습니다.

@section 전원, 충전, 음성 피드백, 배터리 확인
@text 전원 버튼을 진동이 울릴 때까지  길게 누르면 리모컨이 켜지거나 꺼집니다. 켜질 때는 1번의 긴 진동이 있고, 꺼질 때는 2번의 긴 진동이 있습니다.
@text USB-C 케이블로 충전하며, 완충까지 약 1시간 30분이 걸립니다.
@text 충전을 위해 USB 케이블을 연결하면 1번의 진동과 함께 빨간색 LED가 켜집니다. 완전히 충전되면 1번의 진동과 함께 LED가 녹색으로 변경됩니다. 충전 케이블이 연결된 상태에서 완충되었을 때는 긴 진동 1번과 짧은 진동 1번으로 피드백이 제공됩니다.
@text S2를 길게 누르면 음성 피드백을 켜거나 끌 수 있습니다.
@text S1을 길게 누르면 배터리 잔량을 확인할 수 있습니다. 음성 피드백이 꺼져 있을 경우, 배터리 잔량은 진동 횟수(1~5회)로 표시됩니다.
@text S1과 S2는 탭의 볼륨을 각각 높이거나 낮춥니다. S3을 누른 상태에서 S1 또는 S2를 누르면 리모컨의 볼륨을 조절할 수 있습니다.

@section 블루투스 페어링 및 연결
@text 리보탭에 포함된 전용 리모컨은 기본적으로 이미 페어링되어 있습니다.
@text 리모컨을 다시 페어링하려면, 먼저 리모컨을 페어링 모드로 설정한 후, 탭의 블루투스 설정 화면에서 ‘RivoTab remote’ 기기를 선택해 페어링해 주세요.
@text 리모컨을 페어링 모드로 설정하려면 키보드 버튼과 단축 버튼을 동시에 길게 눌러주세요. 3번의 진동과 함께 파란색 LED가 깜박입니다. 페어링 모드를 취소하려면 전원 버튼을 짧게 누르세요.
@text 리모컨은 전원을 켜면 자동으로 페어링된 탭에 연결됩니다. 연결이 끊어진 경우에는 키보드 버튼을 짧게 누르면 1번의 진동과 함께 다시 연결됩니다.

@section 키보드 모드, 단축키 모드
@text 리모컨은 전원이 켜지면 기본적으로 키보드 모드로 작동하며, 키보드 버튼을 누르면 1번의 진동과 함께 다시 키보드 모드로 설정됩니다.
@text 단축 버튼을 짧게 누르면 비전크래프트 앱에 등록된 앱을 빠르게 실행할 수 있는 단축키 모드로 설정됩니다. (단축키 설정 기능은 추후 앱 업데이트를 통해 제공될 예정)

@section 버튼 잠금 및 상태 확인
@text 키보드 버튼을 2번의 진동이 울릴 때까지 길게 누르면, 버튼이 잠기고 탭과의 연결이 해제됩니다.
@text 키보드 버튼을 1번의 진동이 울릴 때까지 길게 누르면, 버튼 잠금이 해제되고 키보드 모드로 연결됩니다.
@text 단축 버튼을 진동이 울릴 때까지 길게 누르면 음성 명령을 사용할 수 있습니다.
@text 전원버튼을 짧게 누르면 리모컨 상태에 따라 진동이 울립니다. 1번 진동은 연결된 상태를, 2번 진동은 연결이 해제된 상태를 의미합니다.

@section 시간, 날짜 확인
@text 시계 버튼을 짧게 누르면 음성으로 오전/오후, 시간, 분을 알려줍니다.
@text 시계 버튼을 빠르게 2번 누르면 음성으로 날짜를 확인할 수 있습니다.
@text 시간 또는 날짜 알림 정지하기는 전원 버튼을 짧게 누르면 됩니다.
@text 시계 버튼을 길게 누르면 진동으로 시간을 알려줍니다. 10단위는 긴 진동, 1단위는 짧은 진동입니다. 예를 들어 12시 34분은 긴 진동 1번, 짧은 진동 2번, 긴 진동 3번, 짧은 진동 4번 입니다.
@text 버튼 잠금 상태에서도 시간 확인이 가능합니다.

@section 알람
@text 알람모드로 설정하기는 전원 버튼과 시계 버튼을 동시에 누르면 됩니다.
@text 알람 설정하기는 시, 분의 4자리를 입력하고 R3을 누르면 됩니다. 예를들어, 오전 12시 정각이면 0000을 누르고, 오후 3시 20분이면 1520을 누르면 됩니다.
@text 타이머 설정하기는 1분에서 999분까지 설정할 수 있으며 R3을 누르면 저장됩니다.
@text 남은 시간 확인하기는 L1을 누르면 됩니다.
@text R1을 짧게 누르면 마지막 입력된 숫자 하나가 삭제되고, R1을 길게 누르면 입력된 숫자가 모두 삭제됩니다.
@text 알람 취소하기는 R1을 길게 누르면 됩니다.
@text 알람과 타이머 음성안내 정지하기는 전원 버튼을 짧게 누르면 됩니다.


@chapter 앱 모드

@section 기본 사항
@text S3을 누르면 리모컨은 비전크래프트 앱을 제어할 수 있는 앱 모드로 설정됩니다.
@text 앱 모드는 유틸리티, 메뉴, 확대, 스크린, 텍스트, 디스플레이의 여섯 가지 모드를 제공합니다.

@section 유틸리티 모드
@text R1을 누르면 유틸리티 모드로 설정됩니다.
@text 4를 누르면 카메라가 켜지거나 꺼집니다.
@text 5를 누르면 카메라가 켜진 상태에서 전면 카메라와 후면 카메라가 전환됩니다.
@text 6을 누르면 후면 카메라가 선택된 상태에서 라이트를 켜거나 끌 수 있습니다.
@text 7을 누르면 일반 화면에서는 화면 캡처가, 카메라 사용 중에는 사진 촬영이 실행되어 저장됩니다.
@text 3을 누르면 카메라나 화면에 보이는 글자를 인식하는 OCR 기능이 실행되어 텍스트를 음성으로 읽어줍니다. 인식된 텍스트는 자동으로 클립보드에 복사됩니다.
@text 2를 누르면 클립보드에 있는 영문 텍스트를 한글로 번역합니다. 번역된 텍스트는 자동으로 클립보드에 복사됩니다.
@text 9를 누르면 카메라나 화면에 보이는 이미지에 대한 설명을 음성으로 들을 수 있습니다. 설명된 텍스트는 자동으로 클립보드에 복사됩니다.
@text R3은 현재 재생 중인 읽기를 정지하거나, 읽기를 다시 실행합니다.
@text *와 #은 카메라가 켜진 상태에서 확대 비율을 각각 축소하거나 확대합니다.
@text 0은 카메라가 켜진 상태에서 확대 비율을 1배로 초기화합니다.

@section 메뉴 모드
@text L1을 누르면 메뉴 모드로 설정되며, 메뉴가 열리거나 닫힙니다.
@text 4와 6은 각각 이전 메뉴와 다음 메뉴를 선택합니다.
@text 1과 7은 각각 처음 메뉴와 마지막 메뉴를 선택합니다.
@text 2와 8은 배율, 화면 밝기, 대비 색상, 글자 두께처럼 값이 바뀌는 메뉴에서 값을 높이거나 낮춥니다.
@text 5는 선택된 메뉴를 실행합니다. 선택된 항목이 값 변경 메뉴이면 기본값이나 가운데 동작을 실행하고, 다른 하위 메뉴인 경우 해당 메뉴로 진입합니다.
@text *는 메뉴에 진입한 상태에서 이전 메뉴로 되돌아갑니다.
@text R3은 현재 재생 중인 읽기를 정지하거나, 읽기를 다시 실행합니다.

@section 확대 모드
@text R4를 누르면 메뉴 모드로 설정되며, 화면 확대 기능을 켜거나 끌 수 있습니다. 이 기능은 카메라가 켜져 있을 때에도 동작하며, 카메라의 확대 비율과는 별도로 화면을 확대합니다.
@text *와 #은 화면 확대 비율을 각각 축소하거나 확대합니다.
@text 0은 화면 확대 비율을 2배로 재설정합니다.
@text 5를 제외한 1부터 9는 버튼을 누르고 있는 동안 해당 방향으로 화면을 스크롤합니다.
@text 5는 스크롤 속도를 빠르게 또는 느리게 설정합니다.
@text R2는 화면을 오른쪽으로 자동 스크롤합니다.
@text R3은 화면을 왼쪽 끝의 약간 아래 위치로 이동한 후, 오른쪽으로 자동 스크롤합니다.

@section 스크린 모드
@text L4를 누르면 화면 단위로 빠르게 이동할 수 있는 스크린 모드로 설정됩니다.
@text 5를 제외한 1부터 9는 각 방향으로 한 화면씩 이동합니다.
@text 5는 화면 전체보기를 토글합니다.
@text *와 #은 화면을 각각 반시계 방향과 시계 방향으로 회전시킵니다.
@text 0은 화면 자동 회전 설정을 켜거나 끕니다.

@section 텍스트 모드
@text L3를 누르면 텍스트 모드로 설정되며, 텍스트 화면이 열리거나 닫힙니다.
@text 4와 6은 글자 크기를 각각 작게 또는 크게 조절합니다.
@text 5는 글자 크기를 기본 크기로 재설정합니다.
@text *와 #은 줄간격을 각각 좁게 또는 넓게 조절하며, 0은 줄간격을 기본값으로 재설정합니다.
@text 2와 8은 각각 한 줄씩 위 또는 아래로 텍스트 화면을 스크롤합니다.
@text 3과 9는 각각 한 페이지씩 위 또는 아래로 텍스트 화면을 스크롤합니다.
@text 1과 7은 문서의 처음 또는 마지막 위치로 텍스트 화면을 스크롤합니다.
@text R3은 텍스트 읽기를 시작하거나 중지합니다.

@section 디스플레이 모드
@text L2를 누르면 색상 변경이 가능한 디스플레이 모드로 설정됩니다. 색상 변경은 주로 카메라 화면과 텍스트 화면에서 사용합니다.
@text 4와 6은 색상 조합을 변경하며, 5는 원래 색상으로 되돌립니다. R2는 반전 색상을 설정합니다.
@text 7과 9는 카메라가 켜져 있는 경우 감도 기준값을 각각 낮추거나 높입니다. 8은 감도 값을 초기화합니다.
@text *와 #은 화면 밝기를 각각 어둡게 또는 밝게 조절합니다. 0은 화면 자동 밝기 설정을 켜거나 끕니다.

@text 이전 곡이나 다음 곡으로 이동하기는 4 또는 6을 누르면 됩니다.
@text 되감기나 빨리감기는 4 또는 6을 길게 누르면 됩니다.
@text 오디오 음소거하기는 9를 누르면 됩니다.
@text 볼륨 높이기나 낮추기는 볼륨 업또는 볼륨 다운 버튼을 누르면 됩니다.

@section 텍스트 입력
@text 텍스트를 입력하려면 L3이나 L4를 누르면 됩니다. 만약 리모컨으로 입력하는 문자와 탭에서 실제 입력되는 문자의 언어가 다르다면 L3이나 L4를 다시 반복해 눌러 탭의 입력 언어를 리모컨으로 입력하는 문자의 언어와 동일하게 변경하면 됩니다.
@text 여러 개의 문자가 할당된 버튼의 문자 입력하기는 해당 문자가 입력될때까지 버튼을 반복하여 누르면 됩니다.
@text 하나의 문자 입력 후 동일한 버튼에 할당된 다른 문자 입력하기는 L2나 R2를 누르면 됩니다. 예를 들어, www 입력하기는 1, 1, R2, R2, 1, 1을 누르면 됩니다.
@text 탭을 입력하기나 다음 텍스트 필드로 점프하기는 L1을 누르면 됩니다.
@text 이전 텍스트 필드로 점프하기는 R4 + L1, L1을 누르면 됩니다.
@text 백스페이스를 눌러 이전 글자 삭제하기는 R1을 누르면 됩니다.
@text 엔터를 입력하기는 R3을 누르면 됩니다. 앱에 따라서는 R4 + R3을 눌러야할 수도 있습니다.
@text 스페이스를 입력하기는 #을 누르면 됩니다.
@text 숫자 모드 설정하기는 L4 + R4를 누르면 됩니다. 
@text 숫자 단축 입력은 L4를 누른 상태에서 해당 숫자 버튼을 누르면 됩니다. 어느 모드에서나 모드 변경 없이 숫자를 입력할 수 있습니다.
@text 백스페이스는 L4 + R1, 엔터는 L4 + R3으로 입력할 수 있습니다.
@text *와 #은 L4 + *와 L4 + #으로 입력할 수 있습니다.
@text L3에 설정된 언어의 소문자 모드 설정하기는 L3을 누르면 됩니다.
@text L3에 설정된 언어의 문장 모드 설정하기는 R1 + L3을 누르면 됩니다. 문장 모드에서는 첫 글자만 대문자로 입력됩니다.
@text L3에 설정된 언어의 대문자 모드 설정하기는 R1 + L3, L3을 누르면 됩니다.
@text 텍스트 입력모드에서 기호 모드 설정하기는 *를 누르면 됩니다. 그런 다음 기호 입력은 문자 입력과 같습니다. 참고로 *에 할당된 기호는 L2나 R2로 입력할 수 있습니다.
@text 하나의 기호 입력 후 리모컨은 자동으로 이전 텍스트 입력 모드로 돌아갑니다.
@text 하나의 기호 입력 후 동일한 버튼에 있는 문자를 입력하기 위해서는 L2나 R2를 누르면 됩니다. 예를 들어, @i 입력하기는 *, 6, L2를 누르면 됩니다.

@section 텍스트 편집
@text 텍스트 입력 모드에서 R4 + 해당 버튼을 누르면 편집 명령키를 사용할 수 있습니다.
@text 글자 단위로 이동하기는 R4 + 4 또는 R4 + 6을 누르면 됩니다.
@text 단어 단위로 이동하기는 R4 + L2 또는 R4 + R2를 누르면 됩니다.
@text 화면에서 현재 줄의 처음이나 끝으로 이동하기는 R4 + 1 또는 R4 + 7을 누르면 됩니다.
@text 줄 단위로 이동하기는 R4 + 2 또는 R4 + 8을 누르면 됩니다.
@text 다음 글자 삭제하기는 R4 + R1을 누르면 됩니다. 참고로 이전 글자 삭제하기는 R1을 누르면 됩니다.
@text 텍스트 블록을 선택하기 위해서는 먼저 커서를 시작 위치로 이동해야 합니다. R4를 누른 상태에서 5를 눌러 텍스트 블록의 시작 위치를 지정한 다음 텍스트 블록의 끝 위치까지 커서를 이동한 다음 R4를 떼면 됩니다.
@text 현재 텍스트 필드에서 전체 텍스트 선택하기는 R4 + 9를 누르면 됩니다.
@text 선택된 텍스트 블록을 잘라내기는 R4 + *, 복사하기는 R4 + 0을 누르면 됩니다.
@text 잘라내거나 복사한 텍스트 블록을 붙여 넣기는 R4 + #을 누르면 됩니다.
@text 추가 편집 명령키는 다음과 같이 R4 + L1, 해당 버튼을 누르면 됩니다.
@text 현재 문서 맨 처음이나 끝으로 이동하기는 R4 + L1, 3 또는 R4 + L1, 9를 누르면 됩니다.
@text 글자 단위로 삭제하기는 R4 + L1, 4 또는 R4 + L1, 6을 누르면 됩니다.
@text 단어 단위로 삭제하기는 R4 + L1, L2 또는 R4 + L1, R2를 누르면 됩니다.
@text 현재 커서 위치부터 줄 처음이나 끝까지 모든 글자 삭제하기는 R4 + L1, 1 또는 R4 + L1, 7을 누르면 됩니다.
@text 현재 줄 삭제하기는 R4 + L1, 5를 누르면 됩니다.
@text 취소하기는 R4 + L1, *를 누르면 됩니다.
@text 되돌리기는 R4 + L1, #을 누르면 됩니다.

@section 탐색 모드(톡백 사용 시)
@text 탐색모드에는 톡백을 사용하는 탐색모드와 톡백을 사용하지 않는 탐색모드가 있습니다. 탐색모드를 변경하려면 R4를 빠르게 2번 누르면 됩니다. 이때 진동이 있다면 톡백을 사용하는 탐색모드로 설정된 것이고, 진동이 없다면 톡백을 사용하지 않는 탐색모드로 설정된 것입니다.
@text 탐색모드로 설정하기는 R4를 누르면 됩니다.
@text 왼쪽이나 오른쪽 항목으로 이동하기는 4 또는 6을 누르면 됩니다.
@text 왼쪽이나 오른쪽 항목으로 자동 반복 이동하기는 4 또는 6을 누른 채로 있으면 됩니다.
@text 이전이나 다음 항목으로 5개씩 이동하기는 L1 + 4 또는 L1 + 6을 누르면 됩니다.
@text 위나 아래 항목으로 이동하기는 2 또는 8을 누르면 됩니다.
@text 처음이나 마지막 항목으로 이동하기는 1 또는 7을 누르면 됩니다.
@text 상하 방향으로 스크롤하기는 3 또는 9를 누르면 됩니다.
@text 좌우 방향으로 페이지 스크롤하기는 L2 또는 R2를 누르면 됩니다.
@text 현재 항목 클릭하기는 5를 누르면 됩니다.
@text 안드로이드 홈 버튼 누르기는 0을 누르면 됩니다.
@text 빅스비 실행하기는 0을 길게 누르면 되고, 구글어시스턴트 실행하기는 R1 + 3을 누르면 비프음과 함께 실행됩니다.
@text 음성인식 종료하기는 0을 짧게 누르면 됩니다.
@text 최근 사용 앱 목록 띄우기는 R4 + 0, 앱 목록 닫기는 0을 누르면 됩니다.
@text 최근 사용 앱 목록에서 앱 선택하기는 R4를 누른 상태에서 4 또는 6을 반복해서 누르면 됩니다.
@text 최근 사용 앱 목록에서 앱 닫기는 닫을 앱을 선택한 후 R4를 누른 상태에서 R1을 누르면 됩니다.
@text 이전 메뉴로 돌아가기나 팝업 닫기는 *를 누르면 됩니다.
@text 상태바, 탐색바, 메인 윈도우 간 이동하기는 L1을 반복해서 누르면 됩니다.
@text 알림 센터/빠른 설정 띄우기는 L1 + 3을 누르면 됩니다.
@text 알림 센터/빠른 설정 닫기는 *를 누르면 됩니다.
@text 화면 읽기 정지는 R3이나 L1 + R3을 누르면 됩니다.
@text 화면 끄기와 켜기는 L1 + R4를 누르면 됩니다.
@text 현재 항목을 이중탭하고 누른 채로 있기는 L1 + 5를 누르면 됩니다.
@text 현재 활성화된 미디어의 재생하기와 정지하기는 L1 + R1, R1을 누르면 됩니다.
@text 현재 선택된 항목의 작업 보기 메뉴 띄우기는 L1 + R1, 2를 누르면 됩니다.
@text 현재 화면 검색하기는 L1 + R1, 7을 누르면 됩니다. 누른 다음 리모컨을 문자입력모드로 변경하고 검색 텍스트 입력 후 R3을 누르면 됩니다. 탐색 모드로 되돌아가기위해서는 R4를 눌러야 합니다.
@text 음성 안내 지원 메뉴 띄우기는 #을 누르면 됩니다.
@text 다음 위치에서부터 끝까지 연속해서 읽기는 R1을 누르면 됩니다.
@text 이전 또는 다음 글자 읽기는 R1 + 4 또는 R1 + 6을 누르면 됩니다.
@text 이전 또는 다음 단어 읽기는 R1 + L2 또는 R1 + R2를 누르면 됩니다.
@text 이전이나 다음 읽기 컨트롤을 선택하기는 R1 + * 또는 R1 + #을 누르면 됩니다.
@text 현재 선택된 읽기 컨트롤의 값을 변경하기는 R1 + 2 또는 R1 + 8을 누르면 됩니다.
@text 톡백 음성안내 토글하기는 R1 + R3을 누르면 됩니다.
