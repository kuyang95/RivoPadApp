# Qwen3.5-9B 온디바이스 실행 결과

2026-09-09, USB로 연결된 iPad Pro 11형 M5 256GB에서 앱에 설치해 직접 측정했다. **Qwen3.5-9B MLX 4bit는 이 12GB 기기에서 실행 가능했다.** 짧은 한국어 질문, 대화 맥락 유지, 계산, 긴 문서 질문을 완료했고 이 실행 중 강제 종료는 없었다.

## 기기와 실행 조건

- 기기: iPad Pro 11형 M5, 256GB, iPadOS 26.6.1.
- RAM: 공식 12GB 구성. 앱에서 읽은 실제 물리 메모리 12,082,675,712바이트(약 11.25GiB).
- 모델: `mlx-community/Qwen3.5-9B-MLX-4bit`, 리비전 `938d8919941c6e7efd3c7150eff7fe9d12afa631`.
- 전체 다운로드: 5,977,074,591바이트. Hugging Face의 Git/LFS 체크섬과 대조 후 USB로 앱 저장소에 전송.
- `LLMModelFactory`의 텍스트 경로로 로딩. 모델 패키지에는 이미지 가중치도 있으나 텍스트 로더가 이를 제외한다.
- mlx-swift-lm 3.31.4, mlx-swift 0.31.6, swift-transformers 1.3.4.
- Xcode 26.6, Debug 빌드에 `SWIFT_OPTIMIZATION_LEVEL=-O` 적용. 앱 번들 `net.rivo.visioncraft`에 설치.
- MLX 메모리 상한 7GiB, 캐시 20MiB, 출력 최대 1,024토큰, KV 4bit, prefill 512, `enable_thinking=false`.
- 테스트는 `--local-llm-benchmark`로 실행. 이 모드에서는 모델 다운로드를 금지하고, 기존 로컬 모델과 토크나이저만 사용한다. 응답은 실제 앱의 `LLMService.streamText`를 통과한다. 비행기 모드나 전체 네트워크 차단을 수행한 테스트는 아니다.

## 측정

모델 확인·로딩: **3.89초**. 로딩 직후 MLX 활성 메모리: **5.04GB**.

| 항목 | 입력 글자 수 | 첫 응답 | 완료 | 핵심값 검사 |
|---|---:|---:|---:|---|
| 한국어 안내문 질문 | 93 | 2.43초 | 3.47초 | 통과 |
| 대화 맥락 후속 질문 | 29 | 0.17초 | 0.45초 | 통과 |
| 거스름돈 계산 | 74 | 0.26초 | 2.55초 | 통과 |
| 긴 문서 질문 | 13,244 | 9.88초 | 12.03초 | 통과 |

AI 연산 메모리 최고 사용량은 **6.08GB(5.66GiB)**였다. 이는 MLX가 측정한 값이며 전체 앱의 프로세스 메모리와는 다르다. 첫 질문에는 초기 연산 준비 비용도 포함된다. 짧은 실행 1회의 결과이므로 장시간 발열, 배터리, 백그라운드 전환, 여러 앱 동시 실행의 안정성을 보장하는 수치는 아니다.

## 답변 검토

- 한국어 안내문: 강연 날짜와 무료 참가비를 맞혔다.
- 후속 질문: 이전 안내문의 신청 마감인 10월 10일을 기억했다.
- 계산: 10,000원에서 7,500원을 빼 2,500원이라고 답했다.
- 13,244자 문서: 11월 23일, 7,000원, 11월 18일을 모두 추출했다. 다만 요청하지 않은 **“문서 90의”**라는 부정확한 출처 표현을 덧붙였다. 자동 검사는 핵심값과 비어 있지 않은 응답, 생각 태그 미노출만 검사하므로 이 표현까지 통과로 해석해서는 안 된다.
- Qwen3-8B 또는 Qwen3.5-4B와 동일 질문으로 비교 측정하지 않았다. 이 보고서는 9B 실행 가능성 확인이며 전반적인 한국어 품질 우열의 증거는 아니다.

## 앱 변경

- 12GB 기기가 기존의 정확히 12GiB 이상 조건을 충족하지 못해 작은 메모리 등급으로 분류되는 문제를 수정했다. 12GB용 등급은 MLX 상한 7GiB를 사용하며 현재 프로세스의 가용 메모리와 Metal 권고치도 함께 반영한다.
- 12/16GB 등급은 Qwen3.5-9B, 작은 메모리 등급은 Qwen3.5-4B를 선택한다. 4B의 이 앱 실기기 실행은 이번에 측정하지 않았다.
- 채팅, 문서 질문, 음성 질문 등 기존 로컬 텍스트 호출부의 모델 선택을 통일했다.
- 최신 로딩 API와 로컬 토크나이저 어댑터로 전환했다. 기존 Hub 모델 저장소와 이어받기 구조는 유지한다.
- 앱의 기존 클라우드 이미지 설명 등 별도 기능까지 온디바이스로 바꾼 작업은 아니다.
- Qwen3.5의 현재 상위 라이브러리 구현은 full-attention에 `KVCacheSimple`을 사용하므로 `maxKVSize` 설정만으로 전체 대화 길이가 자동 제한된다고 가정하면 안 된다. 장시간 대화와 매우 긴 입력은 추가 검증 대상이다.

## 검증과 재실행

앱 빌드 및 테스트 빌드 성공. 연결된 M5 iPad에서 `LocalModelPolicyTests`, `LocalModelPreparationTests`, `ChatHistoryStoreTests`, `LocalDiagnosticsTests` 총 **21개 테스트 통과**.

Debug 빌드에서 `--local-llm-benchmark` 인수로 실행하면 같은 합성 질문을 수행하고 앱의 `Documents/LocalLLMBenchmark.json`에 결과를 쓴다. 이 인수가 없으면 일반 앱으로 실행된다. 모델은 미리 앱의 `Library/Application Support/HFModels/models/mlx-community/Qwen3.5-9B-MLX-4bit`에 준비되어 있어야 한다.
