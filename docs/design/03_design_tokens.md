앱 전체가 홈의 soft UI 한 벌을 쓴다. 색·모양·면을 새로 정하지 말고 아래 토큰을 쓴다. 값은 Android `docs/design/03_design_tokens.md`와 같다. 컴포넌트별 규격은 `04_component_specs.md`.

## 앱 테마

- 설정의 화면 및 글꼴 → 앱 테마에서 시스템 설정에 따름·라이트·다크를 고른다. 기본은 시스템 설정에 따름이며, 선택은 저장되고 즉시 적용된다. 시스템 설정에 따름은 기기의 테마 변경을 계속 반영한다.
- `AppSettingsStore.appTheme`과 `AppThemeMode`, 앱 루트의 `preferredColorScheme`가 앱 전체에 적용한다. 기기 자체의 테마는 바꾸지 않는다.
- 카메라 미리보기의 고정 색, 텍스트 뷰어의 사용자 색 조합, 도서 읽기의 본문 테마와 위젯 전용 색은 각 화면 규칙을 유지한다.

### 강조색 쓰임

- **주황**: 뭔가를 실행하는 동작. 촬영, `작업`, 분석, 보낸 말풍선, 마이크. `VisionCraftAndroidButtonStyle(emphasized: true)`.
- **남색 잉크**(글자색을 면으로): 확인·이동 같은 차분한 주 동작. 새 대화 버튼, 다이얼로그 닫기. `VisionCraftAndroidButtonStyle(filled: true)`. 앱 `AccentColor`도 이 색이라 시스템 컨트롤의 tint가 파랑이 아니다.
- **파랑**은 UI 면에 쓰지 않는다. 구분 표시에만 쓴다: 카메라 섹션 밑줄(`SectionTone.camera` `#356AA8`/`#9EC5FF`), 비전링크 연결 원·선(`VisionCraftUI.linkBlue`), 카드 다이얼로그 아이콘 색 중 하나.
- 한 화면에 강한 강조는 하나. 오류·삭제 같은 시스템 상태는 예외(`VisionCraftUI.error`).
- 라이트 주황 `#C0521B`는 흰 글자 4.7:1, 면(`#FAFAFA`) 위 글자로 4.5:1이 되도록 정한 값이다. 더 밝게 바꾸지 않는다.

## 글자

`visionCraftAndroidText(size, weight:, relativeTo:)`가 Android `sp`처럼 Dynamic Type 배율을 따르고, 앱 글꼴 설정(`AppFontCatalogStore.fontName`, 환경값 `visionCraftAppFontName`)을 적용한다. 자간은 0.

| 크기 / 굵기 | 쓰는 곳 |
| --- | --- |
| 24 / Bold | 화면 제목(`VisionCraftScreenTitleRow`), 업데이트 버전 |
| 22 / SemiBold | 섹션 제목(`VisionCraftHomeSectionHeader`), 다이얼로그 제목 |
| 18 / SemiBold | 목록 카드 제목 |
| 18 / Regular | 다이얼로그 줄, 설정 항목 이름, 본문 |
| 16 / Regular | 목록 카드 설명, 안내 글, 업데이트 항목 |
| 16 / SemiBold | 버튼 글자, 값 버튼 |
| 16 / Bold | 뱃지 |
| 14 / Medium | 설정 그룹 이름, 카메라 버튼 상태 줄, 업데이트 날짜 |
| 13 / Bold | 채팅 보낸 사람 이름 |

- 2x2 타일 제목은 타일 안쪽 너비에 비례해 정한다(`VisionCraftHomeTileTitle`).
- 홈·카테고리 머리 제목은 같은 24 Bold와 최소 32pt 글자 칸(`HomeView.homeHeaderTitle`)을 사용한다. 두 값은 같은 `.title2` Dynamic Type 기준으로 확대된다. 제목 줄은 오른쪽 아이콘의 52pt 높이도 확보한다.
- 채팅 말풍선 32pt, 텍스트뷰어 본문은 사용자가 고른 크기.
- 12pt 아래로는 쓰지 않는다(`.caption2` 금지). 사용자 글꼴 크기 설정을 따른다.

## 간격

- 화면 좌우 24pt, 위 12pt, 아래 24pt(`.visionCraftScreenPadding()`). 홈은 화면 가장자리 기준 위 44pt, 아래 최소 32pt이며 안전 영역 여백을 중복해서 더하지 않는다. 안전 영역 자체가 더 크면 안전 영역을 우선한다.
- 목록 카드 사이 16pt(`VisionCraftUI.actionRowSpacing`), 섹션 사이 28pt. 제목 글자와 밑줄 사이 7pt, 밑줄 높이 3pt. 밑줄 아래는 일반 섹션 14pt, 카드 다이얼로그 20pt(기본 14 + 추가 6).
- 카드 안쪽 20/18pt, 패널 안쪽 20/12pt, 다이얼로그 안쪽 24pt. 값 선택 다이얼로그는 제목 아래 16pt, 목록과 닫기 버튼 사이 24pt. 설정 항목 이름과 값/색 견본 사이 최소 10pt, 설명 묶음과 스위치 사이 최소 12pt(행 높이에 여유가 있으면 늘어남).
- 누를 수 있는 것은 최소 48pt. 카드 88pt, 버튼 52pt(주 버튼 64pt), 제목 줄 아이콘 52pt.

## 모서리

모두 `RoundedRectangle(cornerRadius:, style: .continuous)`(연속 곡선).

| 값 | 쓰는 곳 |
| --- | --- |
| 10 | 뱃지 |
| 12 | 값 고르기 다이얼로그 안 줄, 색 견본 |
| 14 | 버튼(`VisionCraftAndroidButtonStyle`), 안내 띠, 채팅 칩, 값 버튼 |
| 16 | 패널(`visionCraftSurfaceCard`), 목록 아이콘 칸(Large), 제목 줄 아이콘 버튼, 카메라 조작 버튼 |
| 22 | 목록 카드, 2x2 타일, 말풍선, 업데이트 카드 |
| 24 | 값 고르기 다이얼로그(`VisionCraftSelectionDialog`), 채팅 입력 영역 위쪽 |
| 28 | 카드 다이얼로그(`VisionCraftDialogCard`), 채팅 입력칸 |

## 면과 테두리

- 떠 있는 면(`visionCraftHomeSurface`): 1.5pt 테두리 + 양방향 그림자(흐림 5, 오프셋 2). 누르면 흐림 2·오프셋 0.75, 면이 그림자 쪽으로 14% 어두워진다. 물결 효과는 쓰지 않는다(`VisionCraftHomePressStyle`).
- 2x2 타일만 테두리 없이 큰 그림자(흐림 10·오프셋 5)와 위아래 밝기 기울기로 띄운다(`raised: true`).
- 묶음 패널은 그림자 없이 1pt 보조글자색 70% 테두리(`visionCraftSurfaceCard`, 면 위 3:1 이상). 오류 패널은 1.5pt 강조색(`visionCraftErrorPanel`).
- 채팅 칩·입력칸·입력 영역은 테두리 없이 면 색으로만 구분한다.
- 카드 안에 카드를 넣지 않는다.

## 위젯

### 카테고리형 런처 첫 페이지 장식

첫 다섯 카테고리 버튼 오른쪽 위의 ¼원은 공통 회색을 사용한다. 라이트는 옅은 웜그레이 `#E0E1DB`, 다크는 낮은 밝기의 회색 `#3A3D38`이며 타일 위의 은은한 배경 장식으로 표시한다.

### 공용 기능 그림 받침

카테고리 하위 메뉴의 기능 그림은 웜그레이 받침을 사용한다. 라이트 면 `#B1B3AD`, 다크 면 `#A1A59D`이며 받침 테두리는 두지 않는다. 받침 모서리는 한 변의 22.5%이며 그림은 받침의 70%로 표시한다. 밝은 크림색과 회색 물체가 받침에 섞이지 않도록 밝은 웜그레이를 사용하고 홈 장식과도 같은 저채도 회색 계열로 맞춘다. 즐겨찾기는 앱만 지원하며 앱의 원래 아이콘과 편집 칸의 격자·별 그림에는 별도 받침을 씌우지 않는다. 바깥 카드 면과 크기는 유지한다.

### 카테고리형 런처 기능 그림의 색 톤

- 그림 속 물체·기능의 익숙한 색을 우선한다. 말풍선·봉투·종이는 밝은 중성색, 카메라·헤드폰은 차콜과 은색, 렌즈·하늘은 파랑, 풍경은 초록·노랑, 연필은 노랑·골드, 유튜브는 빨강과 밝은 재생 기호를 사용한다. 책은 갈색 표지와 아이보리 종이를 사용한다.
- 통일감은 절제된 채도·밝기와 부드러운 명암으로 맞춘다. 기존 12색은 톤의 참고이며 그림 전체에 여러 색을 배분하는 규칙으로 사용하지 않는다. 물체의 색 계열을 유지하고 큰 중성색 면에 기능을 나타내는 컬러를 더한다. 차콜 `#343E44`·슬레이트 `#34444B`·밝은 종이색 `#F2EFE6`·렌즈 파랑 `#8DB9C9`·유튜브 빨강 `#C65455` 등을 사용한다.
- 기존 메뉴 그림의 둥근 형태와 부드러운 명암을 살린 무광 일러스트 17종을 사용한다. 은은한 하이라이트와 작은 명도 차이로 얕은 입체감을 표현하며 외곽선·강한 반사광·바깥 그림자는 생략한다.
- 작은 글자와 기능 기호는 그림의 바탕에 따라 진한 슬레이트·잉크·짙은 초록 또는 밝은 아이보리로 식별할 수 있게 표시한다.
- 이 팔레트로 완성된 NoOutline 그림은 원본 색상으로 표시한다. 다른 기능 그림의 기존 색 보정은 각 컴포넌트 규격을 따른다.

### Ratio 홈 카드의 형태·글자

실행 타일과 홈 검색 줄은 기본 또는 선택색의 불투명 면, 모서리 2dp/pt와 1dp/pt 테두리를 사용한다. 타일 제목은 기본 34·최소 24·최대 56에 면적 배율을 적용하며, 앱 아이콘형 이름은 18이다. 홈 검색 미리보기는 기본 22, 실제 검색 입력은 기존 20이다. 텍스트 바로가기의 사용자 지정 공통 글자 크기는 유지한다. Android 포커스 표시와 편집 도구의 경계를 유지한다.

### 런처 날씨·타이머 전용 위젯 / 검색 줄

날씨·타이머는 앱/기능 목록 없이 런처 위젯 편집/추가에서만 제공한다. 날씨·타이머 카드와 홈 검색은 모서리 2dp/pt를 사용하고 저장한 선택색을 적용한다. 세부 데이터·크기·알림·검색 규격은 `08_ratio_home_grid_proposal.md`의 해당 절을 따른다.

### 유튜브·브라우저 공통 리보 테마

유튜브 로그인 안내·플레이어 바깥 조작은 기존 런처 리보 테마를 유지한다. 브라우저는 독립 실행·홈 위젯 모두 라이트/다크 두 모드를 사용하고 다크를 기본 선택한다. 홈 브라우저의 다크 모드는 위젯의 숲 배경 위에 투명한 캔버스와 흰 글씨를 사용한다. 일반 홈 바탕은 앱 모드를 따르며 쉬운 유튜브 위젯은 기존 숲 배경을 사용한다. 주소창·도구·메뉴·웹 콘텐츠·구글 간단히 보기도 선택 모드의 색을 따른다. 유튜브 목록·로그인·플레이어의 별도 색 규격은 유지한다.

### 유튜브 목록 팔레트와 통합 검색창

유튜브 홈·구독·검색·채널 목록의 기본 팔레트는 밝은 바탕 `#F5F3EE`·흰 면·글자 `#252B28`·보조 글자 `#4C5D54`·초록 강조 `#17644E`·경계 `#69786F`, 어두운 바탕 `#101714`·면 `#1B2821`·글자 `#F1F5F2`·보조 글자 `#BCCDC2`·민트 강조 `#A8DEC0`·경계 `#9BAFA2`다. 위젯은 어두운 목록 색과 투명 캔버스를 유지한다. 목록의 물결 인디케이터는 위젯·어두운 화면에서 리보 테마의 연한 노란 강조색, 독립 밝은 화면에서 청회색 `#405A7A`를 사용하며 빛 번짐도 같은 색이다. 영상 재생창과 로그인 안내는 리보 테마를 따른다. 로그인 버튼은 기본 확대 보기 위젯의 짙은 초록 `#255B4B` 면과 아이보리 `#F8F5EC` 글자·1px 테두리를 사용한다. 영상 목록은 투명한 행과 얇은 구분선을 사용한다. 행의 제목·보조 정보·구분선·키보드 포커스는 현재 목록 팔레트의 글자·보조 글자·경계·강조색을 따르며, 위젯에서는 숲 바탕과 어두운 목록 팔레트를 유지한다. 썸네일의 영상 길이 배지만 흰 글자·검정 85% 면을 사용한다.

유튜브·브라우저의 웹 검색창은 모서리 32·검정 75% 면·밝은 1px 경계·20px 입력 글자·왼쪽 20/오른쪽 6px 여백을 사용한다. 유튜브 검색창의 최소 높이는 72 CSS px·입력칸은 56 CSS px이며, 브라우저 검색창은 최소 높이 88 CSS px·입력칸 64 CSS px다. 검색 기호를 따로 두지 않으며 오른쪽 마이크는 56px로 항상 표시한다. 빈 입력에서는 전송 버튼을 숨기고, 한 글자 이상 입력하면 마이크 왼쪽에 강조색 원형 52px·밝은 1px 테두리·28px 위쪽 화살표를 표시한다. 공백만 입력하면 전송은 비활성화하고 키보드 검색도 유지한다. 검색어·결과 변경 때문에 입력 노드와 포커스를 재생성하지 않는다. 브라우저의 라이트 모드를 선택하면 구조는 유지하고 선택 팔레트에 맞는 글자·면·경계를 적용한다. 유튜브 입력은 `영상 검색`, 원형 전송은 `검색어 전송`, 마이크는 `음성 검색`으로 읽는다. 음성 입력 결과는 유튜브에서는 공개 `/results?search_query=`로, 브라우저에서는 기존 URL/구글 검색 처리로 보낸다.

### 브라우저 모드 선택

선택지는 라이트 모드(`light`)·다크 모드(`dark`) 두 가지이며 새 세션의 기본은 다크 모드다. 선택은 기존처럼 세션 동안 유지한다. Ratio 홈은 모드별 바탕에 흐린 사진을 얹으며 다크 웹과 쉬운 유튜브는 기존 숲 배경을 사용한다. 홈 브라우저의 다크 웹 캔버스는 투명하고 라이트 웹 캔버스는 밝은 면을 사용한다. 원본 보기 토글은 모드 선택과 별도로 유지한다.

### 홈 브라우저 다크 모드의 바탕

다크 모드의 홈 브라우저와 쉬운 유튜브의 전체 페이지 위젯은 숲 사진 바탕을 사용한다. 웹 루트·본문·기본 바탕은 투명해 위젯의 숲 배경이 드러난다. 카드·입력창·메뉴·미디어와 원래 배치는 유지한다. 일반 홈 바탕은 앱 모드를 따르며, 브라우저 라이트 모드는 밝은 웹 면을 사용한다. 두 모드 선택·기본 다크·광고 차단 규격은 유지한다.

### 쉬운 유튜브의 고정 배경

홈의 쉬운 유튜브는 목록·영상·쇼츠·댓글 모두 위젯의 숲 배경을 사용한다. 투명 웹 캔버스·댓글 글자·영상 픽셀·재생 동작을 유지한다. 다크 웹 위젯도 같은 숲 배경을 사용한다.

## 런처 선택과 미디어 (Debug·Release 공통)

설정의 ‘런처 변경’은 기존 홈 / 위젯 런처 두 가지이며 선택 즉시 해당 홈으로 이동하고 다음 앱 실행에서도 유지한다. 기존·신규 사용자의 기본값은 기존 홈이다. 기존 홈의 목록형·카테고리형 선택은 별도로 유지한다. 위젯의 배치·추가·개별 설정은 런처 내부에서만 연다. Android 시스템 기본 HOME 지정은 앱 안의 홈 선택과 독립적이며 자동으로 기본 HOME 권한창을 띄우지 않는다. 사용자가 시스템 설정에서 직접 지정한다. iPad는 앱 내부 시작 화면만 바뀌며 OS 홈을 대신하지 않는다.

기존 홈의 목록형과 카테고리형에 ‘미디어’을 제공하며 ‘쉬운 브라우저’·‘쉬운 유튜브’·‘리보 이메일’이 각각 단독 화면을 연다. 설정의 ‘미디어 표시’는 기본 켬이며 두 홈 구성에 동시에 적용하고 재시작 후에도 유지한다. 숨기기는 해당 그룹 표시만 제어하며 기존 위젯·로그인·즐겨찾기를 삭제하지 않는다. 런처 앱·기능 목록에는 브라우저·유튜브·앱 설정·기존 홈 진입을 제공한다. 기존 홈 진입은 저장된 위젯 런처 선택을 바꾸거나 다시 런처로 튕기지 않는다.

브라우저·유튜브·뉴스·날씨·타이머·데이지 위젯은 릴리즈에도 포함한다. Android 브라우저 코드·리소스·JavaScript는 main 소스셋이며 릴리즈의 브라우저 위젯도 실제 웹뷰를 만든다. iPad Launcher와 AccessibleWeb 코드는 DEBUG 조건 없이 컴파일한다. 개발 화면과 로컬 모델 실험·문서 비교 도구의 빌드 조건은 유지한다. 뉴스 백그라운드 수신도 릴리즈에서 같은 선택 분야·2시간 정책으로 동작한다.

로그인·사이트 저장소와 사용자 즐겨찾기는 위젯·단독 화면에서 공유한다. 일반 브라우저와 Google 서비스는 서로 다른 영속 웹 저장소를 사용하고 문서용 웹뷰와도 분리한다. Gmail과 유튜브만 기존 유튜브 저장소를 공유하며 다른 메일 계정은 계정별 저장소를 유지한다. 비밀번호·쿠키를 네이티브 코드로 추출/복사하지 않는다. 방문 페이지·뒤로가기 목록·스크롤·영상 위치는 열린 화면의 세션에만 두며 단독 화면을 다시 열면 기본 홈에서 시작한다. 이미 열려 있는 위젯의 화면 내 상태 유지 규격은 그대로다. 브라우저가 다시 활성화되면 즐겨찾기 표시를 갱신한다.

새 설정은 기존 설정 값과 섞이지 않으며 기존 위젯 ID·배치·YouTube 로그인 저장소·즐겨찾기 키는 유지한다. 네이티브 설정 선택과 숨기기 스위치는 기존 설정 컴포넌트, 접근성 이름·선택/켜짐 상태·큰 글자·터치 기준을 따른다.

### Ratio 데이지 첫 화면
