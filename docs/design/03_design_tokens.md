## 앱 테마

- 설정의 화면 및 글꼴 → 앱 테마에서 시스템 설정에 따름·라이트·다크를 고른다. 기본은 시스템 설정에 따름이며, 선택은 저장되고 즉시 적용된다. 시스템 설정에 따름은 기기의 테마 변경을 계속 반영한다.
- `AppSettingsStore.appTheme`과 `AppThemeMode`, 앱 루트의 `preferredColorScheme`가 앱 전체에 적용한다. 기기 자체의 테마는 바꾸지 않는다.
- 카메라 미리보기의 고정 색, 텍스트 뷰어의 사용자 색 조합, 도서 읽기의 본문 테마와 위젯 전용 색은 각 화면 규칙을 유지한다.

### 강조색 쓰임

- **주황**: 뭔가를 실행하는 동작. 촬영, `작업`, 분석, 보낸 말풍선, 마이크. `VisionCraftAndroidButtonStyle(emphasized: true)`.
- **남색 잉크**(글자색을 면으로): 확인·이동 같은 차분한 주 동작. 새 대화 버튼, 다이얼로그 닫기. `VisionCraftAndroidButtonStyle(filled: true)`. 앱 `AccentColor`도 이 색이라 시스템 컨트롤의 tint가 파랑이 아니다.
- **파랑**은 UI 면에 쓰지 않는다. 구분 표시에만 쓴다: 카메라 섹션 밑줄(`SectionTone.camera` `#356AA8`/`#9EC5FF`), 비전링크 연결 원·선(`VisionCraftUI.linkBlue`), 카드 다이얼로그 아이콘 색 중 하나.
- 한 화면에 강한 강조는 하나. 오류·삭제 같은 시스템 상태는 예외(`VisionCraftUI.error`).
- 라이트 주황 `#C0521B`는 흰 글자 4.7:1, 면(`#FAFAFA`) 위 글자로 4.5:1이 되도록 정한 값이다. 더 밝게 바꾸지 않는다.

## 글자

`visionCraftAndroidText(size, weight:, relativeTo:)`가 Android `sp`처럼 Dynamic Type 배율을 따르고, 앱 글꼴 설정(`AppFontCatalogStore.fontName`, 환경값 `visionCraftAppFontName`)을 적용한다. 자간은 0.

| 크기 / 굵기 | 쓰는 곳 |
| --- | --- |
| 24 / Bold | 화면 제목(`VisionCraftScreenTitleRow`), 업데이트 버전 |
| 22 / SemiBold | 섹션 제목(`VisionCraftHomeSectionHeader`), 다이얼로그 제목 |
| 18 / SemiBold | 목록 카드 제목 |
| 18 / Regular | 다이얼로그 줄, 설정 항목 이름, 본문 |
| 16 / Regular | 목록 카드 설명, 안내 글, 업데이트 항목 |
| 16 / SemiBold | 버튼 글자, 값 버튼 |
| 16 / Bold | 뱃지 |
| 14 / Medium | 설정 그룹 이름, 카메라 버튼 상태 줄, 업데이트 날짜 |
| 13 / Bold | 채팅 보낸 사람 이름 |

- 2x2 타일 제목은 타일 안쪽 너비에 비례해 정한다(`VisionCraftHomeTileTitle`).
- 홈·카테고리 머리 제목은 같은 24 Bold와 최소 32pt 글자 칸(`HomeView.homeHeaderTitle`)을 사용한다. 두 값은 같은 `.title2` Dynamic Type 기준으로 확대된다. 제목 줄은 오른쪽 아이콘의 52pt 높이도 확보한다.
- 채팅 말풍선 32pt, 텍스트뷰어 본문은 사용자가 고른 크기.
- 12pt 아래로는 쓰지 않는다(`.caption2` 금지). 사용자 글꼴 크기 설정을 따른다.

## 간격

- 화면 좌우 24pt, 위 12pt, 아래 24pt(`.visionCraftScreenPadding()`). 홈은 화면 가장자리 기준 위 44pt, 아래 최소 32pt이며 안전 영역 여백을 중복해서 더하지 않는다. 안전 영역 자체가 더 크면 안전 영역을 우선한다.
- 목록 카드 사이 16pt(`VisionCraftUI.actionRowSpacing`), 섹션 사이 28pt. 제목 글자와 밑줄 사이 7pt, 밑줄 높이 3pt. 밑줄 아래는 일반 섹션 14pt, 카드 다이얼로그 20pt(기본 14 + 추가 6).
- 카드 안쪽 20/18pt, 패널 안쪽 20/12pt, 다이얼로그 안쪽 24pt. 값 선택 다이얼로그는 제목 아래 16pt, 목록과 닫기 버튼 사이 24pt. 설정 항목 이름과 값/색 견본 사이 최소 10pt, 설명 묶음과 스위치 사이 최소 12pt(행 높이에 여유가 있으면 늘어남).
- 누를 수 있는 것은 최소 48pt. 카드 88pt, 버튼 52pt(주 버튼 64pt), 제목 줄 아이콘 52pt.

## 면과 테두리

- 떠 있는 면(`visionCraftHomeSurface`): 1.5pt 테두리 + 양방향 그림자(흐림 5, 오프셋 2). 누르면 흐림 2·오프셋 0.75, 면이 그림자 쪽으로 14% 어두워진다. 물결 효과는 쓰지 않는다(`VisionCraftHomePressStyle`).
- 2x2 타일만 테두리 없이 큰 그림자(흐림 10·오프셋 5)와 위아래 밝기 기울기로 띄운다(`raised: true`).
- 묶음 패널은 그림자 없이 1pt 보조글자색 70% 테두리(`visionCraftSurfaceCard`, 면 위 3:1 이상). 오류 패널은 1.5pt 강조색(`visionCraftErrorPanel`).
- 채팅 칩·입력칸·입력 영역은 테두리 없이 면 색으로만 구분한다.
- 카드 안에 카드를 넣지 않는다.

## 위젯

- WidgetKit small/medium. 런처 배경 위에 그리므로 라이트/다크와 무관하게 어두운 유리·그림자를 쓴다. 규격은 `rivoWidget/`.
- Android 2x2 15개 고정과 달리 하나의 바로가기 위젯에서 기능을 고른다.

## Ratio 홈

`Launcher/RatioLauncherView.swift`의 `RatioStyle`: Android Ratio와 같은 배경 #101010, 면 #262626, 글자 #F5F5F2, 강조 #F3F565. 모든 홈·검색 페이지는 아래 공통 팔레트를 사용하며 내용은 안전 영역 안에 둔다. 타이포는 기존 Dynamic Type 글자 수정자를 사용한다.

### 접근성 웹 라이트·다크 모드 (Debug)

브라우저는 두 모드만 제공하며 다크를 기본 선택한다. 주소창과 도구·메뉴·웹 콘텐츠·구글 간단히 보기가 같은 모드의 색을 사용한다. 두 모드에서 사진·영상 원래 색과 배치·입력값을 유지하고, 원본 보기를 통해 사이트 원래 표현으로 복원할 수 있다.

### Ratio 공통 팔레트

모든 홈 페이지·검색은 숲 안개 사진 배경(대체 바탕 #101C2D)·면 #1C2D43·글자 #F5F3E9·강조 #E6EF87의 공통 팔레트를 사용한다. 일반 타일 모서리는 8이며 선택한 개별 색상은 배경 또는 텍스트에 그대로 적용한다. 세부 규격은 `08_ratio_home_grid_proposal.md`를 따른다.

### Ratio 홈 카드의 형태·글자

실행 타일은 평상시 테두리 없이 기본 또는 선택색의 불투명 면을 사용하고, 홈 검색 미리보기는 투명한 검색 줄을 사용한다. 타일 제목은 기본 34·최소 24·최대 56에 면적 배율을 적용하며, 앱 아이콘형 이름은 18이다. 홈 검색 미리보기는 기본 22, 실제 검색 입력은 기존 20이다. 텍스트 바로가기의 사용자 지정 공통 글자 크기는 유지한다. Android 포커스 표시와 하단 탐색·편집 도구의 경계는 유지한다.

### 런처 날씨·타이머 전용 위젯 / 검색 줄

날씨·타이머는 앱/기능 목록 없이 런처 위젯 편집/추가에서만 제공한다. 모서리 8·선택색을 유지하며 검색은 투명한 줄·밑줄·음성 원 버튼으로 구분한다. 세부 데이터·크기·알림·검색 규격은 `08_ratio_home_grid_proposal.md`의 해당 절을 따른다.

### 유튜브·브라우저 공통 리보 테마

유튜브 로그인 안내·플레이어 바깥 조작은 기존 런처 리보 테마를 유지한다. 브라우저는 독립 실행·홈 위젯 모두 라이트/다크 두 모드를 사용하고 다크를 기본 선택한다. 홈 브라우저의 다크 모드는 이전의 어두운 숲 사진 배경 위에 투명한 캔버스와 흰 글씨를 사용한다. 일반 홈 페이지는 밝은 산 사진을 유지하며 이지 유튜브는 어두운 숲 사진을 사용한다. 주소창·도구·메뉴·웹 콘텐츠·구글 간단히 보기도 선택 모드의 색을 따른다. 유튜브 목록·로그인·플레이어의 별도 색 규격은 유지한다.

### 유튜브 목록 팔레트와 통합 검색창

유튜브 홈·구독·검색·채널 목록의 기본 팔레트는 밝은 바탕 `#F5F3EE`·흰 면·글자 `#252B28`·보조 글자 `#4C5D54`·초록 강조 `#17644E`·경계 `#69786F`, 어두운 바탕 `#101714`·면 `#1B2821`·글자 `#F1F5F2`·보조 글자 `#BCCDC2`·민트 강조 `#A8DEC0`·경계 `#9BAFA2`다. 위젯은 어두운 목록 색과 투명 캔버스를 유지한다. 목록의 물결 인디케이터는 위젯·어두운 화면에서 리보 테마의 연한 노란 강조색, 독립 밝은 화면에서 청회색 `#405A7A`를 사용하며 빛 번짐도 같은 색이다. 영상 재생창과 로그인 안내는 리보 테마를 유지한다. 영상 카드는 화면 모드·위젯 여부와 관계없이 옅은 회색 면 `#D1D5DB`·진한 글자 `#252B28`·보조 글자 `#4C5D54`·경계 `#69786F`·포커스 `#17644E`를 사용한다. 썸네일 아래 제목·채널·시점·길이도 이 카드 색을 따른다.

유튜브·브라우저의 웹 검색창은 런처의 실제 앱·기능 실행 검색창과 같은 모서리 32·최소 높이 88·검정 75% 면·밝은 1px 경계·20px 입력 글자·왼쪽 20/오른쪽 6px 여백을 사용한다. 검색 기호를 따로 두지 않으며 오른쪽 마이크는 56px로 항상 표시한다. 빈 입력에서는 전송 버튼을 숨기고, 한 글자 이상 입력하면 마이크 왼쪽에 강조색 원형 52px·밝은 1px 테두리·28px 위쪽 화살표를 표시한다. 공백만 입력하면 전송은 비활성화하고 키보드 검색도 유지한다. 검색어·결과 변경 때문에 입력 노드와 포커스를 재생성하지 않는다. 브라우저의 라이트 모드를 선택하면 구조는 유지하고 선택 팔레트에 맞는 글자·면·경계를 적용한다. 유튜브 입력은 `영상 검색`, 원형 전송은 `검색어 전송`, 마이크는 `음성 검색`으로 읽는다. 음성 입력 결과는 유튜브에서는 공개 `/results?search_query=`로, 브라우저에서는 기존 URL/구글 검색 처리로 보낸다.

### 브라우저 모드 선택

선택지는 라이트 모드(`light`)·다크 모드(`dark`) 두 가지이며 새 세션의 기본은 다크 모드다. 선택은 기존처럼 세션 동안 유지한다. Ratio 홈은 기본 산 사진을 유지하고 브라우저 다크 모드와 이지 유튜브 페이지에서 이전의 어두운 숲 사진으로 바꾼다. 홈 브라우저의 다크 웹 캔버스는 투명하고 라이트 웹 캔버스는 밝은 면을 사용한다. 원본 보기 토글은 모드 선택과 별도로 유지한다.

### 홈 브라우저 다크 모드의 사진 배경

홈 브라우저 다크 모드와 이지 유튜브 페이지에 숲 사진(`launcher_ratio_forest_mist` / `RatioForestMist`)과 검정 60%·하단 추가 25% 막을 적용한다. 웹 루트·본문·기본 바탕은 투명해 이 사진이 비치며 본문 뒤에 불투명한 검정/회색 면을 추가하지 않는다. 카드·입력창·메뉴·미디어와 원래 배치는 유지한다. 브라우저 라이트 모드와 일반 홈 페이지는 기존 밝은 산 사진을 유지하고, 이지 유튜브의 목록·영상·댓글은 어두운 숲 사진을 사용한다. 두 모드 선택·기본 다크·광고 차단 규격은 유지한다.

### 이지 유튜브의 고정 배경

홈의 이지 유튜브는 목록·영상·쇼츠·댓글 화면 모두 어두운 숲 사진과 검정 60%·하단 추가 25% 막을 사용한다. 홈의 기본 사진이 바뀌어도 이 배경은 독립적으로 유지한다. 기존 투명 캔버스·댓글 글자·영상 픽셀·재생 동작은 유지하며 불투명한 검정 면을 추가하지 않는다. 브라우저 다크 모드에도 같은 사진을 사용한다.
