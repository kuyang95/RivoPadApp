# VisionCraft iPadOS 디자인 규격

점검일: 2026-09-23 · Android 기준: `5eb241e` (디자인 문서 기준 코드 `0878501`)

Android `docs/design/02_accessibility_contract.md`, `03_design_tokens.md`,
`04_component_specs.md`, `05_screen_specs.md`를 iPadOS의 화면 크기와 기본 동작에 맞게 적용한다.
공용 구현은 `shortcuts_example/DesignSystem/`에 둔다.

## 색과 역할

| 역할 | iPadOS | 라이트 | 다크 |
| --- | --- | --- | --- |
| 배경 | `VisionCraftUI.background` | `#FFFFFF` | `#000000` |
| 면 | `.surface` | `#FAFAFA` | `#171717` |
| 보조면 | `.surfaceVariant` | `#F0F2F5` | `#2B2B2B` |
| 본문·이동 버튼 | `.primaryText` / `.primary` | `#283546` | `#F0F4FA` |
| 보조 문구·윤곽선 | `.secondaryText` / `.outline` | `#536176` | `#BBC6D7` |
| 실행 강조 | `.accent` | `#C0521B` | `#FFA05C` |
| 강조 위 글자 | `.onAccent` | 흰색 | 검정 |

실행(촬영, 작업, 전송, 마이크)에는 주황을 쓰고, 이동·확정에는 남색 잉크를 쓴다.
파랑(`VisionCraftUI.linkBlue`)은 카메라 영역 밑줄과 비전링크 연결 원·선에 한정한다.
빨강은 오류·중지, 초록·노랑은 실제 연결 상태에 쓴다. 본문이나 버튼의 의미를 색에만 의존하지 않는다.

## 공통 크기와 접근성

- 화면 좌우 24pt, 섹션 사이 28pt, 목록 카드 사이 16pt. 제목은 22pt, 카드 제목은 18pt, 설명은 16pt가 기준이다.
- `visionCraftAndroidText`는 Dynamic Type에 따라 확대된다. 본문을 잘라 숨기기보다 높이와 줄 수를 늘린다.
- 누를 수 있는 항목은 48pt 이상. 목록 카드는 88pt, 일반 버튼은 52pt, 실행·확정 버튼은 64pt를 기준으로 한다.
- 글자 대비 4.5:1, 상태·아이콘·구분선 3:1을 목표로 한다. 공용 팔레트의 라이트 주황은 흰 글자와 4.7:1이다.
- 장식 아이콘은 접근성 읽기에서 제외한다. 상태는 값·텍스트로 함께 읽힌다.

## 면과 구성 요소

- `VisionCraftHomeUI`와 `VisionCraftUI`가 같은 기본 팔레트를 공유한다. 홈 액션 카드(`VisionCraftHomeActionList`)는 연속 모서리 22pt, 1.5pt 윤곽선과 양방향 그림자를 쓴다. 목록형의 기본 아이콘은 회색 28pt이며, 카테고리 다이얼로그 안의 아이콘 타일만 로고의 빨강·주황·노랑·초록·파랑·보라를 순서대로 쓴다.
- 묶음 패널(`VisionCraftSettingsGroup`)은 16pt 모서리, 보조글자색 70% 윤곽선, 그림자 없음. 그룹 안에는 다시 카드를 넣지 않는다.
- `VisionCraftAndroidButtonStyle()`은 52pt 윤곽선 버튼이며 `filled: true`는 잉크색 이동·확정 버튼이다. 실행 버튼은 주황 면과 `.onAccent` 글자를 쓴다.
- 선택 다이얼로그(`VisionCraftSelectionDialog`)는 28pt 카드, 현재 값만 주황 15% 면과 점으로 강조하며 선택 즉시 적용한다. 기능 다이얼로그(`VisionCraftDialogCard`)는 28pt 카드, 설명이 있는 88pt 액션 행, 기본 취소 버튼을 쓴다.
- 홈 영역 제목은 `VisionCraftHomeSectionHeader`의 3pt 색 밑줄로 구분한다. 밑줄은 영역 식별용이고 버튼 배경의 두 번째 강조색이 아니다.

## 화면별 적용

- 홈의 기본 화면은 Android `VcHomeCategoryGrid`를 따른 카테고리형 타일이다. 세로 화면은 2×2, 가로 화면은 4개 한 줄로 배치한다. 타일 간격 16pt, 가로:세로 4:5, 연속 모서리 22pt, 그림 위·제목 아래 배치와 밝은/어두운 그림을 Android 원본 자산에서 가져왔다. 그림 뒤의 중립색 정사각 면과 그림 크기 70%도 Android 코드에 맞춘다. 기존 설치에서 목록형 설정이 남았더라도 첫 업데이트 때 한 번 카테고리형을 표시하며, 이후 직접 고른 설정은 유지한다. 상단은 앱 제목·리모컨 상태·모든 설정, 다음은 사용법 안내 순서다.
- 타일에 기능이 하나면 바로 열고, 여러 기능이면 해당 섹션 카드가 든 28pt 다이얼로그를 연다. 카메라 타일은 Android처럼 카메라로 바로 이동한다. 카메라·문서 스캔·실시간 문자 읽기 화면의 남색 모드 버튼에서 기본·문서 스캔·실시간 문자 읽기·이미지 분석·AI 질문하기·사진 분석으로 이동하며 현재 모드에는 `현재` 배지를 붙인다. `모든 설정`은 화면 전체로 열고, 목록형은 그 안의 `화면 및 글꼴 > 홈 화면 구성`에서 선택할 수 있다.
- 사진 분석은 저장된 사진을 선택해 큰 미리보기와 작업 버튼을 보여 준다. 글자 인식·번역·AI 대화·텍스트로 보기·이미지 설명·소리 내어 읽기는 iPadOS의 기존 엔진과 화면으로 연결한다.
- 채팅은 주황 사용자 말풍선(22pt, 오른쪽 아래 6pt), 면색 AI 말풍선(1.5pt 윤곽선), 테두리 없는 칩·입력칸·입력 영역을 쓴다. 마이크와 전송은 주황이고 다크 모드 글자는 검정이다.
- 문서 스캔 결과는 면색 화면, 테두리 없는 사진, 같은 높이의 `저장` 윤곽선 버튼과 `작업` 주황 버튼을 쓴다. 진행·결과 띠는 잉크색 면과 대비되는 글자로 표시한다.
- 텍스트·책 본문은 사용자가 고른 고대비 색과 글꼴을 존중한다. 공통 색은 그 바깥의 메뉴·설정·다이얼로그에 적용한다. 책 재생 버튼과 슬라이더에는 실행 강조색을 쓴다.
- 카메라 **미리보기 위** 조작은 항상 흰 글자와 어두운 면을 사용한다. 모드 버튼은 뒤로가기와 겹치지 않게 오른쪽 위에 두고 iPad의 기존 원형 촬영·격자·토치·카메라 전환 제어와 접근성 이름을 유지한다.

## Android와 플랫폼 차이

- Android의 9월 21일 런처 아트를 바탕으로 iOS 앱 아이콘을 만든다. 적응형 아이콘 안쪽 둥근 사각형과 바깥 배경의 남색 톤 차이를 없애고 중앙의 책·돋보기 심볼을 확대한다. 시작 화면에는 같은 심볼의 원형·투명 배경 자산을 중앙 192pt로 배치하고 배경을 라이트 `#F3F5FF`, 다크 `#050816`으로 지정한다. Android의 반짝임 애니메이션은 iOS 정적 시작 화면에 적용하지 않는다.
- Android 런처 위젯의 2×2 크기·RemoteViews/Drawable 규격은 iPadOS 위젯에 그대로 옮길 수 없다.
- Android의 음성 질의는 3.5초 침묵 뒤 듣기를 끝낸다. iPadOS의 RMS 침묵 기준도 3.5초로 맞춘다.
- Android의 웹 검색 사전 판별은 Gemini 호출이라 일일 토큰에 포함된다. iPadOS는 `ChatWebSearchRouter`가 기기 안에서 판별하고, 실제 Gemini 웹 검색은 `CloudAITokenBudgetStore`에서 예약·차감한다.
