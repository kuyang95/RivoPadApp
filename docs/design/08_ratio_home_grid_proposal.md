## 배치 단위

Ratio만 적용한다. 홈 상단 여백은 시스템 안전 영역 안쪽 24dp/pt다. 일반 바로가기는 가로 4열, 열·행 간격 12dp/pt, 좌우 여백 32다. 한 열 너비는 (가용 너비 − 36) / 4다. 한 행의 기본 높이는 88이며 w×h의 기준 크기는 `(열 너비×w + 12×(w−1)) × (88×h + 12×(h−1))`이다. 2×2의 높이는 188dp/pt이고 폭은 화면 너비에 따라 달라지므로 정사각형을 뜻하지 않는다.

저장 순서대로 한 줄에 최대 4열을 채운다. 다음 항목이 남은 열에 맞지 않으면 새 줄로 이동한다. 저장된 기존 항목끼리의 순서나 폭은 바꾸지 않는다. 새 항목을 추가할 때만 현재 페이지의 빈 칸에 맞는 삽입 위치를 선택한다. 줄 높이는 가장 높은 항목을 수용한다. 일반 바로가기는 각자의 크기·콘텐츠 높이를 유지하고, 날씨·타이머의 바깥 면은 해당 줄의 높이에 맞춘다. 이름 줄바꿈·시스템 글자 확대를 반영한 실제 높이로 페이지를 계산한다.

홈은 기본적으로 가로 페이지를 사용하고, 한 줄의 자연 높이가 가용 높이를 넘는 경우에만 그 줄 안에서 세로 스크롤한다. 상단 24 여백·선택 시계·하단 도구막대를 제외한 가용 높이에 맞춰 줄 단위로 페이지를 나눈다. 남은 높이에 맞지 않는 줄은 다음 페이지로 넘기며 저장 순서는 유지한다. 좌우 스와이프 또는 하단 점을 눌러 이동한다. 전체 앱·설정 버튼 왼쪽에 전체 페이지 수만큼 점을 두고 현재 점은 12, 나머지는 6 크기로 구분한다. 점의 터치 영역은 48이며 화면 읽기에는 현재/전체 페이지와 선택됨 상태를 제공한다. 페이지 표시를 위한 별도 줄·번호·화살표는 없다. 회전·크기 편집 후 페이지 수를 다시 계산하고 현재 페이지가 범위를 벗어나면 마지막 페이지로 맞춘다. 자유 좌표 드래그 대신 위/아래 이동으로 순서를 편집한다. 검색 결과·전체 앱·설정·편집 목록은 계속 세로 스크롤한다.

## 전체 페이지 위젯

유튜브·브라우저 페이지에는 별도 하단 `이전 화면` 버튼을 표시하지 않는다. Android 시스템 뒤로가기와 iPad 접근성 탈출을 사용한다. 유튜브의 쇼츠는 로딩·재생 상태에서 바로 유튜브 홈으로 돌아간다. 일반 영상은 재생창 닫기 → 웹 방문 기록 → 새 창 닫기 순서로 돌아가고, 브라우저는 웹 방문 기록 → 새 창 닫기 순서다. 돌아갈 곳이 없으면 첫 홈 페이지로 복귀한다. 첫 홈의 일반 바로가기에서는 기존 앱 뒤로 동작을 유지한다.

이지 유튜브(`widget:youtube`)·이지 브라우저(`widget:browser`)·데이지 플레이어(`widget:daisy`)는 각각 독립된 한 페이지를 사용한다. 4열·행 수에 따른 고정 카드 높이 대신 현재 홈 콘텐츠의 가용 폭·높이를 채우며, 다른 바로가기와 같은 줄·페이지를 공유하지 않는다. 일반 바로가기는 좌우 32dp/pt 여백·4열 배치를 사용하고 전용 페이지는 좌우 16dp/pt 여백 안의 폭을 사용한다. 홈 상단 24dp/pt 여백은 모든 페이지에 공통 적용하며 카드 모서리는 추가하지 않는다. 시스템 안전 영역과 하단 페이지 점·전체 앱·설정 버튼은 유지한다.

최초 전환에서 기존 일반 바로가기의 데이터·순서·크기·색은 그대로 보존하고, 세 기능 페이지를 이지 유튜브 → 이지 브라우저 → 데이지 순서로 뒤에 배치한다. 기존 브라우저·데이지 설정이 있으면 재사용하고 중복 생성하지 않는다. 이후 사용자가 제거·이동한 선택은 유지하며 편집에서 다시 추가할 수 있다. 전용 위젯 편집에는 전체 페이지 사용 안내·순서 이동·제거만 표시하며 바로가기 유형·색·행 수 변경은 제공하지 않는다.

현재 페이지의 콘텐츠를 활성화한다. 이지 유튜브와 브라우저는 현재 페이지와 인접할 때 세션을 준비하고 페이지 간 이동에는 웹 화면과 세션을 유지한다. 페이지를 떠나거나 앱이 배경으로 가면 미디어를 일시 정지한다. 유튜브는 기존 영속 로그인 저장소를, 브라우저는 기존 임시 세션을 공유한다. 데이지는 기존 도서 선택·이어 읽기·본문·재생 바와 진행 저장소를 사용한다. 최초 방문 뒤 페이지 이동에도 본문·스크롤을 유지하고 재생 중이면 이어 재생하며 유휴 오디오만 해제한다. 홈 진입만으로 책이나 영상을 자동 재생하지 않는다.

세 기능 페이지는 별도 배경면과 위젯 설정 버튼을 두지 않는다. 웹의 기본 캔버스·이지 유튜브의 홈/플레이어 표면·서재/도서 본문 배경은 투명하게 해 홈의 현재 사진 배경이 이어지게 한다. 주소 입력·영상/도서 카드·재생 조작부의 콘텐츠 표면은 유지하며 밝은 글자와 어두운 조작부를 사용한다. 위젯 세션만 이 표현을 사용하고 독립 브라우저·독서 화면은 기존 테마를 유지한다. 이지 유튜브는 네이티브 제목 줄과 웹의 브랜드/제목 헤더를 표시하지 않는다. 로그인 화면의 유튜브 재생 아이콘 그림은 유지한다. 배경 투명화는 캔버스에만 적용하고 아이콘·안내·로그인 버튼은 보존한다. 투명 표면 뒤로 원본 유튜브 화면이 겹치지 않도록 이지 유튜브 표시 중에는 원본 본문을 시각적으로 숨기고, 원본 로그인 화면으로 전환하면 복원한다. 순서·삭제·재추가는 하단 런처 설정 → 위젯 편집에서 한다. 이지 유튜브의 닫기는 첫 홈 페이지로 복귀하며 로그인 폼은 이지 유튜브의 Google 로그인 단순화 규격을 따르며 재생 UI는 기존 이지 유튜브 구현을 사용한다. 웹·책 내부의 스크롤과 버튼을 유지하며 하단 페이지 점으로 항상 다른 페이지로 이동할 수 있다. 이지 유튜브와 이지 브라우저 위젯의 좌우 넘김은 앱의 터치 인식기가 처리한다. 사이트가 터치 전달을 막거나 별도 출처 iframe 안에서 시작해도 동작한다. 가로 이동이 세로의 1.5배보다 크면 홈 넘기기로 판별하며 Android는 12dp, iPad는 시스템 팬 인식의 시작 거리를 사용한다. 손을 뗄 때 가로 이동이 64dp/pt와 표시 폭의 15% 중 큰 값 이상이면 방향에 따라 한 페이지만 이동한다. 짧은 드래그·취소·다중 터치는 페이지를 넘기지 않는다. 세로·대각선 드래그와 넓은 문서·가로 스크롤 영역의 가로 드래그는 웹 스크롤을 유지하고, 입력칸·재생 위치 슬라이더와 공식 영상 iframe의 위쪽 56 CSS px/아래쪽 72 CSS px 조작 영역은 홈 넘기기에서 제외한다. 영상 가운데에서 시작하는 좌우 드래그는 홈 페이지를 넘긴다. 탭과 세로 드래그는 공식 영상에 전달한다. 가로 드래그 뒤 카드 클릭은 억제해 의도치 않은 영상 재생을 막는다. 이지 유튜브의 원본 Google 로그인과 위젯 밖의 독립 브라우저에는 홈 넘기기를 적용하지 않는다. iPad 위젯은 WebKit의 웹 방문 기록 스와이프를 끄고 홈 넘김을 우선한다. 웹 방문 기록 복귀는 접근성 탈출로 수행한다. 일반 바로가기 페이지의 좌우 넘기기는 유지한다. 브라우저 위젯은 사이트의 반응형 배치·격자·표·이미지 비율·고정 위치를 유지하고 선택한 비례 확대만 적용한다. 가로 넘침만으로 캐러셀·숨긴 콘텐츠를 세로로 펼치거나 표·행·셀과 접근성 역할을 다시 쓰지 않는다. 넓은 문서나 가로 스크롤 영역에서는 웹 스크롤을 우선하고 하단 페이지 점으로 홈 페이지를 이동한다. 입력·링크·이벤트 처리·접근성 이름·사이트 주소는 원본을 유지하며 사이트 이름에 따른 배치 예외나 자동 모바일 주소 전환은 두지 않는다. Android 위젯은 가상 광폭 뷰포트·전체 페이지 자동 축소를 사용하지 않으며, iPad 위젯은 CSS layout zoom을 사용한다. 키보드가 열려도 저장 배치·페이지 구분을 다시 만들지 않는다. Android의 웹 두 페이지는 기존 이지 웹 구현과 동일하게 Debug에서 제공하고 Release는 데이지 페이지를 제공한다. iPad의 내부 Ratio 홈은 기존처럼 Debug 전용이다.

## 위젯 유형

| 유형 | 기본 | 선택·동작 |
| --- | --- | --- |
| 타일 바로가기 (`TILE`) | 2×2 | 1×1, 2×1, 2×2, 3×2, 4×2, 4×3. 앱 또는 기능 실행. 기능·앱 구분 없이 선택 가능 |
| 텍스트 바로가기 (`TEXT`) | 4×1, 글자 36 | 공통 글자 24~56을 4씩 조절. 아이콘·면 없이 이름으로 실행. 긴 이름과 큰 글자는 높이 확장 |
| 아이콘 바로가기 (`ICON`) | 1×1 | 실제 앱 아이콘(또는 기능 기호)과 18 크기 이름을 가운데 배치. 아이콘 48~72, 기본 배경 투명. 새 앱 추가의 기본 유형 |
| 데이지 플레이어 (`DAISY`) | 전체 페이지 | 도서 선택·이어 읽기·본문·재생 바 |
| 이지 브라우저 (`BROWSER`) | 전체 페이지 | 기존 브라우저 도구·실제 웹 탐색 |
| 이지 유튜브 (`YOUTUBE`) | 전체 페이지 | 기존 이지 유튜브 탐색·로그인·플레이어 |
| 통합 검색 (`SEARCH`) | 4×1 | 3×1, 4×1, 4×2. 일반 위젯 순서에 포함하며 이동·삭제·재추가 가능. 앱·기능 검색, 전송, 음성 검색, AI/브라우저 분기 유지 |

사각형 글자와 아이콘은 `sqrt(열×행 / 4)` 배율을 적용한다. 글자는 기본 34·최소 24·최대 56, 아이콘은 기본 36·최소 24·최대 72. 안쪽 여백은 16에 같은 배율·최소 12·최대 28. 사용자 시스템 글자 배율을 추가 적용한다. 기존 첫 사각형의 노랑은 최초 v2 전환 시 레몬 색상으로 저장한다. 이후 강조색은 순서와 무관하게 위젯에 유지된다.

홈 검색 미리보기 글자는 24, 실제 입력 글자는 20, 아이콘은 28에 `sqrt(열×행 / 4)` 배율(아이콘 최소 24)을 적용한다. 음성 터치 56, 전송 원 52를 유지한다. 홈의 검색 위젯을 누르면 입력·결과 화면으로 들어가며 저장된 배치를 변경하지 않는다. 입력 중에는 키보드와 결과를 위한 검색 화면을 사용하고 뒤로 가면 기존 홈 페이지로 돌아간다. 검색 위젯도 순서 이동·삭제·다시 추가를 지원한다.

Android 앱 사각형은 PackageManager의 실제 앱 아이콘을 표시한다. 아이콘 끄기 설정은 기능에 적용하며 앱 사각형의 앱 아이콘은 유지한다. iPad 앱은 등록한 URL을 실행하며 다른 앱의 아이콘 자동 추출은 지원하지 않는다. 앱 링크 등록에서 사진 선택기로 이미지를 고르면 128×128 PNG로 저장·표시하고, 선택하지 않으면 앱 기호를 표시한다.


### 홈의 빈 공간과 텍스트 터치 영역

홈의 빈 공간을 길게 누르면 전체 위젯 편집을 연다. 텍스트 바로가기에서 실제 입력 영역 밖의 나머지 배치 공간도 빈 공간으로 처리한다. 기존 위젯의 길게 누르기는 해당 위젯 편집을 유지하고, 검색·브라우저·데이지의 내부 조작과 외부 위젯의 짧은 탭·스크롤은 유지한다. Android 외부 위젯의 길게 누르기는 개별 편집을 연다. 빈 공간에서 연 전체 편집의 뒤로 가기는 홈으로 돌아오며 설정에서 연 전체 편집의 기존 복귀 경로는 유지한다.

텍스트 바로가기는 저장한 열·행과 전체 글자 표시 폭을 유지한다. 4×1·2×1 등 배치 크기와 관계없이 입력 영역은 글자 시작 쪽의 한 열 너비 × 88dp/pt이며 배치 높이의 가운데에 정렬한다. 탭·길게 누르기·접근성 실행과 개별 편집은 이 한 칸의 컨트롤에만 연결한다. 표시용 글자는 접근성에서 중복 읽지 않으며 나머지 면적을 눌러 앱을 실행하지 않는다. 기존 배치·순서·색·글자 크기 저장값은 변경하지 않는다. 설정 → 위젯 편집 경로도 유지한다.

## 편집·저장

앱·기능 위젯 또는 검색창을 길게 누르면 해당 위젯만 편집하는 화면으로 이동한다. 이때 뒤로 가기는 홈으로 돌아오며 길게 누르기로 실행 대상 앱을 열지 않는다. TalkBack 길게 클릭/VoiceOver 위젯 설정 동작도 제공한다. 런처 설정 → 위젯 편집은 전체 위젯을 편집한다. 각 위젯 카드에서 크기·색상·위/아래·제거를 선택한다. 실행 위젯은 사각형/이름만/앱 아이콘으로 전환한다. 검색 위젯을 삭제한 경우 전체 위젯 편집에서 다시 추가할 수 있다. 유형 전환은 사각형 2×2, 이름형 4×1, 앱 아이콘형 1×1로 초기화하고, 텍스트 바로가기는 공통 글자 크기를 사용한다. 새로 추가한 앱은 앱 아이콘형 1×1, 기능은 사각형 2×2다. 같은 실행 대상은 한 번만 추가한다.

기존 즐겨찾기와 홈 앱 예시를 최초 한 번 위젯 목록으로 복사한다. 처음 마이그레이션할 때 문서 작업·문서 스캔은 제외하지만 이후 추가 목록에서는 선택할 수 있다. 초기 앱 예시는 이름형으로 복사한다. 이후 앱을 자동 보충하지 않으며 빈 목록도 그대로 저장한다. 삭제된 Android 앱은 마지막 이름·사용 불가를 유지하고 사용자가 제거한다. 다른 두 테마의 즐겨찾기 데이터는 별도로 유지한다.

기존 전역 글자 크기는 ‘목록 글자 크기’로 표시하고 검색 결과·전체 앱 목록 등에 적용한다. 홈의 텍스트 바로가기는 별도 공통 글자 크기를 사용하고 나머지 유형은 면적 배율을 사용한다. 시계·상태는 기존 선택 표시를 유지하며 네 유형 크기 편집에는 포함하지 않는다. 하단 전체 앱·설정 도구막대는 격자 밖 고정이다.

## 접근성

타일·아이콘 위젯은 전체 면을 버튼으로 제공하며 텍스트 바로가기는 표시 폭과 분리한 한 칸의 입력 컨트롤을 사용한다. 앱 아이콘은 장식으로 중복 읽지 않는다. 크기·유형 선택에 선택됨 상태를 제공한다. 편집은 드래그 없이 버튼으로 조작한다. 설정·검색·화면 회전은 저장 순서를 바꾸지 않는다. 큰 글자는 행 높이와 페이지 수를 늘린다. 단일 줄 자체가 가용 화면보다 크면 그 줄만 한 페이지에 두고 자연 크기를 유지한 채 세로 스크롤한다. 실행 대상 이름의 접근성 텍스트와 위젯 설정 진입은 유지한다. 숨겨진 다른 페이지의 위젯은 화면 읽기 탐색 대상에서 제외한다.

Ratio 페이지는 손가락을 따라 좌우 이동하고 놓으면 감쇠된 스프링으로 정착한다(Android 감쇠 .92·강성 420, iPad 공통 페이지 띠/점 선택 spring .34초·감쇠 .92). 전체 앱·설정 등 화면 진입은 짧은 페이드와 0.97→1 확대, 앱 목록은 아래 56에서 올라오는 전환을 사용한다(Android 280ms, iPad spring .36초·감쇠 .92). Android 시스템 애니메이션 배율을 따르고 iPad 동작 줄이기에서는 이동·확대를 제거한다.

## 위젯 색상

공식 이름은 **타일 바로가기·텍스트 바로가기·아이콘 바로가기·통합 검색·이지 유튜브·이지 브라우저·데이지 플레이어**다. 앱과 기능은 바로가기의 실행 대상이며 별도 위젯 유형이 아니다. 저장 식별자와 기존 크기 규격은 유지한다.

전체 페이지 위젯 세 유형을 제외한 네 유형에서 기본 색상 또는 12색 중 선택한다. 텍스트 바로가기는 투명 배경을 유지하고 글자에 선택 색상을 적용한다(기본 흰색). 다른 세 유형은 선택 색상을 배경에 적용하고 글자·기능 기호는 #101010을 사용한다(12색 배경 대비 7:1 이상). 실제 앱 아이콘 원본은 유지한다. 색상 선택은 이름과 선택됨 상태, 체크 표시로도 제공한다(56 터치).

앱의 텍스트 바로가기는 추가로 ‘앱 아이콘 색’을 선택할 수 있다. 아이콘을 64×64로 샘플링하고 알파 128 미만과 RGB 모두 240 이상인 흰색 계열을 제외한다. RGB 채널을 각각 16단위로 묶어 가장 픽셀이 많은 구간의 평균 RGB를 글자 단색으로 사용한다. 동률은 RGB 구간 키가 작은 쪽을 택한다. 무늬·외곽선은 사용하지 않는다. Android는 설치된 앱의 실제 아이콘을 사용하고, iPad는 사용자가 등록한 아이콘 이미지가 있을 때만 옵션을 제공한다. 기능은 기본·12색을 사용한다. 아이콘 로딩 실패·이미지 누락은 저장된 단색 또는 기본 흰색으로 대체한다. Android 텍스트 바로가기의 키보드 포커스는 한 칸 입력 영역에 밝은 반투명 면으로 표시하며 글자 단색을 유지한다. 포커스 동안 앱 아이콘 추출색은 저장 단색 또는 기본색으로 대체한다. 색과 무관하게 실행 대상 이름은 화면 읽기에 한 번만 제공한다. 추출색을 임의로 밝게 바꾸지 않는다. 어두운 아이콘은 글자 대비가 낮을 수 있으며 기본 흰색·12색을 직접 선택할 수 있다. 유효 픽셀이 없으면 저장된 단색 또는 기본 흰색으로 대체한다.

`iconText`는 기본 false이며 기존 저장값에도 false로 해석한다. 12색·기본 선택은 자동 추출색을 해제하고, 앱 아이콘 색 선택은 기존 색을 실패 시 대체색으로 보존한다. 설정은 크기·순서·유형 변경 시 보존하며 자동 추출색은 텍스트 앱에서만 표시한다. 기존 iconText=true도 이 단색 추출 방식으로 표시한다.

ID `widget:browser`는 독립된 전체 페이지다. 기존 브라우저 탐색·임시 저장소 규칙을 유지하며 크기·배치·수명은 전체 페이지 위젯 절을 따른다.

## 데이지 플레이어 위젯

ID `widget:daisy`는 독립된 전체 페이지다. 기존 독서 화면과 저장소를 재사용하며 페이지 이탈 시 재생을 정지한다. 별도 전체화면 확장 없이 현재 페이지를 채운다. iPad는 앱의 내비게이션 스택 안에 별도 스택을 중첩하지 않고 선택한 도서 상태로 서재·독서를 전환한다. 독서 화면에는 서재로 돌아가기와 도서 제목·목차·검색·보기 설정을 위젯 안에 표시한다. 앱의 설정 경로는 변경하지 않는다.


이지 유튜브 영상 카드는 썸네일·제목·정보로 구성하며 카드 전체가 재생 버튼이다. 별도 “영상 보기” 문구는 두지 않는다. 썸네일 영역은 로딩 전부터 16:9 비율을 확보하며, 원본 사진이 늦게 준비되거나 실패하면 해당 영상의 기본 썸네일을 사용한다. 같은 경로에서 원본 피드가 가상화되어 사라져도 이미 불러온 카드와 이미지 노드·포커스·스크롤 위치를 유지한다(현재 경로 최대 120개). 실제 경로가 바뀌면 피드 캐시를 비운다. 숨겨진 원본 탭은 `textContent`로 찾아 실행하며 메뉴를 찾지 못하거나 이동하지 않으면 공개 유튜브 경로로 이동한다. 구독 영상이 없는 계정은 빈 구독 안내를 표시한다. 쇼츠 이전·다음 버튼은 원본 조작부가 늦게 준비되거나 상태가 바뀌어도 피드 이미지와 별개로 활성 상태를 갱신한다. 쇼츠는 원본 영상 ID와 공식 플레이어가 준비되면 큰 재생창을 열며 준비 전 별도 썸네일 카드를 표시하지 않는다.

영상 카드의 제목 아래에는 채널·조회수를 표시하고, 업로드 시점은 그 아래 줄에서 길이와 함께 표시한다(예: `2일 전 · 길이 12:34`). 상대 시점은 원래 공개 메타데이터에서 읽고, 길이는 공개 썸네일 배지에서 읽는다. 화면과 접근성 이름 모두 `길이`로 표기한다. 제목·채널 등 정보·길이를 카드 버튼 하나의 접근성 이름으로 합치고 이미지는 장식, 내부 글자는 중복 탐색에서 제외한다. 길이는 `12분 34초`처럼 읽으며 원본에 없는 길이는 추측하지 않는다. 홈·구독·검색·채널 목록의 초기 로딩은 카드·썸네일 자리 표시 없이 비어 있는 목록 영역의 중앙 인디케이터만 표시하고, 추가 로딩은 기존 카드·포커스·스크롤을 유지한 채 인디케이터만 표시한다. 불러오는 동안 `영상 더 불러오기` 버튼은 숨기고 중복 실행을 막는다. 스크린리더에는 하나의 상태만 알리며 동작 줄이기에서는 인디케이터의 움직임을 멈춘다. 12초가 지나도 결과가 없으면 안내와 다시 시도를 제공한다.

## 이지 유튜브 재생·채널·댓글

쇼츠 메뉴를 누르면 공개 `/shorts` 경로에서 현재 영상을 곧바로 큰 9:16 재생창으로 연다. 영상은 홈의 기본 여백과 재생창 내부 12px 여백을 유지한 가용 폭·높이에 9:16 비율로 최대한 맞춘다. 쇼츠 제목·별도 재생바/시간/배속·준비 중 인디케이터는 표시하지 않는다. 재생 실패 안내와 공식 플레이어 내부 조작은 유지하며 영상 아래에는 이전·다음 쇼츠 두 버튼만 제공한다. 버튼 공간은 처음부터 확보하고 로딩 중에는 표시·접근성 탐색에서 제외한다. 일반 영상 카드는 공개 `/watch?v=` 페이지로 이동해 16:9 재생창을 열며, 두 유형 모두 사용자의 선택 뒤 재생을 요청한다. 홈의 단순 방문·복귀만으로 재생을 시작하지 않는다. 자동 재생이 막히면 영상 안의 기본 재생 버튼을 안내한다.

재생창 위의 추천 복귀 버튼·시험판 배지는 없고, 별도 10초 뒤/앞·재생/일시정지·자막 크기·내부 탐색 버튼은 제공하지 않는다. 공식 iframe의 기본 조작은 접근성·키보드 탐색에 항상 열어 둔다. 일반 영상의 재생 위치 슬라이더와 시간은 유지하며 재생속도는 재생바 오른쪽에 `1×`·`1.5×` 형식의 텍스트 선택으로 표시한다. 별도 줄과 테두리·배경은 두지 않으며 최소 56px 터치와 접근성 이름 `재생속도`·옵션의 배율 이름을 유지한다. 시간은 그 아래에 표시한다. `재생 완료`와 속도 변경의 별도 상태 문구는 표시하지 않는다. 일반 영상·쇼츠는 초기 자막 모듈이 준비될 때 기본 꺼짐을 적용하고 별도 자막 버튼은 없다. 일반 영상에서 시스템 뒤로가기·접근성 탈출은 재생을 닫고 진입 전 웹페이지로 돌아간다. 쇼츠에서는 로딩·재생 상태 모두에서 큰 재생창을 닫고 유튜브 홈으로 돌아간다.

재생바 아래에는 실제 채널 로고(52px 원형)와 이름을 투명한 한 줄 버튼으로 표시한다. 평상시 테두리·배경색 없이 최소 64px 터치를 유지하고, 키보드 포커스 외곽선은 보존한다. 로고는 원본 소유자 영역의 공개 YouTube 이미지 URL에서 읽으며 장식으로 접근성 탐색에서 제외한다. 이미지가 없거나 실패하면 이름을 유지한다. 채널 이름은 실제 영상 페이지의 채널 링크를 검증해 해당 채널의 `/videos` 목록으로 이동한다. 아래에는 실제 원본 댓글 DOM의 작성자·본문을 카드 테두리·배경 없이 여백 30px로 구분해 처음 3개 표시하고 `댓글 더 보기`로 5개씩 늘린다. 더 보기 역시 투명한 밑줄 텍스트 버튼이며 최소 56px 터치를 유지한다. 추가 댓글은 원본 댓글 패널의 스크롤을 통해 불러온다. 댓글 작성·좋아요·구독 변경은 자동으로 실행하지 않는다. 불러오지 못했거나 댓글이 막힌 경우에는 상태 안내를 표시하며 예시 댓글이나 채널 이름으로 대신하지 않는다. 댓글·채널은 현재 웹 메모리 안에서만 사용하며 앱에 저장하거나 외부로 전송하지 않는다.


## 런처 공통 스타일

모든 홈 페이지와 검색 화면은 잉크 + 레몬 팔레트를 사용한다. 배경은 번들 숲 안개 사진(대체 바탕 #101C2D), 기본 타일·음성 버튼 면 #1C2D43, 글자 #F5F3E9, 강조 #E6EF87, 조작 경계 #7F93AB다. 일반 타일 모서리는 8dp/pt이며 평상시 테두리가 없다. 상단 스타일 이름·강조색 표시 줄과 비교용 복제 페이지는 두지 않는다. 저장한 일반 페이지·전체 페이지 위젯·순서·크기·ID는 그대로 사용한다. 각 원본 줄은 한 페이지에만 표시한다. 하단 탐색·페이지 점·포커스·최소 터치 영역은 유지한다.

위젯 편집에서 선택한 12색을 실제 홈 표시에도 적용한다. 사각형·아이콘형은 선택색 배경과 #101010 글자·기호를 사용하며, 텍스트형은 투명 배경과 선택색 글자를 사용한다. 기본 색상은 홈의 기본 면·글자를 따른다. 텍스트 앱의 아이콘 대표색 선택도 표시하며 실제 앱 아이콘 원본은 보존한다. 타일 제목은 기본 34·최소 24·최대 56, 아이콘형 이름은 18, 홈 검색 미리보기는 20, 실제 검색 입력은 20이며 시스템 글자 배율을 따른다.

구현: iPadOS `RatioExperience.swift`의 `RatioExperience`와 `RatioLauncherView`; Android `LauncherThemes.kt`의 `ratioHomeColors`, `LauncherScreen.kt`의 `RatioPagedRows`, `RatioHomeWidget`, `RatioSearchPreview`. 측정용 구성에서는 외부 위젯·웹·도서 화면을 생성하지 않는다. Android 외부 위젯은 저장된 원래 호스트 ID로만 표시한다. iPadOS에서는 다른 앱의 Android 위젯을 호스팅하지 않는다.

### 홈 배경 사진

모든 홈·전체 페이지 위젯·검색 화면은 고정된 밝은 산 사진을 사용한다. iPadOS는 `RatioBlueMist`, Android는 `launcher_ratio_blue_mist.jpg`를 사용한다. Crop·1.06배 확대·10dp/pt 흐림·검정 8%와 아래쪽 최대 10% 추가 막을 적용하며 안전 영역 밖까지 이어진다. 숲 사진 자산은 보존한다. 사진은 장식으로 스크린리더·터치 탐색에서 제외한다. 타일 모서리 8·선택색·기본 면·글자 팔레트·저장된 배치는 그대로 사용한다. 선택·편집·전체 앱·설정 화면은 기존 단색 배경을 사용한다. 출처·라이선스는 각 플랫폼의 wallpaper-license 파일에 보관한다.

### 웹 위젯 로딩과 연속 페이지 이동

웹 위젯도 일반 홈과 같은 페이지 이동 경로를 사용한다. 가로 방향을 인식한 뒤에는 실제 웹 화면과 이웃 페이지가 손가락을 따라 연속 이동하고, 놓으면 동일한 스프링으로 한 페이지에 정착한다. 짧은 이동·취소는 원래 페이지로 돌아가며 처음·마지막 페이지 바깥은 이동량을 25%로 줄인다. 넘기는 동안 원래 웹 화면을 제거하지 않고, 현재 페이지와 가까운 웹 세션을 미리 준비한다. 비활성 페이지는 미디어를 정지하고 접근성 탐색에서 제외한다. 하단 페이지 점과 iPad VoiceOver의 페이지 스크롤 동작도 유지한다. iPad는 일반 홈과 웹 위젯을 같은 가로 페이지 띠로 배치하며 동작 줄이기에서는 정착 애니메이션을 생략한다.

브라우저의 네이티브 진행 막대는 웹 화면 상단에 겹쳐 표시하므로 로딩 전후 웹뷰 높이는 유지된다. 같은 팔레트·확대 값은 스타일을 다시 만들지 않으며 초기 DOM 구성 완료 때만 전체 색상 분류를 한 번 보완한다. 일반 웹 문서에는 폭 보정 스캔·준비용 본문 숨김을 적용하지 않는다. 유튜브는 본문 생성 때 검색·메뉴 위치를 먼저 준비하며 초기 목록 로딩에는 카드 모양을 만들지 않는다. 로딩 영역은 높이 `clamp(180px,36vh,360px)`의 빈 공간에 인디케이터 하나만 중앙 표시하고, 준비된 첫 목록은 180ms로 나타낸다. 추가 로딩은 기존 목록을 유지하며 동작 줄이기에서는 페이드를 생략한다. 유튜브의 네이티브 중앙 로딩 표시는 Google 로그인 등 외부 인증 문서에만 사용한다.

## 런처 날씨·타이머 전용 위젯과 검색 줄

`widget:weather`·`widget:timer`는 `위젯 추가`의 `VisionCraft 위젯` 목록에서 한 개씩 선택한다. 앱·기능 목록·일반 검색 결과·실행 라우트에는 등록하지 않는다. 다른 위젯의 순서·색·크기를 자동 변경하지 않으며 추가는 사용자가 한다. 날씨와 타이머의 기본 크기는 2×2다. 날씨는 2×2/2×3/2×4/4×3/4×4, 타이머는 2×2/2×3/2×4/4×3/4×4를 선택한다. 기존 기본 크기의 날씨 2×4·타이머 4×4는 최초 한 번 2×2로 옮기며 다른 크기·순서·색은 유지한다. 일반 바로가기 유형으로 바꾸지 않는다. 타일과 같은 모서리 8·기본 잉크 면을 사용하고 12색 배경을 선택하면 #101010 글자를 사용한다. 제목 18, 기온 40·시간 72, 본문 16 이상이며 시스템 글자 크기를 따른다. 날씨 새로고침은 48, 타이머 재생·설정 아이콘은 40과 최소 높이 64의 큰 버튼을 사용한다. 작은 화면·큰 글자에서 넘치는 내용은 내부 스크롤로 읽는다.

날씨는 현재 위치로만 표시하며 지역 검색·선택 화면은 없다. 보이는 페이지에서 위치 권한을 요청하고 30분마다 오래된 자료를 갱신하거나 수동 새로고침할 때 위치를 한 번 확인한다. Android는 대략적 위치 권한과 Fused/Network 제공자, iPad는 사용 중 위치 권한과 1km 정확도 요청을 사용한다. 위치 대기는 최대 20초이며 백그라운드 위치 구독은 없다. OS 지오코더로 지역 이름을 표시하고 이름을 얻지 못하면 현재 위치로 표시한다. 소수 둘째 자리로 반올림한 좌표를 Open-Meteo 예보에 전송한다. 위치·권한이 없으면 안내하며 이전 수동 지역으로 대체하지 않는다. 현재 기온·체감·당일 최고/최저·날씨 코드·갱신 시각·출처를 표시한다. 30분 미만 자료는 위치 재조회 없이 재사용하고 실패 시 6시간 미만의 이전 자료와 시각·오류를 함께 표시한다.

타이머 홈은 시간과 큰 재생·설정 아이콘 두 개를 제공한다. 실행 중 재생은 일시정지로 바뀌고 설정은 숨기며 일시정지는 가로 전체를 채운다. 일시정지 후에는 남은 시간을 보존하고 설정이 다시 나타난다. 설정은 별도 시간 설정 창을 열어 1~180분·5/10/25분·1분 증감 또는 알람 시각을 고른 뒤 적용한다. 적용은 정지 상태를 초기화하며 재생 버튼으로 예약을 시작한다. 알람 모드는 지정한 지역 시각의 다음 한 번을 예약하며 이미 지난 시각은 다음 날을 선택한다. 완료는 시스템 알림 한 번으로 전달하며 반복 울림·무음/집중 모드 우회를 제공하지 않는다. 알림 권한이 없으면 예약하지 않고 허용 방법을 안내한다. Android는 정확한 알람 권한도 먼저 확인하며 별도 승인 후 사용자가 다시 시작한다. 페이지 이탈·프로세스 종료에도 OS 예약을 사용하고, 일시정지·초기화·취소·위젯 제거 때 예약과 전달된 알림을 지운다. Android는 재부팅 후 아직 남은 예약을 복원하며 취소/교체한 오래된 알림은 실행하지 않는다. 재실행 후 종료 시각·일시정지 잔여 시간·선택 분·모드를 복원한다. 시간 숫자는 스크린리더에 분·초 남음으로 읽고 매초 강제 낭독하지 않는다.

홈 검색 미리보기와 입력 화면은 유튜브·브라우저와 같은 모서리 32의 둥근 검색창이다. 기본 높이 88, 왼쪽 여백 20·오른쪽/위아래 6, 검색 기호 28, 기본 글자 20, 음성 버튼 56을 사용한다. 기본 면은 #101010의 75% 불투명도이며 밝은 1px 테두리(70%)를 두고 별도 밑줄·음성 버튼 면은 표시하지 않는다. 선택색은 저장값을 유지해 면에 적용하고 어두운 글자·기호·테두리로 읽는다. 입력 중에는 기존 52 크기 위쪽 화살표 전송 버튼을 제공한다. 검색·음성·키보드·AI/브라우저 분기·길게 눌러 편집과 포커스 표시, 저장 크기·순서는 유지한다.

구현: iPad `RatioUtilityWidgets.swift`, `RatioLauncherView.homeWidget`; Android `LauncherUtilityWidgets.kt`, `LauncherTimerReceiver`, `RatioSearchPreview`.

### 유튜브 구독 빈 화면·쇼츠·상단 검색

구독 목록이 비었음이 원본 화면에서 확인되면 구독 영상 캐시와 목록을 비우고 `영상 더 불러오기`를 숨긴다. 중앙에 장식용 구독 아이콘(96px 원 안의 64px 선 아이콘), 제목 `아직 구독 영상이 없어요`, 짧은 안내를 여백으로 구분해 표시한다. 바깥 카드 테두리는 없으며 제목은 24~30px, 안내는 19px다. 하나의 polite 상태로 알리고 아이콘은 중복 낭독하지 않는다. 로딩·통신 실패와 확인된 빈 목록을 구분한다.

검색은 별도 메뉴·입력 화면 없이 영상 목록 상단의 입력칸과 검색 버튼으로 제공한다. 검색창 아래에는 홈·구독·쇼츠 세 메뉴가 있으며 구독·검색 결과·채널 목록에서도 같은 입력칸을 사용한다. 입력칸의 연결된 접근성 라벨은 유지한다. 원본 검색 폼이 아직 준비되지 않았으면 입력한 검색어를 인코딩한 공개 `/results?search_query=` 경로로 이동한다. 쇼츠 진입 준비 중에는 기존 검색·메뉴·목록을 유지하며, 플레이어가 준비되면 검색창을 포함한 기존 화면을 180ms로 사라지게 한다. 로그인 화면에서는 검색창을 표시하지 않는다.

쇼츠는 작은 썸네일 카드·별도 목록·흰 테두리 없이 큰 9:16 공식 플레이어 하나로 표시한다. 기본 위젯 여백과 재생창 안쪽 12px를 유지하며, 아래 두 버튼의 높이와 간격 14px를 뺀 화면 안에 영상을 맞춘다. 쇼츠 아래에는 `이전`·`다음` 두 버튼만 두고 별도 채널·댓글·재생바·제목은 표시하지 않는다. 버튼은 최소 56px이고 준비 전·버퍼링 중에는 자리를 유지한 채 시각·접근성 탐색에서 제외한다. 재생 가능 상태에서만 나타나며 원본 이전/다음 이용 가능 상태를 따른다. 쇼츠 진입은 원본 메뉴의 페이지 내 이동을 우선 사용하고, 플레이어 준비 전까지 기존 검색·메뉴·목록을 유지한다. 공식 플레이어 준비 이벤트 뒤에만 포커스·접근성 탐색을 플레이어로 옮기고 기존 화면과 180ms로 교차 전환한다. 동작 줄이기에서는 페이드를 생략한다. 이전·다음 쇼츠는 동일한 공식 iframe에서 영상 ID만 바꾸며 화면을 닫았다 다시 만들지 않는다. 전환 대기 중에는 현재 재생을 멈추고 아래 버튼을 숨기며 새 영상 재생 준비 뒤 복원한다. 이전 영상이 다시 열리지 않게 하는 ID 제한은 유지한다. 시스템 뒤로가기·접근성 탈출은 로딩 중에도 쇼츠를 종료하고 유튜브 홈(`/`)으로 돌아간다. 일반 영상의 채널·댓글·재생 위치·속도와 뒤로가기는 기존 규격을 유지한다.

### 위젯 추가 화면

편집 화면에서 추가 동작은 `위젯 추가` 버튼 하나로 제공한다. 진입하면 `VisionCraft 위젯`·`모든앱`을 나란히 표시하고 VisionCraft 탭을 기본 선택한다. VisionCraft 위젯은 기능·날씨·타이머/알람·검색·이지 유튜브·이지 브라우저·데이지를 한 목록으로 표시한다. 앱/기능 구분 탭은 두지 않고 `앱 바로가기` 항목에서만 앱 선택 하위 화면으로 이동한다. 앱을 고르면 기본 1×1 아이콘 바로가기로 추가하며 실행하지 않는다. 이미 추가한 항목은 추가됨 상태를 표시하고 중복 저장하지 않는다. 추가에 성공하면 추가 화면·편집·개별 설정 창을 닫고 해당 위젯이 놓인 홈 페이지로 이동한다. 위젯 ID를 실제 행 높이와 페이지 배치에 대응시켜 찾으며 앱 바로가기 대상은 실행하지 않는다. Android 외부 앱 위젯은 제공자 승인·설정이 완료된 뒤 같은 동작을 수행하고 취소·실패 시 이동하지 않는다. 목록 안에서 검색하며 하위 앱 목록의 뒤로/완료는 VisionCraft 위젯 목록, 최상위 추가 화면의 뒤로/완료는 편집으로 돌아간다. 홈에서 편집에 진입한 복귀 맥락도 유지한다.

`모든앱`은 Android 설치 앱의 위젯 미리보기·제공자 추가 승인 경로를 직접 표시한다. 별도의 `다른 앱 위젯 추가` 버튼은 편집에 두지 않는다. iPadOS는 외부 앱 위젯 호스팅이 불가능하므로 같은 탭 안에서 시스템 홈에 위젯을 추가하는 안내를 표시한다. iPad의 `앱 바로가기`는 기존에 등록한 앱 링크를 사용한다. 날씨·타이머를 일반 실행용 앱/기능 목록에 추가하지 않고 위젯 추가의 VisionCraft 목록에만 포함한다. 기존 위젯의 크기·색·순서·저장 형식은 유지한다.

구현: Android `LauncherScreen`의 widget_add/widget_apps, iPad `RatioLauncherView.widgetAddCatalog`·`widgetAppShortcuts`.

### 유튜브 자막 기본 끔·채널과 댓글 구분

일반 영상과 쇼츠 모두 새 플레이어의 준비·자막 모듈 변경·최초 재생 이벤트에서 자막을 기본 꺼짐으로 요청한다. `cc_load_policy=0`만으로 강제 꺼짐을 보장하지 않으므로 실행 중 노출되는 모듈 API의 자막 트랙 비우기·자막 모듈 해제를 함께 사용한다. 트랙 옵션은 실제로 노출될 때만 설정하며 프레임 내부 DOM·로그인·계정 설정을 읽거나 바꾸지 않는다. 모듈 해제가 확인되면 초기 처리를 끝내고, 최대 4회·최초 재생 후 8초 범위로 제한해 반복 이벤트와 사용자의 이후 직접 조작을 방해하지 않는다. 모듈 기능이 없는 플레이어는 기본 자막 꺼짐 요청만 유지한다. 영상 픽셀에 포함된 글자는 변경하지 않는다.

일반 영상의 채널 행은 로고 52px·이름 23px 굵게·보조 문구 `채널 영상 보기` 14px·장식용 꺾쇠로 구성한 투명 버튼이다. 최소 높이 80px와 연결된 접근성 이름을 유지한다. 댓글은 별도의 `댓글` 제목(18px)과 유튜브 원본 헤더·댓글 진입 버튼·현재 영상의 공개 페이지 데이터에서 읽은 전체 댓글 수(14px) 아래 본문을 20px/행간 1.7로 먼저 표시하고, 작성자는 그 아래 14px의 보조색으로 구분한다. 댓글 사이에는 여백 30px를 두며 카드 테두리·채움색은 사용하지 않는다. 원래 댓글 본문·작성자와 더 보기 동작은 유지한다. 쇼츠 아래 버튼의 보이는 이름과 접근성 이름은 `이전`·`다음`이며 다른 쇼츠 재생 동작과 로딩 중 숨김은 유지한다.

### 홈 복귀와 위젯 편집 선택창

위젯 편집은 현재 값이 표시되는 `형태`·`크기`·`색상` 가로 전체 행으로 구성한다. 각 행을 누르면 해당 선택창이 열리고, 선택을 저장한 뒤 닫힌다. 앱 아이콘 대표색도 색상 선택창에 포함한다. 형태는 일반 바로가기, 크기는 텍스트형을 제외한 크기 조절 가능한 위젯, 색상은 자체 위젯에 제공한다. 전체 페이지 위젯은 고정 안내만 표시한다. 위로·아래로·삭제는 편집 카드에 그대로 둔다. `위젯 추가` 버튼은 편집 화면 가로 전체를 채운다.

런처 화면에서 리모컨 홈을 누르면 편집·검색·선택창을 닫고 첫 페이지로 돌아간다. 런처 밖에서는 기존 앱 홈으로 이동한다. iPadOS 시스템 홈 버튼은 앱이 가로챌 수 없으며 다른 앱 위젯도 앱 내부에 호스팅할 수 없다.

### 회전과 낮은 화면의 런처 배치

회전·창 크기 변경 시 현재 페이지의 첫 위젯을 새 페이지 구분에서 찾아 같은 위젯이 계속 보이게 한다. 페이지 번호가 달라져도 유튜브·브라우저의 세션과 표시 뷰를 유지하며 회전으로 홈 복귀나 재탐색을 요청하지 않는다. 전체 페이지 위젯은 새 안전 영역 안의 가용 폭·높이를 사용한다. 일반 위젯은 높이 제한 없이 자연 높이를 먼저 측정해 페이지를 나누고, 한 줄이 화면보다 크면 해당 줄을 한 페이지에 놓아 세로 스크롤한다. 글자·버튼을 화면 높이에 맞춰 축소하거나 잘라내지 않는다. 저장한 순서·열·행·색은 바꾸지 않으며 회전 중 가로 드래그는 취소한다.

### 유튜브 목록의 물결 인디케이터

초기 로딩은 144×80px의 장식용 물결과 아래 17px 상태 문구를 중앙에 표시한다. 강조색의 가는 SVG 곡선 세 겹이 3.6·4.8·6초 주기로 서로 다른 방향과 속도로 흐른다. 한 주기 144 단위를 반복한 경로로 이음새를 맞추며 양끝은 점차 투명해진다. 바탕에는 정적인 은은한 빛만 두고 카드·테두리 패널은 추가하지 않는다. 추가 로딩은 80×48px의 작은 물결을 상태 문구 옆에 표시한다. CSS 위치 이동만 애니메이션하며 별도 타이머·캔버스·영상·블러 필터는 사용하지 않는다. 숨김·동작 줄이기에서는 정적인 물결을 표시하고 강제 색상에서는 시스템 글자색 선을 표시한다. 상태 문구·접근성 알림·기존 로딩 영역 높이는 유지하며 쇼츠에는 별도 로딩 표시를 추가하지 않는다.

### 홈 시스템 바

모든 홈 페이지·전체 페이지 위젯·검색 화면에서 사진 배경이 상단 상태바와 하단 시스템 영역까지 이어진다. Android는 두 시스템 바 배경·하단 구분선을 투명하게 하고 시스템 대비 막을 끈다. 상태·탐색 아이콘은 밝게 표시하며 콘텐츠·버튼은 안전 영역 안에 둔다. iPad는 기존 사진 배경의 안전 영역 확장을 유지한다.

### 현재 위치 날씨와 2×2 기본 크기

날씨·타이머는 2×2로 추가한다. 작은 위젯에는 시간과 큰 재생·설정 버튼만 표시하고 모드·시간 조절은 별도 설정 창에서 제공한다. 지역 선택은 없고 날씨는 현재 위치만 사용한다. 위치 권한·서비스가 없으면 안내와 재시도/설정 경로를 제공한다. 세부 위치·캐시 규격은 `08_ratio_home_grid_proposal.md`를 따른다.

### 유튜브·브라우저 공통 리보 테마

유튜브 로그인 안내·플레이어 바깥 조작은 기존 런처 리보 테마를 유지한다. 브라우저는 독립 실행·홈 위젯 모두 라이트/다크 두 모드를 사용하고 다크를 기본 선택한다. 홈 브라우저의 다크 모드는 이전의 어두운 숲 사진 배경 위에 투명한 캔버스와 흰 글씨를 사용한다. 일반 홈 페이지는 밝은 산 사진을 유지하며 이지 유튜브는 어두운 숲 사진을 사용한다. 주소창·도구·메뉴·웹 콘텐츠·구글 간단히 보기도 선택 모드의 색을 따른다. 유튜브 목록·로그인·플레이어의 별도 색 규격은 유지한다.

### 유튜브 홈 영상 목록 새로고침

홈 추천 목록의 `지금 불러온 추천 N개` 문구 대신 `영상 목록 새로고침` 버튼을 표시한다. 기존 안내 위치에 투명 바탕·밑줄·18px 글자·최소 높이 56px의 글자 너비 버튼으로 제공한다. 누르면 유튜브 홈 원본 문서를 다시 불러와 카드 캐시와 목록을 새로 구성한다. 새로고침 진행 중 중복 실행을 막고 로딩을 안내한다. 로그인은 기존 웹 저장소를 유지하며 구독·검색·채널 목록의 결과 안내와 추가 로딩은 유지한다. 버튼은 홈에만 표시하고 로그인 전·목록 로딩 중에는 비활성화한다. 기존 오류 메시지는 상태 영역으로 계속 제공한다.

### 날씨·타이머 요약과 큰 조작 버튼

2×2 기본 크기에서 여백은 12, 간격은 6이다. 긴 지역명은 두 줄과 말줄임으로 표시하며 접근성에는 원래 이름을 유지한다. 날씨는 지역명 20·기온 56·상태 22로 표시하고 새로고침은 오른쪽 아래 지름 56·아이콘 28의 원형 버튼이다. 상태 아래에 16 크기의 마지막 갱신 시각을 표시한다. 기온·상태를 누르면 체감·최저/최고·갱신 시각·출처의 상세 창을 연다. 타이머는 제목 없이 72 크기 고정폭 시간을 크게 표시한다. 오른쪽 아래에 지름 56·아이콘 28의 원형 재생/일시정지와 시간 설정 버튼을 간격 8로 나란히 놓는다. 설정 버튼은 재생 중에도 표시하며 적용하면 기존 타이머를 취소하고 새 설정으로 바꾼다. 알람 종류는 시간의 접근성 이름에 포함하고 종료 안내·오류는 별도로 유지한다. 시간 숫자는 한 줄을 유지하고 아주 큰 글자에서 가로 스크롤하며 시스템 글자 배율을 줄이지 않는다. Android 기온은 68sp·타이머 시간은 88sp 행간, 18sp 본문은 24sp, 16sp 본문은 22sp 행간을 명시한다. iPad의 시간 설정·날씨 상세 창은 고정 다크 면과 밝은 글자·조작 색을 사용해 선택한 위젯 색과 독립적으로 읽히게 한다. 위젯 색·크기·순서 편집은 길게 누르기와 화면 읽기의 위젯 설정 동작, 기존 전체 위젯 편집에서 제공한다.

### 브라우저 홈의 검색·음성·즐겨찾기

구글 기본 홈(`/`·`/webhp`)에서는 네이티브 주소창·도구 줄을 표시하지 않는다. 기본 검색은 구글만 사용하며 일반 페이지와 검색 결과에서는 기존 주소창·도구가 유지된다. 독립 실행의 닫기와 시스템 뒤로가기·접근성 탈출은 유지한다. 검색 입력은 브랜드명 없이 `검색`이며 통합 검색창과 같은 최소 56px 음성 버튼·입력 후에만 나타나는 52px 위쪽 화살표 전송 버튼으로 구성한다. 좁은 폭에서도 버튼은 최소 48px다. URL 또는 도메인을 입력하면 해당 HTTPS 사이트로 이동하고 일반 문장은 공개 구글 `/search?q=`로 이동한다. `javascript:`·`file:`·`data:` 등은 실행하지 않고 오류를 표시한다. 키보드 검색도 같은 처리를 사용한다.

음성 버튼은 `rivo-browser://voice`라는 값 없는 동작 링크를 사용한다. 네이티브는 활성 웹뷰의 HTTPS 구글 홈/검색 결과 또는 이지 유튜브 페이지에서 온 상위 프레임 요청만 처리한다. 유튜브 인증·임베드 문서는 제외한다. Android는 앱·기능 검색과 같은 시스템 음성 입력 화면, iPad는 같은 `STTManager`의 기기 내 인식을 사용한다. 결과는 네이티브 주소/검색 처리에 전달하며 원래 웹 검색 입력이나 인증 정보를 읽지 않는다. 취소·실패를 처리하고 iPad는 화면 이탈·백그라운드 진입 시 자신이 시작한 녹음을 정지한다.

즐겨찾기 네이버·다음·유튜브·위키백과는 사이트별 컬러 면 72px·모서리 24 안의 로컬 벡터 기호 48px 아래 이름 18px를 가운데 정렬한다. 즐겨찾기 목록의 칸은 왼쪽부터 배치한다. 큰 카드 면·도메인·이동 화살표는 두지 않는다. 투명 링크는 최소 높이 136, 간격 12, 검색창 전체 폭을 사용하며 기본 4열·480px 이하 2열이다. 키보드 포커스는 3px 외곽선으로 표시하고 호버는 3px 상승하며 동작 줄이기에서는 정지한다. 기호는 장식으로 접근성 중복 읽기를 막고 외부 파비콘 요청 없이 기존 네 링크의 목적지를 유지한다. Browser 로고·검색창·즐겨찾기 영역을 세로 중앙에 배치하며 즐겨찾기 항목은 왼쪽 정렬한다. 내용이 길면 세로 스크롤한다. 원본 구글의 인증·동의·보안 문자·미인식 화면으로 복귀하는 규격은 유지한다.

### 유튜브 목록 팔레트와 통합 검색창

유튜브 홈·구독·검색·채널 목록의 기본 팔레트는 밝은 바탕 `#F5F3EE`·흰 면·글자 `#252B28`·보조 글자 `#4C5D54`·초록 강조 `#17644E`·경계 `#69786F`, 어두운 바탕 `#101714`·면 `#1B2821`·글자 `#F1F5F2`·보조 글자 `#BCCDC2`·민트 강조 `#A8DEC0`·경계 `#9BAFA2`다. 위젯은 어두운 목록 색과 투명 캔버스를 유지한다. 목록의 물결 인디케이터는 위젯·어두운 화면에서 리보 테마의 연한 노란 강조색, 독립 밝은 화면에서 청회색 `#405A7A`를 사용하며 빛 번짐도 같은 색이다. 영상 재생창과 로그인 안내는 리보 테마를 유지한다. 영상 카드는 화면 모드·위젯 여부와 관계없이 옅은 회색 면 `#D1D5DB`·진한 글자 `#252B28`·보조 글자 `#4C5D54`·경계 `#69786F`·포커스 `#17644E`를 사용한다. 썸네일 아래 제목·채널·시점·길이도 이 카드 색을 따른다.

유튜브·브라우저의 웹 검색창은 런처의 실제 앱·기능 실행 검색창과 같은 모서리 32·최소 높이 88·검정 75% 면·밝은 1px 경계·20px 입력 글자·왼쪽 20/오른쪽 6px 여백을 사용한다. 검색 기호를 따로 두지 않으며 오른쪽 마이크는 56px로 항상 표시한다. 빈 입력에서는 전송 버튼을 숨기고, 한 글자 이상 입력하면 마이크 왼쪽에 강조색 원형 52px·밝은 1px 테두리·28px 위쪽 화살표를 표시한다. 공백만 입력하면 전송은 비활성화하고 키보드 검색도 유지한다. 검색어·결과 변경 때문에 입력 노드와 포커스를 재생성하지 않는다. 브라우저의 라이트 모드를 선택하면 구조는 유지하고 선택 팔레트에 맞는 글자·면·경계를 적용한다. 유튜브 입력은 `영상 검색`, 원형 전송은 `검색어 전송`, 마이크는 `음성 검색`으로 읽는다. 음성 입력 결과는 유튜브에서는 공개 `/results?search_query=`로, 브라우저에서는 기존 URL/구글 검색 처리로 보낸다.

### 날씨 일러스트·외부 위젯·브라우저 즐겨찾기

날씨 기온 옆에 64dp/pt 컬러 벡터 일러스트를 표시한다. 맑음·구름·비·눈·안개·뇌우 코드를 실제 상태와 맞추며 노랑 해·밝은 구름·파랑 강수·노랑 번개를 사용한다. 그림은 장식으로 화면 읽기에서 제외하며 상태 텍스트는 유지한다. 로컬 Canvas로 그려 이미지 다운로드나 새 권한이 없다. Android 외부 위젯은 이름·설정 도구줄 없이 전체 영역을 사용하며 제공자 최소/최대 크기 계산에서도 도구줄을 빼지 않는다. 편집은 길게 누르기와 접근성 동작·전체 편집으로 제공한다. iPad는 외부 위젯 호스팅이 지원되지 않아 해당 변경이 없다. 브라우저 홈 즐겨찾기는 사이트별 색의 72px 아이콘 면·48px 벡터·18px 이름을 사용하고 도메인·화살표·큰 카드 면은 제거한다.

### 런처 홈 검색창 통일

홈 검색 미리보기와 입력 화면은 유튜브·브라우저와 같은 모서리 32의 둥근 검색창이다. 기본 높이 88, 왼쪽 여백 20·오른쪽/위아래 6, 검색 기호 28, 기본 글자 20, 음성 버튼 56을 사용한다. 기본 면은 #101010의 75% 불투명도이며 밝은 1px 테두리(70%)를 두고 별도 밑줄·음성 버튼 면은 표시하지 않는다. 선택색은 저장값을 유지해 면에 적용하고 어두운 글자·기호·테두리로 읽는다. 입력 중에는 기존 52 크기 위쪽 화살표 전송 버튼을 제공한다. 검색·음성·키보드·AI/브라우저 분기·길게 눌러 편집과 포커스 표시, 저장 크기·순서는 유지한다.

### Browser 홈과 즐겨찾기 추가

브라우저 기본 홈은 `Browser` 영문 로고(38~56px, 굵기 600, 자간 -2px, 작은 장식 점)·검색창·즐겨찾기를 하나의 영역으로 구성해 가용 웹 높이의 세로 중앙에 놓는다. 로고와 검색창은 가운데, 즐겨찾기 칸은 왼쪽부터 배치하고 각 칸의 아이콘 아래 이름은 가운데 정렬하며 검색창과 같은 전체 폭을 사용한다. 내용이 길거나 키보드가 열리면 세로 스크롤한다. 즐겨찾기 목록 마지막의 점선 테두리 `추가` 아이콘은 앱의 웹 주소 입력창을 연다. 이름 입력은 요구하지 않고 추가 중 사이트 정보를 가져오는 진행 상태를 표시한다. HTTPS 주소·이름을 저장한 사용자 즐겨찾기는 최대 24개이며 재실행에도 유지한다. 같은 주소를 다시 추가하면 이름을 갱신한다. 사용자 항목은 페이지의 og:site_name·application-name·og:title·title 순서로 이름을 정하고, apple-touch-icon·icon·favicon.ico 순서의 이미지를 96px 이하 PNG로 저장해 72px 면 안에 48px로 표시한다. 정보가 없거나 접근에 실패하면 도메인 이름과 이름 첫 글자의 로컬 기호를 사용하며 기본 네 사이트 링크는 유지한다.

일반 위젯 추가는 마지막 홈에서 측정한 실제 줄 높이·페이지 가용 높이·줄 사이 간격을 사용한다. 현재 페이지의 남는 열에 들어가고 줄 높이 증가도 수용할 수 있는 자리를 먼저 선택하며, 없으면 같은 페이지에 새 줄을 넣을 위치를 확인한다. 삽입 후의 줄 묶음·높이·페이지를 다시 계산해 현재 페이지의 기존 항목과 새 항목이 함께 들어가는 후보만 사용한다. 현재 페이지에 맞는 자리가 없으면 다른 일반 페이지를 확인하고, 모두 부족하거나 측정 정보가 없으면 첫 전체 페이지 위젯 앞에 추가한다. 기존 항목의 상대 순서·크기·색은 유지하며 새 항목만 선택한 위치에 삽입한다. 앱 자체 위젯과 Android 외부 앱 위젯 모두 이 기준을 사용하고, 외부 위젯은 승인·설정 성공 후 배치를 확정한다. 추가가 성공하면 편집 화면을 닫고 실제 추가된 위젯의 페이지를 표시한다. 기존 전체 페이지 뒤의 날씨·타이머는 최초 한 번 일반 홈 영역으로 옮기며 이후 사용자 순서를 보존한다.

위젯 추가 성공 문구는 홈이나 추가 화면에 별도로 표시하지 않는다. 추가 목록의 `추가됨` 상태와 오류·취소 안내는 유지한다. 브라우저 즐겨찾기는 왼쪽부터 배치하는 격자 안에서 각 항목 폭 112px(좁은 칸에서는 칸 폭 이하), 아이콘과 아래 이름을 같은 중심에 정렬하며 긴 이름은 줄바꿈한다.

날씨·타이머는 일반 네모 버튼 타일과 같은 열 너비·행당 88 및 사이 간격 12(2행 기본 높이 188)를 사용한다. 같은 줄의 버튼 타일이 긴 이름·큰 글자로 더 높아지면 날씨·타이머의 바깥 면도 그 줄의 높이에 맞춘다. 내부의 큰 글자·조작 버튼·스크롤, 저장된 열·행·선택색은 유지한다.

영상 댓글 수는 원본의 전체 댓글 수를 사용하며 천·만·K·M 등 원본의 축약 표기는 유지한다. 처음 보여주는 3개와 더 보기로 늘린 목록 길이를 전체 수로 표시하지 않는다. 전체 수를 읽지 못했지만 댓글 본문이 있으면 숫자를 생략하며, 로딩·사용 불가·불러오기 실패 안내는 유지한다. 읽은 전체 수는 해당 영상을 닫을 때까지 보존한다.

### 데이지 위젯의 본문 유지와 메모리

데이지는 최초 방문 뒤 같은 런처의 홈 페이지 이동 동안 선택한 책과 독서 화면·정확한 스크롤을 유지한다. 숨은 페이지는 터치·접근성 탐색에서 제외한다. 이미 재생 중이면 홈 페이지 이동에도 이어 재생하고, 멈춘 상태로 이동하거나 앱이 배경으로 가면 유휴 오디오 재생 자원을 해제한다. 앱 배경에서는 재생을 일시 정지한다. 책 변경·서재 복귀·위젯 제거·런처 종료 시 기존 독서 세션을 정리한다.

내장 웹 본문은 현재 화면과 앞뒤 약 두 화면의 블록만 렌더링한다. 멀어진 블록은 높이를 보존한 빈 껍질과 가벼운 HTML 문자열로 남기고 자손·이미지 노드를 제거하며, 스크롤·목차·검색·재생 위치 이동 때 복원한다. 표·목록·그림 묶음은 원래 구조를 보존하는 단위로 유지하며 블록이 큰 경우 화면 수보다 더 남을 수 있다. 키보드 포커스·선택 텍스트·재생 강조 블록은 제거하지 않는다. TalkBack/VoiceOver 사용 중에는 읽기 순서와 접근성 포커스를 위해 블록 제거를 끄고 본문을 복원한다. iPad의 일반 텍스트 보기는 기존 현재 장의 LazyVStack을 유지한다.

메모리 부족 시 다른 홈 페이지 또는 앱 배경에 있는 비재생 데이지 본문을 해제하고 책·읽던 위치를 보존한다. 다음 방문에서 기존 진행 저장소로 복원하며 이 복원만으로 자동 재생하지 않는다. 일반 페이지 이동에는 파일을 다시 열거나 스크롤을 재설정하지 않는다. 목차·검색용 텍스트와 인덱스는 화면 블록과 별도로 유지한다. 실제 메모리 절감량은 기기에서 측정하지 않았다.

즐겨찾기 메타데이터는 추가할 때 HTTPS로만 조회하며 웹뷰의 로그인 쿠키·인증정보를 사용하지 않는다. 전체 조회 예산은 12초이며 HTML은 256KiB, 아이콘은 512KiB까지 읽고 원본 스크립트는 실행하지 않는다. 아이콘은 로컬 PNG 데이터로 저장해 홈을 열 때마다 사이트에 다시 요청하지 않는다. 추가 취소 후에는 항목을 저장하지 않는다. 기존 아이콘 없는 즐겨찾기도 계속 표시한다.

### 유튜브 재생 화면의 회전 맞춤

일반 영상은 공식 iframe의 16:9 비율을 유지하며 실제 위젯의 가용 폭과 높이 중 더 작은 제한에 맞춘다. 제목·재생 위치·속도·시간 줄과 내부 여백을 위한 높이를 남겨 가로 회전에서도 영상 아래가 잘리지 않게 한다. 쇼츠는 9:16과 이전/다음 버튼 공간을 유지한다. 실제 컨테이너·조작부 크기와 창·visualViewport 변경 때 치수를 다시 맞추며 기존 iframe·재생 위치를 유지한다. 채널·댓글은 같은 세로 스크롤 안에서 계속 표시하고 플레이어를 닫을 때 크기 관찰과 이벤트를 해제한다.

쇼츠는 공식 플레이어의 영상 종료(ENDED) 때 기존 `다음` 동작으로 다음 쇼츠를 자동 재생한다. 영상별 종료 처리를 한 번만 실행하며 전환 대기 중 반복 종료 신호는 무시한다. 다음 항목이 없거나 비활성이면 현재 영상에 머문다. 일반 영상 종료 동작은 유지한다. 타이머·알람의 시간 숫자는 72dp/pt(Android 행간 88sp)이며 큰 글자와 가로 스크롤을 유지한다. 날씨 기온은 56 크기·68 행간이다.

데이지 읽기 강조는 노랑 #FFF3B0 면과 검정 #111111 글자의 조합이다. Android 원본 문서의 강조한 문장·단어와 자식 글자에도 글자색·text-fill을 적용해 다크 본문 흰 글자와 구분하며 강조가 해제되면 원래 스타일로 돌아간다. iPad의 읽는 단어·문장도 같은 검정 글자를 유지한다. 하단 재생 패널은 모서리 24, 1px 보조색 25% 테두리, 그림자 8과 바깥 가로 12·세로 8 여백을 사용한다. 슬라이더·재생·이동 단위 버튼의 크기와 접근성 이름은 유지한다.

영상에서 뒤로 돌아오면 기존 추천·구독·검색·채널 목록과 목록 스크롤을 복원한다. 현재 탭의 sessionStorage에 경로별 최대 120개 카드의 공개 제목·주소·썸네일 URL·길이·보조 문구와 스크롤을 최대 4개 목록까지 보관한다. 복원한 목록은 원본의 새 추천으로 자동 교체하지 않으며 영상 시청 중의 추천은 목록 캐시에 섞지 않는다. 유튜브를 떠나거나 앱이 비활성인 시간이 30분을 넘으면 다음 목록 진입 때 갱신하고, 홈의 `영상 목록 새로고침`을 누르면 즉시 캐시를 비우고 새로 불러온다. 영상 시청 중에는 목록 만료 때문에 영상을 중단하지 않는다. 로그아웃 상태가 확인되면 목록 캐시를 지운다.

댓글 첫 로딩·추가 로딩 중에는 `댓글 더 보기`를 숨기고 본문 영역에 로딩 접근성 상태를 표시한다. 처음 15초 동안 댓글을 읽지 못하면 상태 안내와 `댓글 다시 불러오기`를 제공하며, 사용 불가·전체 0개 상태에서는 더 보기·재시도를 표시하지 않는다. 새로고침 버튼은 글자 너비의 터치 영역과 56 높이를 사용하고 눌림·호버·포커스 때 배경을 채우거나 탭 하이라이트를 표시하지 않는다. 키보드 포커스 외곽선은 유지한다.

전체 댓글 수는 모바일 댓글 캐러셀 제목(`carouselTitleViewModel.subtitle`)과 댓글 패널 헤더(`engagementPanelTitleHeaderRenderer.contextualInfo`)의 원본 값을 함께 읽는다. 화면에 숫자가 아직 렌더링되지 않았으면 현재 영상 ID와 일치하는 `ytInitialData`의 같은 필드를 사용한다. 페이지 데이터는 객체·JSON 문자열을 모두 지원하고 데이터 참조·영상 ID별로 결과를 재사용하며, 수가 없을 때만 2초 뒤 다시 확인한다. 답글·현재 펼친 댓글 수를 전체 수로 대신 표시하지 않으며 별도 API·새 네트워크 요청·계정 데이터 접근은 없다.

### 브라우저 광고 차단

일반 이지 브라우저·홈 브라우저 위젯은 광고 차단을 기본으로 켠다. 도구 메뉴의 `광고 차단`에서 켜짐·꺼짐을 읽고 바꿀 수 있으며 변경하면 현재 페이지를 새로 불러온다. 선택은 다음 실행에도 유지한다. 번들에 있는 광고 서버 목록·명시적인 광고 컨테이너 선택자만 사용하고 외부 필터 목록·VPN·방문 내역 전송은 없다. Android는 하위 리소스 요청을 로컬에서 차단하고, iPad는 WKContentRuleList의 광고 리소스 차단 규칙을 사용한다. 같은 스크립트가 광고 컨테이너·광고 iframe을 화면과 접근성 탐색에서 숨기며 새로 추가된 광고에도 적용한다. 기사 사진·본문·메뉴·일반 iframe은 유지하고 클래스 이름에 단순히 ad가 들어간다는 이유로 숨기지 않는다.

현재 필터는 Google 광고·DigitalCamp·MCI 등의 광고 서버와 소년한국일보의 `/adManager/` 자원, `.ad-template` 등의 광고 슬롯을 포함한다. 이지 유튜브 전용 세션·도서 웹뷰에는 적용하지 않고 YouTube·Google 계정·reCAPTCHA 문서는 예외로 둔다. 모든 사이트의 광고를 보장하는 기능이 아니며 본문 접근을 제한하는 구독·유료 장벽을 해제하지 않는다. iPad 규칙은 최초 준비 때 컴파일한 뒤 재사용하고 CSS 숨김은 문서 시작부터 적용한다. 구현: Android `BrowserAdBlocker.kt`·`browser-ad-block.json`·`browser-ad-block.js`·`AccessibleWebSession`; iPad `BrowserAdBlocker.swift`·`AccessibleWebBrowserModel`. 양쪽의 호스트·경로·선택자 목록은 같은 규격으로 갱신한다.

### 브라우저 위젯의 네이버 페이지

브라우저 위젯은 사이트의 반응형 배치·격자·표·이미지 비율·고정 위치를 유지하고 선택한 비례 확대만 적용한다. 가로 넘침만으로 캐러셀·숨긴 콘텐츠를 세로로 펼치거나 표·행·셀과 접근성 역할을 다시 쓰지 않는다. 넓은 문서나 가로 스크롤 영역에서는 웹 스크롤을 우선하고 하단 페이지 점으로 홈 페이지를 이동한다. 입력·링크·이벤트 처리·접근성 이름·사이트 주소는 원본을 유지하며 사이트 이름에 따른 배치 예외나 자동 모바일 주소 전환은 두지 않는다. 구현은 Android `launcher-widget.js`, iPad `LauncherWebAppearance`다.

### 밝은 배경에서 브라우저 다크 모드 비교

Ratio 홈의 고정 배경은 밝은 산 사진(`launcher_ratio_blue_mist` / `RatioBlueMist`)에 검정 8%·하단 추가 10% 그라데이션이다. 기존 숲 사진은 자산에 보존한다. 브라우저의 기존 `dark` 선택을 `다크 모드`로 표시하며 바탕 #202124·면 #292A2D·글자와 링크 #F1F3F4·경계 #9AA0A6을 구글 간단히 보기와 일반 사이트에 함께 적용한다. 사진·영상·브랜드 미디어의 색과 원래 배치는 유지한다. 홈 브라우저의 다크 모드 캔버스는 투명하며 그 뒤에 어두운 숲 사진(검정 60%·하단 추가 25%)을 표시한다. 다른 페이지와 브라우저 라이트 모드의 홈 배경은 밝은 산 사진을 유지한다. 선택 메뉴에는 라이트 모드·다크 모드만 두며 초기 선택은 다크 모드다. 홈 브라우저는 다크 모드에서 투명하고 라이트 모드에서 밝은 면을 사용하며 원본 보기 전환·광고 차단·검색·확대 기능을 유지한다.

### 브라우저 모드 선택

선택지는 라이트 모드(`light`)·다크 모드(`dark`) 두 가지이며 새 세션의 기본은 다크 모드다. 선택은 기존처럼 세션 동안 유지한다. Ratio 홈은 기본 산 사진을 유지하고 브라우저 다크 모드와 이지 유튜브 페이지에서 이전의 어두운 숲 사진으로 바꾼다. 홈 브라우저의 다크 웹 캔버스는 투명하고 라이트 웹 캔버스는 밝은 면을 사용한다. 원본 보기 토글은 모드 선택과 별도로 유지한다.

### 홈 브라우저 다크 모드의 사진 배경

홈 브라우저 다크 모드와 이지 유튜브 페이지에 숲 사진(`launcher_ratio_forest_mist` / `RatioForestMist`)과 검정 60%·하단 추가 25% 막을 적용한다. 웹 루트·본문·기본 바탕은 투명해 이 사진이 비치며 본문 뒤에 불투명한 검정/회색 면을 추가하지 않는다. 카드·입력창·메뉴·미디어와 원래 배치는 유지한다. 브라우저 라이트 모드와 일반 홈 페이지는 기존 밝은 산 사진을 유지하고, 이지 유튜브의 목록·영상·댓글은 어두운 숲 사진을 사용한다. 두 모드 선택·기본 다크·광고 차단 규격은 유지한다.

### 이지 유튜브의 고정 배경

홈의 이지 유튜브는 목록·영상·쇼츠·댓글 화면 모두 어두운 숲 사진과 검정 60%·하단 추가 25% 막을 사용한다. 홈의 기본 사진이 바뀌어도 이 배경은 독립적으로 유지한다. 기존 투명 캔버스·댓글 글자·영상 픽셀·재생 동작은 유지하며 불투명한 검정 면을 추가하지 않는다. 브라우저 다크 모드에도 같은 사진을 사용한다.

### 날씨 자동 갱신과 원형 새로고침

날씨 자동 갱신은 마지막 성공 시각 기준 30분 간격으로 보이는 페이지·앱 활성 상태에서만 실행한다. 화면 복귀 때 30분 미만의 자료는 위치 재조회 없이 재사용하고, 오래됐거나 자료가 없으면 즉시 위치 한 번과 예보를 요청한다. 수동 새로고침은 신선도·재시도 대기를 한 번만 무시하며 로딩 중 중복 입력은 막는다. 실패하면 지역명·날씨를 함께 보존하고 갱신 시각·오류를 표시하며 5분 뒤 재시도한다. 실패 대기는 메모리에만 유지하고 페이지 복귀가 대기를 초기화하지 않는다. 캐시는 최대 6시간까지만 표시하며 미래 시각·6시간 이상 자료는 제거한다. 위치 권한이 거부되면 이전 날씨를 숨기고 권한 설정을 안내한다. 위치와 예보는 성공 시 함께 교체하며 주기 위치 구독·백그라운드 예약 작업은 없다.

날씨는 지역명 20·행간 26, 기온 56·행간 68, 상태 22·행간 28로 표시한다. 오른쪽 아래의 지름 56·아이콘 28 원형 새로고침은 타이머 조작과 같은 12% 글자색 면을 사용한다. 상태 옆 아래에는 16·행간 22의 마지막 갱신 시각을 표시한다. 기온·상태를 누르면 기존 상세 창을 열고 새로고침은 별도 접근성 이름·비활성 상태를 제공한다. 기본 2×2 높이와 저장 크기는 유지하며 큰 시스템 글자·긴 지역명은 내부 세로 스크롤로 보존한다.

### 웹 자체 가로 제스처

실제 가로 넘침이 있는 auto/scroll 영역뿐 아니라 overflow:hidden/clip으로 가로 트랙을 감추고 pan-y·자식 transform·더 넓은 다중 항목 트랙으로 직접 드래그를 처리하는 영역도 웹 조작을 우선한다. 사이트의 제스처 초기화 전에도 가로 목록 구조와 header·nav·navigation·tablist·slider 영역을 보호한다. touch-action:none을 지정한 지도·그리기 등의 표면 역시 런처가 가로 드래그를 가로채지 않는다. 원래 사이트가 정한 동작과 하단 페이지 점을 유지하며, 일반 본문에서의 런처 페이지 넘김은 유지한다. 일반 사이트 이름·클래스 이름에 따른 예외는 없다. 앱이 직접 구성한 구글 기본 홈(`data-rivo-google-simple=home`)은 검색 입력·선택·편집 필드를 제외한 전체 표시 영역을 홈 넘기기에 사용한다. 즐겨찾기 격자와 아래 빈 공간은 일반 웹의 가로 탐색·캐러셀 보호 판정에서 제외하며, 해당 위치에 DOM 요소가 없는 빈 뷰포트도 넘김을 허용한다. 검색 입력의 드래그·선택·키보드 동작과 일반 사이트의 가로 스크롤 보호는 유지한다.

### 전체 페이지 뉴스 위젯

뉴스 위젯 `widget:news`(Android NEWS)는 유튜브와 같은 독립된 전체 페이지이며 호환 크기는 4×10이다. 기본 안전 영역·홈 상단 여백·전체 페이지 좌우 16에 내부 20 여백을 유지하고 어두운 숲 배경 위에 투명한 캔버스를 사용한다. 최초 한 번 기존 순서 뒤에 추가하며 삭제 후 자동 보충하지 않는다. 위젯 추가 목록에서 뉴스의 삭제·재추가·순서 이동을 제공하고 성공한 재추가는 편집 화면을 닫아 실제 뉴스 페이지로 이동한다. 크기·색·바로가기 유형 변환은 제공하지 않는다. 좌우 넘김은 기존 네이티브 홈 애니메이션, 세로는 기사 목록 스크롤을 사용한다. 기사 원문에서 돌아오면 뉴스 페이지와 기존 목록 위치를 유지한다.

상단은 최신·사회·경제·문화 선택과 지름 56·기호 28의 원형 새로고침이다. 좁은 폭·큰 글자에서 조작 버튼을 여러 줄로 배치하며 가로 스크롤하지 않는다. 기사는 화면 폭과 관계없이 한 행에 한 기사만 놓는 투명한 단일 열 목록이다. 기사 배경 면·둥근 모서리·외곽 테두리는 없고 좌우 2·위 22·아래 24의 여백을 둔다. 기사 사이에만 두께 1·경계색 `#7F93AB` 28%의 구분선을 놓고 처음·마지막 바깥 선은 표시하지 않는다. 제목은 기존 밝은 글자색, 소개는 같은 색 92%, 언론사·발행 시각은 75%로 표시한다. 구분선은 장식으로 접근성 탐색에서 제외한다. 제목 23·소개 18·언론사/발행 상대 시각 16이며 모두 시스템 글자 확대와 줄바꿈을 따른다. 기사 하나는 제목·소개·실제 언론사·발행 시각을 한 번의 접근성 이동으로 읽고 기사 행 전체가 원문 열기 버튼이다. 사진·장식용 빈 카드·영상 보기 같은 중복 버튼·별도 뒤로 버튼은 없다. 원문은 기존 이지 브라우저로 열며 Android의 내장 브라우저가 없는 Release에서는 기본 웹 브라우저로 연다. 위젯 편집은 기존 전체 편집 경로를 사용한다.

뉴스 목록은 `docs/news_publishers.json`의 74개 매체 등록부에서 확인된 **분야 전용 RSS만** 사용한다. 최신은 별도 전체 RSS를 요청하지 않고 사용자가 고른 분야의 캐시만 합친다. 기본 선택은 사회·경제·문화이고, 상단 ‘뉴스 분야 설정’에서 정치·국제·IT·과학·건강·스포츠·연예를 포함한 9개 분야를 복수 선택해 저장한다(‘IT·과학’은 한 분야). 설정은 재시작 후에도 유지하며 모든 분야를 끄면 안내만 표시하고 수신하지 않는다. 분야 탭도 선택한 것만 표시한다. 현재 사회·경제·문화에는 기존 8개 매체, 정치·국제·스포츠에는 뉴시스·SBS·동아일보, 연예에는 뉴시스·SBS, IT·과학에는 뉴시스·동아일보, 건강에는 동아일보를 연결한다. 뉴시스 IT·바이오와 동아일보 IT·의학은 IT·과학에 포함한다. 매체가 분류한 분야를 따르며 별도의 의미 분류는 하지 않는다. 분야 피드가 없는 매체는 전체/다른 분야로 대체하지 않는다. 전체 피드 주소는 등록부의 참고 자료로만 보존하며 자동 수신에는 사용하지 않는다. 사용자별 언론사 선택 화면은 포함하지 않는다. 제목과 소개는 길이를 자르기 전에 HTML 엔티티 해제와 태그 제거를 최대 6회 반복하고 마지막 잔여 태그·이미지 자리 문자·공백을 정리한다. script/style 본문과 닫히지 않은 태그도 제거하며 숫자 엔티티와 중첩 인코딩을 처리한다. 저장된 분야 캐시에도 같은 정리를 적용한다. HTML 렌더러나 외부 이미지 요청은 사용하지 않는다. 각 피드에서 제목·원문 HTTPS 링크·소개 최대 160자·발행 시각·언론사를 읽는다. 원문 URL(가능하면 RSS guid)·정규화한 동일 제목을 중복 제거한다. 숫자가 같고 제목 길이 비율 85% 이상·발행 간격 6시간 이내인 16자 이상 제목은 문자 쌍 유사도 90% 이상일 때만 같은 기사로 취급한다. 매체별 후보 최대 30개에서 최대 15개, 전체 최대 1200개를 발행 시각 내림차순으로 섞고 시각 미제공 기사는 뒤에 놓는다. 정렬·중복 제거는 백그라운드에서 처리하고 제목 비교용 자료는 후보당 한 번만 만든다. 동일 제목·URL은 집합으로, 유사 제목은 같은 숫자 묶음 안에서만 비교한다. 중요도 순위는 제공하지 않는다. 본문 전문·사진·AI 생성 요약·의미 기반 사건 묶음은 추가하지 않는다. 처음 불러오는 동안 중앙 144×80의 세 겹 물결과 상태 문구를 제공하고, 실패는 재시도 안내와 새로고침으로 구분한다. 화면은 캐시를 먼저 표시하고 보이는 동안의 보충 간격도 2시간이다. 자동 수신한 새 목록은 대기 상태로 두고 ‘새 뉴스가 있어요 · 보기’를 누를 때 적용한다. 수동 새로고침·분야 변경·새 뉴스 적용은 맨 위로 이동하며 그 외에는 기존 읽기 위치를 보존한다. 실패는 이전 목록과 갱신 시각을 유지하고 5분 뒤 재시도한다. 자동 기사 넘김·개별 기사 WebView/이미지 로딩은 없다. 동시 수신은 세 개로 제한하고 나머지는 대기하며 필요한 목록 행만 그린다. 각 매체를 독립적으로 요청하고 일부만 실패하면 성공한 뉴스와 그 매체의 24시간 이내 기존 기사를 함께 표시한다. 실패한 매체의 저장 시각을 갱신하지 않아 오래된 기사를 계속 연장하지 않는다. 일부 실패 안내를 표시하고 5분 뒤 다시 시도하되 각 출처의 마지막 성공부터 2시간 이내인 결과는 재사용한다. 수동 새로고침은 이 재사용을 우회하며 모두 성공하면 2시간 간격으로 돌아간다. 상단 갱신 시각은 여러 언론사 목록의 수신 시각이고 기사 행에는 실제 언론사와 발행 시각을 표시한다.

뉴스 위젯이 배치되어 있으면 사용자가 선택한 분야만 약 2시간마다 화면 밖에서 미리 받아 저장한다. 최신용 전체 피드를 별도로 받지 않는다. 분야를 바꾸면 표시 중인 최신·대기 목록을 비우고 새 선택으로 합치며 진행 중인 수신도 비선택 분야의 추가 요청·결과 반영을 중단한다. 이미 시작한 요청은 종료/취소될 수 있으나 비선택 기사가 최신에 섞이지 않는다. 앱/런처 진입 시에도 예약과 별도로 조용히 보충하되 2시간 이내 캐시는 재사용한다. 정기 예약이 실제 실행될 때는 다시 수신해 예약 경계에서 갱신이 4시간으로 밀리지 않게 한다. 화면은 저장된 목록을 먼저 표시하며 캐시가 전혀 없으면 최초 성공한 출처부터 표시하고 이후 12개 출처 처리마다 중간 결과를 저장한다. 읽는 중 들어온 후속 목록은 ‘새 뉴스가 있어요 · 보기’로 적용해 읽기 위치를 유지한다. 동시 수신은 3개이고 캐시가 없거나 가장 오래된 출처부터 수신한다. 작업이 중단되어도 이미 저장된 결과는 남는다. 수동 새로고침은 캐시 신선도와 관계없이 수신한다. 뉴스 위젯 삭제 시 백그라운드 예약·진입 시 보충을 중지한다. 최초 설치·장시간 오프라인 등으로 캐시가 없으면 통신이 필요하다. 예약 시각은 운영체제의 절전·네트워크 상태에 따라 늦어질 수 있어 정확한 2시간 실행을 보장하지 않는다.

### 브라우저 기본 홈 전체 영역 넘기기와 뉴스 목록

브라우저 기본 홈은 즐겨찾기 위·아래의 빈 공간과 즐겨찾기 항목에서 모두 좌우 드래그로 옆 홈을 넘긴다. 검색 입력에서는 편집 동작을 유지하고, 즐겨찾기를 탭하면 기존 링크를 연다. 뉴스는 Android LazyColumn·iPad LazyVStack으로 한 행에 한 기사를 표시하며, 기사 전체 클릭·접근성 묶음·발행 시각·스크롤 복귀·갱신 동작은 유지한다.
