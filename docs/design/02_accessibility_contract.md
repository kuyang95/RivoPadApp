# Accessibility Contract

점검일: 2026-09-29 · 기준 코드: `babc3875`+작업 트리 · Android 기준: `c6a03f0`

이 문서는 디자인 변경 시 깨면 안 되는 하한선이다. VisionCraft는 접근성 보조 앱이므로 일반 앱보다 보수적으로 잡는다. 값은 Android와 같다.

## Visual

- 모든 텍스트 크기는 Dynamic Type을 따르게 지정한다(`visionCraftAndroidText(size, relativeTo:)` 또는 시스템 텍스트 스타일). `.system(size:)` 고정 크기는 카메라 미리보기 위 버튼과 타일 제목(자체 배율 계산)에만 쓴다.
- 본문 텍스트는 16pt 이상을 기본값으로 삼고, 매우 보조적인 메타 정보도 12pt 미만으로 내리지 않는다(`.caption2`는 11pt라 쓰지 않는다. `VisionCraftUI.minTextSize`).
- 사용자 시스템 글씨 크기에서 레이아웃이 깨지면 텍스트를 줄이는 대신 줄바꿈, 높이 확장, 콘텐츠 우선순위 조정을 먼저 한다.
- 텍스트 대비는 최소 4.5:1을 목표로 한다.
- 아이콘, 구분선, 테두리, 토글 상태 같은 비텍스트 UI는 최소 3:1 대비를 목표로 한다.
- 색만으로 상태를 전달하지 않는다. 라벨, 아이콘, 상태 텍스트, 접근성 값 중 하나 이상을 함께 제공한다.

## Touch And Motor

- 누를 수 있는 항목은 실제 터치 영역 기준 최소 48pt를 확보한다(`VisionCraftUI.minTouchTarget`). 공용 뒤로 가기 `VisionCraftBackButton`도 48pt다.
- 리스트 행 전체를 누를 수 있게 만들고, 보조 아이콘 버튼은 행 클릭과 역할이 충돌하지 않게 한다.
- 스와이프, 길게 누르기, 드래그가 필요한 기능은 항상 대체 버튼을 제공한다.
- 반복 작업은 같은 위치, 같은 이름, 같은 역할로 유지한다.

## Screen Reader

- 화면에 보이는 라벨과 접근성 이름은 최대한 일치시킨다.
- 장식 아이콘은 `.accessibilityHidden(true)`로 둔다.
- 버튼은 동사 중심으로 읽혀야 한다. 예: `문서 스캔 시작`, `음성 명령 실행`, `채팅 기록 열기`.
- 토글은 값이 함께 읽혀야 한다. 예: `효과음 피드백, 켬`(`.isToggle` 특성 + `accessibilityValue`).
- 화면 제목은 `.isHeader`로, 다이얼로그가 열리면 `UIAccessibility.post(.screenChanged, 제목)`으로 제목을 읽어 준다.
- 로딩, 실패, 권한 필요, 빈 상태는 화면 텍스트로도 제공한다.

## Audio Feedback

- 효과음은 보조 신호다. 실패 이유, 권한 부족, 빈 입력, 네트워크 문제는 텍스트 또는 TTS로 설명한다.
- 효과음 피드백 설정이 꺼져 있으면 효과음은 재생하지 않는다.
- 음성 피드백 설정은 효과음 설정과 분리되어 있다. 안내 TTS는 음성 피드백이 켜져 있을 때만 말한다(VoiceOver 켜짐 여부와 무관하게).
- TTS는 긴 설명보다 짧고 행동 가능한 문장을 우선한다.

## Settings

- 시스템 설정을 앱 설정으로 덮어쓰지 않는다.
- 앱 설정은 VisionCraft 고유 기능에 대한 선호만 둔다.
- 설정 라벨은 사용자가 결과를 예측할 수 있게 쓴다.
- 기본값은 대부분의 사용자에게 안전하고, 배터리/데이터/방해를 최소화하는 쪽으로 둔다.

## QA Checklist

- VoiceOver로 홈, 전체 설정, 대화기록, 데이지, 문서 스캔 진입을 읽어본다.
- 시스템 글씨 크기를 크게 하고 버튼/카드/위젯 텍스트가 잘리지 않는지 본다.
- 다크/라이트 모드에서 텍스트와 상태 대비를 확인한다.
- 권한 없음, 파일 없음, 네트워크 실패, 음성 인식 실패를 일부러 발생시켜 안내를 확인한다.
- 위젯은 small 크기에서 이름이 잘리지 않는지 확인한다.

## 기준을 벗어난 곳 (사용자가 정한 예외)

코드와 대조해 확인한 것 중 사용자가 그대로 두기로 한 것. 바꾸기로 하면 이 목록을 고친다.

- 테두리를 뺀 요소는 경계 대비가 3:1에 못 미친다: 2x2 타일(면/배경 1.04:1, 그림자로 경계를 만듦), 채팅 칩·입력칸(1.12:1, 안의 글자로 식별).
- 카메라 확대와 사진 분석·문서 스캔 결과의 사진 확대는 두 손가락 제스처로만 된다. 화면 위 대체 버튼이 없다.
- 문서 편집기(엑셀·워드·한글)의 문서 본문 렌더링 글자·손잡이 크기는 문서 내용이므로 12pt/48pt 하한을 적용하지 않는다.

- iPad의 Rivo 리모컨 연결은 사용자 지정으로 매번 기기를 선택하는 수동 연결이다. 앱 재시작·Bluetooth 재활성화·연결 끊김 때 자동 연결하지 않는다(`RivoRemoteManager.swift` · `RivoRemoteManager`).

## Source Anchors

- Android Accessibility: `sp`, 12sp 하한, 4.5:1 텍스트 대비, 3:1 비텍스트 대비, 48dp 터치 타깃.
- Apple HIG Accessibility: Dynamic Type, VoiceOver 특성, 동작 줄이기.
- WCAG 2.2: Label in Name, Pointer Cancellation, Target Size, Consistent Identification.
