# 카메라 도구 보류 작업

최종 갱신: 2026-07-30

## 현재 상태

카메라 도구 허브와 카메라 돋보기 1차 세로 단면은 구현되었다.

- AVFoundation 실시간 카메라
- Metal/Core Image 직접 렌더링
- 슬라이더·핀치 확대와 10배 제품 한도
- 더블 탭 1배 초기화
- 전면·후면 카메라 전환
- 후면 토치
- 원본·흑백·반전·고대비 필터
- Rivo 카메라/DISPLAY 모드, Android 16색·임계값·미리보기 밝기·반전
- Android처럼 마지막 16색 조합·반전·임계값을 로컬에 저장하고
  DISPLAY 모드 진입 시 복원
- Rivo 중앙 자동 초점과 카메라·필터 키 안내
- 현재 필터 프레임 캡처 후 OCR 결과 화면 연결
- 촬영·사진·공유 이미지의 교정된 OCR 결과를 M4 로컬 번역으로 즉시 연결
- 카메라 촬영 프레임을 임시 파일 없이 M4 로컬 비전 모델에 직접 전달하는
  이미지 설명
- 이미지 설명 완료 뒤 한국어 답변 자동 TTS
- 현재 필터·확대 프레임을 사진 보관함 추가 전용 권한 또는 Files로 저장
- Rivo 촬영 키는 Android처럼 사진 보관함에 즉시 저장
- VoiceOver 레이블과 상태값
- 앱에서 고른 한국어·영어·일본어에 맞춘 카메라 선택·돋보기·실시간
  OCR·사진 저장 버튼, 동적 상태, 오류와 VoiceOver 문구
- Android 홈처럼 문서 스캔과 실시간 텍스트 읽기를 한 단계에서 바로
  열고, iPad의 카메라 돋보기와 이미지 설명도 같은 홈 카드에서 직접 실행

시뮬레이터 자동 테스트와 M4 실기기용 빌드는 통과했다. 무선 설치
채널도 복구되어 최신 기능 빌드를 설치하고 있으며, 실제 카메라의
화질·성능·버튼 조합 검증은 아래 일괄 점검 목록에 보류했다.

## MAG-001: M4 실기기 설치

상태: 해결

2026-07-29 무선 디버깅 상태는 `paired`, `localNetwork`,
`tunnelState: connected`였지만 설치 과정에서 다음 오류가 발생했다.

- `IXRemoteErrorDomain error 5`
- `CoreDeviceError 4000: device disconnected immediately after connecting`

케이블을 한 번 연결하거나 무선 개발 터널이 안정된 뒤 최신 빌드를
다시 설치한다.

2026-07-30 무선 개발 터널이 복구된 뒤 `iPad Pro 11-inch (M4)`에
서명된 앱의 반복 설치가 성공했다. 이후 기능 묶음마다 무선 설치를
계속 수행한다.

## MAG-002: 카메라·방향·성능 검증

상태: 미검증

- 세로, 가로 왼쪽, 가로 오른쪽에서 영상이 바른 방향인지 확인
- 전면 카메라가 좌우 반전된 자연스러운 미리보기인지 확인
- 후면↔전면 전환을 10회 반복해 세션 정지나 검은 화면이 없는지 확인
- 5분 이상 실행해 프레임 저하, 발열, 메모리 증가가 없는지 확인
- 백그라운드 진입과 복귀 후 카메라가 정상 재개되는지 확인

## MAG-003: 확대·토치·필터 검증

상태: 미검증

- 슬라이더와 핀치가 같은 배율 상태를 유지하는지 확인
- 더블 탭이 1배로 초기화되는지 확인
- 기기 최대 배율 또는 제품 한도 10배에서 더 증가하지 않는지 확인
- 토치 켜기·끄기 및 전면 카메라에서 비활성화되는지 확인
- 원본·흑백·반전·고대비 전환 시 프레임 멈춤이 없는지 확인
- 필터 전환 뒤 캡처 이미지에도 같은 필터가 적용되는지 확인
- 사진 저장에서 사진 보관함과 Files를 각각 선택해 JPEG 이름·방향·필터를
  확인하고, 사진 추가 권한 거부 시 Files 대체 안내가 보이는지 확인
- Rivo 카메라 모드의 촬영 키가 OCR 화면을 열지 않고 사진 보관함에
  한 번만 저장하는지 확인
- Rivo R1 카메라 모드에서 R2가 화면 중앙에 자동 초점을 맞추는지 확인
- Rivo L2 DISPLAY 모드에서 16색 순환과 임계값 변경이 프레임과
  캡처 이미지에 동일하게 적용되는지 확인
- 색상·반전·임계값을 바꾸고 앱을 완전히 종료한 뒤 다시 열어 L2를
  누르면 마지막 값이 복원되며, 설정 초기화 뒤 기본값으로 돌아가는지 확인
- 별표/0/샵이 시스템 밝기가 아닌 돋보기 미리보기 밝기만
  감소·초기화·증가시키는지 확인
- R2 반전과 기존 반전 필터를 조합해도 프레임이 멈추지 않는지 확인

## MAG-004: OCR 연결 검증

상태: 미검증

- `텍스트 읽기`가 현재 확대·필터 프레임을 캡처하는지 확인
- OCR 결과 화면으로 한 번만 이동하는지 확인
- 한글, 영어, 일본어 대표 문서에서 텍스트 추출 확인
- 텍스트가 없는 장면의 오류 안내 확인
- OCR 화면에서 뒤로 이동하면 카메라가 중복 실행되지 않는지 확인

## MAG-005: 접근성 검증

상태: 미검증

- 홈 카메라 카드의 문서 스캔·실시간 텍스트 읽기·카메라 돋보기·
  이미지 설명 버튼이 접근성 최대 글자 크기에서도 겹치거나 잘리지 않는지 확인
- VoiceOver 탐색 순서가 닫기→배율→필터→카메라 제어 순서인지 확인
- 배율 슬라이더의 현재 값이 읽히는지 확인
- 토치 상태가 켜짐·꺼짐으로 읽히는지 확인
- 필터 변경 announcement가 중복되거나 잘리지 않는지 확인
- 동적 글자 크기에서 하단 제어가 잘리거나 겹치지 않는지 확인
- 영어·일본어에서 긴 버튼·상태 문구가 잘리지 않고 선택한 앱 언어로
  VoiceOver가 읽는지 확인

## 완료 조건

MAG-001부터 MAG-005까지 M4에서 통과하고, 발견된 문제를 수정한 뒤
실기기 결과와 사용한 빌드 커밋을 이 문서에 기록한다.

Android의 화면 회전·회전 잠금과 시스템 자동 밝기 변경은 일반 iPadOS
앱의 공개 API로 실행할 수 없다. 기기 회전은 iPadOS에 맡기고, 밝기
버튼은 앱 카메라 프레임에만 적용하는 안전한 대체 동작으로 구현했다.

## 실시간 텍스트 읽기 현재 상태

돋보기의 카메라·Metal 렌더링 기반을 공유하는 실시간 텍스트 읽기
1차 세로 단면이 구현되었다.

- Android와 같은 1초 간격 온디바이스 Vision OCR
- 한국어·영어·일본어 인식
- 위→아래, 좌→우 읽기 순서 정렬
- 짧은 첫 결과 2회 안정화와 작은 글자 품질 거절
- 순서·토큰 유사도, 12초 재등장과 30초 풍부한 장면 앵커 억제
- 3회 연속 무텍스트 뒤 장면 앵커 초기화
- 인식 텍스트 화면 표시와 자동 TTS
- TTS 중 같은 장면은 억제하고 충분히 다른 새 장면만 이어 읽기
- 실시간 읽기 일시정지·재개
- 돋보기의 줌·토치·카메라 전환·필터 공유

Android `LiveTextReaderActivity`의 안정화·유사도·장면 앵커·품질
임계값을 같은 상태 머신으로 옮겼다. Vision은 단어별 상자를 직접
주지 않으므로, 인식 줄의 프레임 픽셀 높이를 줄 안의 토큰 수만큼
가중해 Android ML Kit의 글자 요소 높이에 대응시켰다.

## LIVE-001: M4 실시간 OCR 검증

상태: 미검증

- 한글, 영어, 일본어 인쇄물에서 최초 인식 시간 확인
- 같은 문서를 30초 비출 때 반복 낭독 횟수 확인
- 문서를 치웠다가 3회 연속 무텍스트가 지난 뒤 새 장면을 읽는지 확인
- 멀리 있는 작은 글자는 읽지 않고 가까이 비추면 읽는지 확인
- 카메라를 천천히 이동할 때 새 문장만 이어서 읽는지 확인
- 짧은 표지판과 여러 줄 문서의 읽기 순서 확인
- 확대 배율과 전면·후면 카메라 전환 뒤 OCR이 계속되는지 확인

## LIVE-002: 자동 TTS·제어 검증

상태: 미검증

- TTS 재생 중 같은 장면은 발화를 끊지 않고, 완전히 다른 장면은
  새 내용으로 전환하는지 확인
- 일시정지 시 OCR과 TTS가 모두 멈추는지 확인
- 재개 시 현재 장면을 다시 읽는지 확인
- 화면을 닫을 때 TTS와 카메라 세션이 정리되는지 확인
- VoiceOver와 자동 TTS가 동시에 말할 때 사용 가능한지 확인

## LIVE-003: 성능·상태 변화 검증

상태: 미검증

- 10분 실행 중 프레임 속도, 메모리, 발열 확인
- 세로·가로 회전 뒤 OCR 방향 확인
- 백그라운드 진입과 복귀 후 OCR 재개 확인
- 카메라 권한 거부와 텍스트 없는 장면의 안내 확인

## IMAGE-001: M4 이미지 설명 검증

상태: 미검증

- 카메라 허브의 `이미지 설명`에서 촬영하면 분석 화면으로 한 번만
  이동하는지 확인
- 사람·사물·간판이 함께 있는 장면에서 Qwen3-VL 로컬 설명이 생성되고
  답변 완료 뒤 한국어 TTS가 자동으로 시작되는지 확인
- 촬영 이미지를 앱 캐시나 사진 보관함에 자동 저장하지 않는지 확인
- 전면·후면 카메라, 확대·필터 조합 뒤에도 현재 보이는 프레임을
  분석하는지 확인
- 분석 화면에서 후속 질문, 답변 문장 이동과 R3 읽기·정지가 동작하는지
  확인
- 모델 로드 실패, 메모리 부족과 카메라 권한 거부 시 앱이 종료되지 않고
  이해 가능한 오류를 표시하는지 확인
