# 카메라 도구 보류 작업

최종 갱신: 2026-07-29

## 현재 상태

카메라 도구 허브와 카메라 돋보기 1차 세로 단면은 구현되었다.

- AVFoundation 실시간 카메라
- Metal/Core Image 직접 렌더링
- 슬라이더·핀치 확대와 10배 제품 한도
- 더블 탭 1배 초기화
- 전면·후면 카메라 전환
- 후면 토치
- 원본·흑백·반전·고대비 필터
- 현재 필터 프레임 캡처 후 OCR 결과 화면 연결
- VoiceOver 레이블과 상태값

시뮬레이터 빌드와 전체 테스트 37개는 통과했다. M4 실기기용
빌드도 성공했지만 무선 설치 채널이 불안정해 실제 카메라 검증은
보류했다.

## MAG-001: M4 실기기 설치

상태: 보류

2026-07-29 무선 디버깅 상태는 `paired`, `localNetwork`,
`tunnelState: connected`였지만 설치 과정에서 다음 오류가 발생했다.

- `IXRemoteErrorDomain error 5`
- `CoreDeviceError 4000: device disconnected immediately after connecting`

케이블을 한 번 연결하거나 무선 개발 터널이 안정된 뒤 최신 빌드를
다시 설치한다.

## MAG-002: 카메라·방향·성능 검증

상태: 미검증

- 세로, 가로 왼쪽, 가로 오른쪽에서 영상이 바른 방향인지 확인
- 전면 카메라가 좌우 반전된 자연스러운 미리보기인지 확인
- 후면↔전면 전환을 10회 반복해 세션 정지나 검은 화면이 없는지 확인
- 5분 이상 실행해 프레임 저하, 발열, 메모리 증가가 없는지 확인
- 백그라운드 진입과 복귀 후 카메라가 정상 재개되는지 확인

## MAG-003: 확대·토치·필터 검증

상태: 미검증

- 슬라이더와 핀치가 같은 배율 상태를 유지하는지 확인
- 더블 탭이 1배로 초기화되는지 확인
- 기기 최대 배율 또는 제품 한도 10배에서 더 증가하지 않는지 확인
- 토치 켜기·끄기 및 전면 카메라에서 비활성화되는지 확인
- 원본·흑백·반전·고대비 전환 시 프레임 멈춤이 없는지 확인
- 필터 전환 뒤 캡처 이미지에도 같은 필터가 적용되는지 확인

## MAG-004: OCR 연결 검증

상태: 미검증

- `텍스트 읽기`가 현재 확대·필터 프레임을 캡처하는지 확인
- OCR 결과 화면으로 한 번만 이동하는지 확인
- 한글, 영어, 일본어 대표 문서에서 텍스트 추출 확인
- 텍스트가 없는 장면의 오류 안내 확인
- OCR 화면에서 뒤로 이동하면 카메라가 중복 실행되지 않는지 확인

## MAG-005: 접근성 검증

상태: 미검증

- VoiceOver 탐색 순서가 닫기→배율→필터→카메라 제어 순서인지 확인
- 배율 슬라이더의 현재 값이 읽히는지 확인
- 토치 상태가 켜짐·꺼짐으로 읽히는지 확인
- 필터 변경 announcement가 중복되거나 잘리지 않는지 확인
- 동적 글자 크기에서 하단 제어가 잘리거나 겹치지 않는지 확인

## 완료 조건

MAG-001부터 MAG-005까지 M4에서 통과하고, 발견된 문제를 수정한 뒤
실기기 결과와 사용한 빌드 커밋을 이 문서에 기록한다.

## 실시간 텍스트 읽기 현재 상태

돋보기의 카메라·Metal 렌더링 기반을 공유하는 실시간 텍스트 읽기
1차 세로 단면이 구현되었다.

- 1.5초 간격 온디바이스 Vision OCR
- 한국어·영어·일본어 인식
- 위→아래, 좌→우 읽기 순서 정렬
- 공백·부분 인식·유사 문장 반복 억제
- 인식 텍스트 화면 표시와 자동 TTS
- TTS 재생 중 새 인식이 기존 발화를 끊지 않도록 억제
- 실시간 읽기 일시정지·재개
- 돋보기의 줌·토치·카메라 전환·필터 공유

시뮬레이터 빌드와 전체 테스트 40개는 통과했다.

## LIVE-001: M4 실시간 OCR 검증

상태: 미검증

- 한글, 영어, 일본어 인쇄물에서 최초 인식 시간 확인
- 같은 문서를 30초 비출 때 반복 낭독 횟수 확인
- 카메라를 천천히 이동할 때 새 문장만 이어서 읽는지 확인
- 짧은 표지판과 여러 줄 문서의 읽기 순서 확인
- 확대 배율과 전면·후면 카메라 전환 뒤 OCR이 계속되는지 확인

## LIVE-002: 자동 TTS·제어 검증

상태: 미검증

- TTS 재생 중 다음 OCR이 현재 발화를 끊지 않는지 확인
- 일시정지 시 OCR과 TTS가 모두 멈추는지 확인
- 재개 시 현재 장면을 다시 읽는지 확인
- 화면을 닫을 때 TTS와 카메라 세션이 정리되는지 확인
- VoiceOver와 자동 TTS가 동시에 말할 때 사용 가능한지 확인

## LIVE-003: 성능·상태 변화 검증

상태: 미검증

- 10분 실행 중 프레임 속도, 메모리, 발열 확인
- 세로·가로 회전 뒤 OCR 방향 확인
- 백그라운드 진입과 복귀 후 OCR 재개 확인
- 카메라 권한 거부와 텍스트 없는 장면의 안내 확인
