# Rivo 리모컨 기능 백로그

## 현재 구현된 1차 범위

- Android VisionCraft와 같은 Rivo Three `F120`, Mini `F121` 검색
- 광고 서비스 UUID가 빠진 경우 `Rivo Mini`, `Rivo 3/Three` 이름으로
  보조 식별하고, 일반 `Rivo`·타사 `Mini` 이름은 제외
- Core Bluetooth 기반 연결, 연결 끊김 후 재시도, 마지막 기기 자동 연결
- 자동 재연결 실패 시 1·2·4·8·16·30초 지수 백오프와 30초 상한,
  성공·수동 재시도 시 초기화
- 자동 재연결 대기 시간·회차 표시와 `지금 다시 연결` 동작
- 연결 중인 기기에서 `다른 리모컨 연결`을 선택하면 저장된 선호 기기를
  유지한 채 전체 검색하고, 사용자가 새 기기를 고른 뒤 준비가 끝날 때만
  선호 기기를 교체
- 새 기기 연결 실패 중 저장된 리모컨으로 즉시 돌아가는 복구 동작
- Android UART 알림 특성
  `6E400003-B5A3-F393-E0A9-E50E24DCCA9E` 구독
- Android UART 쓰기 특성
  `6E400004-B5A3-F393-E0A9-E50E24DCCA9E` 확인
- `atBT` 패킷의 분할 수신, 연속 수신, 잡음 뒤 재동기화
- 한 BLE 알림에 합쳐진 여러 버튼 패킷을 배치 순서대로 모두 라우팅
- L1~L4, R1~R4, 숫자, 별표, 샵의 누름/뗌 코드 완전 대응
- `a/` 음성 액션 시퀀스 해석
- L1으로 여는 앱 내부 빠른 메뉴
- 빠른 메뉴에서 AI 채팅, 독서, 돋보기, 실시간 텍스트 읽기,
  문서 스캔, 리모컨 연결 화면 이동
- Android Remote Ribbon 설정과 같은 빠른 메뉴 펼침·접힘, 문서 보기와
  공유하는 16개 고대비 색상 조합, 저장·복원·초기화
- R3으로 앱의 음성 읽기 정지
- Android `COMMAND`와 같은 R1 명령 모드:
  2 클립보드 자동 번역·결과 TTS, 3 실시간 텍스트 읽기, 4 카메라 돋보기,
  9 촬영 이미지 설명
- Android 원격 모드 오버레이에 대응하는 12키 시각 가이드와 VoiceOver
  키 레이블
- R1 명령 모드의 5/6/7/별표/0/샵은 카메라 돋보기를 먼저 열고,
  화면에서 R1 뒤 같은 키를 눌러 전환·토치·촬영·줌을 실행하도록 안내
- R1 두 번 누름으로 전체 명령 키 안내
- 최근 버튼 해석 결과와 원본 패킷 진단 화면
- Bluetooth 중앙 장치 복원 식별자와 백그라운드 모드, 사용 이력 기반
  앱 재실행 준비
- 저장 기기 우선 다중 복원 후보 선택과 연결됨·연결 중·끊김·해제 중
  상태별 서비스 검색·대기·재연결, 복원된 검색 세션 인계
- Bluetooth·검색·연결·서비스·특성·알림·준비·재연결·패킷·시간
  단계별 진단 최대 80개를 iPad에 저장하고 연결 화면에서 확인·삭제
- Android의 21바이트 `ATDT` 명령과 호환되는 현재 시간 전송
- 연결 준비 직후 자동 시간 동기화, 앱 활성 연결 중 12시간 재전송
- 연결 화면에서 마지막 전송 상태 확인과 수동 재전송
- 빠른 메뉴와 화면별 입력을 한 번만 소비하는 중앙 명령 라우터
- 돋보기의 닫기, 카메라 전환, 토치, 텍스트 읽기,
  0.5배율 확대·축소·초기화
- 실시간 텍스트 읽기의 카메라 전환, 토치, 읽기 일시정지·재개
- 문서 스캐너 촬영 화면의 닫기·수동 촬영과 촬영 결과의 재촬영·
  페이지 추가·한 장 OCR·검토 완료
- 다중 페이지 검토의 이전·다음 페이지 선택, 선택 페이지 회전,
  페이지 추가, 문서로 열기와 PDF 저장
- EPUB·DAISY 독서의 이전·다음, 재생·일시정지,
  탐색 단위 정방향·역방향 변경
- EPUB·DAISY 독서 중 L1 빠른 메뉴를 Android와 같은 독서 닫기,
  재생·이전·다음·탐색 단위·목차·본문 검색·보기 설정 목록으로 전환
- L1 빠른 메뉴를 Android와 같은 4/6 항목 이동, 2/8 선택 값 조절,
  5 선택·기본값 실행 방식으로 정합화하고 카메라의 확대·색상·임계값·
  밝기와 TXT/PDF의 색상·글자·줄 간격 조절 항목을 화면별로 표시
- 로컬 TXT·PDF 문서의 Android TEXTVIEW 12키 행렬:
  처음·끝, 이전/다음 줄·페이지, 글자 크기와 줄 간격 조절·초기화
- 로컬 문서에서 L2 색상 모드, 4/5/6 이전·원본·다음 16색 조합,
  R2 전경·배경 반전, L3 문서 조작 복귀
- 로컬 문서에서 R3로 현재 줄부터 읽기 시작·정지하고 빠른 메뉴 중에는
  기존 전역 음성 정지를 우선
- PDF 원본 보기나 편집 중 원격 탐색 시 텍스트 읽기 보기로 안전 전환
- 로컬 AI 채팅 화면에서 `a/`로 온디바이스 음성 입력 시작·취소
- 채팅 화면의 `a/`를 화면 재진입 없이 우선 소비해 대화 중복 생성 방지
- 로컬 AI 채팅에서 `4/5/6`으로 이전·현재 다시 읽기·다음 답변 문장을
  제어하고 `R3`로 답변 전체 읽기·정지를 화면보다 먼저 소비
- 다른 화면에서 `a/`를 누르면 온디바이스 음성 명령 화면을 열고,
  다시 `a/`를 누르면 듣기를 취소
- 음성 명령으로 문서 스캔, 카메라·돋보기, 실시간 텍스트 읽기,
  AI 새 대화·기록, PDF/TXT 파일 선택, EPUB·DAISY 독서 화면 이동
- 일반 음성 질문과 번역 요청을 M4 로컬 AI에 자동 전송하고 답변 TTS 재생
- 웹 검색 음성 요청을 Brave 출처 검색, M4 로컬 답변과 TTS로 연결
- Android의 다른 앱 화면 OCR·캡처는 iPadOS 공개 API 제약 때문에
  앱 카메라·실시간 OCR을 여는 명시적 대체 동작으로 연결
- R1/L2/L3 두 번 누름을 기능 화면 밖에서 사용하면 카메라·색상·문서
  모드를 사용할 수 있는 앱 내부 화면을 음성으로 안내
- L4 Android 화면 위치 점프와 R4 화면 연속 스크롤은 다른 앱 화면
  제어가 불가능한 iPadOS 제약을 안내하고 카메라 돋보기를 대안으로 제시
- Android `RVButton`과 같은 앱 내부 버튼 제스처 해석:
  일반 누름 10ms, 뗌 50ms, 길게 누름 500ms, 두 번 누름 300ms
- L1 두 번 누름으로 빠른 메뉴 안내를 확실히 열고 단일 누름은
  두 번 누름 판정 뒤 한 번만 실행
- 뗌 패킷 유실 시 버튼별 3초 안전 해제로 고착 입력 방지
- 돋보기에서 R1 카메라 모드, L2 DISPLAY 모드 전환과 두 번 누름 안내
- 돋보기 카메라 모드의 중앙 초점, 닫기·카메라 전환·토치·OCR·줌
- 돋보기 DISPLAY 모드의 Android 16색 순환·원본·반전과
  0~1.05 임계값 조절
- Android 시스템 밝기 키는 iPadOS 공개 API 범위에서 돋보기 미리보기
  밝기 조절·초기화로 대체
- App Group에 마지막 Rivo 상태와 갱신 시각을 저장하는 소형·중형
  홈 화면 위젯
- 중형 위젯의 AI·문서 스캔·카메라·독서 바로가기와 소형 위젯의
  Rivo 연결 화면 바로가기
- 2026-07-31 사용자 확인: 앱 홈 화면의 Rivo 연결 상태 표시가 보임
- BLE 검색·자동 재연결·상태 복원·GATT/UART·시간 동기화·연결 진단과
  버튼 이름·동작·빠른 메뉴·R1 명령 모드의 화면 및 음성 안내를
  영어·일본어 앱 언어에 연결

## 실기기 확인 — M4 iPad에서 수행

- [ ] Apple Developer 최신 Program License Agreement 동의 뒤 Widget
      App Group 프로비저닝 프로필을 만들고 서명 설치한다.
- [ ] 소형·중형 `Rivo 상태와 바로가기` 위젯을 홈 화면에 추가할 수 있다.
- [ ] 연결·검색·연결 끊김 뒤 위젯의 최근 상태와 `마지막 확인` 시각이
      바뀌며, 앱이 종료된 동안의 오래된 상태가 실시간 상태처럼 보이지 않는다.
- [ ] 소형 위젯을 누르면 Rivo 연결 화면, 중형 위젯의 AI·스캔·카메라·독서
      항목을 누르면 정확한 앱 화면이 열린다.
- [ ] 작은 글자·큰 글자와 VoiceOver에서 상태, 마지막 확인 시각,
      네 개 바로가기의 이름과 포커스 순서가 이해 가능하다.
- [ ] 필요하면 iPad 설정의 Bluetooth에서 Rivo를 먼저 페어링한다.
- [ ] 앱의 리모컨 화면에서 Bluetooth 권한을 허용한다.
- [ ] Rivo Three 또는 Mini가 올바른 이름과 신호 세기로 표시된다.
- [ ] 광고에 `F120/F121`가 생략되는 펌웨어에서도 모델명이
  `Rivo Mini`, `Rivo 3/Three`이면 검색 결과에 표시된다.
- [ ] 연결 후 상태가 `연결됨`으로 바뀐다.
- [ ] L/R 버튼, 숫자, 별표, 샵의 누름과 뗌이 진단 화면에 표시된다.
- [ ] 패킷이 잘리거나 여러 개가 한 번에 와도 입력이 빠지지 않는다.
- [ ] L1 메뉴와 2/4/6/8 이동, 1/7 끝 이동, 5 선택이 동작한다.
- [ ] 0은 홈으로 이동하고 별표는 메뉴를 닫는다.
- [ ] 설정의 메뉴바 펼쳐보기를 끄면 이전·현재·다음의 가로 목록, 켜면
      전체 세로 목록이 보이며 어느 상태에서도 이동·선택 키가 동일하게
      동작한다.
- [ ] 빠른 메뉴 16색 조합을 바꿀 때 제목·항목·선택 반전·키 안내가
      충분한 대비로 즉시 바뀌고 앱 재실행 뒤 복원된다.
- [ ] R3가 TTS를 즉시 멈춘다.
- [ ] 앱을 완전히 종료하고 다시 열어 마지막 리모컨에 자동 연결된다.
- [ ] 잠금·화면 꺼짐·짧은 백그라운드 전환 뒤 연결 상태를 확인한다.
- [ ] 앱 전환 화면에서 강제 종료하지 않고 iPadOS가 백그라운드 앱을
      종료한 뒤 Rivo 버튼을 누르면 복원 콜백으로 연결·검색을 이어간다.
- [ ] 복원 진단에 `연결된 서비스 검색`, `진행 중인 연결 대기`,
      `복원된 기기 재연결` 중 실제 상태에 맞는 단계가 한 번만 남는다.
- [ ] Rivo 전원을 끄면 재연결 진단의 대기 시간이
  1→2→4→8→16→30초로 늘고 이후 30초를 유지한다.
- [ ] `지금 다시 연결`을 누르면 대기 없이 시도하고 다음 실패가
  다시 1초부터 시작하며, 연결 성공 뒤에도 백오프가 초기화된다.
- [ ] Rivo 두 대가 있을 때 `다른 리모컨 연결`은 기존 기기에 자동으로
  다시 붙지 않고 두 기기를 목록에 표시하며, 선택한 기기에 연결된다.
- [ ] 새 기기 연결을 실패시킨 뒤 `저장된 리모컨으로 돌아가기`가
  기존 기기에 연결하고, 새 기기가 준비된 경우에만 다음 앱 실행의
  자동 연결 대상이 새 기기로 바뀐다.
- [ ] VoiceOver가 연결 상태, 검색 결과, 진단 기록을 읽을 수 있다.
- [ ] 영어·일본어에서 검색·연결·재연결, GATT/UART·시간 동기화 오류,
      버튼 진단, 빠른 메뉴와 R1 명령 모드 안내가 선택 언어로 표시·발화된다.
- [ ] 연결 실패 시 진단에 마지막 성공 단계와 구체적인 실패 단계가
  남고, 앱을 다시 열어도 유지되며 `지우기`로 삭제된다.
- [ ] 연결 직후 Rivo의 날짜와 시간이 iPad의 현지 시각으로 맞춰진다.
- [ ] `시간 다시 맞추기`를 누르면 상태와 전송 시각이 갱신된다.
- [ ] 자정·연말 경계와 밀리초가 큰 시점에도 Rivo 시각이 정상이다.
- [ ] 앱을 연결된 채 12시간 이상 두었을 때 시간을 다시 전송한다.
- [ ] 돋보기 R1 카메라 모드에서 4/5/6/7, 별표/0/샵과 R2 중앙
  초점 동작 및 음성 안내를 확인한다.
- [ ] 돋보기 L2 DISPLAY 모드에서 4/5/6 색상, 7/8/9 임계값,
  별표/0/샵 미리보기 밝기, R2 반전을 확인한다.
- [ ] 돋보기에서 R1/L2를 두 번 누르면 각 모드의 키 안내를 읽는다.
- [ ] 실시간 텍스트 읽기에서 7을 반복해 일시정지·재개한다.
- [ ] 스캐너에서 7은 한 번만 촬영하고 4는 안전하게 닫는다.
- [ ] 촬영 결과에서 4 재촬영, 9 페이지 추가, 7 검토 완료와 첫 페이지

- [ ] EPUB·DAISY에서 4/5/6과 2/8을 빠르게 반복해도 순서가 유지된다.

      본문 검색과 보기 설정을 선택하면 해당 시트가 한 번만 열린다.
- [ ] L1 빠른 메뉴가 열린 동안 화면별 숫자 명령이 동시에 실행되지 않는다.
- [ ] 돋보기·실시간 읽기·TXT/PDF에서 L1 메뉴를 열고 4/6으로 항목을
      이동한 뒤 2/8 조절과 5 기본값이 화면에 한 번씩 반영된다.
- [ ] TXT/PDF에서 1~9, 별표/0/샵을 눌러 Android TEXTVIEW와
  같은 탐색·글자·줄 간격 동작 및 경계 고정을 확인한다.
- [ ] TXT/PDF에서 L2 뒤 4/5/6과 R2로 색상 순환·원본·반전이
  바뀌고, L3 뒤 4가 다시 글자 축소로 동작한다.
- [ ] L2/L3를 두 번 누르면 각 모드의 키 안내를 읽고, R3는 현재
  줄부터 읽기와 정지를 반복하며 빠른 메뉴 중에는 읽기를 시작하지 않는다.
- [ ] PDF 원본 보기와 텍스트 편집 중 원격 키를 누르면 텍스트 읽기
  보기로 전환되고 입력 내용은 보존된다.
- [ ] 로컬 AI 채팅에서 `a/`를 누르면 음성 입력이 시작되고, 듣는 중
  다시 누르면 질문을 전송하지 않고 취소된다.
- [ ] 음성 인식이 자동으로 끝나면 질문이 한 번만 전송되고 로컬 AI
  답변이 TTS로 재생된다.
- [ ] 로컬 AI 답변에서 `4/5/6`이 이전·현재 다시 읽기·다음 문장을
  읽고 화면의 문장 번호와 일치하며, `R3`가 전체 읽기와 정지를 반복한다.
- [ ] AI 답변을 읽는 중 L1 빠른 메뉴를 열면 숫자 문장 이동은 실행되지
  않고, 메뉴를 닫으면 다시 채팅 화면으로 전달된다.
- [ ] 채팅 밖에서 `a/`를 누른 뒤 “문서 스캐너 열어”, “돋보기 켜”,
  “글자 읽어”, “AI 채팅 기록”, “데이지 책 읽기”가 해당 화면을 연다.
- [ ] 전역 음성 명령을 듣는 중 `a/`를 다시 누르면 녹음과 화면이
  즉시 닫히고 기능이 실행되지 않는다.
- [ ] “무지개는 왜 생겨?” 같은 일반 질문은 로컬 AI로 한 번만
  전송되고 답변 완료 뒤 한국어 TTS가 재생된다.
- [ ] “문서 질문” 또는 “파일 열어”는 홈으로 돌아간 뒤 Files
  선택기를 한 번만 표시한다.
- [ ] 선택적 웹 검색을 켠 뒤 “오늘 주요 뉴스 웹 검색해 줘”가 Brave에서
  출처를 찾고 M4 로컬 답변을 한 번 생성해 TTS로 읽는다.
- [ ] L1을 한 번 누르면 약 0.3초 뒤 빠른 메뉴가 한 번 열리고, 빠르게
  두 번 누르면 기존 메뉴를 닫지 않고 안내 상태로 열린다.
- [ ] 숫자 버튼을 0.5초 이상 누르면 기존 짧은 누름 동작은 한 번만
  실행되고, 3초 넘게 잡고 있거나 뗌 패킷이 빠져도 입력이 고착되지 않는다.
- [ ] 기능 화면 밖에서 R1/L2/L3를 두 번 누르면 각각 카메라 돋보기,
  화면 색상, 로컬 문서 진입 경로를 읽는다.
- [ ] 기능 화면 밖에서 R1 뒤 2를 누르면 현재 클립보드 문자열의 로컬
  번역이 자동 시작되고 완료 결과를 읽으며, 빈 클립보드는 빈 입력으로
  안전하게 열린다.
- [ ] R1 뒤 3은 실시간 카메라 OCR, 4는 카메라 돋보기, 9는 이미지 설명
  카메라를 각각 한 번만 연다.
- [ ] R1 뒤 9, 촬영 뒤 M4 로컬 이미지 설명이 생성되고 답변 완료 뒤
  한국어 TTS로 읽는다.
- [ ] R1 뒤 5/6/7/별표/0/샵은 카메라 돋보기를 연다는 안내를 읽고,
  카메라 화면에서 R1 뒤 같은 키를 누르면 실제 카메라 기능이 동작한다.
- [ ] R1 명령 모드 중 L1은 명령 모드를 끝내고 빠른 메뉴를 열며,
  `a/`는 명령 모드를 끝내고 음성 명령을 시작한다.
- [ ] L4/R4 한 번·두 번 누름은 다른 숫자 동작을 실행하지 않고
  iPadOS 전역 화면 이동 제한과 카메라 돋보기 대안을 읽는다.

## iPadOS에서 의도적으로 제한되는 범위

- 일반 앱은 다른 앱의 버튼, 터치, 홈 동작을 임의로 제어할 수 없다.
- 시스템 전체 제어가 필요하면 Rivo 펌웨어의 HID/Switch Control 지원과
  iPadOS 손쉬운 사용 설정을 별도로 설계해야 한다.
- `bluetooth-central`은 연결 복원 기회를 제공하지만 앱을 항상 실행
  상태로 유지하거나 무제한 백그라운드 처리를 보장하지 않는다.
- Android WorkManager의 12시간 주기와 달리 iPadOS 일반 앱은 정확한
  백그라운드 실행 시각을 보장하지 않는다. 현재 구현은 연결 직후와 앱의
  활성 BLE 세션이 유지되는 동안 재전송하며, 복원 시 다시 즉시 맞춘다.
- Android DISPLAY의 시스템 밝기·자동 밝기와 회전 잠금은 일반 iPad
  앱이 바꿀 수 없다. 밝기 키는 돋보기 미리보기 영상에만 적용하며,
  회전 키는 오동작을 피하기 위해 실행하지 않고 기기 회전을 사용한다.
- Android L4 JUMP와 R4 SCROLL은 접근성 서비스가 만든 다른 앱 화면
  확대 뷰를 이동한다. iPad 앱은 동일 화면 데이터나 이벤트 주입 권한이
  없으므로 실행하지 않고, 앱 카메라 돋보기 사용 안내만 제공한다.
- Android COMMAND의 3 OCR과 9 이미지 설명은 접근성 서비스가 다른 앱을
  무음 캡처한다. iPadOS 일반 앱에는 해당 권한이 없으므로 3은 명시적
  실시간 카메라 OCR, 9는 명시적 카메라 촬영 뒤 M4 로컬 설명으로
  대체한다.
- 현재 배포 대상 iOS 26.2에는 다른 앱을 무음 캡처할 공개 경로가 없다.
  기존 ReplayKit 방송 확장 API는 폐기 예정이며 새 포팅 기반으로 사용하지
  않는다. iOS 27 이상으로 배포 대상을 올릴 때는 ScreenCaptureKit의
  사용자 시작형 전체 화면 공유를 별도 권한·개인정보 UX와 함께 검토한다.
  이 경로도 사용자의 시스템 선택기 조작 없이 몰래 시작할 수 있는
  Android 접근성 서비스 대체는 아니다.
