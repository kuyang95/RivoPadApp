# Rivo 리모컨 기능 백로그

## 현재 구현된 1차 범위

- Android VisionCraft와 같은 Rivo Three `F120`, Mini `F121` 검색
- 광고 서비스 UUID가 빠진 경우 `Rivo Mini`, `Rivo 3/Three` 이름으로
  보조 식별하고, 일반 `Rivo`·타사 `Mini` 이름은 제외
- Core Bluetooth 기반 연결, 연결 끊김 후 재시도, 마지막 기기 자동 연결
- Android UART 알림 특성
  `6E400003-B5A3-F393-E0A9-E50E24DCCA9E` 구독
- Android UART 쓰기 특성
  `6E400004-B5A3-F393-E0A9-E50E24DCCA9E` 확인
- `atBT` 패킷의 분할 수신, 연속 수신, 잡음 뒤 재동기화
- 한 BLE 알림에 합쳐진 여러 버튼 패킷을 배치 순서대로 모두 라우팅
- L1~L4, R1~R4, 숫자, 별표, 샵의 누름/뗌 코드 완전 대응
- `a/` 음성 액션 시퀀스 해석
- L1으로 여는 앱 내부 빠른 메뉴
- 빠른 메뉴에서 AI 채팅, 독서, 돋보기, 실시간 텍스트 읽기,
  문서 스캔, 리모컨 연결 화면 이동
- R3으로 앱의 음성 읽기 정지
- 최근 버튼 해석 결과와 원본 패킷 진단 화면
- Bluetooth 중앙 장치 상태 복원을 위한 백그라운드 모드
- Bluetooth·검색·연결·서비스·특성·알림·준비·재연결·패킷·시간
  단계별 진단 최대 80개를 iPad에 저장하고 연결 화면에서 확인·삭제
- Android의 21바이트 `ATDT` 명령과 호환되는 현재 시간 전송
- 연결 준비 직후 자동 시간 동기화, 앱 활성 연결 중 12시간 재전송
- 연결 화면에서 마지막 전송 상태 확인과 수동 재전송
- 빠른 메뉴와 화면별 입력을 한 번만 소비하는 중앙 명령 라우터
- 돋보기의 닫기, 카메라 전환, 토치, 텍스트 읽기,
  0.5배율 확대·축소·초기화
- 실시간 텍스트 읽기의 카메라 전환, 토치, 읽기 일시정지·재개
- 문서 스캐너의 닫기와 수동 촬영
- EPUB·DAISY 독서의 이전·다음, 재생·일시정지,
  탐색 단위 정방향·역방향 변경
- 로컬 TXT·PDF 문서의 Android TEXTVIEW 12키 행렬:
  처음·끝, 이전/다음 줄·페이지, 글자 크기와 줄 간격 조절·초기화
- PDF 원본 보기나 편집 중 원격 탐색 시 텍스트 읽기 보기로 안전 전환
- 로컬 AI 채팅 화면에서 `a/`로 온디바이스 음성 입력 시작·취소
- 채팅 화면의 `a/`를 화면 재진입 없이 우선 소비해 대화 중복 생성 방지
- 다른 화면에서 `a/`를 누르면 온디바이스 음성 명령 화면을 열고,
  다시 `a/`를 누르면 듣기를 취소
- 음성 명령으로 문서 스캔, 카메라·돋보기, 실시간 텍스트 읽기,
  AI 새 대화·기록, PDF/TXT 파일 선택, EPUB·DAISY 독서 화면 이동
- 일반 음성 질문과 번역 요청을 M4 로컬 AI에 자동 전송하고 답변 TTS 재생
- Android의 다른 앱 화면 OCR·캡처는 iPadOS 공개 API 제약 때문에
  앱 카메라·실시간 OCR을 여는 명시적 대체 동작으로 연결
- Android `RVButton`과 같은 앱 내부 버튼 제스처 해석:
  일반 누름 10ms, 뗌 50ms, 길게 누름 500ms, 두 번 누름 300ms
- L1 두 번 누름으로 빠른 메뉴 안내를 확실히 열고 단일 누름은
  두 번 누름 판정 뒤 한 번만 실행
- 뗌 패킷 유실 시 버튼별 3초 안전 해제로 고착 입력 방지

## 실기기 확인 — M4 iPad에서 수행

- [ ] 필요하면 iPad 설정의 Bluetooth에서 Rivo를 먼저 페어링한다.
- [ ] 앱의 리모컨 화면에서 Bluetooth 권한을 허용한다.
- [ ] Rivo Three 또는 Mini가 올바른 이름과 신호 세기로 표시된다.
- [ ] 광고에 `F120/F121`가 생략되는 펌웨어에서도 모델명이
  `Rivo Mini`, `Rivo 3/Three`이면 검색 결과에 표시된다.
- [ ] 연결 후 상태가 `연결됨`으로 바뀐다.
- [ ] L/R 버튼, 숫자, 별표, 샵의 누름과 뗌이 진단 화면에 표시된다.
- [ ] 패킷이 잘리거나 여러 개가 한 번에 와도 입력이 빠지지 않는다.
- [ ] L1 메뉴와 2/4/6/8 이동, 1/7 끝 이동, 5 선택이 동작한다.
- [ ] 0은 홈으로 이동하고 별표는 메뉴를 닫는다.
- [ ] R3가 TTS를 즉시 멈춘다.
- [ ] 앱을 완전히 종료하고 다시 열어 마지막 리모컨에 자동 연결된다.
- [ ] 잠금·화면 꺼짐·짧은 백그라운드 전환 뒤 연결 상태를 확인한다.
- [ ] VoiceOver가 연결 상태, 검색 결과, 진단 기록을 읽을 수 있다.
- [ ] 연결 실패 시 진단에 마지막 성공 단계와 구체적인 실패 단계가
  남고, 앱을 다시 열어도 유지되며 `지우기`로 삭제된다.
- [ ] 연결 직후 Rivo의 날짜와 시간이 iPad의 현지 시각으로 맞춰진다.
- [ ] `시간 다시 맞추기`를 누르면 상태와 전송 시각이 갱신된다.
- [ ] 자정·연말 경계와 밀리초가 큰 시점에도 Rivo 시각이 정상이다.
- [ ] 앱을 연결된 채 12시간 이상 두었을 때 시간을 다시 전송한다.
- [ ] 돋보기에서 4/5/6/7, 별표/0/샵 동작과 음성 안내를 확인한다.
- [ ] 실시간 텍스트 읽기에서 7을 반복해 일시정지·재개한다.
- [ ] 스캐너에서 7은 한 번만 촬영하고 4는 안전하게 닫는다.
- [ ] EPUB·DAISY에서 4/5/6과 2/8을 빠르게 반복해도 순서가 유지된다.
- [ ] L1 빠른 메뉴가 열린 동안 화면별 숫자 명령이 동시에 실행되지 않는다.
- [ ] TXT/PDF에서 1~9, 별표/0/샵을 눌러 Android TEXTVIEW와
  같은 탐색·글자·줄 간격 동작 및 경계 고정을 확인한다.
- [ ] PDF 원본 보기와 텍스트 편집 중 원격 키를 누르면 텍스트 읽기
  보기로 전환되고 입력 내용은 보존된다.
- [ ] 로컬 AI 채팅에서 `a/`를 누르면 음성 입력이 시작되고, 듣는 중
  다시 누르면 질문을 전송하지 않고 취소된다.
- [ ] 음성 인식이 자동으로 끝나면 질문이 한 번만 전송되고 로컬 AI
  답변이 TTS로 재생된다.
- [ ] 채팅 밖에서 `a/`를 누른 뒤 “문서 스캐너 열어”, “돋보기 켜”,
  “글자 읽어”, “AI 채팅 기록”, “데이지 책 읽기”가 해당 화면을 연다.
- [ ] 전역 음성 명령을 듣는 중 `a/`를 다시 누르면 녹음과 화면이
  즉시 닫히고 기능이 실행되지 않는다.
- [ ] “무지개는 왜 생겨?” 같은 일반 질문은 로컬 AI로 한 번만
  전송되고 답변 완료 뒤 한국어 TTS가 재생된다.
- [ ] “문서 질문” 또는 “파일 열어”는 홈으로 돌아간 뒤 Files
  선택기를 한 번만 표시한다.
- [ ] “웹 검색”은 아직 네트워크 검색을 실행하지 않고 미지원 안내 후
  다시 듣기 상태로 돌아간다.
- [ ] L1을 한 번 누르면 약 0.3초 뒤 빠른 메뉴가 한 번 열리고, 빠르게
  두 번 누르면 기존 메뉴를 닫지 않고 안내 상태로 열린다.
- [ ] 숫자 버튼을 0.5초 이상 누르면 기존 짧은 누름 동작은 한 번만
  실행되고, 3초 넘게 잡고 있거나 뗌 패킷이 빠져도 입력이 고착되지 않는다.

## 다음 구현 우선순위

### P0 — 실기기 호환성과 안정성

- 장시간 연결, 빠른 연타, 전원 껐다 켜기 회귀 테스트
- 복수의 Rivo가 주변에 있을 때 저장 기기와 수동 선택 정책 검증

### P1 — VisionCraft 조작 범위 확장

- 로컬 문서의 색상 조합 변경과 읽기 시작·중지 키 확장
- 돋보기의 Android DISPLAY 색상·밝기 모드와 초점 명령
- 문서 스캔 결과의 재촬영, 페이지 이동, 저장 명령
- L2/L3/L4/R1/R4 두 번 누름을 각 iPad 화면의 조작 안내와 연결
- 앱 상태별 버튼 매핑을 사용자가 바꾸는 설정

### P2 — 연결 경험과 펌웨어 연동

- Rivo 펌웨어가 시간 명령을 적용했는지 응답 패킷으로 확인할 수 있는지 조사
- AccessorySetupKit을 이용한 안내형 페어링 검토
- 펌웨어 버전과 배터리 정보를 제공하는 특성이 있으면 표시
- 재연결 지수 백오프와 배터리 절약 정책

## iPadOS에서 의도적으로 제한되는 범위

- 일반 앱은 다른 앱의 버튼, 터치, 홈 동작을 임의로 제어할 수 없다.
- 시스템 전체 제어가 필요하면 Rivo 펌웨어의 HID/Switch Control 지원과
  iPadOS 손쉬운 사용 설정을 별도로 설계해야 한다.
- `bluetooth-central`은 연결 복원 기회를 제공하지만 앱을 항상 실행
  상태로 유지하거나 무제한 백그라운드 처리를 보장하지 않는다.
- Android WorkManager의 12시간 주기와 달리 iPadOS 일반 앱은 정확한
  백그라운드 실행 시각을 보장하지 않는다. 현재 구현은 연결 직후와 앱의
  활성 BLE 세션이 유지되는 동안 재전송하며, 복원 시 다시 즉시 맞춘다.
