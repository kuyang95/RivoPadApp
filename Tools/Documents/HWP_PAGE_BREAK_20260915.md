# 한글 쪽 나누기 — 2026-09-15

원본 보기의 상단 **쪽**을 메뉴로 바꾸고 **쪽 설정 / 쪽 나누기 / 쪽 나누기 없애기**를 배치했다. 쪽 설정은 커서 없이 열 수 있고, 쪽 나누기는 일반 1단 본문에 커서를 놓아 사용한다. 하드웨어 키보드에서는 **Ctrl+Enter**로 나눈다.

## 사용 동작

- 문장 중간에서 나누면 커서 뒤 내용부터 새 문단으로 만들어 다음 쪽에 배치한다. 선택한 글자가 있으면 그 범위를 대체한다. 한글·이모지의 문자 경계를 유지한다.
- 문단 맨 앞에서는 기존 문단 앞에 나눔을 지정한다. 문서 첫머리나 문단 끝에서는 빈 문단이 만들어질 수 있다. 이미 명시적 나눔이 있는 문단 맨 앞에서 다시 삽입하는 것은 중복 적용하지 않는다.
- **쪽 나누기 없애기**는 현재 문단 앞의 명시적인 나눔을 해제한다. 문단 내용과 문단 자체는 유지한다. 자동으로 다음 쪽에 배치된 문단에는 이 메뉴가 비활성화된다.
- 나눔 뒤 문단 맨 앞에서 **Backspace**를 누르면 나눔부터 해제한다. 그다음 Backspace는 기존 목록 해제·문단 합치기 규칙을 따른다.
- 실행 취소·다시 실행은 문단 구조와 배치를 함께 복원한다. 나누기 전에 입력하던 내용은 별도 편집 이력으로 보존한다. 저장 시 HWP/HWPX 원본 형식을 유지한다.

## 배치와 저장

쪽 나눔 변경 시 해당 구역의 본문을 다시 배치한다. 원래 머리말·꼬리말 영역을 제외한 본문 높이를 사용하고, 기존 표의 크기를 보존하며 표 뒤 본문의 위치를 갱신한다. 나눔을 지울 때는 앞 본문부터 배치를 계산해 이전 페이지의 캐시 위치가 남지 않게 한다.

HWP는 PARA_HEADER의 쪽 나눔 비트만 켜거나 끈다. 공유 문단 모양에서 상속받은 나눔을 해제할 때에는 해당 문단 모양을 복제하고 상속 비트를 제거한다. 다른 문단의 모양, 구역·단 관련 비트와 관계없는 스트림은 보존한다.

HWPX는 선택한 p 요소의 pageBreak 속성을 갱신한다. 공유 paraPr의 breakSetting에서 상속한 나눔을 해제할 때는 문단 모양을 복제해 해당 문단에만 적용한다. 원래 정의와 나머지 속성을 유지한다.

저장 후 서식 비교에 쪽 나눔 여부를 포함했다. HWPX에서 글자가 없어져 빈 문단이 될 때 언어별 대체 글꼴이 바뀌는 경우도 실제 저장 결과와 비교해 원래 입력 글꼴을 유지하도록 보완했다. HWP의 기존 빈 셀 텍스트 저장 경로는 유지한다.
