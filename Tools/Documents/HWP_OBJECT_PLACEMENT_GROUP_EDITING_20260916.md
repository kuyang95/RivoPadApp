# 한글 개체 글 배치·그룹 도형 편집 · 2026-09-16

우선순위 10의 기본 범위를 적용했다. 원본 화면에서 도형 또는 HWP 그룹 도형을 누르면 기존 위치·크기·회전·배치 순서에 더해 글 배치, 기준 위치·정렬과 바깥 여백을 변경할 수 있다.

## 적용 범위

- 글자처럼 취급을 켜거나 끈다.
- 떠 있는 개체는 글 둘레, 위아래, 글 뒤, 글 앞 배치를 선택한다.
- 가로 기준은 종이·쪽·단·문단, 세로 기준은 종이·쪽·문단을 지원한다.
- 가로 왼쪽·가운데·오른쪽, 세로 위·가운데·아래 정렬과 네 방향 바깥 여백을 저장한다.
- HWP와 HWPX는 원래 형식으로 저장하며 다시 열었을 때 배치 속성을 복원한다.
- HWP 그룹 도형은 그룹 전체의 위치·크기·회전·배치 순서·글 배치와 삭제를 편집한다. 후속 [그룹 내부 도형 편집](HWP_GROUP_CHILD_EDITING_20260916.md)에서 HWP/HWPX 자식 도형의 좌표·크기·회전·선·채우기까지 개별 편집하도록 확장했다.
- 원본 화면에서 그룹 도형도 선택 테두리와 편집 창으로 연결한다.

## 검증

[HWPShapeEditingTests.swift](/Users/me/Develop/IOSProject/RivoPadApp/shortcuts_exampleTests/HWPShapeEditingTests.swift)는 HWP/HWPX 도형의 배치 속성 저장과 재열기, 공개 `V25-group.hwp` 그룹 예제의 이동·크기·회전·글 뒤 배치, 자식 도형 보존을 검사한다. M4 실기기에서 5개 검사가 통과했다.

## 남은 범위

글 둘레 속성은 저장하고 기존 줄 배치를 유지하지만, 개체를 새 위치로 옮긴 뒤 주변 문장을 한컴 한글과 같은 좌우 흐름으로 다시 조판하는 기능은 제한적이다. 맞쪽의 안쪽·바깥쪽 정렬은 남아 있다. 자유 다각형·연결선, [복합 글상자 편집](HWP_COMPLEX_TEXTBOX_EDITING_20260916.md), [다단 편집](HWP_COLUMN_EDITING_20260916.md), [그룹 내부 도형 편집](HWP_GROUP_CHILD_EDITING_20260916.md), [그룹 구조 편집](HWP_GROUP_STRUCTURE_EDITING_20260916.md), [새 그룹 만들기](HWP_GROUP_CREATION_20260916.md), [여러 도형 정렬·간격 맞춤](HWP_SHAPE_ALIGNMENT_EDITING_20260917.md)을 후속 적용했다.
