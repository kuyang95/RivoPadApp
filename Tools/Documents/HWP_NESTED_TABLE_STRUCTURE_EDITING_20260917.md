# 중첩 표 구조·크기 편집

우선순위 33으로 HWP/HWPX 중첩 표의 행·열, 셀 병합·분할과 크기 편집을 적용했다.

## 동작 범위

- 안쪽 표 셀에 커서를 놓고 **표 편집**에서 위·아래 행과 왼쪽·오른쪽 열을 추가하거나 선택한 행·열을 삭제한다.
- **병합·분할**에서 오른쪽·아래 셀 병합, 좌우·상하 분할과 병합 풀기를 실행한다.
- **크기**에서 안쪽 표의 선택 행 높이와 열 너비를 바꾼다.
- 안쪽 표의 셀 내용과 서식을 유지하고, 새 셀은 바로 입력할 수 있는 빈 셀로 만든다.
- 안쪽 표의 최대 너비를 바깥 셀의 좌우 여백을 뺀 영역으로 제한한다.
- 안쪽 표 높이가 바뀌면 바깥 셀과 바깥 표의 행 높이, 표 뒤 본문 위치를 순서대로 다시 계산한다.
- 실행 취소·다시 실행과 HWP/HWPX 원본 형식 저장·재열기를 지원한다.

## 경계

- 구조를 바꿀 대상 표의 셀에 그림·도형이 있거나 그 안에 표가 한 단계 더 들어 있으면 해당 구조 명령을 제한한다.
- 암호·배포용·DRM 문서와 보호된 셀은 기존과 같이 편집하지 않는다.
- 표 셀 안 Enter 문단 추가와 Backspace 문단 합치기는 우선순위 34에서 적용했다. 자세한 범위는 [표 셀 문단 편집 기록](HWP_TABLE_CELL_PARAGRAPH_EDITING_20260917.md)에 정리했다.

- 바깥 표 내용 보존, 부모 표 연결, 바깥 셀 너비 제한과 뒤 본문 재배치를 확인했다.
