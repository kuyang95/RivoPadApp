# 그림 테두리·밝기·대비 · 2026-09-17

우선순위 25를 적용했다. HWP/HWPX 원본 화면에서 그림을 누르면 기존 그림 설정을 불러와 밝기·대비와 테두리 사용 여부, 색, 굵기, 선 종류를 바꿀 수 있다.

## 적용 범위

- 밝기와 대비를 각각 -100부터 100까지 조절하고 미리보기에 즉시 반영
- 보정 초기화로 밝기·대비를 한 번에 0으로 복원
- 테두리 사용 여부, 색, 0.25~12pt 굵기 편집
- 실선·파선·점선·일점쇄선 선택
- 문서 화면에서도 밝기·대비와 테두리 렌더링
- 기존 자르기·크기·회전·뒤집기·글 배치·여백·앞뒤 순서와 한 번에 적용
- HWPX의 `img` 밝기·대비와 `lineShape` 보존
- HWP 그림 속성의 INT8 밝기·명암, 테두리 색·굵기·속성 보존
- 테두리 해제, 실행 취소·다시 실행, 원본 형식 저장·재열기 지원

HWP 바이너리 위치는 한컴 공개 HWP 5.0 파일 형식의 표 107 그림 개체 속성과 표 32 그림 정보를 기준으로 구현했다.
