## 판정 기준

1. **사실 정확성**: 최종 표시문에 질문의 정답이 있고 상충하는 결론이 없는가.
2. **답변 회수율**: 문서로 답할 수 있는 질문을 실제로 답했는가.
3. **직접성·가독성**: 질문에 직접 답하며 표·페이지 전체를 그대로 쏟지 않는가.
4. **안전성**: 문서에 없거나 모호하거나 해석이 필요한 질문을 확정적으로 답하지 않는가.
5. **차단 설명 품질**: 차단 시 사용자가 다음 행동을 선택할 수 있도록 실제 이유를 설명하는가.

- 최종 답변 조립: 9개 모두 원문 덩어리라 실패

따라서 현재 결과를 “구현 완료”나 “16/30 성공”으로 표현하면 안 된다. 정확한 상태는 **안전 게이트 POC는 작동하지만, 답변 회수와 출력 조립은 아직 실패**다.
