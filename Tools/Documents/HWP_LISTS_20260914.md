# 한글 글머리표·번호 매기기 — 2026-09-14

원본 보기의 문서 상단에 글머리표와 번호 매기기 버튼을 추가했다. 현재 문단에 기본 목록을 적용하거나 다른 종류로 바꾸고, 같은 버튼을 다시 눌러 해제할 수 있다. 글자 앞에 기호를 붙이는 방식이 아니라 HWP/HWPX의 문단 목록 서식으로 저장한다.

## 적용한 동작

- 기본 글머리표 `•`와 십진수 `1.`, `2.`, `3.` 목록을 지원한다. 글자 서식과 실제 본문 문자열은 유지한다.
- 같은 위치의 연속 문단에 번호를 적용하면 앞 문단의 목록을 이어받는다. 목록을 해제하거나 항목을 추가하면 뒤 번호를 갱신한다. 다른 구역·표 셀·별도 목록의 번호는 분리한다.
- 일반 본문에서 Enter는 다음 목록 항목을 만든다. 빈 항목에서 Enter는 새 문단을 더 만들지 않고 목록을 끝낸다.
- 목록 문단 맨 앞에서 Backspace는 먼저 목록을 해제한다. 그다음 Backspace는 기존 본문 문단 병합 동작을 따른다. Shift-Enter는 항목 안에서 줄만 바꾼다.
- 줄이 길어지면 목록 기호의 공간을 확보해 줄바꿈한다. 여러 줄과 여러 쪽에 걸쳐도 기호는 문단 첫 줄에 한 번만 표시한다. 입력창에도 목록 기호와 들여쓰기를 적용해 커서가 본문에 맞게 놓인다.
- 서식 변경의 실행 취소·다시 실행은 선택 위치와 글자 서식을 보존한다. 문단 추가·삭제와 문서 실행 취소는 번호와 배치를 함께 복원한다.

## 저장과 기존 문서 보존

HWP는 NUMBERING/BULLET 정의를 추가하고 새 문단 모양이 해당 정의를 참조하게 한다. 문서 정보의 정의 개수도 갱신하며, 원본의 다른 목록 정의와 글꼴·글자 서식을 수정하지 않는다. HWPX는 `numberings`/`bullets`와 문단 `heading` 참조를 사용한다. 문단 구조 변경 후에도 같은 목록의 정의가 이어지도록 저장하고 재열기한다.

형식 구현은 [한컴 HWP 5.0 공개 문서 §4.2.8–4.2.10](https://cdn.hancom.com/link/docs/%ED%95%9C%EA%B8%80%EB%AC%B8%EC%84%9C%ED%8C%8C%EC%9D%BC%ED%98%95%EC%8B%9D_5.0_revision1.2.pdf)과 [한컴 OWPML 목록 모델](https://github.com/hancom-io/hwpx-owpml-model/tree/main/OWPML/Class/Head)을 참고했다.

## 범위와 다음 순서

현재 추가하는 목록은 한 수준의 기본 글머리표와 십진수 번호다. 다단계 목록, 사용자 지정 기호·번호 형식, 시작 번호 지정·다시 시작 메뉴, 여러 문단을 한 번에 선택해서 적용하는 기능은 후속 범위다. 기존 복합 번호 정의는 보존하지만 모든 번호 형식의 표시를 구현한 것은 아니다.

일반 표 셀의 문단에도 목록 서식을 적용할 수 있다. 다만 **표 셀 안의 Enter는 아직 항목 안 줄바꿈**이며, 셀 내부 문단 구조 추가는 기존 표 편집의 후속 범위다. 중첩 표·개체가 포함된 셀과 다단 본문의 복합 배치 한계도 남아 있다.

저장·재열기 검증은 앱의 HWP/HWPX 파서를 사용했다. 외부 한컴 제품에서 재열기·인쇄한 결과를 확인한 것은 아니다.

다음 순서는 강조·취소선·위/아래 첨자·서식 지우기다. 그다음은 셀 테두리·채우기·수직 정렬과 행·열 추가·삭제·병합·분할이다.
