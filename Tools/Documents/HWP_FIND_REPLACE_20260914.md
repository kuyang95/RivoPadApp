# 한글 찾기·바꾸기 — 2026-09-14

원본 보기의 문서 상단에 찾기·바꾸기를 넣었다. 본문과 표 안의 검색어를 실제 등장 횟수대로 찾고, 선택한 한 곳 또는 편집 가능한 결과 전체를 바꿀 수 있다.

## 사용 흐름

- 상단 서식 버튼 오른쪽의 돋보기 또는 Command-F로 검색창을 연다.
- 같은 문단 안의 여러 검색 결과도 각각 이동한다. 선택한 검색어를 노란색으로 표시하고 해당 쪽으로 이동한다.
- 대소문자 구분 옵션을 제공한다. 공백과 기호도 입력한 문자열대로 검색한다.
- ‘바꾸기’를 펼쳐 바꿀 내용을 입력한다. 빈 문자열로 검색어를 지울 수도 있다.
- 한 곳을 바꾸면 다음 결과로 이동한다. 모두 바꾸기는 실행 취소 한 번으로 내용과 배치를 함께 복원한다.

## 구현과 보존

- 검색 위치는 원본 문단의 UTF-16 범위와 원문 스냅샷으로 관리한다. 표의 반복 머리글과 여러 쪽의 화면 조각이 같은 원문을 중복 집계하지 않는다.
- 교체 문자열에 검색어가 포함되어도 새 문자열을 다시 교체하지 않는다. 원문이 그사이 바뀌면 오래된 검색 위치로 교체하지 않는다.
- 바꾸는 글자는 첫 번째 대상 글자의 서식을 이어받고, 바꾸지 않는 글자의 혼합 서식은 보존한다. 한글 결합 문자와 이모지 중간을 끊지 않는다.
- 편집할 수 없는 결과는 검색할 수 있지만 교체하지 않으며, 모두 바꾸기 후 건너뛴 개수를 알린다.
- 여러 결과를 바꿀 때 각 셀을 한 번 측정하고 각 구역의 뒤 본문을 한 번 배치하도록 공통 경로를 정리했다. 기존 표 일괄 편집과 실행 취소도 다시 확인했다.
- 결과가 20,000개를 초과하면 모두 바꾸기를 막고 검색어를 좁히도록 안내한다. 문단당 100,000 UTF-16 단위 제한도 적용 전 검사한다.
- HWP/HWPX의 기존 저장 경로를 사용한다. 한국어 문구와 영어·일본어 번역을 추가했다.
