# Android VisionCraft ↔ iPadOS 미이식 항목 (2026-09-29 대조)

**이식 작업 전 대조 기록.** 표의 "iOS 현재"는 2026-09-29 이식 시작 전 상태이며, 지금 앱 상태를 뜻하지 않는다. 현재 화면 규격은 [`docs/design/05_screen_specs.md`](../../docs/design/05_screen_specs.md)를 본다.

Android 기준: HEAD `c6a03f0` (iOS 규격 문서 기준은 `5eb241e`). 양쪽 실제 코드를 영역별로 대조한 결과다.
판정: **이식** = 옮긴다 · **불가** = iPadOS에서 구조적으로 못 만든다 · **애매** = 사용자 결정 필요.

`5eb241e` 이후 Android UI 커밋 2건(가로 4열 `140bdaa`, 회색 squircle `c6a03f0`)은 코드는 이미 반영됐고 **타일 그림 파일만** 옛 것이다.
