# 한글 자유 다각형·연결선 편집 · 2026-09-16

우선순위 11을 적용했다. 원본 화면 상단 **도형** 메뉴에서 자유 다각형과 연결선을 새로 넣고, 개체를 눌러 점을 직접 끌어서 모양을 바꿀 수 있다.

## 적용 범위

- HWP/HWPX 일반 1단 본문에 자유 다각형과 꺾인 연결선을 삽입한다.
- 자유 다각형은 기본 5개 꼭짓점을 제공하며 점을 추가하거나 마지막 내부 점을 삭제할 수 있다. 최소 3개, 최대 32개다.
- 연결선은 시작점·끝점과 꺾임점을 직접 끈다. 점 추가·삭제를 지원하며 최소 2개, 최대 32개다.
- 연결선 시작과 끝에 없음, 화살표, 창, 오목 화살표, 빈 마름모·원·사각형을 각각 지정한다.
- 기존 위치·크기·회전·선 스타일·그림자·글 배치·앞뒤 순서 편집과 함께 사용할 수 있다.
- HWP는 다각형·곡선 기하 기록과 선 화살표 비트를 저장한다. HWPX는 `polygon` 꼭짓점과 `connectLine`의 시작·끝·제어점을 저장한다.
- 점과 선 스타일만 바뀌고 개체의 바깥 배치가 같으면 문단 줄 기록을 불필요하게 다시 쓰지 않아 복합 개체 문서의 원본 구조를 보존한다.

## 검증

- 새 HWPX 자유 다각형과 연결선의 삽입, 점 이동, 서로 다른 시작·끝 화살표, 저장·재열기를 검사했다.
- 공개 `V32-polygon.hwp`와 `V34-curves.hwp`에서 기존 다각형·곡선을 찾아 점과 화살표를 바꾼 뒤 재열었다.
- 기존 사각형·타원·선과 HWP 그룹 도형 검사를 함께 실행했다.
- M4 실기기에서 `HWPShapeEditingTests` 7개가 모두 통과했다.
- 최종 Debug 빌드를 2026-09-16 16:32 KST에 무선 M4에 설치하고 실행했다.

## 남은 범위

- 연결선을 다른 도형의 특정 연결 지점에 자동 부착하고 도형 이동을 따라가게 하는 기능은 아직 없다.
- 곡선 구간의 베지어 제어점과 구간별 직선/곡선 전환은 제공하지 않는다. 기존 HWP 곡선은 열린 연결 경로로 편집한다.
- HWPX 그룹 내부의 개별 도형 선택과 한컴 수준의 글 둘레 자동 재조판은 기존 제한이 유지된다.
