# 한글 문단 편집 1차 · 2026-09-11

후속: [표 셀·행 높이와 쪽 배치 1차 · 2026-09-14](HWP_TABLE_EDITING_20260914.md)를 적용했다.

우선순위 1의 기본 작업으로, 원본 보기에서 일반 본문 문단을 나누고 합치며 뒤 문단과 쪽 배치를 갱신하는 기능을 추가했다. 상단 서식 도구와 기본 커서 편집은 그대로 사용한다.

## 적용 범위

- Enter: 커서에서 문단을 나눈다. 선택한 글자가 있으면 선택 부분을 지우고 나눈다. 다음 문단 맨 앞에 커서를 놓는다.
- Backspace: 문단 맨 앞에서 앞 문단과 합친다. 합쳐진 경계에 커서를 놓고 양쪽 글자 서식을 유지한다.
- Shift+Enter: 같은 문단 안에서 줄만 바꾼다. 마지막 빈 줄도 배치에 포함한다.
- 한글 조합과 이모지: 조합을 확정하고 구조를 바꾸며, 이모지·결합 문자 중간을 자르는 잘못된 범위는 거부한다.
- 입력 중 미리보기: 조합 중이 아닌 입력을 짧게 모아 본문 줄과 뒤 문단의 배치를 갱신한다. 여러 쪽으로 늘어나도 첫 입력창의 식별자를 유지하여 커서와 UIKit 실행 취소를 보존한다.
- 확정 시 배치: 본문 길이와 글자 크기·문단 간격에 맞춰 뒤 문단과 쪽을 다시 배치한다. 글자색·밑줄·정렬만 바뀌면 원본 줄 좌표를 유지한다.
- 기존 표: 본문 문단이 이동하면 표의 본문 기준점도 이동한다. 표 높이를 확보하고 표 뒤의 다음 쪽 문장이 표 위로 겹치지 않도록 처리한다.
- 실행 취소·다시 실행: 문단 추가·삭제, 선택 문단과 배치를 한 묶음으로 복원한다.
- HWP/HWPX 저장: 원본 문단 순서와 새 문단의 출처를 기록하여 저장 시 문단 번호를 다시 맞춘다. 새 문단에는 구역 설정이나 개체를 복제하지 않는다. 문자/문단 서식, 수정된 줄 배치와 다른 표·그림 자료를 보존하며 재열어 검사한다.

## 경계와 남은 작업

- 구조 편집과 자동 배치는 일반 본문, 표 셀 문단, 중첩 표와 개체 없는 동일 너비 1~4단 본문을 대상으로 한다. 서로 다른 너비의 단 재조판과 복합 개체가 섞인 다단 배치는 제한된다.
- 구역·단 설정 등 문단에 붙은 제어 정보가 있는 문단의 경계는 삭제하지 않는다. 원본 제어 정보를 잃는 병합은 허용하지 않는다.
- 여러 쪽에 걸친 문단의 입력기는 현재 쪽 영역에서 문단 전체를 스크롤하여 편집한다. 다음 쪽에서 시작한 편집이나 입력창의 첫 줄이 다른 쪽으로 이동하는 배치는 확정 시 반영한다. 한컴과 동일한 여러 페이지 연속 입력면을 구현한 것은 아니다.
- 표 셀/행 높이와 중첩 표의 부모 높이 전파를 지원한다. 3단 이상 중첩, 복합 글 둘레 배치와 다양한 실제 문서에 대한 추가 검증은 필요하다.
- 외부 한컴 제품에서 재열기·인쇄한 결과는 아직 검증하지 않았다. 저장 검사는 앱의 실제 HWP/HWPX 파서로 재열어 비교한다.
