# 표 셀 그림·도형 삽입 기록

우선순위 31로 HWP/HWPX 일반 표 셀에 새 그림과 도형을 삽입할 수 있게 했다.

## 적용 범위

- 원본 화면에서 일반 표 셀 글자에 커서를 놓으면 상단 **그림**과 **도형** 버튼이 활성화된다.
- 그림은 사진 보관함이나 파일에서 고르고, 도형은 사각형·타원·선·다각형·연결선에서 고른다.
- 본문 삽입처럼 별도 빈 문단을 만들지 않고 현재 셀 문단에 개체를 연결한다.
- 기존 셀 글자, 글자 서식, 셀 테두리·배경, 다른 셀과 표 앞뒤 본문을 유지한다.
- 개체 높이에 맞춰 셀과 행 높이를 늘리고 표 뒤 본문 위치를 다시 계산한다.
- 삽입 후 같은 화면에서 선택·이동·크기·회전과 상세 편집을 이어서 사용할 수 있다.
- HWP 바이너리는 셀 문단의 실제 기록 단계를 기준으로 제어점과 개체 기록을 넣고,
  커서 앞뒤 글자 및 글자 모양·줄 배치 위치를 보정한다.
- 중첩 표 셀은 이번 범위에서 제외하며 우선순위 32에서 다룬다.

## 검증

- 실제 HWP 표 셀에서 기존 글자를 유지한 채 그림과 도형을 삽입하고 재열기했다.
- HWPX 표 셀에서 그림과 도형을 삽입하고 재열기한 뒤 상세 편집 대상으로 다시 선택했다.
