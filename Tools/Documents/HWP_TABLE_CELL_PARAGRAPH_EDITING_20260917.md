# 표 셀 내부 문단 추가·합치기

우선순위 34로 HWP/HWPX 표 셀 안에서 문단을 나누고 합치는 키보드 편집을 적용했다.

## 동작 범위

- 셀 글자 중간에서 **Enter**를 누르면 커서 앞뒤를 같은 셀의 두 문단으로 나누고 새 문단 맨 앞에 커서를 둔다.
- 글자를 선택한 뒤 Enter를 누르면 선택 부분을 지운 위치에서 문단을 나눈다. 한글 조합, 이모지 경계와 글자 서식을 보존한다.
- 둘째 이후 셀 문단 맨 앞에서 **Backspace**를 누르면 같은 셀의 앞 문단과 합치고 합친 경계에 커서를 둔다.
- **Shift+Enter**는 새 문단을 만들지 않고 현재 셀 문단 안에 줄바꿈을 넣는다.
- 나누기·합치기 뒤 셀 문단 순번을 다시 매기고, 내용 높이에 맞춰 행과 표 뒤 본문을 다시 배치한다.
- HWP의 셀 문단 목록 마지막 표시와 HWPX의 셀 하위 문단 XML을 각각 갱신해 원본 형식으로 저장한다.
- 실행 취소·다시 실행과 저장·재열기를 지원한다.

## 경계

- Backspace 합치기는 같은 셀 안에서만 허용한다. 첫 셀 문단과 옆 셀·다른 표·일반 본문 사이 경계는 합치지 않는다.
- 쪽 나누기는 셀 문단에 넣지 않는다.
- 보호된 문서나 편집할 수 없는 제어 개체를 가진 셀 문단은 기존과 같이 구조 편집하지 않는다.

## 검증

- HWP/HWPX에서 셀 문단 나누기, 문단 순번 증가, 다시 합치기와 원본 복원을 확인했다.
- 화면 모델에서 실행 취소·다시 실행, 선택 문단 이동, 원본 형식 저장·재열기를 두 형식 모두 확인했다.
