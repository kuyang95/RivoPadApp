# 문서·텍스트 뷰어 포팅 백로그

Android `TextEditorViewerScreen`과 iPad의 `LocalDocumentView`를 대조해,
자동 검증 가능한 항목은 구현과 테스트로 닫고 파일 선택·VoiceOver·대용량
문서처럼 사람의 조작이 필요한 확인은 여기에 모은다.

## 구현 완료

- PDFKit 원본 보기와 PDF 내장 텍스트/OCR 추출
- TXT UTF-8/UTF-16 가져오기와 읽기/편집 모드 전환
- 전체 텍스트 복사와 iPad 네이티브 부분 선택
- 현재 보이는 논리 줄부터 로컬 TTS 읽기와 즉시 정지
- 문서 처음/끝, 이전/다음 논리 줄, 화면 높이 기반 이전/다음 페이지 이동
- Android와 같은 16개 고대비 색상 조합
- 10단계 글자 크기와 줄 간격, 줄 구분선, 설정 영구 저장
- UTF-8 TXT와 여러 페이지 PDF Files 내보내기
- 문서 전체를 문맥으로 전달하는 로컬 AI 질문

## 실기기 일괄 확인

- [ ] 11인치 M4 iPad의 세로·가로·Split View에서 1~10단계 글자 크기와
      줄 간격이 잘리지 않고 탐색 막대와 질문 입력창이 겹치지 않는다.
- [ ] 16개 색상 조합이 본문·줄 구분선·VoiceOver 포커스에서 충분한 대비를
      유지하며 설정이 앱 재실행 뒤에도 복원된다.
- [ ] 긴 TXT와 텍스트 PDF에서 처음/끝·줄·페이지 이동이 맞는 위치로
      스크롤되고 화면에 표시되는 줄 위치가 수동 스크롤을 따라간다.
- [ ] 읽기 버튼이 현재 보이는 줄부터 시작하고 정지·화면 닫기에서 음성이
      남지 않는다.
- [ ] 한글·영문·이모지와 빈 줄이 섞인 내용을 편집하고 부분 선택 복사한 뒤
      TXT로 저장하면 UTF-8 내용이 보존된다.
- [ ] 여러 페이지 PDF 내보내기 결과가 Files와 다른 PDF 앱에서 열리고
      마지막 문장이 잘리지 않는다.
- [ ] 원본 PDF/텍스트 전환, 편집 모드, 큰 글자, VoiceOver를 함께 사용할 때
      포커스 순서와 버튼 이름이 이해 가능하다.

## 다음 구현

- 가로 화면에서 한 줄을 크게 표시하고 좌우로 이동하는 읽기 모드
- TTS 발화 문장 강조와 이전/다음 문장 이동
- 긴 문서를 로컬 AI 컨텍스트 크기에 맞춰 검색·분할하는 전략
- 사용자가 선택한 폴더의 보안 범위 북마크와 문서 목록
- XLS/XLSX 셀 텍스트 추출과 시트 탐색
- HWP/HWPX 텍스트 추출 또는 안전한 변환 경로
- Share/Action Extension에서 사진·PDF·선택 텍스트 바로 열기

## iPadOS 제약

- 사용자가 선택하지 않은 기기 전체 저장소를 앱이 재귀 검색할 수 없다.
- Android식 임의 파일 경로 접근 대신 Files 선택기와 보안 범위 URL을 써야 한다.
