# 문서·텍스트 뷰어 포팅 백로그

Android `TextEditorViewerScreen`과 iPad의 `LocalDocumentView`를 대조해,
자동 검증 가능한 항목은 구현과 테스트로 닫고 파일 선택·VoiceOver·대용량
문서처럼 사람의 조작이 필요한 확인은 여기에 모은다.

## 구현 완료

- PDFKit 원본 보기와 PDF 내장 텍스트/OCR 추출
- 텍스트 레이어가 없는 PDF 페이지를 Vision OCR한 뒤 설정에 따라 페이지
  이미지와 원문을 M4 Qwen3-VL로 대조 교정하고 실패 시 원문 유지
- TXT UTF-8/UTF-16 가져오기와 읽기/편집 모드 전환
- 전체 텍스트 복사와 iPad 네이티브 부분 선택
- 현재 보이는 논리 줄부터 로컬 TTS 읽기와 즉시 정지
- 문서 처음/끝, 이전/다음 논리 줄, 화면 높이 기반 이전/다음 페이지 이동
- Android와 같은 16개 고대비 색상 조합
- 10단계 글자 크기와 줄 간격, 줄 구분선, 설정 영구 저장
- UTF-8 TXT와 여러 페이지 PDF Files 내보내기
- 문서 전체를 문맥으로 전달하는 로컬 AI 질문
- Share Extension의 PDF를 App Group 로컬 수신함으로 받아 문서 화면 열기
- Action Extension의 선택 텍스트를 로컬 AI 질문 화면으로 열기
- Files에서 문서 하나를 직접 고르거나 사용자가 승인한 폴더를 보안 범위
  북마크로 저장해 다음 실행에도 다시 검색
- 승인 폴더 안의 PDF·TXT·XLSX·XLS·HWP·HWPX를 최대 5,000개·64단계로
  제한해 재귀 검색하고 숨김·패키지·심볼릭 링크를 건너뜀
- 파일 이름과 상대 폴더 경로의 대소문자·악센트·전각 차이를 무시한
  여러 검색어 필터, 최근 수정 순 정렬, 새로고침·폴더 재선택·권한 삭제
- 폴더 문서는 열 때 앱 임시 영역에 복사하고 경로 이탈·링크 교체를 다시
  검증해 승인 폴더 밖 파일을 열지 않음
- 문서 뷰어에서 XLSX·Excel 97-2003 BIFF8 XLS·HWP 5.x·HWPX 추출문을
  표시·TTS·복사·편집·AI 질문에 사용
- HWPX의 `Contents/content.hpf` 읽기 순서와 `section*.xml`의 문단·표 셀,
  탭·줄바꿈을 ZIP/XML에서 직접 추출하고 스크립트·외부 링크·첨부 개체는
  실행하지 않음
- HWPX에 20MB 입력·4,096개 ZIP 항목·64MB 압축 해제·64개 구역·
  1MB 결과 제한과 CRC·심볼릭 링크·중복/이탈 경로·손상 XML 방어 적용
- Android 설정과 같이 가로 화면에서만 현재 논리 줄 하나를 줄바꿈 없이
  크게 표시하는 한 줄 읽기 모드와 설정 저장
- 현재 보이는 줄부터 문장 단위로 연속 TTS하고 발화 문장을 강조하며
  이전·현재 다시 읽기·다음 문장으로 이동
- PDF·TXT·XLS·XLSX·HWP·HWPX의 보기·편집·복사·내보내기, 문장 TTS,
  줄·페이지 탐색, 16색 테마와 Rivo 음성 피드백이 앱에서 선택한
  영어·일본어로 즉시 바뀌도록 동적 문구와 오류까지 번역

## 실기기 일괄 확인

- [ ] 11인치 M4 iPad의 세로·가로·Split View에서 1~10단계 글자 크기와
      줄 간격이 잘리지 않고 탐색 막대와 질문 입력창이 겹치지 않는다.
- [ ] 16개 색상 조합이 본문·줄 구분선·VoiceOver 포커스에서 충분한 대비를
      유지하며 설정이 앱 재실행 뒤에도 복원된다.
- [ ] 긴 TXT와 텍스트 PDF에서 처음/끝·줄·페이지 이동이 맞는 위치로
      스크롤되고 화면에 표시되는 줄 위치가 수동 스크롤을 따라간다.
- [ ] 읽기 버튼이 현재 보이는 줄부터 시작하고 정지·화면 닫기에서 음성이
      남지 않는다.
- [ ] 한글·영문·이모지와 빈 줄이 섞인 내용을 편집하고 부분 선택 복사한 뒤
      TXT로 저장하면 UTF-8 내용이 보존된다.
- [ ] 여러 페이지 PDF 내보내기 결과가 Files와 다른 PDF 앱에서 열리고
      마지막 문장이 잘리지 않는다.
- [ ] 원본 PDF/텍스트 전환, 편집 모드, 큰 글자, VoiceOver를 함께 사용할 때
      포커스 순서와 버튼 이름이 이해 가능하다.
- [ ] 앱 언어를 영어·일본어로 바꿔 PDF와 TXT를 각각 열고 진행 상태,
      원본/텍스트 전환, 읽기·편집·저장, 16색 이름과 Rivo 탐색 안내가
      선택 언어로 자연스럽게 표시·발화된다.
- [ ] iCloud Drive·나의 iPad·외부 저장 장치·SMB 공급자 폴더를 각각
      선택하고 앱 재실행 뒤 권한과 문서 목록이 복원된다.
- [ ] 승인 폴더의 문서를 추가·이름 변경·삭제한 뒤 새로고침하면 최근 수정
      순서와 검색 결과가 맞고 오래된 항목을 열 때 이해 가능한 오류가 난다.
- [ ] 실제 XLSX·XLS·HWP 5.x·HWPX를 폴더 목록에서 열어 표/문단, TTS, 복사,
      편집, AI 질문이 동작하고 암호화·손상 파일은 구체적으로 안내된다.
- [ ] 한컴오피스에서 만든 단일·다중 구역 HWPX의 일반 문단·표·탭·줄바꿈이
      자연스러운 순서로 보이고 20MB·압축 해제·손상 XML 제한이 동작한다.
- [ ] 가로 한 줄 읽기를 켠 뒤 세로에서는 일반 줄바꿈, 가로에서는 현재
      논리 줄만 좌우 스크롤되며 회전 뒤 줄 위치와 앱 재실행 뒤 설정이 유지된다.
- [ ] 한국어·영어·일본어와 문장 부호가 없는 목록 문서에서 문장 강조,
      이전·다시·다음, 연속 재생 완료와 중지 뒤 오래된 콜백 무시가 맞다.
- [ ] 텍스트 레이어가 없는 1·20페이지 PDF를 OCR 교정 켬·끔으로 열어
      페이지 순서·줄바꿈·숫자·URL이 보존되고 진행 상태와 총 시간이
      이해 가능한지 확인한다.

## iPadOS 제약
