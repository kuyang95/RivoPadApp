# 엑셀 일괄 검증 목록

업데이트: 2026-09-15

사용자 요청에 따라 구현을 먼저 진행하고, 실사용 검증 항목은 이 문서에
누적한다. 기능마다 사용자에게 확인을 요청하지 않고 추후 한꺼번에 검증한다.
빌드·설치·실행 성공은 아래 사용 흐름의 검증 완료를 의미하지 않는다.

## 상단 편집줄과 메뉴

- [ ] 파일명 헤더 없이 뒤로 가기, 셀 주소·값, 값 지우기, 셀 도구,
      실행 취소·다시 실행, 더보기가 한 줄에 표시된다.
- [ ] M4 세로·가로·좁은 창에서 값 입력칸과 버튼이 잘리지 않는다.
      좁은 창이나 큰 글자 설정에서는 실행 취소·다시 실행을 더보기에서 쓸 수 있다.
- [ ] 셀 도구는 아이콘과 배경색 없이 글자와 둥근 테두리만 표시된다.
- [ ] 셀 도구에서 범위 선택·복사, 행·열 편집, 글꼴·색·테두리,
      정렬·필터·찾기와 기존 표시 형식·드롭다운·조건부 서식·링크 및 메모·
      행 추가·이미지·차트 등에 접근할 수 있다.
- [ ] 행 추가와 이미지·차트 등이 더보기에서는 빠지고, 간편 표 보기에서도
      셀 도구로 접근할 수 있다. 이미지·차트 관리 화면의 제목도 일치한다.
- [ ] 문서 로딩·오류 상태에서 뒤로 가기가 가능하며, 미저장 문서의
      뒤로 가기에는 변경 내용 확인이 유지된다.

## 셀 편집

- [ ] 한글·숫자·수식을 입력하고 셀 이동, 키보드 닫기, 셀 도구 열기를
      해도 입력 내용이 사라지거나 중복 반영되지 않는다.
- [ ] 값 지우기와 실행 취소·다시 실행이 올바른 셀과 편집 단위에 적용된다.
- [ ] 표시 형식을 셀 하나 또는 현재 데이터 열에 적용할 수 있고,
      저장된 원래 값은 유지된다.
- [ ] 드롭다운 목록 생성·값 선택·변경·제거가 셀과 열 범위에 맞게 적용된다.
- [ ] 조건부 서식 생성·수정·제거와 링크·메모 편집·제거가 동작한다.
- [ ] 셀 도구에서 선택한 뒤 해당 편집 창이 정상적으로 열리고,
      닫기·뒤로 가기·바깥 영역 누르기로 메뉴를 벗어날 수 있다.

## 행 추가

- [ ] 현재 표의 마지막에 행이 추가되며 다른 표나 시트가 바뀌지 않는다.
- [ ] 새 행에 입력한 값과 관련 수식·서식이 의도대로 유지된다.
- [ ] 행 추가를 실행 취소·다시 실행한 뒤 데이터와 선택 위치가 맞는다.
- [ ] 빈 시트·여러 표가 있는 시트·간편 보기에서 적용 대상을 확인한다.

## 이미지·차트 등

- [ ] 이미지 추가·교체·삭제 후 올바른 위치와 내용으로 표시된다.
- [ ] 도형·텍스트 상자를 추가·편집·삭제하고 표시 결과를 확인한다.
- [ ] 차트의 원본 범위·종류·제목을 설정하거나 변경하고 결과를 확인한다.
- [ ] 피벗 요약표의 분류별 합계·개수를 원본 데이터와 대조한다.
- [ ] 개체 편집을 취소하거나 창을 다시 열었을 때 목록과 내용이 일치한다.

## AI 답변과 셀 참조

- [ ] Microsoft 매출·이익 샘플에서 국가별 건수 등 질문의 답과 참조 셀을
      원본 데이터와 대조한다. 독일 이외의 국가와 다른 열도 포함한다.
- [ ] `Units Sold가 888인 제품`처럼 정확한 값 검색에서 제품명·행 수·합계가
      혼동되지 않는다. 복수 조건·비교 조건·결과 없음도 확인한다.
- [ ] 질문과 수정에 같은 보라색 점선 테두리가 표시되고, 배경색은 채우지 않는다.
      파란색 선택 표시와 동시에 보일 때도 구별된다.
- [ ] 후속 질문, 새 질문, 참조 없는 답변, 시트 전환에서 오래된 참조가 남지 않는다.
- [ ] 여러 참조의 이전·다음 이동과 화면 밖·400행 이후 참조 이동이 맞다.

## 저장과 접근성

- [ ] 셀·행·서식·드롭다운·링크·메모·개체 수정 후 저장하고 다시 열어

- [ ] 원본 저장과 XLSX 복사본 내보내기를 각각 확인하고, 다른 엑셀 앱에서
      파일이 정상적으로 열리는지 확인한다.
- [ ] 보호된 시트·수식 확장 결과 셀·대용량 문서에서 편집 제한이 유지된다.
- [ ] 밝은 화면·어두운 화면·큰 글자·VoiceOver에서 버튼 이름,
      포커스 복귀, 메뉴 스크롤, 참조 표시를 확인한다.
- [ ] 한국어·영어·일본어에서 변경한 메뉴 이름과 설명이 자연스럽게 표시된다.

## 2026-09-15 편집 확장: 실사용 검증 대기

- [ ] 셀을 길게 누른 뒤 끌면 파란색 범위가 선택되고 일반 스크롤·핀치와
      충돌하지 않는다. 가장자리에서 끌면 선택을 계속 확장할 수 있다.
- [ ] 셀 주소 입력으로 빈 영역과 화면 밖 범위를 선택하고 이동할 수 있다.
      행 번호·열 이름으로 해당 데이터 행·열을 선택할 수 있다.
- [ ] 여러 행·열의 복사·붙여넣기에서 값·수식·기존 서식이 유지된다.
      탭·줄바꿈·따옴표, 선행 0, 문자로 저장된 TRUE와 =문자열도 확인한다.
- [ ] 잘라내기는 붙여넣을 때 원본을 지우며, 원본 수정 후 붙여넣기는
      중단한다. 겹치는 범위와 다른 시트로 값 이동, 관련 수식 이동도 확인한다.
- [ ] 한 셀을 여러 셀에 붙여넣고 아래·오른쪽으로 채우기를 적용한다.
      숫자 간격과 수식의 상대·절대 참조가 맞는지 확인한다.
- [ ] 범위 편집 전체가 실행 취소 한 번으로 되돌아가고 다시 실행된다.
      일반 셀 편집과 범위 편집을 섞어도 기록이 이어진다.
- [ ] 행·열 삽입·삭제 후 값, 수식, 병합 범위, 표, 드롭다운, 조건부 서식,
      링크·메모와 개체 기준 위치가 일치한다.
- [ ] 행 높이와 열 너비가 원본 보기와 XLSX 재열기에 반영된다.
- [ ] 글꼴·크기·굵게·기울임·밑줄, 글자색·배경색, 가로·세로 정렬,
      줄바꿈과 모든/바깥/없음 테두리가 빈 셀을 포함한 선택 범위에 적용된다.
- [ ] 정렬은 머리글을 유지하고 선택 범위의 행 전체를 함께 이동한다.
      숫자·문자·빈 값·동일 값과 행 내 수식, 링크·메모를 포함한다.
- [ ] 필터가 기준 열과 조건에 맞는 행만 보여주고, 원본·간편 보기에서
      같은 결과를 보여준다. 필터 해제·정렬 후 결과와 저장도 확인한다.
- [ ] 찾기·다음 결과·현재 셀 바꾸기·시트 전체 바꾸기에서 대상 값과
      수식이 정확하고, 없는 값·한글·대소문자·실행 취소도 확인한다.
- [ ] 보호·대용량·배열 수식·복잡한 참조에 대한 제한 안내가 정확하며,
      실패한 작업은 기존 데이터와 실행 취소 기록을 바꾸지 않는다.
- [ ] 구조·서식 편집 전후에 저장·자동 저장·내보내기·재열기·실행 취소를

## 2026-09-15 셀 병합·해제: 실사용 검증 대기

- [ ] 셀 도구의 셀 병합·해제에서 범위와 남는 셀의 값을 확인하고,
      병합 또는 병합 후 가운데 정렬을 적용할 수 있다.
- [ ] 가로·세로·여러 행과 열을 병합했을 때 내부 격자선이 사라지고
      하나의 셀로 보인다. 글자·줄바꿈·배경·테두리와 확대·축소도 확인한다.
- [ ] 다른 셀에 값이나 수식이 있으면 지워질 셀 개수를 표시한다.
      취소는 내용을 유지하고, 병합은 왼쪽 위 값만 남긴다. 왼쪽 위가 빈 경우도 포함한다.
- [ ] 기존 병합에 걸치는 범위는 병합 전체로 확장된다. 범위 일부를
      선택해 병합 해제하면 겹친 병합만 해제되고 다른 병합은 유지된다.
- [ ] 병합·값 입력·X로 값 지우기·병합 해제 후 실행 취소/다시 실행으로
      값과 수식, 서식, 병합 상태가 함께 복원된다. 원본 저장·자동 저장·내보내기도 확인한다.
- [ ] 병합한 셀 어디를 눌러도 같은 셀을 선택하며 파란색 선택과
      보라색 무채움 참조 점선이 전체 병합 크기에 맞는다. VoiceOver는 한 셀로 읽는다.
- [ ] 빈 영역, 400행·40열 표시 구간의 경계, 필터로 시작 행이 숨겨진
      병합도 표시·선택할 수 있으며 다시 열어도 병합 범위가 유지된다.
- [ ] 표·피벗 요약표·배열 수식·보호·대용량 시트의 병합 제한이 안내되고,
      실패한 병합이나 해제는 내용과 실행 취소 기록을 바꾸지 않는다.

- [ ] 삭제 확인창의 시트 이름이 맞고 취소하면 유지된다. 삭제하면 해당

- [ ] 목록 끌기와 왼쪽·오른쪽 이동으로 순서를 변경해도 선택 시트,
