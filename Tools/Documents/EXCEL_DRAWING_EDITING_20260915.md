# 엑셀 이미지·차트 직접 편집 구현

2026-09-15. 틀 고정 다음 작업으로 원본 셀 화면의 이미지·차트 편집을 구현했다.

## 화면과 동작

- 원본 셀 보기 위에 이미지와 차트 미리보기를 표시한다. 가져온 개체의 앞뒤 순서를 따른다.
- 탭으로 선택하면 테두리와 네 모서리 조절점, 설정·삭제·선택 해제 도구가 나타난다.
  선택 전에는 작은 **개체 선택** 메뉴를 제공해 겹친 개체와 화면 밖 개체도 찾을 수 있다.
- 선택한 개체를 끌어 이동하거나 모서리로 크기를 조절한다. 드래그 중에는 화면 상태만
  갱신하고 손을 놓을 때 기존 개체 편집 기록에 한 번 적용한다. 취소 시 미리보기를 버린다.
- 빈 영역의 스크롤·범위 선택·핀치와 개체 드래그를 구분한다. 좌표는 기존 확대·틀 고정
  계산을 사용하며, 가장자리 드래그는 현재 표시 구간 안에서 스크롤한다.
- 이미지 설정: 이름·설명·사진 교체. 차트 설정: 제목·지원되는 종류·원본 셀 범위.
  별도의 위치 적용으로 왼쪽 위 기준 셀과 오른쪽 아래 경계 셀에 맞춰 배치할 수 있다.
- VoiceOver에는 선택·설정·상하좌우 이동·크게/작게 동작을 제공한다.
- 기존 실행 취소·다시 실행·저장·자동 저장·내보내기 경로를 사용한다.

## 파일 보존과 미리보기

- 셀 내부 위치를 EMU 단위로 읽고 쓴다. 한 셀 기준 및 절대 위치 개체의 크기도 읽는다.
  직접 위치를 바꾸면 두 셀 기준과 셀 내부 오프셋으로 저장한다.
- 이동·크기 변경은 개체의 위치 노드와 필요한 이름·설명만 갱신한다.
  이미지 자르기·회전·효과, 차트 관계와 다른 개체의 XML 내용을 보존한다.
- 차트 위치만 바꿀 때 차트 내부 XML을 다시 만들지 않는다.
  미리보기 미지원 고급 차트도 원래 내용을 보존하며 위치·크기를 바꿀 수 있다.
- 사진 교체는 새 미디어 경로를 사용해 같은 이미지 파일을 공유하는 다른 개체를 유지한다.
- 기본 막대·꺾은선·영역·분산형·원형·도넛 차트를 현재 셀 값 또는 리터럴 계열로 그린다.
  현재 문서의 원본 범위를 읽을 수 없는 경우 캐시를 정답처럼 표시하지 않는다.

## 현재 범위와 제한

- 기본 미리보기이며 Excel의 테마·복잡한 그래픽 효과를 그대로 재현하는 렌더러는 아니다.
  이미지 미리보기는 원본 비트맵을 표시하고, 자르기·회전·효과 설정은 XLSX에 보존한다.
- 혼합·누적·방사형 등 미지원 차트는 제목과 미지원 안내를 표시한다.
  차트 미리보기의 원본 데이터 범위는 2,000셀까지이며, 데이터가 없는 숫자를 만들지 않는다.
- 현재 표시하는 행·열 구간에 전체 크기가 들어오는 개체만 직접 끌 수 있다.
  숨긴 행이나 생략한 구간에 걸치면 일부를 표시하고, 설정을 통해 셀 경계로 재배치할 수 있다.
- 일반 편집 범위는 2,000행·200열이며, 끝 경계는 다음 행·열 시작까지 가능하다.
  보호·저장 중·대용량 문서는 직접 편집을 제한한다. 대용량 창 단위 보기에는 개체를 그리지 않는다.
- 도형·텍스트 상자는 기존 이미지·차트 등 관리 화면에서 편집한다. 이번 직접 편집 대상은 이미지·차트다.

## 확인

- 운영 코드로 구성한 독립 Swift 패키지에서 기본 검사 10개가 통과했다.
  셀 내부 오프셋과 작은 개체, 앞뒤 순서, 이동 후 이미지 효과·다른 개체·미디어 보존,
  고급 차트 XML 보존, 한 셀·절대 위치 변환, 공유 이미지 교체, 부분 구간 제한,
  네 모서리 크기 변경, 현재 차트 값 반영, 이동 후 삭제를 확인했다.
- 실제 터치·VoiceOver와 ViewModel의 전체 저장·실행 취소 흐름은 실행하지 않았다.
  사용자 요청대로 [일괄 검증 목록](EXCEL_VALIDATION_BACKLOG.md)에 10개를 추가해 총 83개로 모았다.
- 검사·빌드·설치·실행 기록: `output/excel_drawing_editing_20260915/`.
  `core-tests-final.log`의 10개 검사와 `build-m4-final.log` 빌드가 성공했다.
  영어·일본어 문자열 파일 형식 검사도 통과했다.
- 다른 M4 문서 검사가 끝난 뒤 빌드 결과를 별도로 복사해 코드 서명을 확인했다.
  `install-m4.json` 설치와 `launch-m4.json` 실행이 모두 성공했다.
