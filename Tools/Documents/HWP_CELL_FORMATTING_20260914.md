# 한글 표 셀 테두리·채우기·세로 정렬 — 2026-09-14

원본 보기에서 표 안의 글자를 누르면 상단 서식 도구 맨 앞에 **셀** 버튼이 나타난다. 셀 서식 창에서 채우기, 네 면의 테두리, 위·가운데·아래 정렬을 바꿀 수 있다. 적용 후 같은 위치에서 입력을 이어가며 HWP·HWPX 원본 형식으로 저장한다.

## 화면과 편집

- 채우기는 기본 색상 10개와 ‘채우기 없음’을 제공한다.
- 테두리는 모두 켜기·끄기와 왼쪽·오른쪽·위쪽·아래쪽 개별 전환, 선 굵기 0.1·0.3·0.5·1mm와 선 색상 변경을 제공한다. 원본 선 굵기가 목록에 없으면 그 값도 표시한다. 기존 선의 굵기·색상을 바꿀 때 선 종류를 보존하고 새로 켜는 선은 실선으로 만든다.
- 미리보기에서 채우기·선·세로 정렬을 확인한 다음 적용한다. 취소하면 변경을 버리고 문서의 커서로 돌아간다. 창은 iPad의 넓은 공간을 사용하고 작은 화면에서는 스크롤할 수 있다.
- 한 셀에 문단이 여러 개 있어도 모두 같은 셀 서식을 공유한다. 편집 중 미리보기, 한 번의 실행 취소·다시 실행, 편집 종료 후 문서의 실행 취소·다시 실행을 연결했다.
- 기존 병합 셀의 서식을 바꿔도 병합 범위와 셀 크기를 보존한다. 셀의 내용이 늘어 행 높이가 커지거나 본문에서 문단을 추가한 뒤에도 서식을 저장한다.
- 새로 만드는 HWPX 문서의 기본 글자 음영을 ‘없음’으로 바꿨다. 셀 채우기 위에 불필요한 흰 글자 배경이 생기지 않는다. 원본에 명시적으로 지정된 글자 강조색은 보존한다.

## 저장

공유하는 테두리·채우기 정의를 복제하고 선택한 셀의 참조를 변경한다. 다른 셀의 원본 정의를 덮어쓰지 않는다. HWP는 DocInfo의 BORDER_FILL과 해당 셀의 LIST_HEADER를 갱신하며, HWPX는 header.xml의 borderFill과 셀의 borderFillIDRef·subList.vertAlign을 갱신한다. 세로 정렬만 바꾸면 테두리 정의를 추가하지 않는다.

한 셀 안의 문단마다 서로 다른 셀 서식이 전달되면 저장을 거부한다. 글자 서식·내용 수정·표 높이 변경·본문 문단 추가와 함께 저장되는 경로도 검증한다. 저장된 파일을 다시 파싱하여 요청한 셀 서식과 비교한다.
