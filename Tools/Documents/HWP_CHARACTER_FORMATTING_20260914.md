# 한글 강조색·취소선·첨자·글자 서식 지우기 — 2026-09-14

원본 보기의 상단 서식 도구에 강조색 메뉴와 글자 효과 메뉴를 추가했다. 문단 안에서 고른 글자에 적용하며, 선택 영역이 없으면 이후 입력할 글자의 서식을 바꾼다. 빈 문단도 서식을 먼저 지정한 뒤 입력할 수 있다.

## 화면과 편집 동작

- 형광펜 아이콘의 **강조색** 메뉴에서 노랑·초록·파랑·분홍·보라와 ‘없음’을 선택한다. HWP/HWPX의 글자 음영색으로 저장한다.
- **Aa ▾ / 글자 효과** 메뉴에 취소선, 위 첨자, 아래 첨자, 글자 서식 지우기를 배치했다. 첨자는 서로 동시에 켜지지 않으며, 켜진 항목을 다시 누르면 해제된다.
- **글자 서식 지우기**는 바탕 10pt, 검정 글자로 바꾸고 지원하는 글자 장식·강조색·첨자·장평·자간·글자 위치를 초기화한다. 문단 정렬·목록·문단 여백과 탭 위치는 유지한다.
- 여러 서식이 섞인 선택 영역은 모두 같은 효과를 가진 경우에만 해당 효과를 켜진 상태로 표시한다. 선택 위치를 유지하고, 서식 지우기도 한 번의 실행 취소로 복원한다.
- 첨자는 저장된 글자 크기 값을 유지하면서 화면에서는 작은 글자로 표시한다. 편집창과 문서 화면에 같은 크기 비율·기준선 이동을 사용하고, 줄 높이는 입력창에서 글자가 잘리지 않도록 글꼴의 줄 간격과 첨자 이동량까지 포함한다.
- 취소선은 문서 화면에서도 직접 그린다. 강조색과 검색 강조의 위치도 첨자 기준선을 따른다.

## 저장 처리와 보완

HWP는 공유 글자 모양을 복제해 취소선·위/아래 첨자 비트와 음영색을 기록한다. 해당 버전에 취소선 색 필드가 있으면 새 취소선에 글자색을 기록한다. HWPX는 `shadeColor`, `strikeout`, `supscript`, `subscript`를 저장하고 해제도 반영한다. 원본 글자 모양과 다른 문단·표 셀·첨부 자료는 보존한다.

형식은 [한컴 HWP 5.0 공개 문서 §4.2.6](https://cdn.hancom.com/link/docs/%ED%95%9C%EA%B8%80%EB%AC%B8%EC%84%9C%ED%8C%8C%EC%9D%BC%ED%98%95%EC%8B%9D_5.0_revision1.2.pdf), [한컴 OWPML 글자 모양 모델](https://github.com/hancom-io/hwpx-owpml-model/blob/main/OWPML/Class/Head/CharShapeType.cpp), [취소선 모델](https://github.com/hancom-io/hwpx-owpml-model/blob/main/OWPML/Class/Head/strikeout.cpp)을 확인했다.

서식 저장 검증에 새 속성과 장평·자간·기준선 비교를 추가했다. 이모지의 일부 코드 단위만 선택한 잘못된 범위는 거부한다. 빈 HWPX 문단의 첫 입력에서 언어별 글꼴 참조가 달라지더라도 지정한 입력 서식이 유지되도록 저장 처리를 보완했다.
