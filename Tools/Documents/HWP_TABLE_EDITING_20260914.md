# 한글 표 편집 1차 · 2026-09-14

원본 보기에서 일반 표 셀의 내용을 늘리면 줄 배치를 다시 계산하고, 셀·행·표 높이와 뒤 본문의 위치를 갱신한다. 변경된 셀 높이와 표 높이를 원본 HWP/HWPX에 저장한다.

## 적용한 동작

- 셀 너비, 좌우·위아래 여백, 글자 크기와 문단 간격을 반영하여 입력 내용을 줄로 배치한다. 같은 셀에 문단이 여러 개 있으면 뒤 문단도 이동한다.
- 같은 행의 셀 높이를 함께 맞춘다. 세로 병합 셀은 필요한 추가 높이를 병합 범위의 마지막 행에 반영하여 앞 행들의 위치를 유지한다.
- 뒤 행과 뒤 본문을 이동한다. 표가 여러 쪽으로 이어지면 마지막 표 조각 아래에 본문을 배치한다.
- 한 쪽보다 긴 일반 행은 글줄 경계에서 여러 쪽으로 나눈다. 원본 논리 셀은 하나로 유지하며 화면에만 조각을 만든다. 이어지는 쪽의 셀도 원본 편집 대상으로 연결한다.
- 입력 조합 중에는 재배치를 미루고, 조합이 끝난 뒤 같은 입력창의 크기를 갱신한다. 커서·선택과 UIKit 실행 취소를 유지한다. 입력창의 첫 조각이 다른 쪽으로 옮겨지는 변화는 편집 확정 시 반영한다.
- 원본 보기의 직접 입력, 간편 보기의 셀 묶음 편집, AI 텍스트 수정이 같은 배치 경로를 사용한다. 문서 실행 취소·다시 실행은 내용과 배치를 함께 복원한다.
- HWP는 셀 LIST_HEADER의 높이, 표 제어 정보의 높이와 문단 줄 배치를 기록한다. HWPX는 cellSz/sz 및 각 문단 linesegarray를 갱신한다. 본문 문단 분리·병합 후에도 변경된 표 높이를 보존한다.

## 범위와 남은 작업

- 일반 1단 본문의 최상위 표에 있는 일반 텍스트 셀을 대상으로 한다. 다른 셀에 중첩 표가 있어도 해당 일반 셀은 편집할 수 있다.
- **중첩 표 자체, 중첩 표·그림·도형을 포함한 셀, 목록 셀, 다단 본문**의 자동 높이 배치는 후속 범위다. 이들의 기존 편집 가능 여부를 바꾸지는 않았다.
- 세로 병합 구간이나 개체가 포함된 한 행 전체가 한 쪽보다 큰 경우의 세부 분할은 남아 있다. 한 쪽보다 긴 **일반 행**의 텍스트 분할을 이번에 검증했다.
- 셀 안 Enter는 현재 문단 안의 줄바꿈이다. 셀 내부 문단의 구조적 추가·병합은 후속 작업이다.
- 행 높이는 기존 높이를 최소값으로 삼아 늘어난다. 글을 지웠을 때 자동으로 줄어들지는 않는다. 실행 취소는 이전 높이를 복원한다.
- 여러 쪽에 걸친 셀의 입력창은 현재 쪽 안에서 스크롤할 수 있다. 여러 쪽에 걸친 입력창을 하나의 연속 표면으로 만든 것은 아니다.
- 외부 한컴 제품에서 재열기·인쇄한 결과는 확인하지 않았다. 아래 저장 검증은 앱의 실제 HWP/HWPX 파서를 이용한다.
