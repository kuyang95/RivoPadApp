# 그림 색상 효과와 투명도 · 2026-09-17

우선순위 27로 그림 편집창에 **원본·회색조·흑백** 선택과 **투명도** 조절을 추가했다. 선택한 결과는 편집창 미리보기와 원본 문서 캔버스에 즉시 같은 모습으로 표시된다.

## 적용 범위

- HWP와 HWPX에서 원본, 회색조, 흑백 효과를 읽고 같은 원본 형식에 저장한다.
- HWPX의 그림 `alpha` 값을 0~100% 투명도로 읽고 저장한다.
- 효과 초기화는 색상 효과와 투명도만 원본 상태로 되돌리고 자르기, 크기, 회전, 밝기·대비, 테두리와 글 배치는 유지한다.
- 캔버스 이동·크기·회전 손잡이와 방향키 편집도 기존 효과와 투명도를 보존한다.
- HWP 그림 전체 투명도는 원본 규격에 직접 대응하는 값이 없다. HWP의 그림 레코드 73번째 바이트는 **그림 테두리 투명도**이므로 그림 전체 투명도로 덮어쓰지 않고 편집창에서 해당 슬라이더를 비활성화한다.

## 저장 방식

- HWP: 그림 레코드의 효과 값 `0/1/2`를 원본/회색조/흑백으로 저장한다.
- HWPX: 그림의 `effect`를 `REAL_PIC`, `GRAY_SCALE`, `BLACK_WHITE`로 저장한다.
- HWPX 투명도: 화면의 0~100%를 문서의 `alpha` 0~255로 변환하며 다시 열 때 백분율로 복원한다.

## 확인

- 그림 전용 M4 자동 검사 4개에서 HWP/HWPX 효과 저장, HWPX 투명도 왕복, 실행 취소·다시 실행, 직접 조작 시 값 보존과 범위 검사를 확인했다.
- 그림·표·입력·서식·도형·글상자·수식·HWPX 표시 관련 M4 자동 검사 74개를 통과했다.
- 테스트 번들이 없는 일반 Debug 앱의 확장 기능 3개와 서명을 확인하고 2026-09-17 13:43:14 KST에 무선 M4에 설치·실행했다.
