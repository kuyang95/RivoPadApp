# 한글 열 너비·행 높이 조절 — 2026-09-14

원본 보기에서 표의 셀을 누르면 문서 상단 **셀 / 행·열 / 병합·분할** 옆에 **크기** 버튼이 나타난다. 버튼을 누르면 선택한 행·열과 현재 크기를 보여 주며, 열 너비와 행 높이를 mm로 직접 입력하거나 +·−로 1mm씩 조절할 수 있다. 입력 지우기와 키보드 완료 버튼도 제공한다.

## 사용 동작

- 일반 셀은 해당 열 전체의 너비, 해당 행 전체의 높이에 적용한다. 바꾸지 않은 쪽의 수치는 유지한다.
- 병합 셀은 포함된 열·행의 전체 크기를 조절한다. 내부 경계의 기존 비율을 유지하고, 선택 범위 밖의 열·행 크기는 유지한다.
- 열을 좁히면 글을 다시 줄바꿈하고 필요한 행 높이를 계산한다. 행 높이를 줄여도 글이 잘리지 않도록 내용에 필요한 최소 높이를 유지한다.
- 최소 입력은 1mm다. 너비는 페이지 본문 영역과 표 위치를 고려한 상한을 표시한다. 이미 본문보다 넓은 표는 현재 너비까지 허용하여 점진적으로 줄일 수 있다. 표 전체의 내부 상한은 4,000pt다.
- 취소하면 크기를 변경하지 않고 원본 커서로 돌아간다. 적용하면 입력 중인 글과 서식을 보존하고 선택한 셀로 돌아간다. 실행 취소·다시 실행, HWP/HWPX 원본 형식 저장을 지원한다.

모든 셀이 병합되어 내부 경계의 치수가 파일에 남아 있지 않은 경우에는 보이는 경계 사이를 균등 분배한다. 기존 병합·분할과 같은 기준이다. 실제 내용 때문에 요청한 높이보다 커진 경우에는 크기 창을 다시 열었을 때 실제 높이를 표시한다.
