# 엑셀 틀 고정 구현

2026-09-15. 시트 관리 다음 작업으로 틀 고정을 구현했다.

## 화면과 동작

- **셀 도구 → 틀 고정**에서 첫 행, 첫 열, 첫 행과 첫 열, 선택한 셀 기준 고정,
  고정 해제를 지원한다. 현재 고정한 행·열 개수를 함께 표시한다.
- 기준 셀을 B3로 지정하면 위쪽 2행과 왼쪽 1열을 고정한다.
  직접 셀 주소를 입력할 수 있으며, A1 기준 고정은 비활성화한다.
- 원본 셀 보기에서 위쪽·왼쪽·교차 영역을 스크롤 본문과 따로 표시한다.
  확대 배율과 셀 좌표는 공유하며, 경계선은 화면 크기에 맞춰 유지한다.
- 고정 영역이 화면보다 크면 일부를 표시하고 본문 공간을 남긴다.
  본문은 가려진 고정 영역 뒤의 첫 셀부터 표시한다.
- 탭·범위 선택·가장자리 스크롤·셀 이동이 같은 좌표 계산을 사용한다.
  병합 셀과 선택·참조 표시도 각 영역에 반영하며, 병합 셀의 접근성 소유 영역을 하나로 정한다.
- 뒤쪽 행·열 구간으로 이동할 때 고정한 앞쪽 행·열을 함께 표시한다.
  고정 셀 선택으로 본문 구간이 초기화되지 않도록 마지막 이동 구간을 유지한다.

## 파일과 편집 기록

- XLSX의 기본 sheetView에 frozen pane과 선택 셀을 기록하며,
  줌·격자선 등 다른 보기 속성은 보존한다. 다중 선택 인덱스는 새 단일 선택에 맞춰 제거한다.
- 가져온 frozen/frozenSplit 상태를 읽고, 일반 split과 보조 창의 설정은 구별한다.
- 행·열 삽입·삭제 시 고정 범위를 함께 이동한다.
  고정한 행·열을 모두 삭제하면 해당 축의 고정도 해제한다.
- 기존 전체 문서 편집·실행 취소·다시 실행·저장 경로에 연결했다.
  시트 복제는 시트 XML을 복제하므로 고정 설정도 포함한다.

## 범위와 제한

- 새 고정 기준은 일반 편집 범위인 2,000행·200열 안에서 지정한다.
- 보호된 시트, 창 구성이 보호된 문서, 대용량 문서는 설정 변경을 제한한다.
- 대용량 창 단위 보기에서는 고정 설정을 읽고 파일에 보존하되 화면 고정은 적용하지 않는다.
  일반 보기로 가져온 큰 고정 범위의 화면 표시는 최대 1,999행·199열로 제한한다.
- 실제 터치·VoiceOver·저장/실행 취소 전체 흐름은 사용자 요청에 따라 추후 검증한다.
