# 한글 그림 편집 · 2026-09-16

원본 보기 상단에 **그림** 버튼을 추가하고 HWP/HWPX 본문에 그림을 삽입·크기 변경·삭제할 수 있게 했다.

## 적용 범위

- 일반 1단 본문의 커서 위치에 사진 보관함 또는 파일의 PNG/JPEG를 삽입한다.
- 커서 앞뒤 본문을 나누고 별도 문단에 그림을 배치한다.
- 원본 화면에서 그림을 누르면 너비·높이, 가로세로 비율 유지, 삭제 메뉴를 연다.
- 그림 높이에 맞춰 뒤 본문과 쪽 배치를 다시 계산한다.
- 삽입·크기 변경·삭제는 한 번의 실행 취소·다시 실행으로 복원한다.
- HWPX는 `BinData`와 패키지 manifest를, HWP는 OLE `BinData` 스트림과 DocInfo 설명자를 함께 갱신한다.
- 원본 형식으로 저장하고 앱 파서로 다시 열어 그림 데이터와 배치를 확인한다.
- 입력 이미지는 최대 20MiB·5천만 픽셀을 허용하고, 긴 변은 최대 4,096픽셀로 정규화한다.

## 현재 제한

- 글자처럼 배치되는 본문 그림의 삽입과 크기 변경을 우선 지원한다.
- 자르기, 회전, 밝기·대비, 테두리, 글 앞으로·뒤로 배치는 아직 편집하지 않는다.
- 표 셀, 머리말·꼬리말, 도형 내부, 다단 본문에는 새 그림을 넣지 않는다.
- 삭제한 그림의 사용하지 않는 내부 바이너리는 다른 참조 보존을 위해 파일 안에 남길 수 있다.
