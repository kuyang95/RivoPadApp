# 한글 표 행·열 추가·삭제 — 2026-09-14

원본 보기에서 표 안의 글자를 누르면 상단의 **셀** 서식 옆에 **행·열** 메뉴가 나타난다. 위·아래 행 추가, 왼쪽·오른쪽 열 추가, 현재 행·열 삭제를 제공한다. 추가한 빈 셀로 커서를 이동하고 입력을 이어갈 수 있다.

## 편집 동작

- 새 셀은 인접 셀의 글자·문단·테두리·채우기 서식을 가져오고 내용은 비운다. 기존 셀의 여러 문단과 내용은 유지한다.
- 열 수가 바뀌면 표 전체 폭을 유지하며 열 너비를 비례 조정한다. 좁아진 셀에서 내용이 길어지면 행 높이와 뒤따르는 본문 배치를 다시 계산한다.
- 삽입 위치를 가로지르는 기존 병합 셀은 해당 방향의 병합 범위를 늘린다. 삭제 위치를 포함한 병합 셀은 범위를 줄이고 남은 셀에 내용을 유지한다. 새 셀 병합·분할 명령은 별도 작업이다.
- 위·아래 추가는 선택한 병합 셀의 위·아래 경계를 기준으로 한다. 삭제는 선택한 셀이 시작하는 한 행 또는 한 열을 대상으로 한다. 마지막 한 행·열 삭제는 비활성화해 표 전체가 사라지지 않도록 한다.
- 행·열 변경과 삭제된 내용은 한 번의 실행 취소로 복원한다. 전후의 글자 입력과 셀 서식 편집도 각각의 편집 이력으로 유지한다.
- 줄 위치 정보가 없는 문서도 표의 배치를 먼저 계산한다. 반복 추가·삭제 후 표 아래 본문이 표와 겹치지 않도록 보완했다.

## 저장과 원본 보호

행·열 변경은 메모리 안에서 처리하고 원본 파일은 사용자가 저장할 때 갱신한다. 구조 변경 전의 미저장 글자·서식·문단 편집을 먼저 반영한 뒤, 표의 셀 배열과 행·열 수, 병합 범위, 크기를 변경한다. 다시 읽은 문단 ID를 편집 기준으로 사용하므로 변경 이후에도 입력·서식·행·열 편집을 이어갈 수 있다.

HWP는 원래 셀의 LIST_HEADER와 문단 레코드를 보존하여 배치하고, 새 셀에는 빈 문단과 새 문단 식별자를 만든다. TABLE의 행별 셀 수와 행·열 수, 셀 주소·병합 크기·치수, 테두리 영역 주소를 함께 갱신한다. HWPX는 tc를 보존·복제해 tr을 구성하고 rowCnt·colCnt, cellAddr·cellSpan·cellSz, 표 크기와 영역 주소를 갱신한다. 다른 표의 내용, 공유 서식 정의, 첨부 자료는 그대로 유지한다.

실행 취소 이력에는 화면의 문단과 메모리의 파일 기준을 함께 보관한다. 디스크에서 처음 읽은 파일 내용은 별도의 저장 비교 기준으로 유지한다. 따라서 행·열을 바꾼 뒤에도 다른 앱이 원본 파일을 수정했다면 덮어쓰지 않고 저장 오류를 표시한다.

HWP의 개체 크기 읽기 제한도 편집·저장·문서 모델과 같은 4,000pt로 맞췄다. 여러 번 편집해 표 높이가 2,000pt를 넘었을 때 읽은 높이가 잘려 저장 검증이 실패하던 경우를 해결했다.

참고 자료: [한컴 HWP 5.0 파일 형식 §4.3.9.1](https://cdn.hancom.com/link/docs/%ED%95%9C%EA%B8%80%EB%AC%B8%EC%84%9C%ED%8C%8C%EC%9D%BC%ED%98%95%EC%8B%9D_5.0_revision1.2.pdf), [pyhwp의 행별 셀 수 처리](https://github.com/mete0r/pyhwp/blob/master/src/hwp5/xmlmodel.py). HWP의 Row Size를 행별 시작 셀 레코드 수로 기록하는 처리는 공개 형식 문서와 파서 구현을 함께 확인했다.
