# 한글 회전 그림 축 기준 크기 조절 · 2026-09-17

우선순위 29를 적용했다. HWP/HWPX 원본 화면에서 회전·뒤집힌 그림의 네 모서리 손잡이를 그림 자체 가로·세로 축에 맞춰 끌 수 있다.

## 동작

- 화면 좌표의 손가락 이동을 그림의 회전과 좌우·상하 뒤집기 상태에 맞춘 내부 좌표로 변환한다.
- 잡은 모서리의 대각선 반대편은 화면에서 같은 위치를 유지하도록 그림 위치와 중심을 함께 보정한다.
- 그림의 너비·높이는 기존 20~2,000pt 범위를 유지한다.
- 드래그 중 미리보기와 손을 놓은 뒤 저장되는 위치·크기가 같은 계산을 사용한다.
- 회전된 그림을 이동할 때도 미리보기가 손가락의 화면 이동 방향과 일치한다.
- 자르기, 효과, 투명도, 밝기·대비, 테두리와 글 배치 속성은 유지한다.

## 저장과 검사

HWPX의 90° 회전·좌우 뒤집기 그림과 HWP의 270° 회전·상하 뒤집기 그림에서 축 기준 크기 조절을 저장하고 앱 파서로 다시 열어 위치·크기·회전·뒤집기 값을 확인했다. 한 번의 드래그는 기존 실행 취소 한 단계로 기록된다.

- 그림 편집 검사 4개 통과
