# 한글 쪽 설정 — 2026-09-14

원본 문서 상단의 **쪽** 버튼에서 용지 크기·방향·여백을 변경한다. 문단에 커서를 놓지 않아도 사용할 수 있다. 구역이 여러 개인 문서는 **전체 문서 / 현재 구역** 중 적용 범위를 선택한다. 현재 구역은 편집 중인 문단이 있으면 그 구역, 없으면 화면에 보이는 쪽을 기준으로 잡는다.

## 제공 기능

- 용지: A4, A3, A5, B5(JIS), Letter, Legal 및 너비·높이 직접 입력.
- 방향: 세로 / 가로. 너비·높이를 교환하며 HWP와 HWPX의 저장 규칙에 맞게 반영한다.
- 여백: 왼쪽·오른쪽·위쪽·아래쪽 직접 입력, 좁게(10mm)·보통(20mm)·넓게(30mm) 선택. 머리말·꼬리말 여백은 펼침 항목에서 각각 변경한다.
- 취소, 적용, 실행 취소·다시 실행, 원본 HWP/HWPX 형식 저장. 입력 중이던 글을 보존하며 적용 후 같은 문단과 커서 위치로 돌아간다.

용지는 각 변 72~2,000pt(25.4~약 705.5mm) 범위를 허용한다. 여백은 각 항목이 용지 짧은 변의 45% 이내이고 본문 너비·높이가 각각 36pt 이상 남아야 한다. 변경하지 않은 수치는 표시용 반올림 값으로 다시 쓰지 않는다. 제본 여백과 제본 방향 등 이번 창에서 편집하지 않는 설정은 원래 값을 유지한다.

## 배치와 저장

본문은 변경된 폭으로 다시 줄바꿈하고 머리말·꼬리말 영역을 제외한 높이에 맞춰 쪽을 나눈다. 문단에 명시된 쪽 나눔은 유지한다. 기존 표·그림의 크기는 유지하고 표 뒤 본문의 위치와 쪽 배치를 다시 계산한다. 적용 후에는 바뀐 용지를 화면 폭에 맞춘다.

HWP는 선택한 구역의 PAGE_DEF 너비·높이, 여백과 방향 비트만 수정한다. 제본 여백·나머지 비트·확장 데이터·관계없는 레코드와 스트림은 보존한다. HWPX는 해당 구역의 pagePr와 margin 속성만 수정하며, 쪽 설정이 없는 새 문서는 첫 run에 secPr/pagePr를 추가한다. 구역 번호가 연속되지 않아도 선택한 구역에 적용한다.

입력 중인 문단과 문단 추가·삭제를 먼저 메모리 문서에 반영한 뒤 설정을 갱신한다. 문단 내용·서식과 결과 쪽 설정을 다시 읽어 확인하며, 실행 취소 기록에는 변경 전후의 파일 기준과 문단·용지 배치를 함께 보관한다. 원본 파일은 사용자가 저장할 때 갱신하고, 외부에서 파일이 바뀌면 기존 동시 수정 검사를 적용한다.
