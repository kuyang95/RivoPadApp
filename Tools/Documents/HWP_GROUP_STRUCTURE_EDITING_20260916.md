# 한글 그룹 구조 편집 · 2026-09-16

우선순위 15를 적용했다. HWP/HWPX 원본 화면에서 그룹 내부 도형의 표시 순서를 바꾸거나 삭제하고, 그룹 전체를 독립 도형으로 해제할 수 있다.

## 적용 범위

- 내부 도형 편집 창의 `그룹 안 순서`에서 한 단계 뒤로 보내기와 앞으로 가져오기를 제공한다.
- 선택한 내부 도형만 삭제하며 나머지 자식의 좌표·크기·회전·선·채우기·그림자·경로를 보존한다.
- 도형이 두 개인 그룹에서 하나를 삭제하면 남은 도형을 자동으로 독립 도형으로 바꾼다.
- 그룹 외곽 편집 창의 `그룹 해제`로 모든 자식을 독립 도형으로 바꾼다.
- 그룹 좌표를 문단 좌표로 환산하여 해제 전 화면 위치·크기와 표시 순서를 유지한다.
- 구조 변경 전체를 실행 취소·다시 실행 한 단계로 복원하고 HWP/HWPX 원본 형식으로 저장한다.

## 형식별 반영

HWP는 그룹 컴포넌트의 자식 식별자 목록과 자식 레코드 묶음을 함께 이동하거나 삭제한다. 그룹 해제 시 각 자식 레코드를 독립 개체 제어로 승격하고 문단에 필요한 개체 기준 문자를 추가한다. HWPX는 `container`의 직접 자식 요소를 교환·삭제하고, 그룹 해제 시 자식의 크기·좌표·회전·배치 속성을 독립 요소에 기록한다.
