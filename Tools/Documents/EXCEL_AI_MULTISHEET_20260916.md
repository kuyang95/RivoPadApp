# 엑셀 채팅 여러 시트 검색·집계 — 2026-09-16

## 구현 범위

채팅 질문이 여러 시트를 명시하면 각 시트의 데이터 영역과 열 구조를 모델에 제공하고,
모델은 시트마다 정확한 영역·조건 열·계산 열·그룹 열을 따로 선택한다. 실제 검색과 계산,
답변 숫자, 근거 셀 주소는 기기의 로컬 실행기가 만든다.

- 모든/각 시트의 검색, 행 개수, 합계, 평균, 최솟값, 최댓값, 중복 제외 개수
- 시트별 순위와 제품별·국가별 등 그룹 집계
- 시트별 결과, 여러 시트 통합 결과, 시트별 결과와 전체 결과 동시 표시
- 열 순서와 열 제목이 다른 시트 사이의 명시적 열 대응
- 직전 여러 시트 결과의 실제 행을 사용하는 “그중” 후속 질문

## 안전 규칙

- 열 번호가 같다는 이유로 다른 시트의 열을 같은 의미로 취급하지 않는다.
- 통합 계산은 사용자가 전체 합계나 합치기를 요청했을 때만 수행한다.
- 원본 행을 자동으로 중복 제거하지 않는다.
- 한 계획에서 같은 시트를 중복 대상으로 사용할 수 없다.
- 불완전하게 읽힌 통합 문서, 잘못된 시트·영역·열, 서로 다른 단위는 결과를 만들지 않는다.
- 여러 시트를 합친 개별 행 목록과 전체 순위는 원본 행 번호 표현이 모호하므로 지원하지 않는다.
  시트별 개별 행 목록·순위와 여러 시트의 통합 집계는 지원한다.

## 참조 이동

참조는 시트별 주소 묶음으로 보관한다. 이전/다음 참조가 다른 시트에 있으면 앱이 해당
시트로 전환하고 그 시트의 근거 셀에 보라색 무채움 점선을 표시한다. 참조 막대에는 여러
시트인 경우 현재 참조의 시트 이름과 전체 참조 개수를 함께 표시한다.

## 확인 기록

  여러 시트 스키마 제공, 중복 시트·지원하지 않는 통합 행 목록 거부.
- 최종 M4 대상 앱 빌드는 성공했다.
- 기존 집계·채팅·참조 회귀 검사 36개를 실행해 34개 통과, 실제 AI 서버 호출 2개 보류,
  실패 0개를 확인했다. 공유 작업공간의 별도 HWP 파일이 작성 중이던 순간 한 차례 빌드가
  중단됐지만 해당 파일 완료 뒤 같은 검사를 다시 실행해 통과했다.

  일괄 실사용 검증에 포함한다.
