# 한글 여러 도형 크기 맞춤·복제·삭제 · 2026-09-17

우선순위 18을 적용했다. HWP/HWPX 원본 화면에서 같은 문단의 독립 도형을 여러 개 선택해 크기를 맞추거나 한꺼번에 복제·삭제할 수 있다.

## 사용 방법

1. 문서 상단의 `선택`을 누른다.
2. 같은 문단의 독립 도형을 2개 이상 선택한다.
3. `크기`에서 `너비 같게`, `높이 같게`, `크기 같게` 중 하나를 고른다.
4. `작업`에서 `선택 도형 복제` 또는 `선택 도형 삭제`를 고른다.

크기 맞춤 뒤에는 선택을 유지해 정렬과 크기 작업을 연속 적용할 수 있다. 복제·삭제 뒤에는 바뀐 개체 식별자와 선택 상태가 섞이지 않도록 선택 모드를 끝낸다.

## 동작

- 문서에서 먼저 나타나는 선택 도형을 크기 기준으로 사용한다.
- 너비·높이·전체 크기 중 고른 값만 바꾸고 위치·회전·선·채우기·그림자·경로·글 배치 속성은 유지한다.
- 복제본은 원본보다 가로·세로로 12pt 비켜 놓고 표시 순서를 앞으로 올린다.
- 복제본에는 새 개체·문단 식별자를 부여해 원본과 독립적으로 다시 편집할 수 있다.
- 다중 삭제는 선택하지 않은 도형과 본문을 유지한다.
- 한 번의 크기 맞춤·복제·삭제는 각각 실행 취소 한 단계로 기록한다.

## 형식별 저장

HWP는 선택 개체의 레코드 묶음과 본문 기준 문자를 함께 복제·삭제하고 새 인스턴스 및 내부 문단 식별자를 기록한다. HWPX는 선택 도형 XML과 내부 식별자를 복제하고 `pos`와 `zOrder`를 갱신한다. 두 형식 모두 저장 후 앱 파서로 재열어 개체 수·크기·좌표를 확인한다.

## 자동 확인

- 공개 HWP V25 그룹을 해제한 도형의 크기 맞춤, 복제, 다중 삭제와 재열기
- HWPX 독립 도형의 새 식별자 복제, 12pt 이동, 다중 삭제와 재열기
- 화면 모델에서 HWP 다중 복제 한 단계 실행 취소·다시 실행·파일 저장·재열기
- 도형 편집 자동 검사 20개 통과
- 도형·글상자·수식·HWPX 표시를 포함한 M4 관련 회귀 검사 37개 통과
- 일반 Debug 앱을 2026-09-17 09:53:17 KST에 무선 M4에 설치하고 실행

## 현재 범위와 다음 작업

같은 문단의 독립 도형을 최대 32개까지 선택하며, 복제 후 문단의 전체 개체는 최대 128개로 제한한다. 서로 다른 문단·쪽에 걸친 선택과 그룹 내부 도형을 섞은 일괄 작업은 현재 범위에 포함하지 않았다.
