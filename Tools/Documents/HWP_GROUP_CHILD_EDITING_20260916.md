# 한글 그룹 내부 개별 도형 편집 · 2026-09-16

우선순위 14를 적용했다. HWP/HWPX 원본 화면에서 그룹 안의 도형을 직접 눌러 선택하고, 그룹 외곽을 유지한 채 해당 도형만 편집한다.

## 적용 범위

- 그룹 안의 사각형·타원·선·자유 다각형·연결선마다 실제 표시 영역에 선택 동작을 연결한다.
- 선택한 내부 도형에만 파란 테두리를 표시하고 `그룹 안 도형` 편집 창을 연다.
- 그룹 좌표 기준 X·Y, 너비·높이와 회전을 바꾼다.
- 선 색·굵기·종류, 채우기, 그림자, 다각형 꼭짓점, 연결점과 양 끝 화살표를 바꾼다.
- 내부 도형을 바꿔도 그룹 외곽의 위치·크기·글 배치와 다른 자식 도형의 모양·순서를 보존한다.
- 변경은 실행 취소·다시 실행 한 단계로 복원하고 HWP/HWPX 원본 형식으로 저장한다.

## 형식별 반영

HWP는 그룹 제어 안에서 선택한 자식의 도형 컴포넌트와 기하 레코드만 찾아 로컬 좌표·크기·회전·스타일·경로를 수정한다. HWPX는 `container`를 그룹으로 읽고 선택한 자식 요소만 교체한다. 글상자 안의 수식·도형처럼 다른 컨테이너에 속한 개체는 기존 소유 문단에 그대로 연결한다.

## 자동 확인

- 공개 HWP V25 그룹에서 자식 선택, 이동·크기·회전·선·채우기·그림자 변경과 형제 보존
- HWPX 컨테이너 그룹에서 자식 선택·스타일 변경과 형제 보존
- 화면 모델 실행 취소·다시 실행·파일 저장·재열기
- 기존 그룹 전체 편집, 도형 삽입, 다각형·연결선, 글상자 내부 개체와 HWPX 표시 회귀 검사 **27개 통과**
- 이 가운데 그룹 도형 편집 검사 **10개 통과**
