# 한글 여러 도형 선택과 새 그룹 만들기 · 2026-09-16

우선순위 16을 적용했다. HWP/HWPX 원본 화면에서 같은 문단의 독립 도형을 여러 개 선택해 새 그룹으로 만들 수 있다.

## 사용 방법

1. 문서 상단의 `선택`을 누른다.
2. 묶을 독립 도형을 2개 이상 차례로 누른다. 선택된 도형은 파란 점선 테두리로 표시된다.
3. 상단의 `그룹 n`을 눌러 확정한다. X를 누르면 문서 변경 없이 선택을 취소한다.

첫 도형과 같은 문단의 독립 도형을 최대 32개까지 선택한다. 기존 그룹의 내부 도형은 먼저 그룹 해제한 뒤 선택한다.

## 형식별 반영

HWP는 여러 개체 기준 문자를 하나로 합치고 선택한 독립 개체 레코드를 그룹 자식 깊이로 옮긴다. 그룹 컴포넌트의 자식 식별자 목록과 전체 경계를 새로 기록한다. HWPX는 선택한 도형 요소를 `container`의 직접 자식으로 옮기고, 전체 경계 기준의 상대 좌표로 바꾼다. 두 형식 모두 도형의 크기·회전·선·채우기·그림자·경로·표시 순서를 보존한다.

- HWPX 독립 도형 2개를 새 그룹으로 생성하고 재열기
- 화면 모델 실행 취소·다시 실행·파일 저장·재열기

## 현재 범위
