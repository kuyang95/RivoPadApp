# 엑셀 채팅 집계·비교 — 2026-09-15

## 구현한 질문

기존 조건 검색·행 개수에 합계, 평균, 최솟값, 최댓값, 중복 제외 개수,
상위/하위 순위를 추가했다. 제품별·국가별 등 최대 3개 열로 묶어서 집계하고,
집계한 결과를 정렬해 상위 그룹을 표시할 수 있다.

- “독일 매출 합계는?” → 국가 조건에 맞는 전체 행의 매출 합계.
- “제품별 평균 이익” → 제품별로 나눈 뒤 숫자 이익의 평균.
- “매출 높은 순으로 5개” → 개별 행을 정렬한 뒤 상위 5개.
- “매출 합계가 높은 제품 5개” → 제품별 합산 후 상위 5개 그룹.
- “중복 빼면 제품이 몇 종류야?” → 비어 있지 않은 제품 값의 고유 개수.

모델은 대상 열·조건·연산만 결정한다. 결과 문장과 근거 주소는 앱의 로컬
실행기가 만든다. 특정 국가·제품·파일명에 대응하는 임시 분기를 추가하지 않았다.
읽기 순위 질문과 실제 행 정렬 편집은 다른 경로를 유지한다.

## 계산 규칙

- 모델에게 전달된 최대 1,500셀에 제한되지 않고 해당 데이터 영역의 전체 행을 계산한다.
- 정식 Excel 표의 머리글·합계 행을 제외한다. 일반 범위의 임의 요약 행은
  제목만 보고 삭제하거나 추정하지 않는다.
- 기본적으로 숨긴 행을 포함한다. 사용자가 보이는 행/현재 필터 결과만
  요청하면 `visibleOnly`를 적용한다.
- 숫자 계산은 저장된 숫자로 수행한다. 빈 셀·텍스트·텍스트로 저장된 숫자·
  불리언은 숫자 집계에서 제외하고, 0은 포함한다. 평균 분모도 실제 숫자 수다.
- 십진수 정밀도를 사용하며, 합산에서 크기나 정밀도 한도를 넘으면 확정하지 않는다.
  반복 소수 평균은 반올림 표시를 붙인다. 인식하는 통화 형식은 원본 소수 자릿수와
  천 단위 구분으로, 백분율은 백분율로 표시한다. 서로 다른 명시적 단위는 합산/순위에 섞지 않는다.
- 고유 개수는 빈 값 제외, 텍스트 앞뒤 공백·대소문자 무시, 숫자와 문자열 구분이다.
- 순위는 원래 행을 이동하지 않는다. 동점은 같은 순위이며 원래 행 순서로
  제한 개수를 채우고, 경계 밖 동점이 더 있으면 안내한다.
- 그룹 결과는 제한이 없으면 최대 20그룹을 표시하면서 전체 계산 그룹 수를
  안내한다. 요청한 순위/그룹 제한은 1~100개다.
- 수식은 쿼리 안에서 다시 계산한다. 처리할 수 없는 필수 수식의 캐시를
  확정값으로 쓰지 않으며, 원본 셀·서식·파일·편집 이력은 바꾸지 않는다.
- 불완전한 시트, 필요한 셀의 계산 오류, 행 구분이 모호한 세로 병합,
  잘못된 열/옵션, 날짜·시간 합계/평균은 결과를 만들지 않는다.

## 참조와 후속 질문

합계·평균은 실제 숫자 셀과 조건/그룹 셀, 고유 개수는 중복 여부를 확인한
비어 있지 않은 값, 순위·최솟값·최댓값은 실제 결과 행을 참조한다.
표시한 상위 그룹은 그 그룹의 집계 근거를 모두 표시한다.
기존 보라색 무채움 점선과 파란 선택을 유지한다.

“그중 평균”은 직전 순위 결과의 실제 행으로 범위를 좁힌다. 일반 합계/평균 뒤
다른 열을 질문할 때는 이전 조건에 맞던 전체 모집단을 유지하여, 이전 계산에서
숫자가 아니어서 제외했던 행까지 잘못 누락하지 않는다.
이전 결과 범위와 문서 버전은 기기에만 보관하며 모델 JSON에 넣지 않는다.
완전한 새 질문에는 이전 조건을 붙이지 않는다.
질문 처리 중 문서/선택이 바뀌거나 오래된 결과를 참조하면 다시 요청하도록 안내한다.
여러 시트 통합은 2026-09-16에 추가했다. 중첩 AND/OR와 표시된 그룹
합계/평균 자체에 대한 2차 집계는 범위 밖이다.
