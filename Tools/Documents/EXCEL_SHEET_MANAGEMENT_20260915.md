# 엑셀 시트 관리 구현

2026-09-15. 셀 병합·해제 다음 작업으로 시트 관리를 구현했다.

## 화면과 동작

- 아래 시트 탭 옆의 글자 버튼 **시트 관리**로 연다. 원본·간편 보기에서 공통으로 쓴다.
- 시트 목록에서 선택, 끌어서 순서 변경, 왼쪽·오른쪽 이동을 지원한다.
- 이름 변경, 빈 시트 추가, 현재 시트 복제, 확인 후 삭제를 지원한다.
- 이름을 따로 바꾸지 않으면 추가·복제 시 사용 가능한 이름을 자동으로 만든다.
  중복·금지 문자·길이·예약된 이름은 적용 전에 안내한다.
- 복제는 현재 편집을 포함하고, 생성한 시트를 바로 선택한다.
- 삭제 안내에는 지워질 시트 이름과 다른 시트 수식의 참조 오류 가능성을 표시한다.

## 파일과 편집 기록

- 시트의 패키지 경로를 기준으로 처리해 탭의 위치가 바뀌어도 대상을 유지한다.
- 이름 변경 시 셀 수식, 이름 정의, 차트 수식, 드롭다운·조건부 서식 수식,
  내부 하이퍼링크와 피벗 원본 시트 이름을 함께 갱신한다.
  문자열과 외부 문서 참조는 유지한다.
- 복제본은 시트·표·이미지·차트·메모 등 소유한 관련 파일을 따로 가진다.
  표 ID와 이름, 피벗 이름도 충돌 없이 만들고 복제본 내부 참조를 갱신한다.
  시트별 이름 정의도 복제한다. 피벗 캐시는 Excel 구조에 따라 공유한다.
- 삭제 시 남은 시트에서 사용하는 공유 파일은 유지하고, 삭제 시트만 소유한
  파일·관계·콘텐츠 유형을 제거한다. 삭제한 시트·표를 참조하는 수식은
  `#REF!`로 바꾸고 이전 계산값을 그대로 보여주지 않도록 처리한다.
- 순서 변경·추가·삭제 후 시트별 이름 정의의 인덱스와 활성 탭을 조정한다.
  기존 숨김 상태를 보존하며, Excel에서 열 활성 탭은 표시된 시트로 유지한다.
- 전체 편집 상태와 선택한 시트의 경로·셀을 기록해 실행 취소·다시 실행한다.
  기존 저장·자동 저장·내보내기·파일 충돌 확인 경로를 사용한다.
- 시트 변경이나 전체 상태 복원 시 시트 위치에 의존하는 내부 복사 정보를
  비워 잘라내기가 다른 시트에 적용되지 않도록 한다. 시스템의 복사 텍스트는 유지한다.

## 범위와 제한

- 최대 64시트. 구성 보호·대용량 문서는 시트 관리를 제한한다.
- 마지막으로 앱에서 열 수 있는 시트와 마지막 표시 시트를 삭제할 수 없다.
- 여러 시트를 묶은 3차원 참조가 있으면 기존 시트 변경을 제한한다.
  끝에 빈 시트를 추가하는 기능은 사용할 수 있다.
- 다른 시트의 피벗이 원본으로 사용하는 시트는 삭제를 제한한다.
- 슬라이서·새 댓글 등 복제 관계를 지원하지 않는 고급 개체가 있으면
  복제를 중단하며 원본은 그대로 유지한다. 숨김·표시 변경은 이번 범위에 없다.
