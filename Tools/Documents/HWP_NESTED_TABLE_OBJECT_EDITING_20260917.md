# 중첩 표 셀 그림·도형 편집

우선순위 32로 HWP/HWPX 중첩 표 셀의 그림·도형 선택, 새 삽입과 배치 편집을 적용했다.

## 동작 범위

- 안쪽 표 셀에 커서를 놓고 상단 **그림** 또는 **도형**으로 새 개체를 삽입한다.
- 안쪽 셀의 기존 그림·도형을 눌러 이동, 크기, 회전과 상세 배치 속성을 편집한다.
- 셀 글자와 안쪽·바깥쪽 표 구조를 유지하며 HWP/HWPX 원본 형식으로 저장한다.
- 안쪽 개체가 커지면 안쪽 행, 바깥 셀, 바깥 표와 뒤 본문 위치를 순서대로 갱신한다.
- 새 HWP 그림·도형은 글자처럼 취급되는 위아래 배치로 기록해 삽입 직후 직접 조작할 수 있다.

## 경계

- 중첩 표 자체의 행·열 추가·삭제, 병합·분할과 크기 편집은 우선순위 33에서 적용했다. 자세한 범위는 [중첩 표 구조 편집 기록](HWP_NESTED_TABLE_STRUCTURE_EDITING_20260917.md)에 정리했다.
- 암호·배포용·DRM 문서와 보호된 셀은 기존과 같이 편집하지 않는다.

## 검증

- 중첩 표 전용 HWP/HWPX 검사 2개를 포함한 개체 검사 7개를 M4에서 통과했다.
- 표 구조·크기·셀 서식·그림·도형·글상자·HWPX 표시 회귀 검사 121개를 M4에서 통과했다.
- 새 삽입, 이동·크기·회전, 안쪽에서 바깥쪽으로 높이 전달, 저장·재열기를 두 형식에서 확인했다.
- 일반 Debug 앱을 2026-09-17 16:28:11 KST에 무선 M4에 설치하고 실행했다.
