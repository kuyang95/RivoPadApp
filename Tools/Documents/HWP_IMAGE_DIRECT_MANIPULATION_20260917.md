# 그림 직접 이동·크기·회전 · 2026-09-17

우선순위 26을 적용했다. HWP/HWPX 원본 화면의 그림을 한 번 누르면 선택 테두리, 네 모서리 크기 손잡이와 위쪽 회전 손잡이가 나타난다. 같은 그림을 다시 누르면 기존 상세 편집창이 열린다.

## 적용 범위

- 그림 내부를 끌어 캔버스에서 바로 이동
- 네 모서리 손잡이로 너비·높이를 20~2,000pt 범위에서 조절
- 위쪽 회전 손잡이로 0~359도 회전
- 드래그 중 위치·크기·회전 미리보기
- 하드웨어 방향키 1pt, Shift+방향키 10pt 이동
- 손을 뗄 때 한 번의 편집 기록으로 반영하여 실행 취소·다시 실행 지원
- 기존 자르기·뒤집기·테두리·밝기·대비·글 배치 설정 보존
- HWPX 위치 오프셋과 HWP 개체 좌표 저장
- 첫 번째 누르기는 직접 조작 선택, 두 번째 누르기는 상세 편집으로 역할 분리
