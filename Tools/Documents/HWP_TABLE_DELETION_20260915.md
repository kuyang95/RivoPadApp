# 표 전체 삭제 — 2026-09-15

셀 안에 커서를 둔 뒤 **상단 표 편집 → 표 삭제**로 현재 표와 셀 내용을 삭제한다. 기존 ‘행·열’ 메뉴 이름을 ‘표 편집’으로 바꾸고, 맨 아래에 삭제 항목을 추가했다. 1×1 마지막 표, 병합 셀, 여러 문단/줄을 가진 셀을 포함한 표도 지원한다.

삭제 후 표를 담던 본문 문단에 커서를 놓는다. 표 앞뒤의 글은 보존하고 뒤 본문과 다른 표의 위치를 다시 계산한다. 여러 쪽에 걸친 표의 높이를 없애면서 쪽 수와 쪽 번호도 갱신한다. 빈 본문 문단은 계속 입력할 수 있도록 남긴다.

## 저장과 실행 취소

- HWPX의 표 요소 또는 HWP 5의 표 제어·앵커·셀 문단을 제거한다. 표를 담던 문단의 본문과 서식, 구역·쪽 설정은 유지한다.
- HWP 앵커가 차지하던 UTF-16 위치를 제거할 때 글자 모양과 줄 위치도 보정한다. 앞뒤 한글·이모지와 서식이 유지되는지 검사했다.
- 표가 있던 위치와 남은 표 번호에 맞춰 문단 식별자를 다시 연결한다. 텍스트 미리보기를 갱신하고 다른 바이너리 자료와 공유 서식 정의는 유지한다.
- 실제 파일은 ‘이 문서에 저장’을 눌러 반영한다. 삭제 전 입력 중이던 셀 내용도 실행 취소로 돌아온다. 다시 실행하면 표가 삭제된다.
- 현재 편집기의 공통 동작상 저장하면 실행 취소 기록이 초기화된다. 저장 전 복원을 검사하도록 가이드에 명시했다.
