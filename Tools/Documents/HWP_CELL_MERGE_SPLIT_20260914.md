# 한글 셀 병합·분할 — 2026-09-14

원본 보기에서 표 안을 누르면 상단 **셀**, **행·열** 옆에 **병합·분할** 메뉴가 나타난다. 별도의 편집 모드 전환 없이 커서가 있는 셀에 적용한다.

## 사용 동작

- **오른쪽 셀과 병합 / 아래 셀과 병합**: 맞닿은 경계 전체를 직사각형으로 합친다. 넓은 셀 아래에 작은 셀이 여러 개 있는 경우에도 경계가 맞으면 함께 합칠 수 있다. 일부만 걸쳐 ㄱ자 모양이 되는 조합과 표 밖 방향은 비활성화한다.
- **좌우로 둘로 나누기 / 상하로 둘로 나누기**: 선택한 셀을 같은 크기의 두 칸으로 나눈다. 일반 셀과 기존 병합 셀 모두 가능하다. 내용은 첫 번째 셀에 남고 새 셀은 비어 있다. 메뉴 안에도 이 동작을 안내한다.
- **병합 풀기**: 선택한 병합 셀의 내부 행·열 경계를 모두 풀어 각각의 셀로 만든다. 내용은 왼쪽 위 첫 셀에 남고 나머지는 빈 셀이 된다. 이전 병합 전 내용 배치를 되돌리려면 실행 취소를 사용한다.

병합한 셀에는 기존 문단을 위에서 아래, 왼쪽에서 오른쪽 순서로 모두 보관한다. 글자 및 문단 서식은 각각 유지하고, 셀 채우기·테두리·세로 정렬 등 셀 단위 서식은 선택한 첫 셀을 따른다. 빈 셀은 원래 셀의 서식을 물려받는다.

분할은 표의 전체 너비에 열을 덧붙이지 않는다. 선택한 셀의 중간에 기존 경계가 있으면 재사용하고, 없으면 그 위치에 내부 경계를 추가한다. 주변 셀은 새 경계를 가로질러 병합된 상태로 유지해 크기와 위치를 보존한다. 내용이 칸 높이보다 길어지면 기존 편집 동작과 같이 행 높이와 뒤의 본문 배치를 다시 계산한다.

모든 셀이 합쳐져 내부 경계의 크기가 파일에 남아 있지 않은 경우에는 보이는 경계 사이를 균등 분배한다. 남아 있는 셀 경계와 표 전체 크기는 유지한다. 실행 취소는 변경 전 파일 기준과 배치를 함께 복원하므로 원래 크기까지 복원한다.

## 저장 구현

행·열 편집의 메모리 문서 기준, 실행 취소, 원본 파일 동시 수정 검사, 배치 재계산 경로를 그대로 사용한다. 문단 목록이 바뀌더라도 저장 전의 글자 입력을 먼저 반영하며, 저장할 때만 원본 파일을 갱신한다.

HWPX는 병합에 포함된 셀의 문단 XML을 첫 셀의 문단 목록에 모은다. 문단 식별자와 서식 참조는 보존하고, 새 빈 셀에는 새 문단 식별자를 부여한다. HWP는 원래 문단 레코드를 모으고 LIST_HEADER 문단 수와 PARA_HEADER의 마지막 문단 표시를 갱신한다. 두 형식 모두 행·열 주소, 병합 범위, 크기와 배경 영역 주소를 반영하고 다시 읽어 내용·서식·구조를 비교한다.

새 구현은 `HWPTableCellEditing.swift`에서 병합 대상과 분할 경계를 계산하며, 기존 `HWPTableStructureWriter.swift`에서 여러 원래 셀의 문단을 하나의 셀에 기록할 수 있게 확장했다.
