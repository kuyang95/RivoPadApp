## 검사 중 발견하고 고친 문제

1. 일반 글자 수정 뒤 목록 속성이 사라지는 문제를 수정했다.
2. 헤더가 없는 최소 HWPX에서 빈 칸에 처음 입력한 글자가 저장되지 않는 문제를 수정했다.
3. 원본에 셀 높이·표 높이 태그가 없을 때 입력으로 늘어난 높이를 저장하지 못하는 문제를 수정했다.
4. 표 셀 조각 ID를 쪽 조각 ID로 잘못 읽어 25쪽 문서가 57쪽, 23쪽 문서가 56쪽으로 늘어나는 문제를 수정했다.
5. 표 셀 안 글상자의 문단이 바깥 표 셀로 분류되어 제목이 사라지는 문제를 수정했다.
6. 현재 편집 동작과 맞지 않던 UI 높이 검사를 수정했다.
