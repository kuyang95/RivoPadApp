# 한글 글상자 내부 표 셀 편집 · 2026-09-17

우선순위 22를 적용했다. HWP/HWPX 원본 화면에서 글상자 안의 표를 격자로 표시하고 셀을 직접 눌러 글자를 편집할 수 있다.

## 사용 방법

1. 표가 들어 있는 HWP 또는 HWPX 문서를 원본 화면으로 연다.
2. 글상자 안에 표시된 표 셀을 누른다.
3. 셀에 열린 커서로 한글을 입력하거나 일부 글자를 선택한다.
4. 상단 글자·문단 도구로 굵게, 색, 크기, 정렬 등을 바꾼다.
5. 저장 후 문서를 다시 열어 셀 내용과 글상자 배치를 확인한다.

내부 표를 누르면 글상자 전체 편집창보다 셀 입력을 우선한다. 글상자 편집창에서는 내부 표 개수와 셀 직접 편집 안내를 보여준다.

## 저장과 실행 취소

- 셀 편집 한 세션은 실행 취소 한 단계로 기록한다.
- 다시 실행하면 같은 셀 내용과 서식이 복원된다.
- HWP는 HWP, HWPX는 HWPX 형식을 유지해 저장한다.
- 표 구조, 다른 셀, 글상자 외곽과 내부 그림·도형·수식은 보존한다.
- 셀 내용이 늘어나면 글상자 내부 표의 해당 행 높이만 필요한 만큼 다시 계산한다.

## 자동 확인

- 글상자 내부 표 셀의 편집 가능 판정
- HWPX 내부 셀 입력, 실행 취소·다시 실행, 저장 후 재열기
- 내부 표 개수와 글상자 컨테이너 보존
- 표·입력·서식·도형·글상자·수식·HWPX 표시 관련 M4 검사 70개 통과
- 일반 Debug 앱을 2026-09-17 11:14:13 KST에 무선 M4에 설치하고 실행

## 현재 범위와 다음 작업

글상자 내부 표의 셀 글자와 글자·문단 서식을 편집한다. 내부 표의 행·열 추가·삭제, 병합·분할, 셀 배경·테두리 변경은 안전을 위해 계속 제한한다. 중첩 표도 구조를 보존하지만 직접 편집 대상은 글상자에 바로 들어 있는 표부터 지원한다.
