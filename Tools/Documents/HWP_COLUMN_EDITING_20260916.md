# 한글 다단 설정·본문 편집 · 2026-09-16

우선순위 13을 적용했다. HWP/HWPX 원본 화면의 **쪽 → 다단**에서 단 수·간격·구분선을 바꾸고, 각 단의 본문을 별도 편집 버튼 없이 직접 편집한다.

## 적용 범위

- 현재 구역 또는 전체 문서에 동일 너비 1~4단을 적용한다.
- 단 사이 간격은 0~30mm로 지정하고, 2단 이상에서는 세로 구분선을 켜거나 끈다.
- 본문은 왼쪽 단 위에서 아래로, 다음 단, 다음 쪽의 왼쪽 단 순서로 다시 흐른다.
- 다단 문단에서 글자 입력과 서식 변경, Enter 문단 나누기, 문단 맨 앞 Backspace 합치기를 지원한다.
- 설정 변경 전에 입력 중인 글을 확정하고, 적용 후 같은 문단과 커서 위치를 복원한다.
- 실행 취소·다시 실행에 단 설정, 본문 내용과 배치를 한 묶음으로 기록한다.
- HWP와 HWPX 모두 원본 형식으로 저장하고 다시 열어 단 설정과 본문을 확인한다.

## 파일 반영

HWPX는 대상 구역의 `colPr`를 동일 너비 단 정보로 만들거나 교체하고 단 간격과 구분선을 기록한다. HWP는 대상 구역의 `CTRL_HEADER` 다단 제어(`cold`)를 추가·수정·제거한다. 압축 여부와 다른 스트림·레코드는 유지한다. 기존 서로 다른 너비 단은 읽고 표시하며, 사용자가 설정을 바꾸면 선택한 동일 너비 단으로 정리한다.

## 자동 확인

- HWPX 2단·간격·구분선 적용, 왼쪽 단에서 오른쪽 단과 다음 쪽으로 흐름, 저장·재열기
- 다단에서 직접 글자 수정, 문단 나누기·합치기와 저장·재열기
- 실제 HWP의 다단 제어 추가·변경·제거와 본문·다른 자료 보존
- 잘못된 단 수·간격·구역과 복합 구역 변경 거부
- 화면 모델의 적용·실행 취소·다시 실행·저장·재열기
- 다단 5개, 문단 13개, 쪽 설정 12개를 묶은 M4 실기기 검사 **30개 통과**
- 일반 Debug 빌드 성공 후 2026-09-16 17:11 KST에 무선 M4에 설치하고 실행

## 현재 범위

단 설정 변경은 표나 캔버스 개체가 없는 일반 본문 구역에 적용한다. 다단 구역에 새 표·그림·도형·수식을 삽입하는 기능과 명시적인 단 나누기는 아직 지원하지 않는다. 기존 서로 다른 너비 단은 원본대로 표시하지만 글자 길이가 바뀐 뒤 전체를 다시 흐르게 하는 기능은 제한된다. 일반 용지·여백 변경은 기존 쪽 설정 창의 단일 단 범위를 유지한다. 외부 한컴 제품에서 저장 결과를 다시 열고 인쇄한 검사는 아직 수행하지 않았다.
