# 한글 맞쪽 정렬·도형 뒤집기 · 2026-09-17

우선순위 19를 적용했다. HWP/HWPX 원본 화면에서 독립 도형을 맞쪽의 안쪽·바깥쪽에 배치하고 좌우·상하로 뒤집을 수 있다.

## 사용 방법

1. 문서 상단의 `선택`을 누른다.
2. 같은 문단의 독립 도형을 한 개 이상 선택한다.
3. `맞춤`의 `맞쪽 안쪽 맞춤` 또는 `맞쪽 바깥쪽 맞춤`을 고른다.
4. `뒤집기`에서 `좌우 뒤집기` 또는 `상하 뒤집기`를 고른다.

도형을 직접 눌러 여는 편집 창에서도 좌우·상하 뒤집기 값을 바꿀 수 있다. 여러 도형을 선택하면 한 번의 명령으로 모두 같은 축을 반전한다.

## 맞쪽 배치

- 안쪽 맞춤은 홀수 쪽의 왼쪽, 짝수 쪽의 오른쪽 가장자리를 사용한다.
- 바깥쪽 맞춤은 홀수 쪽의 오른쪽, 짝수 쪽의 왼쪽 가장자리를 사용한다.
- 도형을 `쪽` 기준의 떠 있는 개체로 바꾸고 HWP/HWPX의 `INSIDE` 또는 `OUTSIDE` 정렬 값을 저장한다.
- 문서 쪽 순서가 바뀌어 홀짝이 달라져도 저장된 맞쪽 의미에 따라 방향이 다시 계산된다.

## 뒤집기 저장

HWP는 도형 구성 요소의 좌우·상하 반전 비트를 읽고 쓴다. HWPX는 도형의 `<flip horizontal="…" vertical="…"/>` 값을 읽고 쓴다. 원본 화면은 같은 값을 반영해 도형과 그룹 내부 도형을 표시한다.

뒤집기는 위치·크기·회전·선·채우기·그림자·경로·화살표를 유지한다. 같은 축을 다시 누르면 원래 방향으로 돌아온다. 한 번의 다중 뒤집기는 실행 취소 한 단계로 기록한다.

## 자동 확인

- HWPX 다각형의 맞쪽 바깥쪽 정렬과 상하 뒤집기 저장·재열기
- 화면 모델에서 뒤집기 한 단계 실행 취소·다시 실행·파일 저장·재열기
- 도형 편집 자동 검사 23개 통과
