# 한글 도형 속성·글상자 삽입 · 2026-09-16

도형 편집 화면에 회전, 선, 채우기, 그림자를 추가하고 원본 보기 상단에 **글상자** 삽입 버튼을 추가했다.

## 적용 범위

- 도형 회전 0~359°, 선 색·굵기·실선/파선/점선/일점쇄선을 편집한다.
- 사각형·타원의 채우기 유무와 색을 바꾼다.
- 그림자 사용 여부, 색, 가로·세로 이동량과 농도를 바꾼다.
- 글상자 내용과 너비·높이를 지정해 일반 1단 본문 커서 위치에 삽입한다.
- HWP와 HWPX에 각 속성과 글상자 내부 문단을 기록하고 저장 후 다시 읽는다.
- 적용 단위는 실행 취소·다시 실행 한 단계다.

## 자동 확인

- M4 실기기에서 도형·수식·글상자 관련 검사 10개 통과
- HWP/HWPX 도형 회전·선·채우기·그림자 저장·재열기 통과
- HWP/HWPX 글상자 삽입·내부 문단·저장·재열기 통과
- M4 Debug 앱 설치·실행 완료: 2026-09-16 15:10 KST
