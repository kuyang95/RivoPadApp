# 한글 여러 도형 정렬·간격 맞춤 · 2026-09-17

우선순위 17을 적용했다. HWP/HWPX 원본 화면에서 같은 문단의 독립 도형을 여러 개 선택해 방향을 맞추거나 같은 간격으로 배치할 수 있다.

## 사용 방법

1. 문서 상단의 `선택`을 누른다.
2. 같은 문단의 독립 도형을 차례로 누른다. 파란 점선 테두리로 선택 상태를 확인한다.
3. `맞춤`에서 왼쪽·가운데·오른쪽, 위·중간·아래 중 하나를 고른다.
4. 세 개 이상 선택했다면 `가로 간격 동일` 또는 `세로 간격 동일`도 사용할 수 있다.

맞춤 뒤에도 선택을 유지하므로 여러 방향을 연속 적용할 수 있다. X를 누르면 선택 모드를 끝낸다.

## 동작

- 방향 맞춤은 선택한 모든 도형의 전체 경계를 기준으로 해당 가장자리 또는 중심을 일치시킨다.
- 동일 간격은 현재 좌표 순으로 도형을 정렬하고 양 끝 도형의 위치를 유지한 채 사이 여백을 똑같이 계산한다.
- 위치 이외의 크기·회전·선·채우기·그림자·경로·표시 순서·글 배치 속성은 유지한다.
- 한 번의 맞춤 실행은 실행 취소 한 단계로 기록한다.
- 같은 문단의 독립 도형을 최대 32개까지 처리한다. 방향 맞춤은 2개, 동일 간격은 3개 이상일 때 활성화된다.

## 형식별 저장

HWP는 각 독립 도형의 개체 위치 레코드 좌표를 갱신하고, HWPX는 각 도형의 `pos` 좌표를 갱신한다. 두 형식 모두 원래 컨테이너와 식별자를 유지하며 저장 후 앱 파서로 재열어 결과 좌표를 확인한다.

- 화면 모델에서 여러 도형 맞춤 한 단계 실행 취소·다시 실행·파일 저장·재열기
