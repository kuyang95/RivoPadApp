# 그림 자르기·원본 비율 맞춤 · 2026-09-17

우선순위 23을 적용했다. HWP/HWPX 원본 화면에서 그림을 누르면 실제 그림을 보면서 네 방향을 자르고, 자르기를 해제해 원본 가로세로 비율로 되돌릴 수 있다.

## 사용 방법

1. 원본 화면에서 그림을 누른다.
2. **자르기**의 왼쪽·오른쪽·위·아래 슬라이더를 움직인다.
3. 미리보기를 확인하고 **적용**을 누른다.
4. 원래 그림으로 되돌리려면 **자르기 초기화** 또는 **원본 비율로 맞춤**을 누른다.

**가로세로 비율 유지**가 켜져 있으면 남은 그림 영역의 비율에 맞춰 높이를 자동으로 바꾼다. 끄면 자르기 영역과 그림 틀의 너비·높이를 따로 정할 수 있다. **원본 비율로 맞춤**은 자르기를 모두 해제하고 현재 너비를 유지한 채 원본 높이를 계산해 바로 적용한다.

## 저장과 실행 취소

- HWPX의 `imgClip`과 HWP 5 그림 자르기 좌표를 원본 그림 크기에 맞춰 기록한다.
- 그림 틀의 너비·높이도 함께 저장해 자른 그림이 찌그러지지 않도록 한다.
- 한 번 적용한 자르기와 크기 변경은 실행 취소 한 단계로 기록한다.
- 다시 실행과 저장 후 재열기에서도 같은 자르기 영역과 크기를 복원한다.
- 그림 데이터, 앞뒤 본문과 다른 문서 개체는 그대로 보존한다.

## 자동 확인

- HWP 5 그림의 왼쪽 절반 자르기와 원본 비율 복원
- 자른 뒤 크기 변경·삭제와 저장 후 재열기
- 화면 모델의 자르기 실행 취소·다시 실행·파일 저장
- 그림·표·입력·서식·도형·글상자·수식·HWPX 표시 관련 M4 검사 74개 통과
