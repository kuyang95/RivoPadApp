# 한글 복합 글상자 문단·내부 개체 편집 · 2026-09-16

우선순위 12를 적용했다. HWP/HWPX 원본 화면에서 글상자의 문단을 추가·삭제·이동하고, 글상자 안 그림·도형·수식을 직접 선택해 기존 개체 편집 기능으로 바꿀 수 있다.

## 적용 범위

- 글상자 편집 창에서 문단별 내용을 편집한다.
- 문단을 최대 64개까지 추가하고, 개체가 없는 문단을 삭제하며, 위·아래로 순서를 바꾼다.
- 기존 문단을 이동할 때 글자·문단 서식과 그 문단의 내부 표·그림·도형·수식 기록을 한 덩어리로 보존한다.
- 새 문단은 인접한 기존 문단의 문단·글자 모양을 이어받는다.
- 원본 화면에서 글상자 내부 그림·도형·수식을 표시하고 직접 선택한다. 선택 후 크기, 위치, 도형 모양·색, 수식 원문 등 기존 편집 항목을 사용할 수 있다.
- 문단 구조 변경과 내부 개체 변경은 각각 실행 취소·다시 실행 한 단계로 복원한다.
- HWP와 HWPX 모두 원본 형식으로 저장하며 앱 파서로 다시 열어 문단 순서와 개체를 확인한다.

## 개체 보호 규칙

내부 개체나 표가 있는 문단은 글자 변경과 삭제를 잠근다. 문단 순서는 바꿀 수 있고 개체 자체는 원본 화면에서 선택해 편집할 수 있다. 이 규칙은 알 수 없는 제어 기록이나 중첩 구조가 글자 교체 과정에서 사라지는 일을 막는다.

## 자동 확인

- HWPX 글상자 문단 추가·삭제·순서 변경과 저장·재열기
- HWP 글상자 문단 추가·삭제·순서 변경과 저장·재열기
- HWPX 글상자 내부 수식과 도형의 선택 대상 확인, 수정, 구조 보존과 재열기
- 기존 글상자 내용 편집, 수식, 도형, 그림 편집을 포함한 회귀 검사 18개 통과
- 2026-09-16 16:52 KST에 무선 M4 실기기에 Debug 앱을 설치하고 실행

## 남은 범위

- 글상자 안에 새 표·그림·도형·수식을 바로 삽입하는 기능
- 글상자 안 표의 셀 내용·행·열 편집
- 내부 개체가 있는 문단의 일반 글자만 안전하게 분리해 바꾸거나 해당 문단 전체를 삭제하는 기능
- 중첩 글상자와 복잡한 흐름의 한컴 수준 자동 재조판
