# 엑셀 셀 병합·해제

2026-09-15. 편집 확장 다음 단계로 셀 병합·해제를 구현했다.
실사용 검증은 사용자의 요청에 따라 별도 목록에 누적한다.

## 사용 흐름

- 셀 도구 → 셀 병합·해제에서 범위를 입력한다. 선택된 셀·범위를 초기값으로 쓴다.
- 실제 병합 범위, 남는 왼쪽 위 셀 주소와 값을 표시한다.
- 셀 병합과 선택적인 가로 가운데 정렬을 지원한다.
- 왼쪽 위 이외에 값·수식이 있으면 삭제될 셀 개수를 알려주고 확인한다.
  확인 전에는 원본과 편집 기록을 변경하지 않는다.
- 기존 병합에 걸친 범위는 기존 병합 전체를 포함하도록 확장한다.
- 병합 해제는 선택 범위와 겹친 병합만 제거한다. 값은 왼쪽 위에 남으며,
  삭제한 값 복원은 병합 해제가 아닌 실행 취소로 처리한다.

## 데이터와 화면

- 병합 범위를 XLSX에 기록하고 중복·겹친 병합 기록을 정리한다.
- 왼쪽 위 이외의 값·수식만 제거하고 셀 서식, 링크·메모 등은 보존한다.
- 공유 수식을 개별 수식으로 확장한 뒤 병합하므로 지워지는 공유 수식의
  기준 셀을 참조하던 병합 범위 밖의 수식도 유지된다.
- 표·피벗 요약표·배열 수식·보호·대용량 시트는 병합을 제한한다.
  범위는 20,000셀과 일반 문서의 2,000행·200열 한도 내에서 적용한다.
- 기존 전체 편집 상태 기록을 사용해 한 번의 실행 취소·다시 실행으로
  값·서식·병합 상태를 함께 복원한다. 기존 저장·자동 저장 경로를 사용한다.
- 원본 보기에서는 병합 내부의 개별 칸 대신 하나의 셀을 그린다.
  가로·세로 범위, 숨겨진 행, 표시 구간 밖에 기준 셀이 있는 경우를 처리한다.
- 선택은 파란색, 채팅 참조는 배경 없는 보라색 점선으로 병합 전체를 표시한다.
  VoiceOver도 병합을 한 셀로 노출한다. 선택 주소와 값 지우기도 병합에 맞춘다.
