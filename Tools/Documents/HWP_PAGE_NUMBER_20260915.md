# 쪽 번호 편집 — 2026-09-15

상단 **쪽 → 쪽 번호**에서 커서 없이 번호를 넣거나 숨기고, 위/아래·왼쪽/가운데/오른쪽 위치, 양옆 줄표, 시작 번호(1~65535)를 변경할 수 있다. 전체 문서에 적용하면 첫 구역에서 지정한 번호부터 이어지며, 현재 구역만 적용할 때는 그 구역의 시작 번호를 바꾸거나 앞 구역 번호를 이어 쓸 수 있다.

번호 설정은 실행 취소·다시 실행에 포함된다. 설정 창을 열기 전 입력 중이던 내용도 보존하며, 실제 파일에는 ‘이 문서에 저장’을 눌러 반영한다. 번호 표시를 끄더라도 구역의 시작 번호는 유지한다. 하단 쪽 이동은 표시 번호와 별도로 실제 쪽 순서를 사용한다.

## 구현 및 보존 범위

- HWPX의 `pageNum`과 구역 `startNum.page`를 변경한다. 새 문서에 해당 요소가 없으면 추가한다. 기존 머리말·꼬리말, 용지·표·그림과 다른 번호 종류의 시작 값은 보존한다.
- HWP 5의 쪽 번호 제어와 구역 시작 번호를 변경한다. 새 번호 제어는 기존 구역 정의 문단의 끝에 앵커를 추가하여 본문 글자 위치를 보존한다. 다시 표시하거나 숨길 때 제어를 중복 삽입하지 않는다. 문서의 다른 저장 항목은 그대로 유지한다.
- 기존 렌더러에 구역 간 번호 연속성을 연결했다. 쪽 나누기나 용지 변경 후에도 표시 번호가 이어진다.
- 영문·일문 번역과 [직접 테스트 가이드](HWP_MANUAL_TEST_GUIDE_20260915.md)의 51개 체크 항목을 갱신했다.

HWP 제어 코드와 구역 시작 번호 위치는 [한컴 HWP 5.0 공개 명세](https://cdn.hancom.com/link/docs/%ED%95%9C%EA%B8%80%EB%AC%B8%EC%84%9C%ED%8C%8C%EC%9D%BC%ED%98%95%EC%8B%9D_5.0_revision1.2.pdf)의 표 123·141·142에 따랐다. HWPX 속성 이름은 한컴 공개 모델의 [pageNum](https://github.com/hancom-io/hwpx-owpml-model/blob/main/OWPML/Class/Para/pageNum.cpp)과 [startNum](https://github.com/hancom-io/hwpx-owpml-model/blob/main/OWPML/Class/Para/startNum.cpp)을 확인했다.
