# 한글 하이퍼링크 편집 · 2026-09-16

원본 보기 상단에 **링크** 버튼을 추가하고 HWP/HWPX 문서의 하이퍼링크를 삽입·수정·열기·해제할 수 있게 했다.

## 동작

- 선택한 문단 글자에 웹 주소를 연결한다. 주소에 방식이 없으면 `https://`를 붙인다.
- 기존 링크 안에 커서를 놓으면 링크 전체 범위와 현재 주소를 찾아 편집 화면을 연다.
- 편집 화면에서 현재 링크를 열거나 주소를 바꾸고 링크를 해제할 수 있다.
- HWPX는 `fieldBegin type="HYPERLINK"`와 `fieldEnd`, HWP는 `%hlk` 필드 시작·끝 제어와 비영 필드 ID를 기록한다.
- 링크 글자는 파란색과 밑줄을 적용하고 원본 형식으로 저장한 뒤 다시 열어 범위와 주소를 검사한다.
- 링크 작업은 한 번의 실행 취소·다시 실행 단계로 처리한다.

## 지원 범위

- `http`, `https`, `mailto`, `tel` 주소를 지원한다.
- 링크 선택 범위는 한 문단 안이어야 한다.
- 보호 문서, 개체가 포함된 복잡한 문단, 다중 문단 선택은 기존 편집 제한을 따른다.
- 책갈피, 상호 참조, 링크 도구 설명과 새 창 대상 지정은 후속 범위다.

## 검증

- HWPX에서 링크 삽입 → 주소 수정 → 해제 → 재열기 통과
- HWP에서 링크 삽입 → 주소 수정 → 해제 → 재열기 통과
- 허용하지 않는 주소 방식 거부와 `https://` 자동 보정 통과
- 하이퍼링크 자동 검사 3개가 통과했다.
- 누적 한글 검사를 함께 실행했다. iOS 26.3 시뮬레이터의 Emoji 글꼴 오류로 검사 프로세스가 여러 번 재시작됐고 PDF 화면 기준 1개가 한 차례 실패했으나, 그 PDF 검사를 iPad 시뮬레이터에서 단독 재실행해 통과했다.
