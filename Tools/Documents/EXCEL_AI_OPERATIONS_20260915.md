# 엑셀 채팅 편집 기능 연결 — 2026-09-15

## 구현

기존 셀 값·표·표시 형식·드롭다운·조건부 서식에 더해, 수동 UI에서 구현한
엑셀 기능을 구조화된 `workbookOperations` 명령으로 연결했다.
자연어는 모델이 문맥으로 해석하며 특정 국가·제품·예문에만 대응하는 분기는 추가하지 않았다.

- 틀 고정/해제, 셀 병합/해제, 글꼴·색·정렬·줄바꿈·테두리.
- 행·열 삽입/삭제/크기, 정렬·필터/해제.
- 범위 복사/잘라내기/채우기/값 지우기/찾아 바꾸기.
- 시트 추가/복제/이름/삭제/순서.
- 이미지·차트 이동/크기/삭제, 이미지 이름·설명, 차트 추가/수정.
- 앞 작업의 결과에 이어 적용하는 셀 값 수정. 예: 시트를 복제한 후 복제본 B2만 수정.

27종의 일반 작업을 지원한다. 모델에는 시트 ID·이름·순서·보호·고정 상태,
선택 범위, 이미지·차트 ID/배치/종류/원본 범위를 제공한다.
개체 문맥은 현재 시트·선택 개체를 우선하며 최대 200개다.
전체 로컬 통합 문서는 모델로 직렬화하지 않는다.

## 적용과 복원

원본 문서를 보유한 편집기와 별개로, 메모리 안에 임시 편집기를 만든다.
기존 수동 편집의 XML·수식·보호 처리를 순서대로 재사용한 뒤 마지막 XLSX
내보내기와 다시 읽기까지 성공해야 실제 편집기 상태에 한 번에 반영한다.
중간 실패·취소·오래된 문서 상태는 전체 요청을 폐기한다. 파일은 기존 저장 경로로만 쓴다.

전체 요청은 실행 취소 한 번으로 되돌리고 다시 실행 한 번으로 복원한다.
셀 내용 외에도 시트·서식·병합·행열 크기·틀 고정·개체·선택 상태를 수정안의
문서 버전에 포함하여, 준비 중 상태가 바뀐 요청은 적용하지 않는다.

새 작업의 완료 문장은 실제 실행 결과에서 만든다. 변경 참조는 실제 주소를 사용하고
행·열 이동/병합/시트 이름 변경에 맞춰 갱신한다. 현재 시트의 셀은 기존 보라색
무채움 점선으로 표시하며, 개체 작업은 해당 개체 선택을 사용한다.
AI 범위 복사/잘라내기는 기기 클립보드를 읽거나 쓰지 않는다.

## 범위와 제한

- 한 요청 최대 20작업, 범위 합계 20,000셀, 일반 편집 범위 2,000행·200열.
- 보호 및 대용량 제한과 기존 OOXML 편집 제한을 그대로 적용한다.
- 값이 여러 개 있는 병합은 셀 도구의 기존 병합 안내에서 처리한다.
  모델이 임의로 값 삭제 허가를 만들 수 없다.
- 이미지 파일 추가/교체는 이미지 선택 UI를 이용한다. 차트 종류·원본 범위의
  지원 한계는 기존 직접 편집과 같다.
- “오른쪽으로”처럼 거리 없는 개체 이동은 한 열, “크게/작게”는 1.2/0.8배를
  기본값으로 모델에 안내하며 결과에는 실제 위치/크기를 표시한다.
- 복사 대상만 있고 붙일 곳이 없거나, 이름/선택이 모호한 개체는 명확화를 요청한다.
- 한 번의 참조 표시는 마지막 활성 시트를 대상으로 한다. 여러 시트의 참조를
  동시에 보여주는 새 UI는 추가하지 않았다.
