# 한글 캔버스 도형 회전·방향키 이동 · 2026-09-17

우선순위 21을 적용했다. HWP/HWPX 원본 화면에서 선택한 독립 도형과 그룹 외곽을 회전 손잡이로 직접 돌리고 하드웨어 키보드로 미세 이동할 수 있다.

## 사용 방법

1. 원본 화면의 도형을 한 번 누른다.
2. 선택 테두리 위쪽 중앙의 회전 손잡이를 원을 그리듯 끈다.
3. 하드웨어 키보드 방향키로 1pt씩 이동한다.
4. Shift+방향키로 10pt씩 이동한다.
5. 같은 도형을 다시 누르면 기존 상세 편집 창이 열린다.

회전 중에는 도형과 선택 테두리를 함께 미리 보여준다. 손을 놓을 때 각도를 0–359도로 정규화해 문서에 한 번 기록한다. 방향키 이동도 한 입력당 한 번 기록하며 문서 좌표 범위를 넘지 않게 제한한다.

## 저장과 실행 취소

- 한 번의 회전 드래그는 실행 취소 한 단계다.
- 방향키 입력 한 번은 실행 취소 한 단계다.
- 위치·크기·회전 이외의 선·채우기·그림자·글 배치·경로·화살표 값은 유지한다.
- HWP/HWPX 저장 후 앱 파서로 다시 열어 각도와 좌표가 유지되는지 확인한다.

## 자동 확인

- 회전 증분 계산과 0–359도 정규화
- HWPX 직접 이동·크기·회전 저장 후 재열기
- 기존 HWP/HWPX 그룹·도형·글상자·수식·표시 회귀
- 도형 편집 자동 검사 26개 통과
- 관련 M4 회귀 검사 43개 통과
- 일반 Debug 앱을 2026-09-17 10:54:10 KST에 무선 M4에 설치하고 실행

## 현재 범위와 다음 작업

캔버스 직접 조작은 독립 도형과 그룹 전체에 적용한다. 그룹 내부 개별 도형은 상세 편집 창에서 회전과 위치를 바꾼다. 회전된 도형의 크기 손잡이는 문서의 가로·세로 크기를 기준으로 계산하며 회전축 방향 크기 조절은 남아 있다.
