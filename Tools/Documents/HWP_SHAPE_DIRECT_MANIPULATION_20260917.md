# 한글 캔버스 도형 직접 조작 · 2026-09-17

우선순위 20을 적용했다. HWP/HWPX 원본 화면에서 독립 도형과 그룹 외곽을 직접 끌어 이동하고 네 모서리 손잡이로 크기를 조절할 수 있다.

## 사용 방법

1. 원본 화면의 도형을 한 번 누른다.
2. 파란 선택 테두리와 네 모서리의 흰색 손잡이를 확인한다.
3. 도형 안쪽을 끌어 이동하거나 모서리 손잡이를 끌어 크기를 바꾼다.
4. 선택한 도형을 다시 누르면 좌표·회전·스타일을 숫자로 바꾸는 상세 편집 창이 열린다.

손잡이는 화면에는 13pt 원으로 표시하지만 손가락으로 잡는 영역은 28pt로 넓혔다. 왼쪽 또는 위쪽 손잡이를 끌면 반대편 모서리를 고정한 채 위치와 크기를 함께 갱신한다. 너비는 20pt, 높이는 8pt 아래로 줄어들지 않는다.

## 저장과 실행 취소

- 드래그 중에는 화면에서 위치와 크기를 바로 미리 본다.
- 손을 놓을 때 HWP/HWPX의 개체 위치·크기 값을 기록한다.
- 한 번의 이동 또는 크기 조절은 실행 취소 한 단계다.
- 회전·뒤집기·선·채우기·그림자·글 배치·경로·화살표 값은 유지한다.
- 저장한 문서를 앱 파서로 다시 열어 좌표와 크기가 같은지 검사한다.

## 자동 확인

- 이동 및 네 모서리 크기 계산, 최소 크기 제한
- HWPX 이동·크기 조절 저장 후 재열기
- 기존 HWP 도형 이동·크기·그룹 편집 저장 회귀
- 도형 편집 자동 검사 25개 통과
- 도형·글상자·수식·HWPX 표시를 포함한 M4 관련 회귀 검사 42개 통과
- 일반 Debug 앱을 2026-09-17 10:26:35 KST에 무선 M4에 설치하고 실행

## 현재 범위와 다음 작업

그룹 내부의 개별 도형은 기존 상세 편집 창에서 위치와 크기를 변경한다. 캔버스 직접 조작은 독립 도형과 그룹 전체에 적용한다. 회전된 도형도 이동·크기 변경 값을 저장하지만, 회전 각도에 맞춘 축 방향 크기 조절은 아직 상세 편집 창을 사용한다.

후속 우선순위 21에서 캔버스 회전 손잡이와 방향키 미세 이동을 적용했다. 자세한 내용은 [회전·방향키 기록](HWP_SHAPE_ROTATION_KEYBOARD_20260917.md)에 정리했다.
