# 중첩 표 셀 서식·목록 · 2026-09-17

우선순위 35로, 표 안에 들어 있는 안쪽 표의 셀에서도 상단 서식 도구를 그대로 사용할 수 있게 했다.

## 적용 범위

- 안쪽 셀을 선택하면 상단 `셀` 버튼이 활성화된다.
- 셀 배경색, 네 방향 테두리의 선 종류·굵기·색, 위·가운데·아래 세로 정렬을 변경한다.
- 안쪽 셀 문단에 글머리표와 번호 목록을 적용하거나 해제한다.
- 번호는 같은 안쪽 셀 안에서 이어지고 다른 셀의 번호와 섞이지 않는다.
- 셀 서식은 같은 셀의 모든 문단에 적용하며 바깥 셀과 이웃 셀 서식은 유지한다.
- HWP와 HWPX 원본 형식으로 저장하고 다시 열었을 때 셀 서식과 목록을 복원한다.

## 사용 방법

1. 중첩 표의 안쪽 셀 글자를 눌러 커서를 놓는다.
2. 상단 `셀`에서 채우기·테두리·세로 정렬을 바꾸거나, 상단 글머리표·번호 버튼을 누른다.
3. `… → 이 문서에 저장`을 누르고 다시 열어 확인한다.

## 검증

- HWPX 중첩 표에서 셀 채우기·테두리·세로 정렬과 번호 목록을 한 번에 저장하고 재열기했다.
- HWP 중첩 표에서도 같은 조합을 저장하고 재열기했다.
- 두 형식 모두 안쪽 표의 부모 관계, 원문, 바깥 표와 다른 셀을 유지하는지 검사했다.
- 표·문단·목록·글자·그림·도형·글상자·HWPX 표시 관련 자동 검사 180개를 무선 M4에서 통과했다.
- 일반 Debug 앱을 2026-09-17 18:05:45 KST에 무선 M4에 설치하고 실행했다.

## 현재 경계

- 목록 단계는 한 단계 글머리표와 번호를 대상으로 한다.
- 여러 셀을 한 번에 선택해 동일한 셀 서식이나 목록을 적용하는 기능은 아직 제공하지 않는다.
- 3단 이상 깊이의 중첩 표는 실제 문서 표본을 더 확보해 별도로 검증해야 한다.
