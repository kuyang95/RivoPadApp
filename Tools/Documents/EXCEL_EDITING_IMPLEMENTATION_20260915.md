# 엑셀 편집 확장 구현 기록

2026-09-15. 사용자가 우선순위로 선택한 범위 편집 → 행·열 편집 → 기본 서식
→ 정렬·필터 순서로 구현했다. 실기기 사용 흐름 검증은 별도 목록에 누적한다.

## 추가한 기능

- 범위 선택·복사: 길게 눌러 끌기, 행·열 머리글 선택, 셀 주소 범위 입력,
  복사·잘라내기·붙여넣기·값 지우기, 아래·오른쪽 채우기.
  앱 내부 복사는 셀의 값 종류와 서식을 보존하며, 외부 텍스트는 탭 구분 표를 읽는다.
- 행·열 편집: 선택 앞뒤 삽입, 선택한 행·열 삭제, 행 높이·열 너비 변경.
  일반 A1 수식 참조와 관련 표·범위·메타데이터를 함께 이동한다.
- 기본 서식: 글꼴 이름·크기, 굵게·기울임·밑줄, 글자색·배경색,
  가로·세로 정렬, 줄바꿈, 모든/바깥/없음 테두리.
  화면 렌더링과 XLSX 읽기·쓰기를 연결했다.
- 정렬·필터·찾기: 열 기준 오름·내림차순, 첫 행 머리글 유지,
  포함/같음/보다 큼/보다 작음 조건 필터, 필터 해제,
  시트 내 찾기·다음 결과·현재 셀/전체 바꾸기.

네 화면은 셀 도구에서 열린다. 기존 표시 형식·드롭다운·조건부 서식·링크 및
메모·표 끝 행 추가·이미지와 차트 관리도 유지한다.

## 저장과 편집 기록

일괄 변경은 하나의 실행 취소 기록으로 묶는다. 구조·기본 서식 변경은
현재 편집을 반영한 XLSX를 메모리에서 변환하고 재파싱한다. 원본 파일의
마지막 저장 기준은 따로 유지해 파일 충돌 검사를 보존한다.
계산 순서 파일은 관계와 콘텐츠 유형에서 함께 제거하고 Excel에 재계산을 요청한다.

## 현재 지원 제한

- 범위 일괄 편집·복사는 한 번에 20,000셀 이하. 일반 편집의 로딩 한도를
  넘어가거나 보호·대용량 시트의 구조·서식 편집은 적용하지 않는다.
- 병합 셀·배열 수식을 포함한 범위의 붙여넣기·채우기·정렬은 제한한다.
  배열 수식이 있는 시트의 구조 편집도 제한한다.
- 전체 행·열 참조와 3차원 참조가 있는 문서는 행·열 삽입/삭제를 제한한다.
  표의 머리글이나 표 전체를 제거하는 구조 변경도 제한한다.
- 수식이 든 범위의 시트 간 잘라내기는 복사·붙여넣기를 안내한다.
  외부 앱으로의 복사는 텍스트 표이며 서식은 앱 내부 복사에서 사용한다.
- 필터는 현재 한 개 기준 열의 한 조건을 적용한다. 지원 필터는 원본·간편
  보기에서 숨겨진 행을 제외하고 XLSX에 필터 조건을 기록한다.
- 새 기능의 AI 채팅 명령 연결, 셀 병합·해제, 시트 관리, 틀 고정,
  이미지·차트의 시트 위 직접 조작은 이번 네 묶음의 범위에 포함하지 않았다.
