# 한글 상단 도구 분류

## 배치

- 제목/내비게이션 줄을 숨기고 뒤로 가기, 분류 탭, 도구 접기, 실행 취소, 다시 실행, 더보기를 하나의 48pt 상단 줄로 통합.
- 간편 보기·로딩·오류 화면에서도 공통 상단 버튼을 유지하여 뒤로 가기 가능.
- 분류 줄: 글자 / 문단 / 삽입 / 쪽 / 찾기. 기본 선택은 글자.
- 선택한 분류의 도구만 다음 줄에 표시. 좁은 화면에서는 가로 스크롤.
- 오른쪽 접기 버튼으로 도구 줄을 숨기며, 분류를 누르면 다시 펼침.
- 표 셀에 커서를 놓으면 표 탭 추가. 글자·문단 탭도 계속 이용 가능.
- 그림 또는 도형을 선택하면 개체 탭 추가 및 선택. 본문 편집을 시작하면 개체 선택 해제.
- 원본/간편 전환과 문서 이동·확대는 기존 하단 위치 유지.

| 탭 | 도구 |
| --- | --- |
| 글자 | 글꼴, 크기, 굵게, 기울임, 밑줄, 글자색, 강조색, 글자 효과·서식 지우기 |
| 문단 | 글머리표, 번호, 왼쪽·가운데·오른쪽·양쪽 정렬, 문단 상세 |
| 삽입 | 표, 그림, 도형, 글상자, 수식, 링크, 각주·미주, 도형 다중 선택 진입 |
| 쪽 | 쪽 설정, 쪽 번호, 다단, 머리말·꼬리말, 쪽 나누기·해제 |
| 찾기 | 검색 입력, 결과 이동, 바꾸기, 검색 옵션. Command-F 지원 |
| 표 | 셀 서식, 행·열 편집, 병합·분할, 크기 |
| 개체 | 선택한 그림/도형 상세 편집, 삭제, 그룹 해제, 다중 선택 시 정렬·크기 맞춤·뒤집기·복제·그룹 |

시뮬레이터에서는 변경된 Swift 파일 컴파일까지 완료했으나, 기존 `Pods/MLImage/Frameworks/MLImage.framework`의 arm64 코드가 iOS 실기기용이어서 링크가 실패했다. 이 의존성은 이번 도구 분류 변경 범위에서 수정하지 않았다. 당시 화면 조작 항목은 미확인으로 유지했다. 이후 M5 실기기 재개 결과는 아래에 기록한다.

사용자 확인 경로: M5에서 한글 문서 열기 → 상단 글자/문단/삽입/쪽/찾기 탭 선택. 표 셀을 누른 뒤 표 탭, 그림/도형을 누른 뒤 개체 탭을 확인한다. 오른쪽 꺾쇠는 도구 접기/펼치기이다.

Device Hub 화면 공유가 정상 작동한다. 화면을 보고 직접 클릭·입력하여 확인했으며, 빌드나 자동화 테스트 실행을 수동 조작으로 계산하지 않았다.
테스트 파일: 기기의 VisionCraft 폴더 `HWP_UI_M5_20260923.hwpx`. 기존 사용자 문서는 편집하지 않았다.
