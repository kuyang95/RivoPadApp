# 한글 회전 도형 축 기준 크기 조절 · 2026-09-17

우선순위 28을 적용했다. HWP/HWPX 원본 화면에서 회전된 독립 도형과 그룹 외곽의 네 모서리 손잡이를 도형 자체 가로·세로 축에 맞춰 끌 수 있다.

## 동작

- 화면 좌표의 손가락 이동을 도형의 회전 각도에 맞춘 내부 좌표로 변환한다.
- 좌우·상하 뒤집기가 적용된 도형은 뒤집힌 손잡이 방향까지 반영한다.
- 잡은 모서리의 대각선 반대편은 화면에서 같은 위치를 유지하도록 위치와 중심을 함께 보정한다.
- 너비 20pt, 높이 8pt의 기존 최소 크기와 2,000pt 최대 크기를 유지한다.
- 드래그 중 미리보기와 손을 놓은 뒤 저장되는 위치·크기가 같은 계산을 사용한다.
- 회전된 도형을 이동할 때도 미리보기가 손가락의 화면 이동 방향과 일치한다.

## 저장과 실행 취소

손을 놓으면 기존 직접 조작 경로로 위치와 크기를 기록하므로 한 번의 드래그가 실행 취소 한 단계가 된다. 회전, 뒤집기, 선, 채우기, 그림자, 글 배치, 경로와 화살표 속성은 유지한다. HWP와 HWPX 모두 회전된 상태에서 크기를 바꾼 뒤 앱 파서로 다시 열어 위치·크기·회전값을 확인했다.

- 좌우 뒤집기 상태의 손잡이 방향과 중심 위치 확인
- HWP/HWPX 회전 도형 크기 변경 후 저장·재열기
- 도형 편집 검사 26개 통과
