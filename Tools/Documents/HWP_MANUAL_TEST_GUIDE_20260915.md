# 한글 기능 직접 테스트 가이드

2026-09-17 기준. 이 작업에서 추가한 한글 편집 기능을 현재 화면의 버튼 이름으로 정리했다. 설치된 앱 이름은 **VisionCraft**다. 수동 확인 항목은 총 235개다. 중첩 표 셀 서식·목록까지 포함한 빌드는 관련 자동 검사 180개를 통과했으며 2026-09-17 18:05:45 KST에 무선 M4에 설치하고 실행했다.

## 시작하기

1. **VisionCraft → 문서 작업**을 연다.
2. 본문 테스트: **새 문서 만들기 → 한글 (.hwpx)**을 선택하고 파일을 만든다.
3. 표 테스트: 새 한글 문서에서 상단 **표**로 표를 만들거나, **파일 불러오기**에서 표가 있는 `.hwp` 또는 `.hwpx`를 연다.
4. 문서 아래의 **원본 / 간편** 중 **원본**을 선택한다.
5. 본문 또는 셀 안의 글자를 누른다. 별도의 ‘편집’ 버튼 없이 커서가 나타난다. 빈 문서는 빈 본문을 눌러 입력한다.

서식 도구줄은 좌우로 넘길 수 있다. 글자·문단 도구는 편집할 문단에 커서를 놓아야 활성화된다. **셀 / 표 편집 / 병합·분할 / 크기**는 지원되는 표의 셀을 편집할 때 나타난다. **쪽 → 쪽 설정 / 다단 / 쪽 번호 / 머리말 / 꼬리말**과 **돋보기**는 커서 없이도 사용할 수 있다. **쪽 나누기**는 일반 본문에 커서를 놓고 사용한다.

글자 서식은 문단 안에서 선택한 글자에 적용된다. 선택 영역 없이 커서만 놓고 바꾸면 이후 입력하는 글자의 서식이 바뀐다. 문단 정렬·간격·목록은 커서가 있는 문단에 적용된다.

## 본문·글자·문단

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 기본 입력 | 본문을 누르고 `한글 테스트 가나다 ABC 123 😀` 입력 | 한글 조합·공백·이모지가 온전하고 커서가 유지됨 |
| ☐ | 부분 수정 | 한 단어를 선택해 다른 단어로 입력, 복사·붙여넣기도 시도 | 선택한 범위만 바뀌고 앞뒤 내용이 보존됨 |
| ☐ | 문단 나누기 | 일반 본문 중간에서 Enter | 뒤 글자가 새 문단으로 이동 |
| ☐ | 문단 합치기 | 새 문단 맨 앞에서 Backspace | 앞 문단과 합쳐지고 글자 서식이 유지됨 |
| ☐ | 문단 안 줄바꿈 | 하드웨어 키보드에서 Shift+Enter | 같은 문단 안에서 줄만 바뀜 |
| ☐ | 글꼴·크기 | 단어 선택 → 상단 글꼴 이름 / `10 pt` 같은 크기 버튼 | 선택한 글자의 글꼴·크기가 변경됨. 크기는 ‘직접 입력’도 가능 |
| ☐ | 기본 글자 장식 | 단어 선택 → 굵게(B), 기울임(I), 밑줄(U), 글자색(A 아래 색 막대) | 선택한 부분에만 적용되고 같은 장식 버튼을 다시 누르면 해제됨 |
| ☐ | 강조색 | 단어 선택 → 형광펜 아이콘 → 색상, 이어서 ‘없음’ | 글자 배경에 색이 생기고 ‘없음’으로 제거됨 |
| ☐ | 취소선·첨자 | 단어 선택 → `Aa ▾` 글자 효과 → 취소선 / 위 첨자 / 아래 첨자 | 취소선 또는 작은 위·아래 글자로 표시. 위·아래 첨자는 동시에 켜지지 않음 |
| ☐ | 글자 서식 지우기 | 서식 있는 단어 선택 → `Aa ▾` → 글자 서식 지우기 | 바탕 10pt·검정으로 초기화. 문단 정렬과 목록은 유지됨 |
| ☐ | 문단 정렬 | 문단에 커서 → 왼쪽 / 가운데 / 오른쪽 / 양쪽 정렬 아이콘 | 현재 문단 전체의 정렬이 변경됨 |
| ☐ | 문단 간격 | 상단 ‘문단’ → 여백·첫 줄 들여쓰기·문단 앞뒤 간격·줄 간격 → 적용 | 설정한 간격과 들여쓰기 반영. 첫 줄 음수는 내어쓰기 |
| ☐ | 글머리표 | 문단에 커서 → 글머리표 아이콘 | 기본 `•` 목록 적용. 같은 버튼을 다시 누르면 해제 |
| ☐ | 번호 목록 | 문단에 커서 → 번호 매기기 아이콘 → 내용 입력 → Enter | 다음 본문 문단의 번호가 이어짐. 빈 항목에서 Enter를 누르면 목록 종료 |
| ☐ | 목록 해제 키 | 목록 문단 맨 앞에서 Backspace | 먼저 목록 서식이 해제됨. Shift+Enter는 항목 안 줄바꿈 |

## 표

새 표는 빈 문서에서 바로 **상단 표**를 누르거나, 일반 본문에 커서를 놓고 **표 → 행 수·열 수 → 삽입**으로 만든다. 삽입하면 커서 앞뒤 글이 표 위아래 문단에 남고 첫 셀에서 입력을 시작한다. 새 셀은 바탕 10pt, 검은 테두리로 만든다. 글자 선택을 해제한 일반 본문에서 사용하며, 목록·다단·기존 셀 안에 표를 넣는 기능은 아직 없다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 빈 문서 표 삽입 | 새 한글 문서 → 상단 ‘표’ → 3행·2열 → 삽입 | 테두리가 있는 6개 셀이 생기고 첫 셀에 커서가 놓임 |
| ☐ | 본문 중간 표 삽입 | 글 중간에 커서 → ‘표’ → 삽입 | 커서 앞뒤 글·서식이 표 위아래에 유지됨. 한글·이모지도 보존 |
| ☐ | 표 크기 입력·취소 | 행/열에 0·21·빈칸 입력 / 유효 값으로 바꾸고 취소 | 유효하지 않으면 삽입 불가. 취소하면 원래 문서와 커서 유지 |
| ☐ | 표 삽입 실행 취소 | 빈 표 삽입 직후 실행 취소 → 다시 실행 | 원래 문서로 복원되고 다시 실행하면 같은 표가 복원됨 |
| ☐ | 새 표 편집·저장 | 삽입된 표의 셀 입력, 행열 추가·병합·크기 변경 → 저장·재열기 | HWP·HWPX 모두 표 구조·셀 내용·서식 유지 |
| ☐ | 긴 표 쪽 넘김 | 20행 표 삽입 후 아래로 이동 | 표가 여러 쪽에 나뉘며 뒤 본문과 겹치지 않음. 쪽 번호도 이어짐 |

먼저 **기존 표의 셀 안**을 눌러 커서를 놓는다. 표 테스트는 일반 1단 본문에 있는, 그림·중첩 표가 없는 단순한 표부터 진행한다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 셀 입력·높이 증가 | 셀에 긴 글을 입력해 자동 줄바꿈 확인 | 글이 줄바꿈되고 필요한 행 높이가 늘어남. 뒤 행·본문이 겹치지 않음 |
| ☐ | 셀 문단 나누기 | 셀 글자 중간에 커서 → Enter | 커서 앞뒤가 같은 셀의 두 문단으로 나뉘고 새 문단에 커서가 놓임 |
| ☐ | 선택 영역 지우고 나누기 | 셀 안의 한글·이모지 일부 선택 → Enter | 선택 부분만 지워지고 그 위치에서 두 문단으로 나뉘며 글자 서식이 유지됨 |
| ☐ | 셀 문단 합치기 | 셀의 둘째 문단 맨 앞 → Backspace | 같은 셀의 앞 문단과 합쳐지고 합친 경계에 커서가 놓임. 옆 셀과는 합쳐지지 않음 |
| ☐ | 셀 안 줄바꿈 | 셀 문단 중간 → 하드웨어 키보드 Shift+Enter | 새 문단을 만들지 않고 현재 문단 안에서 줄만 바뀜 |
| ☐ | 셀 문단 저장·복원 | HWP/HWPX에서 나누기·합치기 → 실행 취소·다시 실행 → 저장·재열기 | 문단 순서·글자 서식·셀 크기와 다른 셀 내용이 유지됨 |
| ☐ | 셀 서식 | 상단 ‘셀’ → 채우기 색·세로 정렬 → 적용 | 선택 셀의 배경색과 위/가운데/아래 정렬 변경 |
| ☐ | 테두리 | ‘셀’ → 테두리 모두/없음 또는 각 방향, 선 굵기·색 → 적용 | 고른 테두리와 선 굵기·색 반영 |
| ☐ | 표 전체 삭제 | 셀에 커서 → ‘표 편집’ → 표 삭제 | 선택한 표와 셀 내용이 모두 사라지고 본문 입력 위치가 남음 |
| ☐ | 표 삭제 취소·복원 | 내용을 넣고 서식을 바꾼 표 삭제 → 저장 전에 실행 취소 → 다시 실행 | 셀 내용·서식·병합과 크기가 복원되고 다시 실행하면 삭제됨 |
| ☐ | 마지막 셀 표 삭제 | 1×1 표 생성 → 표 삭제 → 그 자리에 본문 입력 | 마지막 표도 삭제할 수 있고 커서로 본문 입력을 계속함 |
| ☐ | 긴 표 삭제 | 여러 쪽에 걸친 표 삭제 | 뒤 본문이 올라오고 불필요해진 쪽이 없어짐. 쪽 번호는 이어짐 |
| ☐ | 다른 표·본문 보존 | 표가 두 개 이상인 문서에서 하나만 삭제 | 다른 표의 내용·서식과 표 앞뒤 본문이 보존됨 |
| ☐ | 표 삭제 저장 | HWP와 HWPX 각각 표 삭제 → 저장 → 닫고 다시 열기 | 원래 형식으로 저장되고 삭제된 표가 다시 나타나지 않음 |
| ☐ | 행 추가·삭제 | ‘표 편집’ → 위에 행 추가 / 아래에 행 추가 / 행 삭제 | 행이 추가·삭제됨. 추가한 빈 셀에 입력 가능 |
| ☐ | 열 추가·삭제 | ‘표 편집’ → 왼쪽에 열 추가 / 오른쪽에 열 추가 / 열 삭제 | 열이 추가·삭제되고 기존 내용이 유지됨 |
| ☐ | 가로·세로 병합 | ‘병합·분할’ → 오른쪽 셀과 병합 / 아래 셀과 병합 | 맞닿은 셀이 하나가 되고 기존 내용이 보존됨 |
| ☐ | 셀 나누기 | ‘병합·분할’ → 좌우로 둘로 나누기 / 상하로 둘로 나누기 | 같은 크기 두 칸 생성. 내용은 첫 번째 셀에 남고 새 셀은 비어 있음 |
| ☐ | 병합 풀기 | 병합 셀 선택 → ‘병합·분할’ → 병합 풀기 | 내부 행·열 경계가 복원됨. 내용은 왼쪽 위 셀에 남음 |
| ☐ | 열 너비·행 높이 | ‘크기’ → mm 직접 입력 또는 +/− → 적용 | 해당 열·행 전체 크기가 바뀜. 행은 글이 잘리지 않는 최소 높이 유지 |
| ☐ | 취소 | ‘셀’ 또는 ‘크기’에서 값을 바꾼 뒤 취소 | 원래 내용·서식·크기를 유지하고 입력으로 돌아감 |
| ☐ | 셀 안 그림 선택 | 그림이 든 표 셀 문서 열기 → 셀 안 그림을 한 번 누르고 다시 누르기 | 첫 탭에는 선택 테두리와 이동·크기·회전 손잡이가, 두 번째 탭에는 그림 상세 편집창이 열림 |
| ☐ | 셀 안 그림 직접 조작 | 셀 안 그림을 이동·회전하고 모서리 손잡이로 셀 아래쪽까지 키우기 | 조작 결과가 즉시 보이고 필요한 만큼 행 높이가 늘며 뒤 행·본문이 겹치지 않음 |
| ☐ | 셀 안 도형 편집 | 셀 안 도형 선택 → 이동·회전·크기 변경 → 다시 눌러 배치·선·채우기 변경 | 도형만 바뀌고 셀 내용·테두리·다른 셀은 유지되며 필요한 행 높이가 반영됨 |
| ☐ | 셀 개체 저장·복원 | HWP/HWPX에서 셀 안 그림·도형 변경 → 실행 취소·다시 실행 → 저장·재열기 | 원래 형식과 개체 좌표·크기·회전·스타일, 표 구조·행 높이·뒤 본문이 유지됨 |
| ☐ | 셀 안 그림 삽입 | 일반 표 셀 글자 사이에 커서 → 상단 ‘그림’ → 사진 보관함 또는 파일 선택 | 선택한 셀에 그림이 들어가고 기존 셀 글자·테두리·다른 셀은 유지됨 |
| ☐ | 셀 안 도형 삽입 | 일반 표 셀에 커서 → 상단 ‘도형’ → 사각형·타원·선·다각형·연결선 중 선택 | 고른 도형이 해당 셀에 들어가고 바로 선택·이동·크기·회전 가능 |
| ☐ | 셀 삽입 높이·본문 배치 | 셀보다 높은 그림·도형을 삽입하고 표 아래 본문 확인 | 행 높이가 개체에 맞게 늘고 다음 행과 표 뒤 본문이 겹치지 않음 |
| ☐ | 셀 삽입 저장·실행 취소 | HWP/HWPX에서 셀 개체 삽입 → 실행 취소·다시 실행 → 저장·재열기 | 삽입 전후가 복원되고 원래 형식, 셀 글자, 새 개체와 표 구조가 유지됨 |
| ☐ | 중첩 셀 그림·도형 삽입 | 표 안에 든 안쪽 표의 셀에 커서 → 상단 ‘그림’ 또는 ‘도형’ | 선택한 안쪽 셀에 개체가 생기고 셀 글자·안쪽/바깥쪽 표 구조가 유지됨 |
| ☐ | 중첩 셀 개체 직접 편집 | 안쪽 셀 개체 선택 → 이동·크기·회전 → 다시 눌러 상세 속성 변경 | 안쪽 개체만 바뀌며 바깥 셀의 글자와 다른 셀 개체는 유지됨 |
| ☐ | 중첩 표 높이 전달 | 안쪽 셀보다 높은 그림·도형 삽입 또는 크기 확대 | 안쪽 행부터 바깥 셀·바깥 표가 함께 늘고 표 뒤 본문이 겹치지 않음 |
| ☐ | 중첩 셀 개체 저장·복원 | HWP/HWPX 중첩 셀 개체 변경 → 실행 취소·다시 실행 → 저장·재열기 | 원래 형식과 안쪽/바깥쪽 표 구조, 개체 배치가 모두 유지됨 |
| ☐ | 중첩 표 행 추가·삭제 | 안쪽 표 셀에 커서 → ‘표 편집’ → 위/아래 행 추가 → 추가한 행 삭제 | 안쪽 표만 바뀌고 바깥 셀 글자·바깥 표 구조는 유지됨 |
| ☐ | 중첩 표 열 추가·삭제 | 안쪽 표 셀에 커서 → ‘표 편집’ → 왼쪽/오른쪽 열 추가 → 추가한 열 삭제 | 안쪽 표 너비가 바깥 셀 범위 안에서 조절되고 기존 내용이 유지됨 |
| ☐ | 중첩 표 병합·분할 | 안쪽 표에서 오른쪽/아래 병합 → 좌우/상하 분할 → 병합 풀기 | 선택한 안쪽 표 셀만 바뀌며 내용은 첫 셀에 보존됨 |
| ☐ | 중첩 표 크기·배치 | 안쪽 표의 열 너비와 행 높이 변경, 긴 글 입력 | 안쪽 표가 바깥 셀 가용 너비를 넘지 않고 바깥 행과 뒤 본문이 겹치지 않음 |
| ☐ | 중첩 표 구조 저장·복원 | HWP/HWPX에서 위 작업 → 실행 취소·다시 실행 → 저장·재열기 | 원래 형식과 안쪽/바깥쪽 표 내용·구조·크기가 유지됨 |
| ☐ | 중첩 셀 채우기·세로 정렬 | 안쪽 표 셀에 커서 → 상단 ‘셀’ → 채우기 색과 위/가운데/아래 정렬 변경 | 선택한 안쪽 셀만 바뀌고 바깥 셀과 다른 안쪽 셀은 유지됨 |
| ☐ | 중첩 셀 테두리 | 안쪽 표 셀 → ‘셀’ → 네 방향 테두리의 선·굵기·색 변경 | 안쪽 셀 경계에 고른 테두리가 표시되고 바깥 표 테두리는 유지됨 |
| ☐ | 중첩 셀 글머리표·번호 | 안쪽 셀 문단에 커서 → 상단 글머리표 또는 번호 버튼 | 셀 글자는 바뀌지 않고 문단 앞에 선택한 목록 표식이 표시됨 |
| ☐ | 중첩 셀 번호 이어가기 | 번호 문단 끝에서 Enter로 다음 셀 문단 추가, 빈 번호 문단에서 다시 Enter | 번호가 1, 2로 이어지고 빈 항목에서 목록이 정상 종료됨 |
| ☐ | 중첩 셀 서식·목록 저장 | HWP/HWPX에서 위 변경 → 실행 취소·다시 실행 → 저장·재열기 | 셀 배경·테두리·세로 정렬·목록과 안쪽/바깥쪽 표 구조가 유지됨 |

셀 안 Enter는 **새 셀 문단**, Shift+Enter는 **현재 셀 문단 안 줄바꿈**이다. 문단 맨 앞 Backspace는 같은 셀의 앞 문단과 합치며 셀 경계를 넘지 않는다. 내용을 지워도 행 높이는 자동으로 줄지 않으므로 ‘크기’에서 조절한다. 병합 전 내용의 위치까지 되돌리려면 ‘병합 풀기’ 대신 **실행 취소**를 사용한다.

## 찾기·쪽 설정·문서 이동

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 찾기 | 상단 돋보기 또는 Command+F → 찾을 내용 입력 → 위/아래 화살표 | 본문·표의 각 결과를 찾아 해당 쪽으로 이동하고 강조 표시 |
| ☐ | 한 곳 바꾸기 | 검색창의 ‘바꾸기’ 펼치기 → 바꿀 내용 → 바꾸기 | 선택한 결과만 바뀌고 다음 결과로 이동 |
| ☐ | 모두 바꾸기 | 같은 단어를 여러 곳에 준비 → 모두 바꾸기 | 편집 가능한 결과 전체가 변경. 실행 취소 한 번으로 복원 |
| ☐ | 검색 옵션 | 검색창의 검색 옵션 → 대소문자 구분 | 영어 대소문자 구분 여부가 반영됨 |
| ☐ | 쪽 나누기 삽입 | 일반 본문 커서 → ‘쪽’ → 쪽 나누기, 또는 Ctrl+Enter | 커서 뒤 내용부터 다음 쪽으로 이동. 문단 맨 앞에서는 현재 문단을 다음 쪽으로 넘기며, 문서 첫머리·문단 끝에서는 빈 문단이 생길 수 있음 |
| ☐ | 쪽 나누기 삭제 | 나눔이 있는 문단 → ‘쪽’ → 쪽 나누기 없애기 | 명시적인 나눔만 없어지고 문단 내용은 그대로 유지 |
| ☐ | 나눔 뒤 Backspace | 나눔 직후 문단 맨 앞에서 Backspace | 먼저 쪽 나눔만 삭제. 다시 Backspace를 누르면 목록 해제 또는 앞 문단과 합치기 |
| ☐ | 용지 크기·방향 | 상단 ‘쪽’ → 쪽 설정 → A5·가로 → 적용 | A5 가로 용지로 변경되고 본문 줄과 쪽 배치가 갱신됨 |
| ☐ | 여백 | ‘쪽’ → 쪽 설정 → 좁게/보통/넓게 또는 상하좌우 직접 입력 → 적용 | 여백 반영. 머리말·꼬리말 여백도 펼쳐 변경 가능 |
| ☐ | 구역별 적용 | 구역이 여러 개인 문서에서 ‘쪽’ → 쪽 설정 → 전체 문서 / 현재 구역 선택 | 선택 범위에만 적용. 현재 구역은 편집 중 문단, 없으면 보고 있는 쪽 기준 |
| ☐ | 설정 취소·잘못된 값 | ‘쪽 → 쪽 설정’ 값을 바꿔 취소, 다시 열어 너비 0 입력 | 취소 시 원래 용지 유지. 잘못된 값은 적용 불가 |
| ☐ | 1~4단 설정 | ‘쪽’ → 다단 → 1단·2단·3단·4단을 차례로 적용 | 선택한 수만큼 같은 너비의 단이 생기고 본문이 왼쪽부터 배치됨 |
| ☐ | 단 간격 | 2단 이상에서 단 간격을 5mm, 15mm로 바꿔 적용 | 단 사이 간격이 바뀌고 각 단 너비와 줄바꿈이 다시 계산됨 |
| ☐ | 단 구분선 | 2단 이상 → 단 구분선 켜기/끄기 → 적용 | 단 사이 세로선이 나타나거나 사라지고 본문은 유지됨 |
| ☐ | 다단 적용 범위 | 여러 구역 문서 → 현재 구역/전체 문서를 각각 선택해 적용 | 선택한 구역만 또는 모든 구역의 단 수·간격·구분선이 바뀜 |
| ☐ | 다단 자동 흐름 | 긴 본문을 2~4단으로 변경 | 왼쪽 단 아래까지 채운 뒤 오른쪽 단, 이어서 다음 쪽 왼쪽 단으로 흐름 |
| ☐ | 다단 본문 직접 편집 | 각 단의 글자를 누르고 입력, Enter로 나누기, 문단 맨 앞 Backspace로 합치기 | 별도 편집 버튼 없이 커서가 생기고 단 사이 배치가 다시 계산됨 |
| ☐ | 다단 HWP/HWPX 저장 | 두 형식에서 단 설정과 본문 변경 → 실행 취소·다시 실행 → 저장·재열기 | 단 수·간격·구분선, 본문과 쪽 배치가 유지됨 |
| ☐ | 쪽 번호 넣기 | 커서 없이도 ‘쪽’ → 쪽 번호 → 쪽 번호 표시 켜기 → 적용 | 기본 아래쪽 가운데에 숫자가 표시됨 |
| ☐ | 번호 위치·정렬 | 쪽 번호에서 위쪽/아래쪽, 왼쪽/가운데/오른쪽 선택 → 적용 | 여섯 위치에 맞춰 이동. 번호 양옆에 줄표를 켜면 `- 1 -`처럼 표시 |
| ☐ | 시작 번호 | ‘새 번호로 시작’ 켜고 7 입력 → 적용 | 첫 적용 구역이 7부터 시작하고 다음 쪽은 8. 0·65536·빈칸은 적용 불가 |
| ☐ | 번호 적용 범위 | 여러 구역 문서에서 ‘현재 구역’ 또는 ‘전체 문서’ 선택 | 현재 구역만 설정하거나 전체에 적용. 전체는 첫 구역에서 시작하여 연속 번호 유지 |
| ☐ | 번호 지우기 | ‘쪽 번호 표시’ 끄기 → 적용 | 선택 범위의 번호가 사라지고 본문·여백·기존 시작 번호는 유지됨 |
| ☐ | 번호 설정 취소·실행 취소 | 번호 설정 변경 후 취소 / 적용 후 실행 취소·다시 실행 | 취소하면 원래 설정 유지. 실행 취소·다시 실행으로 표시·위치·시작 번호 복원 |
| ☐ | 번호 저장·재열기 | 번호 넣기 → 쪽 나누기 → ‘이 문서에 저장’ → 닫고 다시 열기 | HWP·HWPX 모두 번호 설정과 연속 번호 유지. 하단 쪽 이동은 실제 쪽 순서 기준 |
| ☐ | 쪽 이동 | 하단 이전/다음 화살표 또는 `1 / 3` 같은 쪽 표시 누르기 | 앞뒤 쪽 또는 입력한 쪽으로 이동 |
| ☐ | 확대·축소 | 두 손가락 확대·축소 또는 하단 % → 화면 폭에 맞추기 | 확대·축소되고 화면 폭에 맞게 복귀 |

일반 **쪽 설정**은 단일 단 구역에 적용하고, 단 구성은 별도 **다단** 창에서 바꾼다. 다단 변경은 표·캔버스 개체가 없는 일반 본문 구역에서 동일 너비 1~4단을 지원한다. 기존의 서로 다른 너비 단은 읽어 표시하지만 본문 재조판은 제한되며, 다단에서 새 표·그림·도형·수식을 넣거나 명시적인 단 나누기를 만드는 기능은 아직 없다. 표·그림 크기는 자동으로 줄이지 않는다. 머리말·꼬리말의 **여백**과 **내용**을 각각 변경할 수 있다. **쪽 나누기** 삽입·삭제를 추가했다. **쪽 번호**는 숫자 형식, 위/아래·왼쪽/가운데/오른쪽, 줄표, 시작 번호와 구역별 적용을 지원한다. 구역 중간의 개별 번호 재시작·여러 번호 제어가 섞인 문서는 번호 편집을 제한한다. 로마 숫자·한글 번호·맞쪽 안/바깥 정렬은 아직 없다. 글이 길어서 자동으로 넘어간 쪽에는 지울 명시적 나눔이 없으므로 ‘쪽 나누기 없애기’가 비활성화된다.

## 머리말·꼬리말

원본 화면의 **상단 쪽 → 머리말 / 꼬리말**을 누른다. 본문에 커서를 놓지 않아도 된다. 내용을 입력하고 정렬·글자 크기·표시할 쪽을 고른 뒤 **적용**한다. 여러 구역이 있으면 기본값은 **현재 구역**이며, **전체 문서**로 바꿀 수 있다. 파일에 반영하려면 이어서 **이 문서에 저장**을 누른다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 새 머리말 | 빈 문서 → 쪽 → 머리말 → 제목 입력 → 적용 | 페이지 위 여백에 제목이 나오며, 본문 입력을 계속할 수 있음 |
| ☐ | 새 꼬리말 | 쪽 → 꼬리말 → 이름·설명 입력 → 적용 | 페이지 아래 여백에 표시되고 머리말·본문은 유지됨 |
| ☐ | 정렬·크기 | 머리말 → 가운데 또는 오른쪽 / 글자 크기 변경 → 적용 | 선택한 정렬·크기 반영. 기존 유지 선택 시 원래 서식 보존 |
| ☐ | 입력 취소 | 본문 입력 중 머리말 열기 → 내용 변경 → 취소 | 문서는 바뀌지 않고 본문 입력 위치로 돌아옴 |
| ☐ | 여러 쪽 반복 | 본문을 여러 쪽으로 늘리고 ‘모든 쪽’ 적용 | 각 쪽에 같은 내용이 반복되고 본문과 겹치지 않음 |
| ☐ | 홀수·짝수와 구역 | 표시할 쪽 변경, 다구역 문서에서 현재 구역/전체 문서 선택 | 선택한 쪽과 구역에 표시. 시작 쪽 번호를 바꿔도 홀짝 기준이 맞음 |
| ☐ | 여러 줄·공간 제한 | 내용 안에서 줄바꿈, 이어서 여백보다 많은 줄 입력 → 적용 | 들어가는 내용은 줄바꿈 표시. 넘치면 안내가 나오고 문서 원본은 유지됨 |
| ☐ | 내용 지우기 | 머리말 → 내용 지우기 → 적용 | 머리말만 사라지고 꼬리말·쪽 번호·본문은 유지됨 |
| ☐ | 실행 취소·다시 실행 | 내용 적용 → 저장 전에 실행 취소 → 다시 실행 | 기존 머리말·꼬리말과 입력 전 상태를 복원할 수 있음 |
| ☐ | 저장·재열기 | HWP·HWPX 각각 내용·정렬 수정 → 저장 → 닫고 다시 열기 | 내용·정렬·표시할 쪽과 본문·표가 함께 보존됨 |

현재는 구역 처음에 있는 **한 종류당 하나의 일반 텍스트 영역**을 편집한다. 기존 여러 문단은 문단별 입력창에서 수정한다. 새 영역은 바탕 10pt, 최대 2,000자이며 실제 여백에 들어가는 내용만 적용한다. 표·그림·필드·목록이 들어간 영역, 한 구역 안에 같은 종류의 영역이 여러 개 있는 경우, 구역 중간부터 시작하는 영역은 편집을 제한한다. 전체 문서 적용 시 기존 영역의 문단 개수가 서로 다르면 현재 구역별로 수정한다.

## 그림

일반 본문에 커서를 놓고 상단 **그림**을 누르면 사진 보관함이나 파일에서 이미지를 고를 수 있다. 삽입된 그림 또는 기존 HWP/HWPX의 그림을 한 번 누르면 이동·크기·회전 손잡이가 나타난다. 같은 그림을 다시 누르면 자르기 미리보기, 너비·높이, 회전·뒤집기, 원본/회색조/흑백 효과, 투명도, 밝기·대비, 테두리, 글 배치, 원본 비율 맞춤과 삭제 메뉴가 열린다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 사진 보관함에서 삽입 | 본문 중간에 커서 → 그림 → 사진 보관함 → 사진 선택 | 커서 앞뒤 글은 위아래 문단에 남고, 그 사이에 비율을 유지한 그림이 생김 |
| ☐ | 파일에서 삽입 | 그림 → 파일 선택 → PNG 또는 JPEG 선택 | 투명 PNG와 일반 사진이 표시되고 문서 폭보다 크게 삽입되지 않음 |
| ☐ | 크기 변경 | 그림 누르기 → 너비 변경, 비율 유지 켜기 → 적용 | 높이가 비율에 맞춰 바뀌고 뒤 본문이 겹치지 않게 이동 |
| ☐ | 직접 너비·높이 변경 | 그림 누르기 → 비율 유지 끄기 → 너비·높이 입력 → 적용 | 입력한 크기로 표시. 20pt 미만·2,000pt 초과 값은 적용할 수 없음 |
| ☐ | 네 방향 자르기 | 그림 누르기 → 왼쪽·오른쪽·위·아래 슬라이더 이동 | 미리보기가 즉시 갱신되고 적용하면 선택한 영역만 그림 틀에 표시됨 |
| ☐ | 자르기 비율 유지 | 비율 유지 켜기 → 자르기 슬라이더 이동 → 적용 | 남은 그림 영역의 비율에 맞춰 높이가 바뀌고 그림이 찌그러지지 않음 |
| ☐ | 원본 비율 복원 | 일부를 자른 그림 → 그림 누르기 → 원본 비율로 맞춤 | 자르기가 모두 해제되고 현재 너비를 기준으로 원본 가로세로 비율 복원 |
| ☐ | 회전 | 그림 누르기 → 왼쪽/오른쪽 90° 또는 회전 슬라이더 → 적용 | 미리보기와 문서의 그림이 지정한 각도로 회전하고 저장 후에도 유지됨 |
| ☐ | 좌우·상하 뒤집기 | 그림 누르기 → 좌우 뒤집기와 상하 뒤집기 각각 켜기 → 적용 | 선택 방향으로 그림만 반전되고 자르기 영역과 크기는 유지됨 |
| ☐ | 글 배치 | 글자처럼 취급 끄기 → 글 둘레/위아래/글 뒤/글 앞을 차례로 적용 | 고른 방식으로 본문과 그림의 겹침·위아래 배치가 바뀜 |
| ☐ | 기준 정렬·여백 | 글자처럼 취급 끄기 → 종이/쪽/단/문단 기준, 정렬, 네 방향 여백 변경 | 기준과 정렬 위치가 바뀌고 입력한 여백만큼 본문과 간격이 생김 |
| ☐ | 앞뒤 순서 | 겹친 그림·도형 준비 → 뒤로 보내기/앞으로 가져오기 → 적용 | 같은 배치 영역에서 그림의 겹쳐 보이는 순서가 한 단계 바뀜 |
| ☐ | 그림 선택·상세 편집 | 그림 한 번 누르기 → 선택 테두리와 손잡이 확인 → 같은 그림 다시 누르기 | 첫 번째에는 직접 조작 손잡이가, 두 번째에는 그림 편집창이 열림 |
| ☐ | 캔버스 직접 이동 | 그림 선택 → 그림 내부를 끌기 → 하드웨어 방향키와 Shift+방향키 사용 | 끈 위치로 이동하고 방향키는 1pt, Shift+방향키는 10pt씩 이동 |
| ☐ | 모서리 크기 조절 | 그림 선택 → 네 모서리 손잡이를 각각 안쪽·바깥쪽으로 끌기 | 끄는 동안 크기가 바로 보이고 손을 떼면 20~2,000pt 범위로 저장 |
| ☐ | 회전 손잡이·복원 | 그림 위 회전 손잡이 끌기 → 실행 취소·다시 실행 → 저장·재열기 | 회전 미리보기가 즉시 보이고 한 번에 취소·복원되며 HWP/HWPX에 유지 |
| ☐ | 90° 회전 그림 축 크기 | 그림을 90° 회전 → 오른쪽 아래 손잡이를 화면 아래로 끌기 | 화면 높이 대신 그림 자체 너비가 늘고 끄는 동안 손잡이가 손가락을 따라감 |
| ☐ | 임의 각도 그림 반대 모서리 | 그림을 30~60° 회전 → 네 모서리 손잡이를 각각 안팎으로 끌기 | 잡은 모서리만 그림 축을 따라 움직이고 대각선 반대 모서리는 화면에서 같은 위치를 유지함 |
| ☐ | 회전·뒤집기 그림 저장 | 좌우 또는 상하 뒤집은 그림을 회전 → 손잡이로 크기 변경 → 실행 취소·다시 실행 → 저장·재열기 | 미리보기와 놓은 뒤 결과가 같고 HWP/HWPX 모두 위치·크기·회전·뒤집기와 자르기가 유지됨 |
| ☐ | 밝기·대비 | 그림 누르기 → 밝기와 대비를 각각 음수·양수로 변경 | 미리보기가 즉시 밝아지거나 어두워지고 대비가 낮아지거나 높아짐 |
| ☐ | 보정 초기화 | 밝기·대비 변경 → 보정 초기화 | 두 값이 0으로 돌아오고 원래 색감의 미리보기가 표시됨 |
| ☐ | 테두리 모양 | 테두리 사용 켜기 → 색·굵기·실선/파선/점선/일점쇄선 변경 → 적용 | 고른 색·굵기·선 종류의 테두리가 그림 둘레에 표시됨 |
| ☐ | 테두리 해제·복원 | 테두리 적용 → 다시 열어 테두리 사용 끄기 → 실행 취소·다시 실행 | 테두리만 사라지고 실행 취소로 같은 설정이 복원됨 |
| ☐ | 회색조·흑백 | 그림 누르기 → 색상 효과에서 회색조와 흑백을 차례로 선택 | 미리보기가 즉시 바뀌고 적용 후 캔버스에도 같은 효과가 표시됨 |
| ☐ | 효과 초기화 | 회색조 또는 흑백 선택 → 효과 초기화 | 원본 색상으로 돌아오며 밝기·대비와 테두리는 그대로 유지됨 |
| ☐ | HWPX 투명도 | HWPX 그림 누르기 → 투명도 슬라이더를 40%로 변경 → 적용 | 그림 내용만 반투명해지고 테두리는 선명하게 유지되며 저장·재열기 후 40%가 유지됨 |
| ☐ | HWP 형식 제한 | HWP 그림 편집창 열기 → 투명도 확인 | 투명도 슬라이더가 비활성화되고 회색조·흑백은 적용·저장할 수 있음 |
| ☐ | 삭제·실행 취소 | 그림 누르기 → 그림 삭제 → 실행 취소 → 다시 실행 | 그림만 삭제되고 앞뒤 글은 유지. 실행 취소로 같은 그림과 크기가 복원됨 |
| ☐ | HWP/HWPX 저장·재열기 | 두 형식에서 삽입·크기·자르기·회전·뒤집기·글 배치 변경 → 실행 취소·다시 실행 → 저장·재열기 | 원래 형식을 유지하며 그림 데이터와 모든 그림 설정·앞뒤 본문이 보존됨 |

그림은 일반 1단 본문과 지원되는 글상자 내부 그림을 대상으로 한다. 원본/회색조/흑백 효과, 밝기·대비와 테두리 색·굵기·선 종류, 회전·뒤집기, 글자처럼 취급, 글 둘레·위아래·글 앞·글 뒤, 기준 위치·정렬, 바깥 여백과 배치 순서를 편집한다. 그림 전체 투명도는 HWPX의 `alpha` 값으로 저장한다. HWP의 같은 위치에 있는 값은 테두리 투명도라서 그림 전체 투명도로 사용하지 않는다. ‘글 둘레’는 저장과 기본 배치를 지원하지만 한컴과 같은 복잡한 옆 흐름 재조판은 제한적이다. 아주 큰 이미지는 문서 안정성을 위해 최대 4,096픽셀로 줄여 넣는다.

## 하이퍼링크

문단 안의 글자를 선택하면 상단 **링크**가 활성화된다. 기존 링크 안에 커서를 놓으면 링크 전체가 선택 대상으로 잡혀 주소를 수정하거나 해제할 수 있다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 링크 삽입 | 본문 글자 선택 → 링크 → `example.com` 입력 → 적용 | `https://`가 자동으로 붙고 선택 글자가 파란색 밑줄 링크로 표시됨 |
| ☐ | 현재 링크 열기 | 링크 안에 커서 → 링크 → 현재 링크 열기 | 등록한 웹 주소가 시스템 브라우저에서 열림 |
| ☐ | 주소 수정 | 링크 안에 커서 → 링크 → 다른 주소 입력 → 적용 | 표시 글자는 유지되고 이동 주소만 변경됨 |
| ☐ | 링크 해제·실행 취소 | 링크 안에 커서 → 링크 → 링크 해제 → 실행 취소·다시 실행 | 링크 필드가 제거되고 실행 취소로 같은 주소가 복원됨 |
| ☐ | HWP/HWPX 저장·재열기 | 두 형식에서 링크 삽입 또는 수정 → 저장 → 닫고 재열기 | 원래 파일 형식을 유지하고 링크 범위·주소·표시 글자가 보존됨 |

`http`, `https`, `mailto`, `tel` 주소를 지원한다. 선택 범위는 한 문단 안이어야 하며 표·도형·머리말처럼 복잡한 문단은 기존 편집 제한을 따른다.

## 각주·미주

상단 **주석**을 누르면 현재 구역의 각주·미주 목록이 열린다. 일반 본문에 커서를 놓으면 현재 위치에 새 각주나 미주를 넣을 수 있다. 기존 항목은 목록에서 눌러 수정하거나 삭제한다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 각주 삽입 | 본문 문장 중간에 커서 → 주석 → 각주 추가 → 내용 입력 → 적용 | 커서 위치에 각주 번호가 생기고 같은 쪽 아래쪽에 내용이 표시됨. 본문 글자는 그대로 유지 |
| ☐ | 미주 삽입 | 본문에 커서 → 주석 → 미주 추가 → 내용 입력 → 적용 | 미주 번호와 내용이 생기며 기존 각주와 번호 체계가 분리됨 |
| ☐ | 내용 수정 | 주석 → 현재 구역의 각주 또는 미주 선택 → 내용 변경 → 적용 | 번호와 본문 위치는 유지되고 주석 내용만 변경됨 |
| ☐ | 삭제·번호 정리 | 각주·미주를 각각 두 개 이상 만든 뒤 중간 항목 삭제 | 선택 항목만 사라지고 뒤 항목 번호가 문서 순서대로 다시 매겨짐 |
| ☐ | 실행 취소·다시 실행 | 삽입·수정·삭제 후 상단 실행 취소 → 다시 실행 | 주석과 본문 표식이 함께 사라지거나 복원되고 본문 내용은 유지됨 |
| ☐ | HWP/HWPX 저장·재열기 | 두 형식에서 각주·미주 삽입·수정·삭제 → 이 문서에 저장 → 닫고 재열기 | 원래 형식, 주석 종류·순서·내용과 본문 표식이 보존됨 |

새 주석은 일반 1단 본문의 단순 문단에서 최대 2,000자까지 넣는다. 기존 여러 문단 주석이나 표·그림·필드가 들어간 복합 주석은 목록에서 확인할 수 있지만, 구조를 안전하게 보존할 수 없는 경우 수정이 제한된다.

## 도형

일반 본문에 커서를 놓고 상단 **도형**을 누르면 사각형·타원·선·자유 다각형·연결선을 넣을 수 있다. 원본 화면에서 도형을 누르면 위치·크기·배치 순서와 삭제 메뉴가 열린다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 사각형 삽입 | 본문 문장 중간에 커서 → 도형 → 사각형 | 커서 앞뒤 글은 위아래 문단에 남고 그 사이에 파란색 사각형이 생김 |
| ☐ | 타원·선 삽입 | 각각 도형 → 타원, 도형 → 선 | 선택한 모양과 기본 크기로 표시되고 뒤 본문이 겹치지 않음 |
| ☐ | 화살표로 이동 | 도형 누르기 → 위치의 왼쪽·위·아래·오른쪽 버튼 여러 번 → 적용 | 한 번에 5pt씩 이동하고 X·Y 값도 함께 바뀜 |
| ☐ | 위치·크기 직접 입력 | 도형 누르기 → X·Y·너비·높이 입력 → 적용 | 입력한 위치와 크기로 바뀜. 너비 20pt·높이 8pt 미만 값은 적용할 수 없음 |
| ☐ | 앞뒤 순서 | 겹치는 도형 두 개 준비 → 뒤로 보내기 또는 앞으로 가져오기 → 적용 | 숫자와 겹쳐 보이는 순서가 한 단계씩 바뀜 |
| ☐ | 회전 | 도형 누르기 → 회전 슬라이더를 30°로 이동 → 적용 | 도형 전체가 30° 회전하고 다시 열어도 각도가 유지됨 |
| ☐ | 선 모양 | 도형 누르기 → 선 색·굵기 변경 → 파선 또는 점선 → 적용 | 선택한 색·굵기·선 종류로 바로 표시됨 |
| ☐ | 채우기 | 사각형·타원 누르기 → 채우기 색 변경 → 채우기 사용 끄기 | 색이 바뀌고 끄면 내부가 투명하게 표시됨 |
| ☐ | 그림자 | 도형 누르기 → 그림자 사용 → 색·가로/세로 이동·농도 변경 | 설정한 방향과 농도의 그림자가 표시됨 |
| ☐ | 글자처럼 취급 | 도형 누르기 → 글 배치 → 글자처럼 취급 켜기 → 적용 | 도형이 글자 위치를 따라가고 위아래 본문이 겹치지 않음 |
| ☐ | 위아래 배치 | 글자처럼 취급 끄기 → 본문과의 배치 ‘위아래’ | 도형 좌우로 본문이 흐르지 않고 위아래에 배치됨 |
| ☐ | 글 앞·글 뒤 | 본문과의 배치를 ‘글 앞’과 ‘글 뒤’로 각각 변경 | 도형이 본문 위 또는 아래 계층에 표시되고 문단 높이를 불필요하게 늘리지 않음 |
| ☐ | 사각형 둘레 배치 | 본문과의 배치 ‘글 둘레’ → 적용 | 사각형 둘레 속성이 저장되고 기존 문서의 줄 배치가 유지됨 |

| ☐ | 연결점·화살표 편집 | 연결선 누르기 → 연결점을 끌고 시작·끝 화살표를 서로 다르게 선택 → 적용 | 꺾이는 위치와 양 끝 모양이 선택대로 바뀜 |

| ☐ | 경로 HWP/HWPX 저장·재열기 | 두 형식에서 다각형·연결선의 점과 화살표 변경 → 저장 → 닫고 재열기 | 꼭짓점 수·좌표·화살표가 그대로 유지됨 |

새 도형은 일반 1단 본문의 글자처럼 배치한다. 사각형·타원·선·자유 다각형·연결선 삽입, 위치·크기·회전·좌우·상하 뒤집기, 배치 순서, 선·채우기·그림자, 꼭짓점·연결점, 연결선 시작·끝 화살표, 글자처럼 취급, 글 둘레·위아래·글 앞·글 뒤, 기준 위치·일반 및 맞쪽 안쪽·바깥쪽 정렬과 바깥 여백을 지원한다. 선택한 독립 도형과 그룹 외곽은 캔버스에서 이동·크기·회전을 직접 바꾸고 하드웨어 방향키로 미세 이동할 수 있다. HWP/HWPX 그룹 도형은 그룹 전체 편집, 내부 도형별 모양 편집·삭제·앞뒤 순서와 그룹 해제, 같은 문단의 독립 도형 다중 선택, 새 그룹 만들기, 여섯 방향 맞춤, 가로·세로 동일 간격, 크기 맞춤과 일괄 복제·삭제·뒤집기를 지원한다. ‘글 둘레’ 속성은 저장하지만 새 위치에 맞춰 주변 문장을 한컴과 같은 옆 흐름으로 다시 조판하는 기능은 제한적이다.

## 수식·글상자

일반 본문에 커서를 놓고 상단 **수식**을 누르면 한글 수식 문법으로 수식을 넣을 수 있다. 원본 화면에서 기존 수식을 누르면 원문과 글자 크기를 바꾸거나 삭제한다. 글자가 들어 있는 도형을 누르면 글상자의 기존 문단을 편집한다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | HWPX 수식 삽입 | HWPX 본문 중간에 커서 → 수식 → `{a} over {b}` → 삽입 | 커서 앞뒤 본문 사이에 분수 수식이 생기고 뒤 본문이 겹치지 않음 |
| ☐ | HWP 수식 삽입 | HWP 본문 중간에 커서 → 수식 → `x^{2}+y^{2}` → 삽입 | 원본 HWP 화면에 위 첨자를 포함한 수식이 표시됨 |
| ☐ | 수식 예제·크기 | 수식 → 분수·제곱·근호·행렬 버튼을 각각 누르고 글자 크기 변경 | 예제 문법이 입력되고 선택한 크기로 수식이 표시됨 |
| ☐ | 기존 수식 수정 | 원본 화면의 수식 누르기 → 수식 원문과 글자 크기 변경 → 적용 | 같은 위치의 수식 내용과 크기만 변경됨 |
| ☐ | 수식 삭제·실행 취소 | 수식 누르기 → 수식 삭제 → 실행 취소 → 다시 실행 | 수식만 사라지고 앞뒤 본문은 유지되며 실행 취소로 복원됨 |
| ☐ | 수식 저장·재열기 | HWP/HWPX에서 수식 삽입 또는 수정 → 이 문서에 저장 → 닫고 재열기 | 원래 형식과 수식 원문·크기·앞뒤 본문이 보존됨 |
| ☐ | 글상자 한 문단 편집 | 글자가 있는 도형 누르기 → 내용 변경 → 적용 | 도형 위치·크기와 글자 서식은 유지되고 글상자 내용만 변경됨 |
| ☐ | 글상자 여러 문단 편집 | 두 문단 이상인 글상자 누르기 → 각 문단 변경 → 적용 | 문단 수·순서·문단 서식을 유지하며 각 내용이 바뀜 |
| ☐ | 글상자 문단 추가 | 글상자 누르기 → 문단 추가 → 내용 입력 → 적용 | 마지막에 새 문단이 생기고 기존 문단과 내부 개체가 유지됨 |
| ☐ | 글상자 문단 삭제 | 개체가 없는 문단의 삭제 → 적용 | 선택한 문단만 사라지고 최소 한 문단은 남음 |
| ☐ | 글상자 문단 순서 | 위·아래 화살표로 문단 이동 → 적용 | 문단과 해당 문단의 서식·내부 개체가 함께 이동함 |
| ☐ | 내부 수식 편집 | 글상자 안 수식 누르기 → 원문 또는 크기 변경 → 적용 | 바깥 글상자와 다른 문단을 유지하며 수식만 변경됨 |
| ☐ | 내부 도형·그림 편집 | 글상자 안 도형 또는 그림 누르기 → 크기·모양 변경 → 적용 | 내부 개체만 바뀌고 글상자 위치와 문단은 유지됨 |
| ☐ | 내부 표 보존 | 표가 든 글상자의 다른 문단 순서 변경 → 저장·재열기 | 내부 표의 행·열·셀 내용이 그대로 남음 |
| ☐ | 복합 글상자 HWP/HWPX 재열기 | HWP와 HWPX에서 문단 추가·이동과 내부 개체 수정 → 저장·재열기 | 두 형식 모두 문단 순서와 내부 개체 변경을 복원함 |
| ☐ | 글상자 저장·재열기 | HWP/HWPX 글상자 내용 변경 → 실행 취소·다시 실행 → 저장·재열기 | 실행 취소가 한 번에 적용되고 원본 형식과 바뀐 내용이 보존됨 |
| ☐ | HWPX 글상자 삽입 | HWPX 본문 중간에 커서 → 글상자 → 내용·크기 입력 → 삽입 | 앞뒤 본문 사이에 입력한 내용의 글상자가 생김 |
| ☐ | HWP 글상자 삽입 | HWP 본문 중간에 커서 → 글상자 → 내용·크기 입력 → 삽입 | 원본 HWP에 글상자와 내부 문단이 생김 |
| ☐ | 새 글상자 편집·저장 | 새 글상자 누르기 → 내용 변경 → 저장·닫기·재열기 | 크기와 변경한 내용이 원본 형식으로 유지됨 |

수식은 원문·글자 크기와 삭제를 편집한다. 글상자는 새로 삽입하고 기존 문단의 추가·삭제·순서 변경을 지원한다. 내부 그림·도형·수식은 원본 화면에서 직접 눌러 편집한다. 내부 개체나 표를 가진 문단은 개체 보호를 위해 글자 변경과 삭제가 잠기며 문단 순서만 바꿀 수 있다. 글상자 안 표는 원본 화면에서 격자로 표시하고 셀 글자와 글자·문단 서식을 직접 편집한다. 내부 표의 행·열 추가·삭제·병합과 새 내부 개체 삽입은 아직 지원하지 않는다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 글상자 내부 표 표시·선택 | 표가 든 글상자 문서 열기 → 원본 화면의 내부 셀 누르기 | 표 테두리·셀 여백이 글상자 안에 표시되고 글상자 편집창 대신 셀 커서가 열림 |
| ☐ | 내부 셀 입력·서식 | 셀 글자 입력·선택 → 굵게·색·정렬 등 적용 | 선택 셀의 글자와 문단 서식만 바뀌고 글상자 외곽·다른 셀·내부 개체는 유지됨 |
| ☐ | 내부 셀 저장·복원 | HWP/HWPX 내부 셀 수정 → 실행 취소·다시 실행 → 저장·재열기 | 한 단계로 복원되고 원래 형식, 표 구조·셀 내용·글상자 배치가 유지됨 |

## PDF 저장·인쇄

문서 상단 **… → PDF로 저장**을 누르면 현재 편집 내용으로 출력 미리보기를 만든다. 미리보기 오른쪽 위 **PDF로 저장**에서 파일 이름과 위치를 고른다. **… → 인쇄**는 미리보기를 만든 뒤 시스템 인쇄 창을 바로 연다. 미리보기의 프린터 버튼으로도 열 수 있다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | PDF 미리보기 | HWP·HWPX 각각 상단 … → PDF로 저장 | 현재 원본 보기의 본문·표·그림 배치로 미리보기가 열림 |
| ☐ | 입력 직후 출력 | 본문에 글자를 입력하고 원본 저장 전에 PDF로 저장 | 방금 입력한 내용까지 PDF에 들어감 |
| ☐ | 파일 저장·재열기 | 미리보기 → PDF로 저장 → 파일 이름/위치 → 저장, 파일 앱에서 열기 | 별도 PDF가 생성되고 동일한 쪽 수·내용으로 열림 |
| ☐ | 용지·머리말·번호 | 가로/세로 용지와 머리말·꼬리말·쪽 번호가 있는 문서를 출력 | 각 쪽의 용지 크기와 반복 영역, 번호를 유지 |
| ☐ | 여러 쪽 이동 | 여러 쪽 문서의 미리보기를 아래로 넘기고 확대 | 쪽 표시가 바뀌며 마지막 쪽까지 볼 수 있음 |
| ☐ | 저장 창 취소 | PDF 저장 위치 선택 화면에서 닫기 | 미리보기로 돌아오며 본문·PDF가 유지됨 |
| ☐ | 인쇄 창 | … → 인쇄 또는 미리보기 프린터 버튼 | 프린터·매수·용지 등 시스템 인쇄 설정이 표시됨. 여러 쪽은 범위 선택 확인 |
| ☐ | 실제 인쇄 | 연결된 AirPrint 프린터를 선택하고 인쇄 | 프린터에서 페이지 순서·표·여백 확인. 이 항목은 실제 프린터로 직접 확인 필요 |
| ☐ | 인쇄 취소·편집 복귀 | 인쇄 창 닫기 → 미리보기 닫기 → 본문 입력 | 문서로 돌아와 편집을 계속할 수 있음 |
| ☐ | 원본 저장 상태·실행 취소 | 본문 수정 → PDF만 저장 → 미리보기 닫기 → 실행 취소 | PDF 저장이 원본 저장으로 처리되지 않음. 원본 변경과 실행 취소 기록이 유지됨 |

현재 PDF는 화면 모양을 보존한 **이미지 방식**으로, PDF 안의 글자 선택·검색은 지원하지 않는다. 원본 보기에서 지원하는 배치를 출력하므로 한컴 한글과의 완전한 배치 일치를 보장하는 별도 변환 엔진은 아니다. 원본 HWP/HWPX의 수정 내용은 따로 **이 문서에 저장**해야 한다. 출력은 최대 500쪽·200MiB이며, 생성 중 취소할 수 있다. 인쇄 용지와 방향은 연결한 프린터의 설정도 확인한다.

## 실행 취소·저장·추가 메뉴

현재 저장하면 실행 취소·다시 실행 기록이 초기화된다. 복원 검사는 저장 전에 진행한다.

| 완료 | 테스트 | 실행 방법 | 확인할 결과 |
|---|---|---|---|
| ☐ | 실행 취소·다시 실행 | 글자·서식·표·쪽 설정을 하나씩 변경한 뒤 상단 되돌림/다시 실행 화살표 | 내용과 관련 배치가 이전 상태로 돌아갔다가 다시 적용됨 |
| ☐ | 원본에 저장 | 상단 `…` → 이 문서에 저장 | 현재 파일에 저장됨. HWP는 HWP, HWPX는 HWPX로 유지 |
| ☐ | 다시 열기 | 저장 후 문서 목록으로 나갔다가 같은 파일 재열기 | 입력 글자·서식·표 크기·용지 설정 유지 |
| ☐ | 복사본 내보내기 | `…` → 복사본 내보내기 → 별도 파일명/위치 선택 | 별도 파일 생성. 해당 복사본도 다시 열어 확인 |
| ☐ | 보기 전환 | 하단 원본 / 간편 전환 | 원본은 페이지 배치, 간편은 읽기 쉬운 문단·표 목록으로 표시 |
| ☐ | 추가 글꼴 | `…` → 글꼴 → TTF/OTF 글꼴 가져오기 | 글꼴 등록. 글자에 적용하는 기능은 상단 글꼴 이름 버튼에서 사용 |

저장은 자동 저장으로 가정하지 말고 **‘이 문서에 저장’**을 눌러 확인한다. 편집을 적용하는 것과 파일에 저장하는 것은 별도다. 저장 경로가 필요한 문서는 저장 위치를 고르는 화면이 열린다.

기존 추가 기능으로 `… → AI 도우미 표시`가 있으며, 사용 가능한 연결·설정에서 한글 문서 질문과 텍스트 수정 요청을 할 수 있다. 오래된 한글 형식에서 변환이 필요한 경우에만 `… → HWPX로 변환`이 나타난다. 이 두 항목은 위 수동 편집 기능의 이번 테스트와 별도로 확인한다.

## 짧게 한 번 확인하는 순서

1. 새 한글 문서에서 한글·영문·이모지 입력 → Enter → Backspace.
2. 단어 하나 선택 → 굵게·색·강조색 → 문단 가운데 정렬.
3. 본문 번호 목록 → 다음 항목 추가 → 빈 항목에서 종료.
4. 표 있는 문서에서 셀 입력 → Enter로 문단 나누기 → 문단 맨 앞 Backspace로 합치기 → Shift+Enter 줄바꿈 → 셀 색 → 행 추가 → 병합 → 크기 변경. 중첩 표도 안쪽 셀에서 셀 색·테두리·세로 정렬·번호 목록과 행·열 추가, 병합·분할, 크기 변경 후 저장·재열기. 그림·도형이 든 셀은 개체를 눌러 이동·크기·회전하고 저장·재열기.
5. 찾기·모두 바꾸기 → 실행 취소 → 다시 실행.
6. 쪽 → 쪽 나누기 삽입·삭제, 쪽 → 쪽 설정 → A5 가로·여백 변경 → 실행 취소 → 다시 실행.
7. 본문 중간에서 **그림** 삽입 → 그림 누르기 → 네 방향 자르기·크기 변경 → 캔버스에서 이동·크기·회전 → 다시 눌러 회전·뒤집기 → 밝기·대비와 테두리 변경 → 글 앞/글 뒤와 기준 정렬·여백·순서 변경 → 원본 비율로 맞춤 → 실행 취소·다시 실행.
8. 본문 중간에서 **주석** → 각주·미주 삽입 → 내용 수정 → 하나 삭제 → 실행 취소·다시 실행.
9. 본문 중간에서 **도형** → 사각형·자유 다각형·연결선 삽입 → 도형을 한 번 눌러 캔버스에서 직접 이동하고 네 모서리 손잡이로 크기 변경 → 위쪽 회전 손잡이로 회전 → 하드웨어 방향키와 Shift+방향키로 미세 이동 → 같은 도형을 다시 눌러 뒤집기·선·채우기·그림자·꼭짓점·연결점·화살표·글 배치·기준 위치·앞뒤 순서 변경 → 실행 취소·다시 실행. 그룹 도형 파일도 열어 그룹 전체 크기·회전, 내부 도형 개별 선택·스타일·순서·삭제와 그룹 해제를 확인. 같은 문단의 독립 도형은 상단 **선택**으로 골라 새 그룹을 만들고, **맞춤**으로 방향·맞쪽 정렬과 3개 이상 동일 간격, **크기**로 크기 맞춤, **뒤집기**로 좌우·상하 반전, **작업**으로 복제·삭제를 적용한 뒤 저장·재열기.
10. 본문 중간에서 **수식** → 분수 삽입 → 원문·크기 변경. **글상자** → 새 글상자 삽입 → 글상자 눌러 내용 변경. 표가 든 글상자는 내부 셀을 직접 눌러 입력·서식 변경 → 실행 취소·다시 실행 → 저장·재열기.
11. 쪽 → 머리말·꼬리말·쪽 번호를 넣고 **… → PDF로 저장**으로 출력 모양 확인, **인쇄** 창 열었다 닫기.
12. 각 파일에서 **이 문서에 저장 → 닫기 → 다시 열기**로 유지 여부 확인.

버튼이 비활성화되면 먼저 문단·셀 안에 커서가 있는지 확인한다. 개체가 들어 있는 표의 일부 구조 변경, 3단 이상 중첩된 표, 다단 영역, 보호된 문서 등은 기능별 편집 제한이 있다. 여러 문단·여러 셀의 일괄 선택 서식, 다단계 목록과 사용자 지정 번호 형식도 아직 테스트 대상이 아니다.

문제를 알려줄 때는 **파일 형식/파일명 → 누른 버튼 순서 → 기대한 결과 → 실제 결과 → 저장 후 재열어도 같은지**를 적으면 재현하기 쉽다.
