# 한글 각주·미주 편집 · 2026-09-16

원본 보기 상단에 **주석** 버튼을 추가했다. 일반 본문에 커서를 놓아 각주나 미주를 삽입하고, 현재 구역의 기존 항목을 목록에서 수정하거나 삭제할 수 있다.

## 적용 범위

- 각주·미주 삽입: 커서 위치에 본문 표식과 주석 본문을 함께 만든다.
- 목록과 수정: 현재 구역의 각주·미주를 문서 순서와 종류별 번호로 표시한다.
- 삭제와 번호 정리: 본문 표식과 주석 본문을 함께 지우고 뒤 번호를 다시 매긴다.
- 실행 취소·다시 실행: 변경 전후 문서 원본을 한 단계로 보관한다.
- HWPX: `footNote`/`endNote`, `subList`, `autoNum` 구조를 원본 XML 안에 기록한다.
- HWP 5: 본문 제어 문자와 `CTRL_HEADER`, `LIST_HEADER`, 주석 문단, 자동 번호 레코드를 기록한다. 본문 레코드가 생략된 빈 문단도 지원한다.
- 저장 검증: 다시 파싱하여 본문 텍스트와 쪽 설정이 그대로인지, 요청한 주석 개수와 내용이 맞는지 확인한 뒤에만 적용한다.

## 제한

- 새 주석은 일반 1단 본문의 표·그림·도형이 없는 문단에서 넣는다.
- 주석 내용은 최대 2,000자다.
- 기존 주석이 여러 문단이거나 표·그림·필드 같은 복합 구조를 포함하면 읽기와 목록 표시는 유지하지만 직접 수정은 제한한다.
- 화면에서 **적용**한 뒤 원본 파일에 반영하려면 **이 문서에 저장**을 눌러야 한다.

## 자동 검사

- HWPX 삽입 → 수정 → 삭제와 본문 보존
- HWP 일반 문단 삽입 → 수정 → 삭제와 본문 보존
- HWP 본문 레코드가 없는 빈 문단 삽입
- 편집 가능한 본문 커서 판정과 2,000자 제한
