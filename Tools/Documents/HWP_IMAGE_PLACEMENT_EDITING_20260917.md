# 그림 회전·뒤집기·글 배치 · 2026-09-17

우선순위 24를 적용했다. HWP/HWPX 원본 화면에서 그림을 누르면 자르기와 크기뿐 아니라 회전, 좌우·상하 뒤집기, 본문과의 배치와 겹침 순서까지 한 편집창에서 바꿀 수 있다.

## 적용 기능

- 왼쪽·오른쪽 90도 회전과 0~359도 직접 회전
- 좌우 뒤집기와 상하 뒤집기
- 글자처럼 취급 켜기·끄기
- 글 둘레, 위아래, 글 뒤, 글 앞 배치
- 종이·쪽·단·문단 가로 기준과 왼쪽·가운데·오른쪽·맞쪽 안/바깥 정렬
- 종이·쪽·문단 세로 기준과 위·가운데·아래 정렬
- 네 방향 바깥 여백
- 한 단계 뒤로 보내기와 앞으로 가져오기

편집창의 미리보기는 자르기, 회전과 뒤집기를 함께 반영한다. **적용**하면 크기·자르기·회전·배치를 한 번에 저장하므로 실행 취소도 한 단계로 처리한다.

## 파일 저장

- HWPX의 `pos`, `outMargin`, `flip`, `rotationInfo`, `textWrap`, `zOrder`를 갱신한다.
- HWP 5의 공통 개체 속성, 바깥 여백, 배치 순서와 그림 구성요소의 회전·뒤집기 값을 갱신한다.
- HWP는 HWP, HWPX는 HWPX 형식을 유지한다.
- 그림 원본 데이터와 자르기 영역, 앞뒤 본문과 다른 개체를 보존한다.
- 글 앞·글 뒤 그림은 본문 높이를 불필요하게 늘리지 않고 겹침 순서로 표시한다.

## 자동 확인

- HWPX 그림 90도 회전, 좌우 뒤집기, 글 앞 배치와 기준 정렬·여백 저장
- HWP 그림 270도 회전, 상하 뒤집기, 글 둘레 배치와 기준 정렬·여백 저장
- 자르기·원본 비율 복원·크기 변경과 새 배치 속성의 연속 저장
- 화면 모델의 자르기·회전·뒤집기·글 뒤 배치 실행 취소·다시 실행·재열기
- 그림·표·입력·서식·도형·글상자·수식·HWPX 표시 관련 M4 검사 74개 통과
