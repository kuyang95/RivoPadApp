# VisionCraft → RivoPad 포팅 마스터 매트릭스

이 문서는 Android 원본
`/Users/me/Develop/AndroidProject/VisionCraft`의 매니페스트, 화면, 서비스,
프로토콜과 현재 iPad 앱 소스를 대조한 전체 작업표다. 세부 실기기 검증은
각 영역의 `BACKLOG.md`에 모으고, 구현은 아래 우선순위대로 자동 진행한다.

## 상태

- ✅ 구현됨: 자동 테스트 또는 빌드로 확인 가능한 코드가 있음

- ⏳ 예정: iPadOS에서 구현 가능하지만 아직 없음
- 🧪 실기기 확인: 구현은 있으나 실제 카메라·BLE·서버 확인이 남음
- 🚫 동일 구현 불가: 공개 iPadOS API로 Android와 같은 동작을 만들 수 없음

## 자동 진행 순서

한 영역을 완성할 때까지 다른 기능을 멈추지 않고, 사용자 확인이 필요한
항목은 각 백로그에 쌓은 뒤 다음 구현으로 이동한다.

1. VisionLink 데이터 채널·일반 파일·클립보드
2. VisionLink 원격 OCR·이미지 분석·번역 ✅
3. VisionLink 원격 AI 채팅·실시간 읽기
4. EPUB 독서 연속성·목차·검색
5. DAISY/SMIL 재생
6. 문서 뷰어 탐색·외형·저장
7. Rivo 화면별 조작·시간 동기화·상태 복원
8. Share/Action Extension·위젯·App Intent
9. 통합 설정·다국어·도움말
10. 스캐너의 보류된 다중 페이지·PDF·성능 작업

## 일괄 실기기 검증 원칙

- 카메라, BLE, 실제 VisionLink 송신기, 다양한 문서 형식은 구현을 막지
  않고 해당 영역의 `BACKLOG.md`에 기록한다.
- 자동 테스트, 시뮬레이터 빌드, M4 서명 빌드·설치는 각 코드 묶음마다
  수행한다.
- 실제 조작이 꼭 필요한 검증은 기능 묶음이 충분히 쌓였을 때 한 번에
  사용자에게 요청한다.
