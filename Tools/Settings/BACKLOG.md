# VisionCraft 통합 설정 백로그

Android 원본의 홈 설정과 `AppSettingsActivity`, 문서 스캐너·텍스트
뷰어·독서 설정을 iPad 앱의 한 화면에 모은다. 설정은 모두 로컬
`UserDefaults`에 저장하고 대화·책·문서 데이터와 분리한다.

## 구현 완료

- 홈의 큰 `설정` 버튼과 `rivopad://open/settings` 딥링크
- Siri·단축어의 `VisionCraft 설정 열기`
- 효과음 피드백 켜기/끄기와 모든 `SoundEffectManager` 재생에 즉시 적용
- 자동 음성 안내 켜기/끄기와 처리 상태 안내에 적용
- 느리게·보통·빠르게·매우 빠르게 기본 TTS 속도 선택과 예시 듣기
- 문서 스캔 색상 자동 보정 켜기/끄기, 다음 촬영과 fallback 경로에 적용
- 문서 자동 촬영 켜기/끄기. 끄면 LCNet 모서리·안정 안내와 화면/Rivo
  수동 촬영은 유지하고 자동 초점 잠금·촬영만 하지 않음
- UVDoc 휘어진 페이지 보정 켜기/끄기. 끄면 31MB 모델 준비·추론을
  생략하고 LCNet 모서리와 원근 보정 결과를 그대로 사용
- 다른 앱의 공유 텍스트·웹페이지·사진·지원 문서 전체를 음성 질문·
  AI 채팅 중 어디로 열지 선택하고, 기존 저장 키를 유지하면서 Android
  기본값과 같은 음성 질문을 기본으로 저장·복원
- Android 기본값과 같은 OCR 오타 자동 교정 켜기/끄기, 다음 실행 복원과
  초기화. Qwen3-VL 로컬 교정 실패·AI 사용 중에는 Vision OCR 원문 유지
- Android 카메라와 같은 마지막 16색 조합·반전·임계값 저장, Rivo
  DISPLAY 모드 진입 시 복원과 앱 설정 초기화 연동
- Android Remote Ribbon의 펼침·접힘과 16색 조합을 앱 내부 Rivo 빠른
  메뉴에 적용하고 저장·복원·초기화
- Android와 같은 시스템 설정·한국어·영어·일본어 앱 언어 선택,
  즉시 화면 갱신·저장·복원·초기화와 번역·웹 검색 기본 언어 연동
- iPad 시스템 글꼴·나눔스퀘어라운드와 Android 서버의 언어별 9개 글꼴
  전역 전환. 매니페스트 캐시, 선택 시 HTTPS 다운로드, 정확한 크기와
  SHA-256 검증, 앱 재실행 시 오프라인 복원, 라이선스 링크 제공
- 텍스트 문서의 10단계 글자 크기·줄 간격·16색 조합·줄 구분선 기본값
- EPUB/DAISY 테마·글자 배율·줄 간격·재생 속도와 안전한 원본 표현
  기본값
- Rivo와 VisionLink 설정 화면 진입
- 앱 권한 설정 열기
- 앱 설정 초기화. 대화·책·문서는 삭제하지 않음
- 저장·복원·잘못된 값 fallback·초기화 자동 테스트

## 실기기 일괄 확인

- [ ] 설정을 바꾸고 앱을 완전히 종료·재실행해 모든 값이 복원된다.
- [ ] 효과음을 끄면 녹음·AI 처리 효과음이 사라지고 다시 켜면 복원된다.
- [ ] 자동 음성 안내를 끄면 처리 상태 안내만 사라지며, 사용자가 누른
      문서·OCR·독서 읽기는 계속 동작한다.
- [ ] 네 가지 기본 말하기 속도의 차이가 들리고 새 발화에 즉시 적용된다.
- [ ] 같은 문서를 색상 보정 켬·끔으로 촬영했을 때 모서리·원근 보정은
      유지되고 마지막 색상 강화만 달라진다.
- [ ] 자동 촬영을 끄면 안정된 문서에서도 저절로 촬영하지 않고 화면
      촬영 버튼과 Rivo `7`은 한 번씩 촬영하며, 다시 켜면 3회 통과 뒤
      자동 촬영한다.
- [ ] UVDoc을 끄면 백엔드 표시에 곡면 보정 꺼짐이 보이고 책 페이지가
      원근 보정까지만 처리되며, 다시 켜면 다음 촬영부터 곡면 보정한다.
- [ ] 한국어·영어·일본어마다 시스템·번들 글꼴과 해당 언어용 서버
      글꼴만 보이며, 각 언어에서 서버 글꼴 하나 이상을 선택하면 다운로드
      진행 뒤 홈·AI·스캐너에 즉시 적용된다.
- [ ] 서버 글꼴 선택 뒤 앱을 완전히 종료·재실행하고 오프라인으로
      실행해도 검증된 캐시 글꼴과 선택이 복원된다.
- [ ] 글꼴 다운로드 실패나 파일 변조 상황에서는 이전 글꼴을 유지하고
      오류를 표시하며, 각 서버 글꼴의 라이선스 링크가 열린다.
- [ ] 시스템·나눔스퀘어라운드·서버 글꼴에서 큰 글자와 VoiceOver를
      사용해도 잘리거나 의미가 사라지는 항목이 없다.
- [ ] 설정 초기화 뒤 나눔스퀘어라운드로 돌아가되 내려받은 글꼴 캐시는
      유지된다.
- [ ] 초기화 뒤 대화 기록, 가져온 책, 문서 파일은 그대로 남는다.
- [ ] 단축어와 `rivopad://open/settings`가 설정 화면을 한 번만 연다.
- [ ] 공유 항목 기본 화면을 음성 질문으로 두면 텍스트·웹페이지·사진·
      지원 문서를 문맥 또는 원본 첨부로 준비한 뒤 바로 듣기를 시작하고,
      답변 완료 뒤 자동으로 읽는다.
- [ ] AI 채팅으로 바꾸면 같은 자료를 첨부한 새 대화에서 자동 녹음·
      자동 질문 없이 입력을 기다리고, 요약·정보 목록·다음 행동과
      후속 질문이 공유 자료를 쓴다.
- [ ] OCR 오타 자동 교정을 끄면 모델 준비 없이 Vision OCR 원문이 바로
      나오고, 다시 켜면 정지 이미지에서만 로컬 교정 진행 상태가 표시된다.
- [ ] OCR 교정 설정을 바꾸고 앱을 완전히 종료·재실행한 뒤 값이 복원되며
      설정 초기화 뒤 기본값인 켜짐으로 돌아간다.
- [ ] 카메라 DISPLAY 모드의 색상·반전·임계값이 앱 재실행 뒤 복원되고,
      앱 설정 초기화 뒤 원본 색상·기본 임계값으로 돌아간다.
- [ ] Rivo 빠른 메뉴를 펼침·접힘으로 바꾸면 각각 전체 세로 목록·
      이전/현재/다음의 가로 목록이 보이고, 16색 조합이 즉시 적용되며
      재실행 뒤 복원된다.
- [ ] 접힌 빠른 메뉴에서도 Rivo 2/4/6/8로 선택 항목이 가운데로
      이동하고 5로 실행되며, 큰 글자와 VoiceOver에서 세 항목의 관계를
      이해할 수 있다.
- [ ] 앱 언어 네 항목이 즉시 화면·로컬 번역 기본 대상·웹 검색 지역에
      적용되고, 재실행 뒤 복원되며 설정 초기화 뒤 시스템 설정으로 돌아간다.
- [ ] 독서의 `출판물 원본 표현`을 끄고 재실행하면 텍스트 표현이 유지되며
      설정 초기화 뒤 기본값인 켜짐으로 돌아간다.

## 제품 확장 — Android 포팅 완료 조건 아님

- 문서 스캐너 출력 크기·JPEG 품질 설정

## iPadOS 대체와 제약

- Android APK 자체 업데이트 버튼은 제공하지 않는다. App Store,
  TestFlight 또는 MDM 업데이트로 대체한다.
- Remote Ribbon을 다른 앱 위에 표시하는 것은 일반 iPad 앱에서 구현할
  수 없다. 펼침·접힘과 색상 설정은 앱 내부 Rivo 빠른 메뉴에 적용하고,
  다른 앱에서는 위젯과 시스템 빠른 실행을 사용한다.
- 시스템 밝기·색상 필터·VoiceOver·회전 잠금을 앱이 직접 바꾸지 않는다.
  iPad 설정과 접근성 단축키로 안내한다.
- 내려받은 글꼴은 크기와 SHA-256을 검증한 뒤 Application Support의
  파일 URL을 CoreText의 process scope로 등록한다. 앱이 실행되는 동안
  원본 파일을 이동하지 않고, 다음 실행에서 같은 검증과 등록을 반복한다.
