# EPUB·DAISY 독서 기능 백로그

## 현재 구현된 1차 범위

- 외부 ZIP 라이브러리 없이 EPUB의 저장/Deflate 압축 해제
- ZIP64, 암호화 파일, 경로 탈출, 손상된 CRC 방어
- EPUB 2/3의 `container.xml`, OPF manifest/spine 파싱
- EPUB 3 nav·EPUB 2 NCX의 계층 목차와 인쇄 페이지 목록 읽기
- 텍스트가 없는 `epub:type="pagebreak"` 표식도 다음 본문 문단
  위치로 보존하고 실제 페이지 이전·다음과 목록 선택에 사용
- Android와 같은 EPUB → DAISY 2.02 → DAISY 3 탐지 우선순위
- DAISY 2.02 NCC 메타데이터·계층 목차와 malformed HTML 대체 파싱
- NCC, `master.smil`, 전체 SMIL 순서의 DAISY 2.02 대체 탐색
- DAISY 3 OPF manifest/spine, NCX 계층 목차·페이지 목록 파싱
- DAISY DTBook의 제목·문장·페이지 요소와 fragment 위치 추출
- UTF-8/UTF-16 외 Shift-JIS, CP949/EUC-KR, CP437 텍스트·경로 호환
- XHTML 본문을 로컬 텍스트로 변환
- 출판물 계층 목차·페이지 목록 이동, 이전/다음 장, 본문 검색
- 밝게/세피아/어둡게 테마
- 글자 크기, 줄 간격, TTS 속도 설정
- 본문 선택과 한국어 TTS 읽기/정지
- 가져온 EPUB·DAISY ZIP의 앱 샌드박스 보관
- 전체 서재 목록과 최근 읽은 순 정렬, 앱 재실행 뒤 복원
- SHA-256 내용 비교로 파일 이름이 달라도 같은 책은 기존 보관본 재사용
- 삭제 확인 뒤 앱 보관본과 해당 책의 읽기 위치만 정리하고 Files 원본 보존
- 기존 버전에서 가져온 책을 메타데이터가 있는 새 서재로 자동 편입
- 마지막으로 연 책과 책별 마지막 장·문단 위치 복원
- 검색어의 모든 일치 위치와 문맥 목록 표시
- 검색 결과 선택 시 해당 문단 이동과 일치 문자열 강조
- EPUB OPF `media-overlay`와 spine 순서에 따른 SMIL 연결
- SMIL `par → text fragment + audio clip` 파싱과 Android식 clock 값 지원
- EPUB 내부 오디오를 앱 전용 임시 공간에 안전하게 추출
- AVPlayer 구간 시작/끝 재생, 이전/다음 클립, 자동 연속 재생
- 오디오 클립 전환 시 연결된 장·문단 이동과 현재 문단 강조
- 모든 본문 문단을 하나의 읽기 타임라인으로 구성하고, 연결된 SMIL
  오디오는 AVPlayer로, 오디오 없는 문단은 iPad 로컬 TTS로 연속 재생
- 한 문단의 여러 오디오 클립 순서 보존과 오디오 로드 실패 시 TTS 대체
- 재생 막대에서 현재 `오디오`/`로컬 음성` 방식과 전체 읽기 위치 표시
- iPad TTS가 보고하는 UTF-16 발화 범위를 본문의 현재 단어 강조로 연결
- TTS를 문장 단위로 나눠 합성하고 단어·문장 위치에서 안전하게 재시작
- 탐색 단위를 단어·문장·문단·페이지·장 순서로 전환하며, 출판물의 실제
  페이지 목록이 없으면 Android와 같은 500자 단위 페이지 폴백 사용
- 오디오 실제 클립 길이와 TTS 글자 수·재생 속도 추정을 합친 책 전체
  타임라인, 현재/전체 시간·백분율 표시와 임의 위치 슬라이더 이동
- 슬라이더 조절 중 재생을 잠시 멈추고, 재생 중 시작한 조절은 새 위치부터
  이어 재생하며 정지 중 시작한 조절은 위치만 변경
- 저장/Deflate 혼합 EPUB·DAISY 2.02·DAISY 3 픽스처 자동 테스트
- 영어·일본어 서재·목차·검색·보기 설정·재생 조작과 동적 단위·
  재생 방식, ZIP/EPUB/DAISY 오류 번역 및 앱 내부 언어 즉시 반영

## 실기기 확인 — 다음 M4 테스트 때 수행

- [ ] Files에서 한국어 EPUB 2권 이상을 차례로 가져올 수 있다.
- [ ] 실제 DAISY 2.02 ZIP을 가져와 NCC 목차·본문·오디오 순서가
      원본과 일치한다.
- [ ] 실제 DAISY 3 ZIP을 가져와 NCX 계층 목차·페이지 목록·DTBook
      본문이 원본과 일치한다.
- [ ] CP949/EUC-KR 또는 Shift-JIS로 작성된 구형 DAISY의 제목과
      본문, 한글·일본어 파일 경로가 깨지지 않는다.
- [ ] NCC 링크가 없고 `master.smil`만 있는 DAISY 2.02와
      XML 규칙을 벗어난 NCC HTML을 정상적으로 연다.
- [ ] 텍스트만 있는 구간, 오디오만 있는 구간, `clipEnd`가 없는
      구간을 포함한 DAISY에서 탐색과 재생이 멈추지 않는다.
- [ ] 오디오 문단 앞뒤의 텍스트 전용 문단이 로컬 음성으로 읽히며
      `로컬 음성 → 오디오 → 로컬 음성` 전환이 끊기지 않는다.
- [ ] 혼합 재생 중 일시정지·재개, 이전·다음 읽기 위치, 속도 변경이
      오디오와 로컬 음성 양쪽에 적용된다.
- [ ] 오디오·TTS 혼합 책의 슬라이더를 앞·중간·끝으로 옮기면 표시 시간과
      본문 강조가 맞고, 재생 중/정지 중 상태가 각각 보존된다.
- [ ] 1시간 이상인 DAISY에서 H:MM:SS 시간 형식과 VoiceOver 조절 값이
      정확하며, clipEnd가 없는 오디오에서도 슬라이더가 멈추지 않는다.
- [ ] 책의 언어 메타데이터에 맞는 iPad 음성을 우선 사용하고,
      설치된 음성이 없을 때 한국어 기본 음성으로 안전하게 대체한다.
- [ ] 로컬 음성 낭독 중 현재 단어의 주황색 강조가 실제 발화에 맞춰
      이동하고, 이모지·한글·영문이 섞인 문장에서도 범위가 어긋나지 않는다.
- [ ] 탐색 단위를 단어·문장·문단·페이지·장으로 바꾼 뒤 이전·다음이
      정지 상태에서는 위치만 바꾸고 재생 중에는 새 위치부터 이어 읽는다.
- [ ] SMIL 오디오 구간에서 단어·문장 탐색을 선택하면 잘못된 가상
      타임코드를 만들지 않고 인접 본문/오디오 구간으로 이동한다.
- [ ] 앱을 완전히 종료한 뒤 최근 책과 마지막 장·문단 위치가 복원된다.
- [ ] EPUB·DAISY 책을 3권 이상 가져오면 최근 읽은 순으로 모두 표시되고
      각 책을 다시 열면 책별 장·문단 위치가 복원된다.
- [ ] 내용은 같고 파일 이름만 다른 책을 다시 가져오면 사본이 늘지 않고
      기존 책이 열렸다는 안내가 표시된다.
- [ ] 서재에서 책을 삭제해도 Files의 원본은 남고, 마지막 책을 삭제하면
      남은 책 중 가장 최근 책으로 최근 읽음 표시가 이동한다.
- [ ] 기존 앱 버전에서 가져온 최근 책이 업데이트 뒤 전체 서재에 자동으로
      나타나며 정상적으로 열린다.
- [ ] 목차의 장 제목과 이동 순서가 원본 책과 일치한다.
- [ ] EPUB 3 `page-list`와 EPUB 2 NCX `pageTarget`이 있는 실책에서
      인쇄 페이지 번호를 선택하거나 페이지 이전·다음으로 이동하면
      빈 pagebreak 표식 뒤의 정확한 문단으로 이동한다.
- [ ] 한글/영문/숫자의 모든 검색 결과가 맞는 문단으로 이동하고 강조된다.
- [ ] 매우 긴 장을 스크롤해도 메모리 경고나 멈춤이 없다.
- [ ] 읽기/정지, 장 이동 시 TTS 중지, 속도 조절이 정상이다.
- [ ] 세로/가로 회전과 Split View에서 본문과 하단 조작부가
      겹치지 않는다.
- [ ] VoiceOver로 제목, 본문, 장 위치, 모든 버튼을 탐색할 수 있다.
- [ ] 밝게/세피아/어둡게 테마의 대비와 큰 글자 크기를 확인한다.
- [ ] 손상된 파일과 EPUB이 아닌 파일에 이해 가능한 오류가 표시된다.
- [ ] 앱 언어를 영어·일본어로 바꿔 서재, 목차, 검색, 보기 설정,
      오디오·로컬 음성 탐색 단위와 손상 파일 오류가 같은 언어로 보인다.
- [ ] 실제 EPUB 3 Media Overlay 책에서 각 오디오가 `clipBegin`부터
      `clipEnd`까지만 재생되고 다음 클립으로 이어진다.
- [ ] 오디오 이전/재생·일시정지/다음과 0.5~2배속이 정상이며
      Bluetooth·내장 스피커 전환 뒤에도 재생이 이어진다.
- [ ] 오디오 클립이 바뀔 때 정확한 장·문단으로 스크롤되고 현재
      문단 강조가 VoiceOver에서도 구분된다.
- [ ] `clipEnd`가 없거나 잘못된 SMIL, 여러 `audio`가 한 `par`에
      있는 책, 손상된 오디오에서 멈춤 없이 대체/오류 처리된다.

## 다음 구현 우선순위

### P0 — 독서 연속성과 호환성

- [x] 장 내부 문단 위치까지 책별로 저장하고 복원
- [x] 최근 책 한 권이 아닌 전체 서재, 책 삭제와 중복 가져오기 처리
- [x] 한 장 안의 첫 결과만이 아니라 모든 검색 일치 위치 표시
- [x] 검색 결과로 이동한 뒤 해당 문자열을 강조하고 근처로 스크롤
- XML 규칙을 벗어난 XHTML과 더 많은 HTML named entity 대응
- [x] 중첩된 EPUB 2 NCX 목차의 계층과 제목을 공통 목차 모델에 보존
- 실제 출판사 EPUB 회귀 픽스처 확대

### P1 — 원본 표현과 사용자 독서 도구

- 이미지, 표, 목록, 강조, 링크, 각주 표시
- EPUB CSS와 글꼴을 안전하게 제한하여 원본 레이아웃 선택 제공
- 세로 스크롤/페이지 넘김 모드 선택
- 북마크, 밑줄, 하이라이트, 메모
- 책 표지와 저자 메타데이터를 사용하는 서재 화면
- 본문 언어에 따른 TTS 음성 선택과 문장 단위 읽기 위치 표시

- [x] DAISY 제목·페이지 단위 접근성 탐색
- [x] 오디오가 없는 본문 구간을 로컬 TTS로 이어 읽기
- [x] TTS 문장·단어 단위 하이라이트와 문장 내부 이동

## 의도적으로 지원하지 않는 형식

- 암호화 또는 DRM EPUB
- ZIP64 EPUB
- EPUB 안의 실행 스크립트

지원이 필요해질 때 별도 보안 검토와 파일 크기/메모리 정책을 먼저
정한다.
