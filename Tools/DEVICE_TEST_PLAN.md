# VisionCraft iPad 통합 실기기 검증 계획

최종 갱신: 2026-07-31

## 목적

기능마다 사용자에게 테스트를 요청하지 않고, 자동 검증이 끝난 한 빌드를
M4 iPad에 설치한 뒤 Android VisionCraft에서 옮긴 기능을 한 번의 검증
기간에 순서대로 확인한다. 각 세부 백로그의 실기기 항목은 유지하되,
이 문서를 실제 실행 순서와 결과 기록의 기준으로 사용한다.

## 작성 시점 기준

- 브랜치: `codex/local-first-foundation`
- 코드 기준: `000cdad`
- 자동 검증: iPad Air 11-inch (M4) 시뮬레이터 333/333 통과
- 빌드 검증: unsigned arm64 generic iOS 빌드 통과
- 대상 기기: iPad Pro 11-inch (M4), `iPad16,3`
- 대상 OS: iPadOS 26.5.2, 빌드 `23F84`
- CoreDevice ID: `47D0154B-D439-51E8-83B7-30A88DA08447`
- 현재 연결: paired/local network. 실행 전 기기 잠금 해제와 개발 터널
  연결을 다시 확인한다.

실행할 때는 위 코드 기준을 그대로 쓰지 말고 다음 값을 결과표에 기록한다.

```sh
git rev-parse HEAD
xcrun devicectl device info details \
  --device 47D0154B-D439-51E8-83B7-30A88DA08447
```

## 시작 차단 조건

다음 항목이 모두 해결되기 전에는 실기기 결과를 합격으로 기록하지 않는다.

- [ ] Apple Developer Account Holder가 최신 Program License Agreement에
      동의했다.
- [ ] 본 앱과 Share/Action/Widget Extension의 App Group 프로비저닝
      프로필이 갱신됐다.
- [ ] 현재 HEAD의 signed 빌드가 `iPad16,3`에 설치되고 한 번 실행된다.
- [ ] iPad가 잠금 해제됐고 Developer Mode와 무선 또는 유선 개발 터널이
      연결됐다.
- [ ] 테스트 중 유지해야 할 기존 대화·책·문서가 있으면 먼저 Files로
      내보냈다.

서명이 막힌 동안에는 같은 signed 빌드를 반복 시도하지 않는다. 자동
테스트와 unsigned arm64 빌드는 계속 수행하고, 동의가 끝난 뒤 한 번에
프로필을 갱신한다.

## 준비물

### 하드웨어와 외부 연결

- M4 iPad와 충전기
- Rivo Three 또는 Mini. 가능하면 두 대를 준비해 기기 전환도 확인
- Android VisionCraft/VisionLink 송신 기기
- Bluetooth 이어폰 또는 스피커
- 안정된 Wi-Fi와 네트워크 전환용 다른 Wi-Fi 또는 핫스팟
- 카메라를 10분 이상 실행할 수 있는 고정 거치대

### 카메라·스캐너 샘플

- 한국어·영어·일본어 인쇄물
- 숫자·날짜·전화·이메일·URL이 포함된 영수증
- 흰 문서, 컬러 인쇄물, 낮은 대비 문서, 반사되는 문서
- 평평한 페이지와 두께 있는 책의 곡면 페이지
- 일부가 프레임 밖에 있는 문서와 글자가 없는 장면
- 20페이지 다중 스캔용 문서 묶음

### 파일·독서 샘플

- 텍스트 PDF와 1·20·100페이지 스캔 PDF
- UTF-8/UTF-16 TXT, XLSX, BIFF8 XLS, HWP 5.x, HWPX
- 암호화·손상·크기 제한 초과 파일
- EPUB 2권 이상과 실제 출판사 EPUB 3 Media Overlay 책
- DAISY 2.02, DAISY 3, 구형 한글 또는 일본어 인코딩 DAISY
- 텍스트 전용·오디오 전용·`clipEnd` 없는 SMIL 구간을 포함한 책
- Share Extension 배치용 사진 20장과 혼합 문서
- VisionLink 스트리밍용 작은 파일, 손상 해시 파일과 1GB 근접 파일

### 선택적 온라인 기능

- Brave Search API 키와 사용 가능한 Search 요금제
- redirect·동적 렌더링·2MB 초과·오프라인 오류 확인용 URL
- 비용이 생기는 검색은 이 계획의 AI 온라인 구간에서만 실행

## 결과 기록 규칙

각 항목은 다음 중 하나로 기록한다.

- `[x]` 합격
- `[!]` 결함 발견. 재현 절차와 증거를 남기고 다음 독립 항목은 계속
- `[-]` 환경 또는 외부 조건 때문에 실행하지 못함
- `[ ]` 미실행

결함마다 다음을 남긴다.

1. 설치한 commit SHA와 iPadOS 버전
2. 기능 ID와 정확한 입력 파일 또는 장면
3. 재현 순서, 기대 결과, 실제 결과
4. 화면 녹화 또는 스크린샷
5. 앱 내 진단 JSON 또는 스캐너 진단 로그
6. 크래시·데이터 손실·잘못된 파일 삭제 여부

앱 크래시, 원본 파일 삭제, 반복되는 잘못된 자동 촬영, BLE 입력 고착,
1GB 수신 중 메모리 종료는 P0로 기록한다. 해당 기능의 파괴적 반복만
멈추고 다른 독립 기능은 계속 확인한다.
