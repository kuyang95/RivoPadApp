# Word 장문 검색 POC

긴 Word 문서를 매 요청마다 전부 보내지 않고, 로컬 검색으로 관련 문단만 고르는 초기 방식의 한계를 측정한다.

이 디렉터리는 제품 코드와 연결되지 않은 독립 POC다. 실행 중 AI API 호출은 없으며 제품의 검색·편집 동작도 바꾸지 않는다.

## 기준 로직

1. 질문을 최대 8개 검색어로 분리하고 한국어 조사 일부를 제거한다.
2. 문단별 정확 문자열 포함 여부를 점수화한다.
3. 희귀 검색어, 제목 일치, 숫자 일치를 가중한다.
4. 상위 10개 문단과 각 문단 앞뒤 1개를 합쳐 최대 30개 문단을 컨텍스트로 고른다.
5. 최고 점수 문단의 검색어 포함률과 차점자 대비 점수 차로 신뢰도를 정한다.

동의어 사전, 형태소 분석기, 임베딩, LLM 재정렬은 의도적으로 넣지 않았다. 즉 현재 논의한 가장 저렴한 1차 검색의 성능만 본다.

## 샘플

- 국가법령정보센터 `근로관계법령집`: 1,145쪽
- 통계청 `2025 고령자 통계`: 106쪽
- 한국은행 `경제전망보고서(2026년 2월)`: 93쪽

PDF를 `pdftotext -enc UTF-8`로 추출한 텍스트를 입력으로 사용한다. PDF 표와 줄바꿈이 완전히 복원되지 않는 현실적인 조건을 그대로 유지한다.

## 실행

```bash
Tools/WordRAGPOC/fetch_sources.sh tmp/pdfs/word-rag-poc

python3 Tools/WordRAGPOC/word_rag_poc.py \
  --source-dir tmp/pdfs/word-rag-poc \
  --format markdown
```

상세 근거와 상위 검색 결과가 필요하면 `--format json`을 사용한다.

고정 실행 결과와 허점 분석은 `REPORT.md`에 기록되어 있다.
