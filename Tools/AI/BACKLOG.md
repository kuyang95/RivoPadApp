# 로컬 AI·웹 기능 백로그

최종 갱신: 2026-07-30

Android VisionCraft의 AI 기능을 M4 iPad에서 로컬 우선으로 옮기되,
URL 본문과 최신 검색처럼 네트워크가 본질적으로 필요한 입력만 명시적으로
온라인 처리한다. 사용자가 조작해야 하는 품질 확인은 구현을 막지 않고
아래 실기기 목록에 모은다.

## 구현 완료

- M4 MLX 텍스트·비전 모델 로드와 스트리밍 대화
- 대화 기록 저장·복원·삭제
- 이미지, OCR, PDF·TXT 문서 질문
- 온디바이스 음성 인식 질문과 답변 TTS
- 앱 기능을 여는 로컬 규칙 기반 음성 명령
- 한국어·영어·일본어 대상의 전용 로컬 번역 화면
- 번역 원문 16,000자 제한, `<think>` 제거, 스트리밍 결과와 중지
- 명시적 클립보드 붙여넣기, 결과 복사·선택·읽기
- 앱 언어를 기본 번역 대상으로 사용하고 음성 번역 명령을 화면에 연결

## 다음 구현

### AI-001: URL 본문 추출과 질문

- HTTP(S) URL 검증, redirect·응답 크기·시간 제한
- HTML의 script/style/navigation 제거와 제목·본문 추출
- JavaScript 렌더링 페이지의 제한적 WebKit fallback
- 공유한 URL과 직접 붙여넣은 URL을 같은 흐름으로 처리
- 추출 본문을 M4 로컬 AI에 전달하고 원본 URL·제목을 보존
- prompt injection을 줄이도록 웹 본문을 신뢰하지 않는 데이터로 구분

### AI-002: 출처가 있는 선택적 웹 검색

- 최신성·날씨·가격·일정처럼 로컬 모델 지식으로 답하면 안 되는 질문만
  온라인 검색으로 분리
- 검색 제공자 API 키와 이용약관을 코드에 하드코딩하지 않는 구성
- 결과 제목·URL·발췌를 보존하고 답변에 실제 사용한 출처 표시
- 검색 실패 시 로컬 모델이 최신 정보인 것처럼 추측하지 않도록 차단
- 네트워크 사용과 검색 제공자를 사용자가 켜고 끌 수 있는 설정

### AI-003: 대화 기록 관리

- Android와 같은 대화 제목 직접 수정
- 제목·최근 메시지 검색
- 전체 삭제 확인과 삭제 실패 복구
- 길어진 대화의 컨텍스트 요약·분할 정책

## 실기기 일괄 확인

- [ ] M4에서 첫 번역 모델 로드 시간과 두 번째 번역 시작 시간을 측정한다.
- [ ] 한국어↔영어, 한국어↔일본어와 영어↔일본어 문단·숫자·URL 보존을
      확인한다.
- [ ] 16,000자 입력, 생성 중 중지, 화면 닫기와 다른 AI 작업 충돌을
      확인한다.
- [ ] 붙여넣기·복사 때 iPadOS 개인정보 배너와 VoiceOver 안내가
      자연스러운지 확인한다.
- [ ] Dynamic Type와 가로·세로 화면에서 원문·결과 편집 영역을 확인한다.
